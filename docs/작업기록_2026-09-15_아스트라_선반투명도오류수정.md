# 선반이 거의 보이지 않는 오류 수정

stage_2-1에는 선반이 연결되어 있었지만 전용 셰이더의 알파 계산이 잘못되어 화면에서 가느다란 조각만 남았다. 사용자가 제공한 캡처의 지지대만 보이는 현상과 일치한다.

Godot canvas_item fragment의 COLOR.a는 기본 메시 UV로 샘플한 텍스처 알파를 포함한다. 선반 셰이더는 ledge_uv(local_pos)로 다른 위치를 읽으므로 이 COLOR.a를 다시 곱하면 원본 투명 여백에 의해 선반이 지워진다.

vertex에서 색조/정점 알파만 ledge_modulate_alpha로 보관하고, fragment에서는 전용 UV의 base.a와 그 값만 곱하도록 수정했다. 노드의 투명도와 유령 발판의 ghost_alpha 처리는 유지한다. 셰이더 영어 주석과 이 한글 문서에 이유를 남겼다.

검증: A_L2 크기의 내부 350개 표본에 대해 원본 PNG 알파를 읽고 기존 UV와 전용 UV의 곱을 계산했다. 기존 식은 0개 표시, 수정 식은 350개 표시였다. 이는 CPU 픽셀 계산이며 Godot 실행 캡처가 아니다. shader ASCII 및 git diff --check 통과. 엔진 실행 검사는 미실행이다.
