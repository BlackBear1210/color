# 맞물림 리소스 ID 오류 수정

사용자 실행 화면의 빨간 `set_scene_unique_id` 오류 원인은 2-1에 추가한 내부 ext/sub resource ID 221개에 한글을 사용한 것이다. 파일명/노드명은 한글을 유지해도 되지만 내부 리소스 ID는 ASCII 영숫자와 밑줄만 사용해야 한다. 이전 정적 검사가 이 제한을 확인하지 않아 놓쳤다.

2-1의 해당 선언과 ExtResource/SubResource 참조를 함께 ASCII ID로 변경했다. SS2D 점, 재질 경로, 충돌, 노드명은 변경하지 않았다. 2-2도 스캔했으나 현재 파일에는 잘못된 ID가 없었다.

두 적용 도구에 결정적인 ASCII ID 변환과 충돌 검사를 추가했다. 기존 적용 여부 감지도 새 ID를 인식한다. 2-1 정적 검사에 ID 허용문자 검사를 추가했고, 980개 경계 표본 및 나머지 정적 검사와 함께 통과했다.

하수도_자연발판.gd의 for material 변수도 terrain_material로 바꿔 CanvasItem.material을 가리는 경고를 없애도록 수정했다. 화면의 조명표준 이름 중복/삼항식 타입/시작 변수 경고는 별도 원인으로 이번 수정에서 해결했다고 주장하지 않는다.

Godot 실행 검증은 안전 예외에 따라 미실행. 디버거 기록을 비우고 씬을 새로 실행해 재발 여부를 확인해야 한다.
