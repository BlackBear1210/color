# 주철 밸브 외관 교체

호퍼 승인 도안에 맞춘 투명 주철4살 손잡이를 제작했다. 제어레버.gd 원형 모드의 코드 원 대신 텍스처를 그리며 기존 각도로 회전한다. 배관 받침은 고정, 중심 켜짐 표시 유지. 직선 레버와 커스텀 그림 슬롯 우선 규칙 유지.
기존 제어레버 스크립트 사용 씬에 자동 반영되므로 씬의 위치/배선/반경은 수정하지 않았다.
정적: 알파 투명, 리소스 경로 확인. _draw 외에는 아트 preload만 추가한 것을 변경 전후 비교해 게임 로직 불변 확인. Godot는 기존 충돌/실행제한에 따라 미실행, 실제 작동/외관 검증은 남음.
