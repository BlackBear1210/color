# 하수도 지형 시험 실행 확인

- 사용자가 시험 씬의 Godot 실행을 명시적으로 요청했다.
- Godot 4.6.3 본체와 콘솔을 `C:/Users/Public/godot46/`에 복사해 한글 경로의 콘솔 실행 문제를 피했다.
- 해당 시험 씬만 headless 3프레임 로드: 종료 코드 0, 오류 로그 없음.
- 실제 OpenGL Compatibility 그래픽 모드 1280×720, 30프레임 후 캡처: 종료 코드 0, 오류 로그 없음, PNG 저장 결과 0.
- 실제 화면에서 SS2D 지형 3개, 반복 벽돌과 가장자리, 앞뒤 배경이 표시되는 것을 확인했다. 캡처는 로컬 임시 산출물 `.godot/sewer_terrain_capture.png`에 저장했다.
- 근접 반사·흰색 짝·페인트 시스템·실제 플레이어는 이 시험에 포함되지 않는다. 캡처만으로 충돌·이동·모든 카메라 위치나 최종 미술 품질을 검증했다고 보지 않는다. 옆면과 모서리는 현재 얇은 재질 띠이며 원화 수준의 두께감은 후속 조정 대상이다.
- 사용자가 WASD로 관찰할 수 있도록 같은 씬을 창 모드로 실행했다. 기존 맵과 프로젝트 시작 씬 설정은 변경하지 않았다.
- 이전 문서의 엔진 미실행 표기는 해당 문서 작성 시점의 상태이며, 이번 기록은 위 시험 범위에 한하여 갱신한다.
