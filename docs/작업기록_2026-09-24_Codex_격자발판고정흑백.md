# 격자 발판 검정·흰색 고정형

- 사용자 최종 요청: 검정/흰색 두 버전을 만들고 플레이어의 색칠을 금지한다. 회색 공통 안전형은 채택하지 않는다.
- 통과플랫폼.gd에 고정색(검정=0, 흰색=1)을 추가. 현재색/반대색 판정/그림이 같은 값을 사용한다.
- 물감 대상 그룹 등록 제거, 직접 명중도 blocked, 되돌리기는 false, 사망 초기화는 고정색 보존. 기존 물 통과/물에 안 지워짐 계약 유지.
- 초안의 프레임/살대/양끝 볼트 구조를 코드 드로잉으로 구현. 검정과 흰색 팔레트를 제공하고 구멍은 배경이 보이는 실제 빈 영역으로 남겼다. 생성 이미지 텍스처를 이식한 것은 아니다.
- 격자발판_검정.tscn 및 격자발판_흰색.tscn 추가(192×26). 필요횟수는 기존 씬 저장 호환용으로만 유지.
- 기존 통과플랫폼 사용처에도 색칠 금지가 적용되며 고정색 미지정 인스턴스는 검정이다. 기존 원웨이 설정/크기/위치는 변경하지 않았다. 예전 색칠 의존 퍼즐은 별도 레벨 검토 대상이다.
- 정적 검사: 두 씬 리소스 선언, 고정색 참조, 명중 차단 및 그룹 미등록, diff 공백 확인 통과. 엔진/플레이 테스트는 사용자 안전 규칙에 따라 미실행.
- graphify query/update는 출력 없이 종료 코드 1로 실패. git pull은 앞서 기존 편집과 충돌하여 중단된 상태이며 기존 작업을 덮어쓰지 않았다.
