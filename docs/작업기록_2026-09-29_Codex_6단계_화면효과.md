# 6단계 — ver.2 화면 효과 동작 마무리

## 적용 범위와 이유
- 화면효과 공통 스크립트는 world_2_클로드 11개 씬에서 참조된다. 실제 엔진 시각 검증은 2-9에서 수행했다.
- 기존에는 발이 하강할 때만 입수 효과가 생겨 수평 진입을 놓쳤다. 실제 이동 및 물 밖→안 경계 전환으로 조건을 변경했다.
- 리스폰을 이동 거리만으로 추정하면 같은 자리 재시작에 물방울이 남는다. 월드의 실제 _리스폰에서 효과 그룹에 초기화 알림을 보내 물방울/쿨다운/진입 상태를 지운다.
- 플레이어가 없는 프레임도 초기화한다. 큰 텔레포트의 기존 억제는 유지한다.
- 수량 3~5개, 반지름 2~4px, 수명 0.3~0.5초, 하단 가장자리, 세 물색을 유지했다. 전경 입자 12개, 필름 입자 0.012, 비네트 0.075, 기존 벽등 빛 번짐은 유지했다.

## 실제 실행 및 검증
- Godot 4.6.3 OpenGL / 1920x1080 / 줌 0.8 / 실제 stage_2-9.
- tools/test_화면효과_6단계.gd: 26 PASS, STAGE6_FAILURES=0.
- 효과 _입수 함수를 직접 호출하지 않고 실제 씬 플레이어 좌표를 통제하여 수직/수평 진입, 물 안 이동, 재진입, 텔레포트를 확인했다.
- 같은 물 안 안전점으로 실제 월드 _리스폰을 호출해 즉시 소멸 및 재생 억제, 이후 정상 입수를 확인했다. 전체 사망 원인별 주행검사는 아니다.
- effects_off/on, entry_0/1/2, expired, horizontal_entry, respawn_clear PNG 확보. entry_1과 하단 모음 droplet_sequence.png를 직접 열어 확인했다.
- effects_off/on은 현 코드의 효과 켜짐 비교이며 수정 전 코드의 캡처라고 주장하지 않는다.
- HUD layer100 위로 효과 layer5가 올라가지 않고 입력도 가로채지 않는다.
