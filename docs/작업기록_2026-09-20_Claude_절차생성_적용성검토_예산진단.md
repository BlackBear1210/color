## 결론 (세 줄)

- **된다.** 단 "지형을 상상하는 생성기" 가 아니라 **모양 어휘(S1~S6)를 규칙대로 잇는 조립기** 여야 하고,
  씬 조립은 기존 `tools/하수도_빌더_공통.gd` 에 맡겨야 한다(편집상태 인스턴스·owner·콜리전 offset 사고가 이미 다 들어 있다).
- **CPU 는 문제가 아니다.** 1.7만 × 8.7천 px 맵도 물리 60 틱을 정확히 1,000 ms 로 지켰다.
- **진짜 한계는 광원 하나다.** Godot 4 의 2D 라이트는 **캔버스 아이템 하나당 15~16 개** 가 하드코딩 한계이고,
  SS2D 지형 한 덩어리 = 캔버스 아이템 하나다.

## 받은 프롬프트에서 고친 값

| 받은 것 | 실제 |
|---|---|
| 점프 높이 20칸(320) / 거리 240 | **높이 10칸 = 160 · 거리 20칸 = 320**(하수도) · 집은 거리 15칸 = 240 — 높이와 거리가 뒤바뀌어 있었다 |
| SS2D `Path2D` 포인트 배열 | SS2D 는 Path2D 를 안 쓴다 — `SS2D_Point_Array` + `add_points()` + `close_shape()` |
| Bresenham 직선 LoS | 총알은 **포물선**이다(탄속 1150 · 중력 900 · 수명 3초). 1,000 px 앞은 약 340 px 아래에 맞는다 |
| Collision Simplify | 이 저장소 규약은 `collision_offset = 0` 외곽선 그대로. 깎으면 이웃 사이 48 px 슬롯에 플레이어가 낀다 |
| 국소 색반전 셰이더 신설 | **이미 있다** — `지형_페인트.gdshader` 의 `seeds[24]` |

인자로 씬 경로를 주면 그것만 잰다. 아무것도 안 고치고 **재기만 한다.**

- ✖ 판정: 한 지형에 겹치는 광원 > 12 (엔진 한계 15~16 코앞)
- ⚠: 한 화면보다 큰 덩어리가 광원 6 개 이상 / 전체칠 가능인데 긴변 > 576 / hazard+색레이저 > 60
- 외곽·채움(`meta role`)과 `장식_전용` 은 판정에서 뺀다 — 안 그러면 지금 있는 모든 스테이지가 실패로 나와 아무도 안 본다

### 만들면서 걸렸던 것 (다음 사람용)

- `Performance.TIME_PHYSICS_PROCESS` 는 **헤드리스에서 값이 망가진다**(1,296 ms/틱 같은 수가 나왔다).
  → 벽시계로 "물리 60 틱이 1,000 ms 안에 끝나는가" 를 본다. 이게 훨씬 정직하다.
- 광원은 `발광체`·`빛기둥` 이 **실행 중에** 만든다. 씬을 띄우자마자 세면 겹침이 12↔13 으로 흔들렸다.
  → 물리 60 틱을 **먼저** 돌려 씬을 안정시킨 뒤에 센다.
- `SS2D_Point_Array.get_point_count()` 가 0 을 돌려주는 노드가 있다. `get_all_point_keys().size()` 를 쓴다.
