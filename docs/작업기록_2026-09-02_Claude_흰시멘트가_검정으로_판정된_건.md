# 작업기록 2026-09-02 · Claude — 흰 시멘트가 **검정으로 판정**되고 있었다

> **한 줄 요약**: `TEMPLATE_CEMENT_SOLID_WHITE.tscn` 의 `시작상태 = 2` 에 **따옴표가 빠져 있었다.**
> Godot 은 따옴표 없는 한글 속성명을 **조용히 무시**한다 → 흰 시멘트가 `무색`으로 태어나고,
> 무색 지형의 기본 아트색은 **검정**이라 흰 기둥이 검정 판정을 받았다.

- 제보: 성진님 스크린샷 — "흰 시멘트 위에 검정 플레이어가 살아 있는 게 말이 안 된다.
  흰색으로 바꿔서 뛰었더니 **착지하기도 전에** 계속 죽었다."
- 고친 파일: `TEMPLATE_CEMENT_SOLID_WHITE.tscn` · `TEMPLATE_CEMENT_STAIRS_WHITE.tscn`

## 1. 원인 — 따옴표 한 쌍

`TEMPLATE_CEMENT_SOLID_WHITE.tscn` 의 루트 노드에 이렇게 적혀 있었다.

```
[node name="TEMPLATE_CEMENT_SOLID_WHITE" type="Node2D"]
script = ExtResource("1_enbgp")
# 이 에셋는 시작부터 흰색 규칙 대상으로 등록해 화면색과 사망 판정을 일치시킨다.
시작상태 = 2                      ← ★따옴표 없음
```

`.tscn` 에서 **비 ASCII 속성명은 반드시 따옴표로 감싸야 한다.**
같은 파일의 다른 줄도, 다른 흰색 Template 8 개도 전부 `"시작상태" = 2` 로 적혀 있다.
이 한 줄만 따옴표가 빠졌고, **Godot 은 오류도 경고도 없이 그냥 무시했다.**

### 무시되면 무슨 일이 일어나나

`지형.gd` 의 `_ready()` 는 `현재상태 = 시작상태` 로 시작한다.
`시작상태` 가 안 들어왔으니 기본값 `무색(0)` 이다. 그리고 `기본_아트색()` 은

```gdscript
func 기본_아트색() -> int:
	match 시작상태:
		상태.흰색: return ColorDefs.WHITE
		상태.회색: return ColorDefs.GRAY
	return ColorDefs.BLACK          ← 여기로 떨어진다
```

**검정**을 돌려준다. 흰 아트를 들고 있는 지형이 판정에서는 검정이 된 것이다.

### 실측 (고치기 전)

```
── TEMPLATE_CEMENT_SOLID_WHITE
     시작상태=0  현재상태=0  기본_아트색()=0(검정)  현재색()=-1
     반대색인가(검정)=false   반대색인가(흰색)=false
```

### 실측 (고친 뒤)

```
── TEMPLATE_CEMENT_SOLID_WHITE
     시작상태=2  현재상태=2  기본_아트색()=1(흰색)  현재색()=1
     반대색인가(검정)=true    반대색인가(흰색)=false
```

## 2. 제보하신 두 증상이 정확히 이것으로 설명된다

| 증상 | 원인 |
|---|---|
| 흰 기둥 위에 **검정 플레이어가 살아 있다** | 기둥이 검정으로 판정 → 검정 플레이어는 안전 |
| **흰색**으로 바꿔 뛰면 **착지 전에 죽는다** | 기둥이 검정으로 판정 → 흰색 플레이어는 닿는 순간 죽음.<br>`접촉_여유 3px` 때문에 **눈으로 착지하기 직전**에 판정이 먼저 난다 |

즉 **화면이 흰색이라고 말하는데 판정은 검정이라고 말하고 있었다** — 색이 곧 규칙인 게임에서 가장 나쁜 거짓말이다.

### 고친 뒤 실제 판정 (스크린샷 자리 그대로)

```
흰 기둥 윗면 y=1168, x 1088~1512 · 그 위로 쏟아지는 물 '유체_1 흰색' 은 실제로는 검정(x 1153~1439)

물 왼쪽 (x=1120) · 검정 플레이어 → 죽는다   ✅ 흰 지형이니까
물 왼쪽 (x=1120) · 흰색 플레이어 → 산다     ✅ 성진님이 원래 하려던 그 점프
물 아래 (x=1300) · 검정 플레이어 → 죽는다   (흰 지형 때문)
물 아래 (x=1300) · 흰색 플레이어 → 죽는다   (검정 물 때문 — 규칙대로)
```

⚠ 참고: `유체_1 흰색` 은 **이름과 달리 실제 색이 검정(0)** 이다. 스크린샷의 검은 물줄기가 그것이다.
이름을 바꾸시거나 색을 흰색으로 바꾸시면 헷갈릴 일이 줄어든다.

## 6. 다음 사람이 알아야 할 것 (지뢰 추가)

**`.tscn` 을 손으로 고칠 때, 한글 속성명에는 반드시 따옴표를 붙인다.**

```
시작상태 = 2        ← ✗ Godot 이 조용히 무시한다. 오류도 경고도 없다
"시작상태" = 2      ← ○
```

- 증상: 인스펙터에서 분명히 설정했는데 **런타임에 기본값**이다. 화면과 판정이 어긋난다.
- 확인: 헤드리스로 씬을 띄워 그 속성을 찍어 본다. 파일에 적힌 값과 다르면 이것이다.
- 전수 조사 (수시로 돌려 볼 것):

```bash
grep -rnP '^(?![\s"\[=;#])[^=]*[^\x00-\x7f][^=]*=' --include=*.tscn --include=*.tres scenes/
```

⚠ 이 저장소는 속성 이름이 거의 다 한글이라 **이 실수가 나면 반드시 조용히 터진다.**
씬은 되도록 에디터로 저장하고, 손으로 고쳤으면 **런타임 값을 한 번 찍어서 확인**할 것.
