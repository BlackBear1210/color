# 2-9 배경 경계 여백 수정

- 사용자 스크린샷에서 반복 경계의 세로/가로 빈 띠 확인. 물 디자인은 요청대로 수정하지 않았다.
- 원인: 기존 v02 셰이더가 이미지 가장자리에서 alpha를 0으로 만들고 먼 배경은 단색 안개로 바꾸어 반복마다 빈 띠가 발생했다.
- v03 전용 셰이더 추가: 반대쪽 이미지 경계를 혼합하여 이음을 연결한다. 투명 영역의 검은 RGB가 번지지 않도록 premultiplied 색 혼합, 불투명 경계의 덮임 유지. 아치 안쪽 투명 영역과 시차는 유지한다.
- 중간 기둥 이미지의 위아래 투명 패딩은 source_region y=0.085~0.912로 제외한다. 기존 이미지 자체는 변경하지 않았다.
- 적용 범위는 2-9에서 사용하는 v03 배경뿐. 기존 v02 배경, 물, 지형, 장치 변경 없음.
- 리소스 경로/선언 순서, 셰이더 ASCII, diff 공백 정적 확인 통과. Godot 실행 및 실제 화면 검증은 미실행. 완전한 무봉제 건축 타일 대신 경계 혼합 방식이므로 건축 형태의 이음은 실화면 추가 확인 대상이다.
- graphify update 종료 코드 1로 실패.
