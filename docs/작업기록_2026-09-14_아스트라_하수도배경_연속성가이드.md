# 하수도 배경 연속성 디자인 가이드

- 사용자 요청: 하수구 컨셉을 유지하고 스테이지가 넘어가도 이어지는 배경 이미지 제작 가이드라인.
- 산출물: `scenes/world_2_클로드/가이드라인_스테이지2_하수도배경_연속성_디자인.md`.
- 하나의 시설 안에서 입구→집수→펌프→저수→점검/하부 구역으로 성격이 변하는 방향 제안. 번호별 구역은 확정된 실제 맵 분석 결과가 아니라 디자인 제안임을 명시했다.
- 공통 재료, 연결 배관/아치, 이전 끝과 다음 시작의 중첩, 레이어 시차, 흑백 대비, 투명도/반복/카메라 외곽 검수, 이미지 요청 양식, 자산 관리 기준을 포함했다.
- 우선 인접한 두 구역의 연결 샘플을 만들어 기준을 확정하고 전체로 확대하도록 권장했다.
- 문서 작성만 수행. 이미지 생성·맵 수정·Godot 실행·커밋/푸시는 하지 않았다.
