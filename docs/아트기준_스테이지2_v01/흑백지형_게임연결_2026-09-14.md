# 흑백 SS2D 게임 연결

## 현재 상태

기존 외관 시험의 플랫폼은 기본 `SS2D_Shape`여서 게임의 색칠·사망 판정 계약이 없었다. 이번에 `지형.gd`를 상속하는 `scripts/스마트월드/하수도_벽돌지형.gd`로 연결했다. 공용 규칙을 복제하지 않고 새 아틀라스 재질의 UV와 흑백 짝 준비만 추가했다.

**사용자가 1~3번 진행을 승인한 뒤 Godot 4.6.3에서 전용 검사 120/120을 통과했다.** 실제 그래픽 실행에서도 색칠 전후와 배경 네 모서리를 확인했다. 공용 회귀 검사 전체 통과를 뜻하지는 않는다. 별도 실패와 누락 파일은 후속 작업기록에 정리했다.

## 위치

- 재질·텍스처: `res://assets/textures/smartshape/sewer_masonry_v01/`
- 검정/흰색 재질: `masonry_black.tres`, `masonry_white.tres`
- 부위별 짝: `black/`, `white/` 안의 `fill.tres`, `top.tres`, `side.tres`, `corner.tres`
- 기존 외관 확인: `res://scenes/테스트/하수도_지형_v01/지형_레이어_시험.tscn`
- 실제 플레이어·월드·페인트코어 연결 씬: `res://scenes/테스트/하수도_지형_v01/색칠_사망_플레이시험.tscn`
- 공중 플랫폼 검정 3종: `공중_얇은발판.tscn`, `공중_두꺼운발판.tscn`, `공중_경사발판.tscn`
- 흰색 3종: 위 이름에 `_흰색`이 붙은 씬. 위치는 같은 시험 폴더다.

각 플랫폼은 계속 SS2D 하나이며 지형 점과 충돌을 함께 편집한다. 검정은 시작상태1, 흰색은 시작상태2, 위치별 판정을 켰다. 외관 확인 씬에는 플레이어가 없으므로 직접 총을 쏘려면 `색칠_사망_플레이시험.tscn`을 사용한다.

## 수정 이유

- 내부·모서리의 고정 명암 셰이더가 페인트 재질 적용을 막지 않도록 제거했다.
- 아틀라스 영역은 런타임 ImageTexture로 풀어 실제 UV와 반대색 짝의 샘플 범위를 맞춘다. 이미지 원본은 수정하지 않는다.
- 흑백을 서로 독립된 리소스로 연결하여 밝기 반전 대체에 의존하지 않는다.
- 공용 `지형.gd`, `월드.gd`, 플레이어의 규칙은 수정하지 않았다.

## 검증 준비

전용 테스트: `res://tools/test_하수도_벽돌_색칠사망.gd`.
실제 6개 템플릿을 대상으로 코어 명중·전체칠·부분칠·회수·인스턴스 독립성과 월드의 같은 색/다른 색 접촉·벽·아랫면·비접촉 판정, 물리 레이 충돌, 내부/모서리 흑백 셰이더 연결까지 120개 검사를 통과했다. 발사 검사는 물리 레이와 실제 코어 명중 호출을 결합했으며, 수동 플레이 전체 동선 검사를 대신하지 않는다.

흰색 그림은 내장 ImageGen으로 원본을 편집했다. 프롬프트는 "원본의 벽돌 위치·균열·아틀라스 좌표와 실루엣을 유지한 흰색 도장 상태, 밝기 반전이 아니라 밝은 면과 어두운 홈 유지"이다. 생성 결과는 둘 다 1254×1254이며 실제 전환 화면에서 내부와 테두리의 흰색 전환을 확인했다. 생성된 요철이 픽셀 단위로 완전히 일치하는 것은 아니다. 흰 아틀라스는 RGB 출력이므로 투명 배경 원본으로 사용하지 않고 지정된 내부 영역만 참조한다.

## 반사·배경 사용 기준

- 근접반사 세기 기본 0.10, 반경 190. 실제 충돌 외곽을 따라 1~2픽셀의 약한 반사를 더하며 다른 벽에 가린 면은 제외한다. 검정 테두리 원본의 밝은 띠는 셰이더로 낮췄다.
- 전용 페인트 셰이더는 공용 페인트 셰이더에서 파생했다. 공용의 색칠 수식이 변경되면 함께 반영해야 한다. 반사 외곽은 현재 최대 32개 선분을 처리하므로 점이 많은 지형은 추가 검증이 필요하다.
- 먼 벽 0.25, 가까운 아치·배관 0.60의 Parallax2D를 쓴다. 가까운 그림의 아래 끝과 양옆은 안개처럼 흐려 먼 벽으로 이어진다.
- 배경 범위 검증은 시험 씬의 카메라 중심 (0,0)~(1950,1100), 줌 0.55 기준이다. 다른 크기의 맵은 그 맵의 카메라 끝·최소 줌에 맞춰 배경 범위를 다시 잡는다.
- 실제 플레이 씬은 하수도 공통 빌더 기준 점프 높이 10칸·거리 20칸, 줌 1.0, 치명 낙하 1500을 명시한다. 전체 배치 관찰용 캡처는 더 넓은 줌을 사용한다.

초기 작성 도구 `작성_하수도_지형시험_v01.mjs`는 외관 시험 초안용이다. 최신 게임 연결 씬을 다시 만드는 용도로 사용하지 않는다.
