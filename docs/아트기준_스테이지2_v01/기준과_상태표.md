# 스테이지 2 · 하수도 아트 기준 v01

상태: **디자인 검토용 초안**. 기준 이미지와 상태 설계이며 실제 게임 화면·구현 완료 보고가 아니다.

## 이번 단계의 목표

낡은 하수 처리 시설 한 방에서 배경·벽돌 지형·배관·폭포·고인 물·정비 발판·분쇄기·유령 발판·붕괴 발판이 같은 재질과 조명 아래 놓인 것처럼 보이게 한다. 이 기준을 검토한 뒤 작은 시험 씬을 만들고 실제 동작을 확인한다.

기준 시안은 `기준장면_v01.png`에 저장한다. 이미지에 그려진 발판 간격은 아트 구성용이며 점프 거리·충돌·색 판정이 검증된 레벨 설계가 아니다. 이 그림을 통째로 플레이 배경으로 사용하지 않는다.

## 시각 규칙

| 구분 | 기준 |
|---|---|
| 재질 | 젖은 벽돌, 거친 콘크리트, 부식된 철제 설비. 같은 벽돌 크기·거칠기·외곽 처리 사용 |
| 화면 | 옆에서 보는 2D. 플레이 지형의 상면과 실제 충돌 윤곽이 일치해야 함 |
| 배경 | 큰 아치·후면 벽·배수구·배관. 낮은 대비와 약한 흐림으로 거리 표현. 앞쪽 발판처럼 읽히는 선반은 제외 |
| 검정 표면 | 대부분이 어두운 면으로 읽힘. 젖은 반사는 짧고 드물게. 두꺼운 흰 테두리를 전체 윤곽에 두르지 않음 |
| 흰 표면 | 대부분이 밝은 면으로 읽힘. 검정 표면과 같은 요철·마모를 사용. 발광체처럼 번지지 않음 |
| 회색 | 일반 플레이 물체의 넓은 회색 안전 표면을 기본 구성에서 제외. 배경의 중간 명도와 재질 음영은 공간 표현으로만 사용 |
| 고정 위험 | 검정 본체와 흰 날의 반복, 톱니·날카로운 실루엣·기계 운동으로 표시. 빨강·노랑 경고색을 추가하지 않음 |
| 기계 | 레일·축·체인·받침 등 설치 구조를 함께 표현. 움직임 방향과 정지 위치를 시설에서 읽을 수 있게 함 |
| 물 | 흐르는 물과 고인 물에 같은 흑백 재질·거품·물방울 문법 적용. 회색 안전수는 기준 방에 배치하지 않음 |

중요: 안전 판정인 물체에 검정 그림만 덮어씌우지 않는다. 외형을 바꾸기 전 각 물체의 색 판정 계약을 확인한다. 이동 플랫폼과 압력발판의 밟는 면은 그 아래 지형과 판정이 어긋나지 않게 설계한다. 물체의 명도를 바꾸는 작업과 게임 규칙을 바꾸는 작업을 섞지 않는다.

## 장치 상태표

아래 시간은 시험 구간에서 조정할 초기 설계값이다. 현재 맵의 구현값을 바꿨다는 뜻이 아니다.

| 장치 | 평상시 | 작동 예고·변화 | 작동 결과 | 복구·재시도 |
|---|---|---|---|---|
| 폭포 | 배관 입구부터 연결된 검정 또는 흰 물줄기 | 밸브 회전, 배관 진동과 물 흐름 감소 | 위험 판정 범위와 물 그림이 함께 줄어듦. 수문도 연결된 방향으로 이동 | 다시 열면 물줄기가 돌아오는 것을 먼저 읽을 수 있어야 함 |
| 고인 물 | 수평 수면, 잔물결, 물 높이를 보여주는 안쪽 벽 | 낙하 위치에 같은 재질의 작은 물보라 | 색이 맞고 수심이 충분할 때 낙하를 받음 | 물 아래 실제 바닥과 올라갈 길이 존재해야 함 |
| 압력발판·이동 플랫폼 | 바닥에 매립된 발판, 다리의 레일과 정지 받침 | 발판이 눌리고 연결 기구가 움직임 | 다리가 길을 연결. 도착 시 짧은 철제 맞물림 반응 | 이 시험에서는 최초 누름 유지형. 해제형과 시각 신호를 혼용하지 않음 |
| 페인트 분사기 | 배관에 고정된 분사 노즐 | 실제 발사색을 노즐 끝 작은 액적과 분사 준비 동작으로 예고 | 그 색의 액적이 지형에 닿아 표면을 바꿈 | 예고→발사→휴지의 반복을 읽을 수 있게 함 |
| 가시·회전톱 | 부서진 배수 격자, 축에 고정된 분쇄 날 | 고정 날은 실루엣, 회전 날은 운동 범위를 계속 드러냄 | 플레이어 색과 무관한 기계적 위험 | 첫 소개에서는 회피할 발판과 관찰 자리를 확보 |
| 투명 발판 | 같은 벽돌 재질의 반투명 실루엣, 약한 부드러운 블러 | 칠해질 때 잉크가 보이고 상면이 선명해짐 | 실제로 밟히는 순간과 상면이 선명해지는 순간을 맞춤 | 회수 시 실체가 풀리는 것을 표시. 회수 후 복귀 경로 유지 |
| 붕괴 발판 | 큰 균열, 갈라진 지지대, 뚜렷한 파손 면 | 밟으면 즉시 균열 반응·가루. 약 0.7~0.9초 동안 붕괴 예고 | 파편이 아래로 떨어지며 충돌 해제. 단순 알파 소멸만으로 끝내지 않음 | 약 3초 이후 복구하되 플레이어 몸 안에서는 복구하지 않음 |

투명 발판의 블러는 1080p 화면 기준 2~4px 정도의 작은 범위부터 비교한다. 불투명도 0.45~0.60은 초기 비교 범위다. 현재 모자이크 26px·가로 번짐 16px를 그대로 스타일 기준으로 채택하지 않는다. 실제 확대율에 맞춰 조정한다.

## 화면 검토 기준

1. 플레이어가 서 있는 면과 뒤쪽 벽을 구분할 수 있는가?
2. 밟을 수 있는 면의 검정·흰색이 크게 읽히는가?
3. 가시·톱이 단색 발판과 구분되는가? 색 전환으로 안전해질 것처럼 보이지 않는가?
4. 투명 발판을 회색 안전 발판으로 착각하지 않는가?
5. 붕괴 발판을 밟기 전에도 파손 재질을 알아볼 수 있는가?
6. 물의 공급원·배수 위치·기계의 고정 위치가 시설 구조로 이어지는가?
7. 세부 질감·거품·안개가 중요한 상면과 실루엣을 가리지 않는가?

## 다음 구현 순서

### v01 시안 검토 결과

- 벽돌·철제 배관·밸브·체인·톱의 설치 구조가 하나의 시설로 묶이는 방향은 확인했다.
- 검정 발판 상면의 흰 반사가 연속 테두리처럼 강하다. 실제 자산에서는 반사를 끊고 줄여 검정 판정을 명확하게 해야 한다.
- 투명 발판은 모자이크 없이 표현되었으나 회색 안전 지형처럼 보일 가능성이 남아 있다. 외곽의 끊김·입자와 실체화 전후 비교가 필요하다.
- 흰색 지형과 페인트 분사기의 표현은 이 시안에서 충분히 비교되지 않았다. 자산 단계에서 검정/흰색 짝과 장치 상태를 따로 비교한다.
- 폭포와 수면의 밝기 차이는 분위기 표현일 뿐 색 판정의 확정안이 아니다. 실제 물 자산은 동일 색의 폭포와 웅덩이를 짝으로 검토한다.
- 그림 속 캐릭터는 크기 비교용 대역이며 기존 플레이어 디자인 변경안이 아니다.

1. **현재:** 기준 장면 시안과 상태표 검토. 질감·밝기·단순화 정도를 확정한다.
2. 확정된 장면을 배경·벽돌·물·철제 장치로 분리해 자산을 제작한다. 완성 장면 그림을 게임 배경으로 그대로 쓰지 않는다.
3. 별도 시험 씬에서 붕괴·투명·물·이동 플랫폼의 색과 충돌을 확인한다. 현재 붕괴 발판은 실제 접촉 감지 누락과 지연 뒤 시각 피드백을 각각 확인해야 한다.
4. 기존 맵 한 곳에 적용해 실제 시야에서 확인한다.
5. 검토된 자산과 설정을 다른 스테이지에 확장한다.

Godot 실행은 아직 명시적으로 요청받지 않았다. 편집기·콘솔·headless 검사는 실행하지 않으며, 시안 검토 후 시험 씬을 준비했을 때 필요한 실행 범위를 별도로 안내한다.
