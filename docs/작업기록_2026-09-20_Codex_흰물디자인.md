# 흰 물 모듈 디자인과 애니메이션

요청: 흰 물을 실제 맵용 디자인으로 제작. 너비와 길이 변경에도 물결이 늘어지지 않고 웅덩이 수면은 지형 윗면 비율에 맞출 것.

생성 PNG 1장과 공통 셰이더, 시각 전용 프리팹, 6종 비교 씬, 독립 HTML 애니메이션 미리보기를 추가했다. 텍스처는 로컬 픽셀 좌표로 거울 반복, 흐름은 TIME으로 이동. 모양은 물줄기/물막/출수/웅덩이/물보라/잔물 6종. 원본을 늘여 프레임마다 충돌을 다시 굽는 구조를 새 디자인에는 사용하지 않는다.

정확한 사용법과 제한은 `assets/textures/obstacles/liquid/white_modular_v1/README.md`.

기존 지형 코드를 확인해 웅덩이 윗면 뒤깊이 4px·모따기 3px 적용. 앞쪽 24px 마감 띠는 수평 면 깊이로 오해하지 않는다.

기존 유체.gd와 웅덩이.gd, stage_2-1과 사용자 수정 stage_2-3는 변경하지 않았다. 현재 유체의 판정은 이전 프레임 실루엣 기반이므로 그림만 교체하는 잘못된 적용을 피했다. 새 프리팹은 장식/디자인 부품이며 아직 게임플레이 유체의 대체품이 아니다.

검증: 브라우저 WebGL2에 동일 함수 이식해 6종 표시 및 물막 448px/웅덩이 480px 변경 확인. 리소스 경로/셰이더 한글 미포함/텍스트 정적 확인. Godot 실행은 명시적 요청 전 금지 규칙으로 미실행. graphify query/update는 종료 1, 결과 없음. git pull은 FETCH_HEAD 권한 오류로 미수행. 커밋/푸시 안 함.
