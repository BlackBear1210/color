# 발 교대와 발목 보존 시안

- 요청: 처음 시안을 바탕으로 최대한 자연스럽게 교차하게 만들고, 발목이 꺾인 부분을 고치며 실제 이미지를 직접 눈으로 확인한다. 기존 게임 미적용 요청을 유지했다.
- 원인: 이전의 종아리/신발 개별 변형은 관절 방향과 신발 방향이 달라 발목 경계가 꺾이고 삼각형이 과하게 눌려 보였다. 원화 첫 자세의 앞꿈치도 올라가 있어 반대 방향으로 보낼 때 각도가 과장됐다.
- 최종 시안: 검정 원화 6번, 흰색 원화 7번의 비교적 곧은 종아리/신발을 기준으로 두 다리를 만든다. 발목만 독립 변형하지 않고 코트 아래의 다리 전체에 같은 회전/이동을 적용한다. 추가 무릎 굽힘과 상체 움직임은 없다. 원래 뒤꿈치/앞꿈치의 가장 낮은 점을 바닥에 맞춘다. 앞꿈치 들림이 과하지 않도록 다리 각도를 제한했다.
- 중간 시안에서 확인한 문제: X자로 늘어난 허벅지, 다른 신발의 작은 조각, 움직이는 코트/총 호스 조각, 코트 아래 다리 연결 틈. 연결 위치와 마스크를 수정하고 최종 출력에서 다시 확인했다.
- 제작 도구: `tools/시안_발교대_발목보존.py`. 새 시안 폴더에만 저장하며 실제 게임 파일을 쓰지 않는다.
- 결과 폴더: `docs/visual_review/player_walk_20261012/발교대_발목보존_미적용시안/`.
  - `발목보존_발교대.gif`: 관찰용 A/B 표시가 있는 32프레임 GIF.
  - `전체_8자세.png`, `발목_교차_8자세_확대.png`: 주요 자세 검토.
  - `black_전체32프레임_눈검토.png`, `white_전체32프레임_눈검토.png`: 최종 GIF의 모든 프레임을 번호순으로 모은 확대 검토 그림.
  - 검정/흰색 투명 16프레임 시트: 표시 없는 원화 시안.
- 직접 시각 확인: 원본 16자세 다리 비교표, 여러 수정본의 전체/확대 자세, 최종 검정/흰색 각 32프레임 확대 그림을 직접 열었다. 교차 전후 A/B의 위치 반전과 발목/신발 연결, 따라붙는 조각 제거를 확인했다. 실시간 GIF 재생을 관찰한 것은 아니며, 프레임별 정지 이미지로 검사했다.
- 정적 확인: 반 주기 후 두 발의 X 순서 반전, 발목/신발 영역의 거리와 각도가 원화의 강체 회전으로 보존됨을 확인했다. 작업 전후 `assets`, `scripts`, `scenes`, `shaders`, `project.godot` 전체 해시가 같았다.
- 한계: 실제 게임 이동속도와 접지/미끄러짐 동기화는 검증하지 않았다. Godot 실행 허용이 없어 엔진 실행, 엔진 검사 13개, 게임 캡처는 미실행이다. 시안은 게임 리소스에 연결하지 않았다.
- graphify query/update 실행. 갱신 시 기존 그래프 노드 축소 보호가 발생해 강제 덮어쓰지 않았다.
