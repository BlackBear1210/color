# 병합 충돌 표시로 인한 지형 로드 오류 복구

- 원인: 미완료 Git 병합이 공용 `하수도_자연발판.gd`에 충돌 표시를 남겨 GDScript 파싱이 실패했다. 2-9 씬에도 네 군데 충돌 표시가 있었다.
- 공용 스크립트는 원격 측 충돌 내용이 비어 있음을 검사한 뒤 표시 세 줄만 제거했다. 실제 코드는 삭제하지 않았다.
- 2-9 씬은 사용자가 승인한 벽돌 배경 v04와 매립 발판 스크립트, 두 버튼의 지형 정렬값을 유지해 충돌 표시를 제거했다. 다른 병합 내용은 유지했다.
- 정적 확인: scripts/scenes의 gd/tscn 충돌 표시 없음. 2-1~2-9 직접 외부 리소스 경로 누락 0개. pressure inset --check 위치 변경 없음.
- Godot 실행 및 엔진 검사는 저장소 안전 규칙에 따라 미실행. 실제 화면 복구는 실행 검증하지 않았다.
- Git 병합 완료 및 push는 아직 하지 않았다. 인계 문서 두 개의 충돌도 남아 있다. Office 임시 파일 삭제는 이번 작업에서 스테이징하지 않았다.
