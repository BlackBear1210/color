## 확정 원화 전에 고칠 점

1. 최종 시안도 목표 150×46~60보다 다소 높아 보인다. 판·코일·받침을 분리해서 높이를 맞춘다. 통째로 세로 축소하면 철선 굵기가 왜곡된다.
2. 윗면 시점을 더 얕게, 광택을 더 약하게 한다. 장치 명도 77은 현재 결과의 실측 통과값이 아니라 후속 보정 목표다.
3. 목재에 미세한 색기가 남아 있다. R=G=B 검수가 필요하다.
4. 투명 요청 2회는 검정 배경으로 나왔다. 마지막 결과는 문서에서 허용한 초록 배경 대안이다. 알파 완성품으로 취급하지 않는다.
5. 실제 파일은 **2048×768 / RGB 24bit / 알파 없음**이다. 요청한 1536×1024와 다르다. 좌상단 배경은 RGB(18,240,15)로 순수 #00FF00도 아니다. 따라서 확정 규격·배경 검수 미통과이며, 색상 허용 범위를 둔 배경 제거 또는 재생성이 필요하다.
6. 원문 확정 시트는 1536px / 3열 = 512px 칸인데 판 폭은 600px로 지정되어 서로 맞지 않는다. 권장: **2열×3행**, 열=집/하수도, 행=상판/코일/받침. 768px 칸에 폭 600px 상판과 좌우 여백 84px가 들어간다.
7. 코일 반복 부품은 앞·뒤 선의 겹침과 이음새를 별도 검수해야 한다. 생성 시트만으로 매끄러운 반복이 보장되지 않는다.

- 카드 3 전에 사용자 하트 열쇠 원본 레퍼런스 확보 필요. 이번 입력에는 해당 이미지가 직접 첨부되지 않았다.
- 카드 4는 카드 3 머리 모양 확정 후 진행.

## 검증과 저장소 상태

- 실제 게임 전후 캡처: 이번 작업에서는 없음. 위 자료는 기존 캡처다.
- Godot 편집기·headless·빌더·엔진 검사: **미실행**, 사용자 명시 허용 규칙 준수.
- 지정된 `docs/다음작업_프롬프트.md`는 현재 체크아웃에 없음. 파일 검색에도 나오지 않아 13개 검사 명령을 확보하지 못했다. 통과로 보고하지 않는다.
- `graphify-out/graph.json` 없음. 기존 그래프 쿼리를 실행할 수 없었으며 코드 변경이 없어 그래프 생성·갱신은 하지 않았다.
- `git pull --ff-only`: 최초 sandbox FETCH_HEAD 쓰기 제한 이후 권한 허용 재시도. 로컬·원격 분기 때문에 fast-forward 불가. 병합·리베이스·기존 변경 덮어쓰기 없이 현재 체크아웃에서 시안만 추가.
- 게임 코드·씬 수정 없음. 커밋·푸시 없음.
- 최종 git status에서 삭제(D) 없음. 기존 변경 보존. git diff --check 오류 없음(새 PNG의 시각 품질 검증을 뜻하지 않는다).
- 원격 대비 로컬 1 / 원격 2 커밋으로 분기됨.
- 생성 프롬프트 3회분: 시안 옆 `스프링_4안_20261008_생성프롬프트.txt`.
