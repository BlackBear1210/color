# 로비 메뉴 확인음

## 최종 정정: 명중음 사용 취소

- 사용자 "아니야 명중으로 하지마"에 따라 페인트 명중음 연결을 취소했다. 현재 로비는 최초 별도 확인음 `로비_확인.wav`를 사용하며 -8dB/SFX, 나가기 대기 0.50초로 복원했다.
- 새 생성 프롬프트는 붓으로 짧게 물감을 긋는 질감으로 수정하며 명중·충돌·튀김을 제외한다. 프롬프트의 새 음원은 아직 생성·적용하지 않았다.
- 복원 전후 정적 계약 13개 통과. Godot·실제 청취는 미실행.
- 아래 페인트 명중음 연결 내용은 취소된 작업 이력이다.

## 사용자 후속 요청: 페인트로 선택한 효과음 사용

- 로비 확인음을 기존 선택 음원 `assets/audio/sfx/플레이어_페인트명중.ogg`로 교체했다. 아래 WAV 합성음은 최초 제작 이력이며 현재 메뉴에서는 재생하지 않는다.
- AudioStreamOggVorbis.load_from_file로 원본을 읽고 -12dB/SFX 버스로 재생한다. 실제 게임의 페인트 명중음과 같은 파일·기본 음량이다. 원본 음원을 변경하지 않았다.
- 메뉴·창 버튼 확정 및 씬 전환 중 끝까지 재생하는 연결은 유지한다. 나가기 대기는 음원 길이 약 0.255초에 맞춰 0.30초로 줄였다.
- 변경 전후 정적 계약 13개 모두 통과, 대상 음원 경로 존재, 변경 파일 diff 공백 검사 통과. Godot 실행·청취 검증은 사용자 명시적 요청이 없어 미실행이다.
- git pull은 기존 월드.gd·챕터.gd와 원격 변경의 충돌 우려로 중단되어 기존 작업을 보존했다.

## 최초 제작 이력

- 요청: 이어하기·처음부터 등을 선택한 뒤 확인할 때 나는 효과음 제작.
- 제작: `assets/audio/sfx/로비_확인.wav`. 낮고 둥근 타격 위에 작은 유리 공명을 얹은 0.48초, 48kHz 모노 16비트 PCM. 음원 청취 평가를 수행했다고 간주하지 않는다.
- `tools/생성_로비_확인음.py`는 외부 음원·추가 라이브러리 없이 고정 시드로 합성한다. 매번 원본 파형에서 다시 계산한다. 재생성 SHA256 일치 확인.
- `scripts/ui/타이틀.gd`의 메인 메뉴·확인/설정/챕터 창 버튼의 실제 pressed 신호에 연결. 포커스·마우스 이동은 무음. 창이 닫혔거나 씬 전환 중이면 잔여 버튼 신호를 무시한다.
- AudioStreamWAV.load_from_file로 원본을 읽으므로 임포트 전에도 음원을 읽을 수 있도록 구현했다. SFX 버스, -8dB. 루트 자식으로 재생해 씬 교체에도 잔향이 이어지며 finished에서 해제한다. 나가기는 0.50초 후 종료한다.

## 확인과 제한

- 수정 전후 `tools/검사_로비소리_정적.py --parser-path tmp/lobby_audio_validation` 정적 계약 13개 통과. GDScript 문법 파싱·리소스 경로·전체 오디오 버스 지정·설정 보존·지도 계약 포함. Godot 타입 검사를 대신하지 않는다.
- WAV 형식·길이·클리핑 없음·양끝 페이드·동일 재생성 확인. `git diff --check` 통과(CRLF 안내만 있음).
- `graphify update .` 완료: 34,986 노드·117,239 관계·953 커뮤니티. graph.json·GRAPH_REPORT.md 갱신, HTML은 그래프 크기 제한으로 생략. Git 삭제 파일 없음.
- `git pull --ff-only`는 기존 미커밋 월드.gd·챕터.gd와 원격 변경이 겹쳐 중단. 기존 변경을 보존하며 작업했다. 커밋·푸시하지 않음.
- 시작 안내 `docs/다음작업_프롬프트.md`가 현재 체크아웃에 없어 원본 엔진 검사 13개 명령 및 지뢰밭 본문 확인 불가.
- AGENTS.md 사용자 안전 예외에 따라 Godot 편집기·콘솔·headless·빌더 및 엔진 검사 13개 미실행. 실제 게임 청취·마우스/키보드 동작·씬 전환/종료/음소거 검증 대기. 새 엔진 캡처 없음.
