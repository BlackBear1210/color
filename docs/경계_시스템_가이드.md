# 색 경계 시스템 가이드

## 한 문장 정의

색 경계는 월드를 검정·흰색·무색 영역으로 나누는 다각형이다. 플레이어 몸의 각 위치는 자신이 들어간 영역의 색을 강제로 따르며, 무색·회색 영역은 강제하지 않는다.

## 색 구역의 의미

| 영역 | 플레이어에게 하는 일 |
|---|---|
| 검정 경계 | 그 안에 든 몸 부분을 검정으로 강제 |
| 흰색 경계 | 그 안에 든 몸 부분을 흰색으로 강제 |
| 무색·회색 | 색을 강제하지 않음. 플레이어의 자유색 유지 |

경계는 화면에 보이는 장식이 아니라 물리와 시각 표현이 함께 쓰는 규칙 영역이다. 따라서 경계의 모양과 사망 판정, 플레이어 그림의 분할선은 같은 폴리곤 데이터에서 계산한다.

## 제작 규칙

1. 서로 다른 색 경계는 **면적으로 겹치면 안 된다.**
2. 변끼리 맞닿거나 꼭짓점만 닿는 것은 허용한다.
3. 한 경계의 꼭짓점 순서가 교차하면 안 된다. 활 모양·나비 모양처럼 선이 자기 자신을 가르는 폴리곤은 사용할 수 없다.
4. 꼭짓점 두 개를 같은 좌표에 두거나, 면적이 거의 0인 가느다란 폴리곤을 만들면 안 된다.
5. 회색 지대는 새 경계로 만들지 않는다. 색을 강제하지 않는 빈 영역으로 남긴다.

면 겹침을 금지하는 이유는 한 위치에 두 강제색이 생기면 몸 분할·사망 판정·총알색 모두 어느 색을 우선할지 모순이 생기기 때문이다.

## Godot 2D 편집 방법

`ColorZone`의 자식 `CollisionPolygon2D`를 선택해 꼭짓점을 편집한다.

- 가까운 다른 ColorZone의 변·꼭짓점에는 기본 12px 범위에서 자석처럼 붙는다.
- 양의 면적 겹침이 생기면 마지막 안전 배치로 되돌리는 것이 목표 동작이다.
- 이미 겹친 오래된 배치를 처음 열었을 때는 겹친 부분을 빨간색으로, Inspector에는 경고로 표시한다.
- `스냅거리`를 0으로 하면 자석 스냅만 끌 수 있다. 면 겹침 금지 규칙은 유지한다.

### 현재 알려진 편집기 문제

꼭짓점을 빠르게 드래그하거나 여러 꼭짓점이 한 스냅 대상에 동시에 붙을 때, 폴리곤이 순간적으로 자기 교차·중복 꼭짓점 상태가 될 수 있다. 이때 Godot 콘솔에 아래 오류가 반복된다.

```text
ERROR: Invalid polygon data, triangulation failed.
```

이는 Godot이 반투명 경계 면을 그리기 위해 다각형을 삼각형으로 나누는 과정에서 실패했다는 뜻이다. 런타임 규칙이 색을 잘못 해석했다는 뜻은 아니지만, 그 모양을 저장하면 충돌 폴리곤도 불안정해질 수 있다.

- 오류가 보이면 해당 꼭짓점 이동을 `Ctrl+Z`로 되돌린다.
- 선이 교차하지 않도록 꼭짓점 순서를 정리하고, 겹친 꼭짓점을 분리한다.
- 유효성 검사 전에는 해당 경계를 저장하지 않는다.

## 기술 계약

새 경계 종류를 만들 때는 `색경계.그룹`에 등록하고 다음 두 함수를 구현한다.

```gdscript
func 강제색(월드좌표: Vector2) -> int
func 경계_폴리곤들() -> Array
```

- `강제색()`은 해당 월드 좌표가 강제 영역이면 `ColorDefs.BLACK` 또는 `ColorDefs.WHITE`, 아니면 `-1`을 반환한다.
- `경계_폴리곤들()`은 월드 좌표 기준의 `PackedVector2Array` 목록을 반환한다.

공통 계산은 `scripts/스마트월드/색경계.gd`가 담당한다. `ColorZone`, 식물B, 빛기둥은 이 계약을 통해 플레이어에게 같은 방식으로 색을 전달한다.

## 검사

- `tools/test_색경계_분할.gd`: 경계 분할·사망·총구·좌우 얼굴색·겹침 규칙 검사
- `tools/레벨검사.gd`: 스테이지 안 모든 색 경계의 양의 면적 겹침 검사

레벨검사에서 경계가 겹치면 종료 코드 1로 실패한다. 변·꼭짓점 접촉은 통과한다.
