# 비대칭 벽체 SS2D 템플릿

작성: 2026-09-04 · Codex

## 작업 내용

- `WALL_벽체` 폴더에 기본형·계단형 SS2D 템플릿을 검정·흰색으로 각각 만들었다.
- 공용 재질과 텍스처는 `assets/textures/smartshape/wall_sparse_bricks_v1/`에 분리했다.
- 검정판은 비대칭 벽돌 타일을 그대로 쓰고, 흰색판은 같은 타일의 역명암 짝을 사용한다.
- 흰 템플릿은 `시작상태 = 2`로 등록해 화면색과 사망 판정이 흰 아트와 일치한다.
- 검정 기본형의 비교용으로 `TEMPLATE_WALL_SOLID_돌출.tscn`을 추가했다. 채움 타일과 충돌 윤곽은 기존 검정 기본형을 유지하고, 모든 외곽에 적용되는 모서리 텍스처만 낮은 벽돌 돌출 버전으로 분리했다.
- 돌출판의 모서리 텍스처는 32px에서 16px로 줄였다. 또한 `uniform_width`를 꺼서 직사각형 모서리에서 miter 보정이 두꺼운 액자처럼 보이지 않게 했다.
- 돌출판은 원본 벽체 타일과 같은 1:1(960×960px) 기본 외곽을 쓴다. 상·하·좌·우 각각에 시안 원본에서 추출한 전용 16px 돌출 스트립과 방향별 normal range를 연결해, 하나의 256px 조각을 반복하던 임시 방식과 달리 시안의 돌출 위치를 한 번씩 유지한다.

## 검증

- 템플릿·재질의 외부 리소스 경로를 정적으로 점검했다.
- Godot 실행 및 헤드리스 검사는 사용자 안전 규칙에 따라 실행하지 않았다.
