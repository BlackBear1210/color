# 작업기록 — 하수도 SS2D 콘크리트 배관 초안

- 날짜: 2026-09-07
- 작업자: Codex
- 범위: `scenes/world_2_클로드`에만 적용할 후보 재질의 **원본 초안**. 기존 배관·템플릿·씬은 바꾸지 않았다.

## 판단과 방향

기존 회색 배관은 볼트, 강한 테두리 광택, 규칙적인 금속 이음새 때문에 하수도 배경의 안개 낀 시멘트·석조 톤보다 현대 산업재처럼 읽혔다. 월드 2의 지형 시멘트와 재질 언어를 통일하기 위해, SS2D 경로/굵기/반복 이음 위치는 유지하고 표면만 무광 회색 콘크리트로 바꾼 초안을 만들었다.

## 초안 규칙

- 중간 회색의 무광 콘크리트와 저대비 흐림만 사용한다.
- 금속 광택, 볼트, 리벳, 녹은 넣지 않는다.
- 이음부는 단순한 어두운 홈과 두꺼운 콘크리트 칼라로 남긴다.
- 균열·기공·물때는 멀리서 노이즈가 되지 않도록 최소화한다.
- 생성 초안의 체커보드는 실제 투명이 아니므로, 경계 밖 체커 영역을 알파로 분리한 `pipe_base_concrete_gray_v1.png`을 템플릿에 연결했다.
- 수평으로 반복되는 재질이며, 원본 폭이 커진 만큼 `texture_scale = 0.093`으로 맞춰 기존 배관과 같은 약 69px 굵이를 유지한다.

## 새 SS2D 템플릿

- `TEMPLATE_PIPE_OPEN_CONCRETE_GRAY.tscn`은 기존 열린 경로·물 포트·끝마개 노드 이름을 그대로 유지한다. 그래서 배치한 뒤 기존 배관과 같은 방식으로 경로 점을 편집할 수 있다.
- 양 끝은 본체의 콘크리트 이음부에서 잘라낸 끝마개를 쓴다. 금속 끝마개가 남아 재질 통일이 깨지는 일을 막는다.
- 고도(`깊이`)는 **3**으로 명시했다. 유체는 실효 고도 0·1·2만 쓰므로 배관 본체는 3, 끝마개는 4가 되어 물에 깔리지 않는다.

## 아직 하지 않은 일

- 기존 `PIPE_배관` 템플릿이나 월드 2 씬에 연결하지 않았다. 새 템플릿만 만들었으므로 현재 플레이 중인 모든 스테이지의 모습과 참조는 그대로다.
- 장식 배관의 실제 배치는 사용자 승인 뒤에 별도 작업으로 한다.

## 확인

- 이미지의 투명 배경과 파이프 외곽 실루엣을 정적으로 확인했다.
- 사용자 안전 예외에 따라 Godot 편집기·헤드리스 검사·빌드는 실행하지 않았다.
