# 작업기록 2026-08-25 · 성진 — 벽돌 테두리(SS2D 엣지) 만들기

> 목표: **brick_black_seamless 로 채운 도형에 벽돌 테두리를 두른다.**
> 결과: 텍스처 30장 + 머티리얼 3개를 만들고, **SS2D 애드온의 용접 결함 하나를 고쳤다.**
> 검사 14개 전부 통과.

---

## ▣ 한 줄 요약

도형 모양을 어떻게 바꿔도 **두께가 일정한 벽돌 테두리**가 나온다.
`res://assets/textures/smartshape/brick_v2_opaque/tres/지형_벽돌v2_opaque_black_사방.tres`
를 `Shape Material` 칸에 끌어다 놓으면 끝이다.

---

## ▣ 왜 이 작업을 했나

`brick_v2/black/fill_detail.png` 로 벽을 채우면 **그냥 사각형**이라 밋밋했다.
SS2D 는 테두리를 `SS2D_Material_Shape._edge_meta_materials` 로 그리는데
그 배열이 비어 있어서 채우기만 있었던 것이다.

---

## ▣ 막혔던 것 7가지 — 원인과 해결

작업 중에 실제로 걸린 순서대로 적는다. **전부 한 번씩 터진 것**이다.

### 1. 스냅 격자에 341 을 못 넣는다

도형 크기를 타일 크기(341×307)의 배수로 맞추려고 SS2D 스냅을 켰는데,
`Grid Step` 에 `341` 을 치면 **100 으로 잘렸다.**

`addons/rmsmartshape/scenes/SnapPopup.tscn` 의 SpinBox 에 `max_value` 가 없어서
Godot `Range` 기본 최대값 **100** 이 걸린 것. `Grid Offset` 은 음수도 못 넣었다(최소 0).

**해결** — 네 칸의 상·하한을 넓혔다 (±4096, `allow_greater/lesser`).
※ 팝업 **씬 파일**을 고친 것이라 반영되려면 **플러그인을 껐다 켜야 한다.**

### 2. 텍스처 끝이 투명해서 못 쓰겠다

`brick_v2` 의 엣지 그림들은 끝이 흐리게 사라진다. 그대로는 쓸 수 없어 보였다.

재보니 **좌우는 원래 투명하지 않았다** — `edge_top.png` 의 세로줄 알파가
`min 160.0 / max 160.3` 으로 완전히 균일했다. 가로 반복은 이미 완벽했던 것.

투명한 건 **위아래**였고 두 종류였다:

| y | 알파 | 정체 |
|---|---|---|
| 0 ~ 66 | 0 | 그냥 빈 여백 |
| 67 ~ 199 | 255 | 실제 갓돌 그림 |
| 200 ~ 255 | 255→0 | fill 로 스며들라고 넣은 페이드 |

256px 중 실제로 쓰는 건 133px 뿐이었다. 쿼드가
`외곽선 기준 ±(tex_size.y × scale)/2` 로 잡히므로(`shape.gd:1574`, `988`)
**절반을 빈 여백에 쓰고 있었다.**

**해결** — 빈 여백을 잘라내고, 페이드 구간의 알파를 굳혔다.
페이드 밑에 **벽돌 한 줄이 통째로 살아 있어서 그림이 오히려 늘었다.**
아래쪽 컷은 **줄눈 한가운데**에 맞췄다 (밝기를 재서 가장 어두운 행을 찾음):

```
edge_top:  219:29  222:16  225:9   228:30  231:44
                           ↑ 여기서 절단
```

→ `brick_v2_opaque/` 24장 (black·white). **원본 `brick_v2/` 는 안 건드렸다.**
기존 `.tres` 8개와 스테이지들이 물고 있어서 덮어썼으면 맵이 전부 바뀐다.

⚠ **`corner_inner/outer.png` 는 손대지 않았다.** 이 둘은 알파가 여백이 아니라
**모서리 모양 자체**를 그린다. 불투명하게 만들면 512×512 사각 덩어리가 된다.

### 3. PNG 를 어디에 넣는지 모르겠다 (금지 표시)

`Edge Meta Materials` 칸에 `edge_top.png` 를 떨구면 금지 표시가 뜬다.
그 배열은 `Array[SS2D_Material_Edge_Metadata]` 라 Texture2D 를 안 받는다.

PNG 의 실제 자리는 **세 단계 안쪽**이다:

```
Shape Material (SS2D_Material_Shape)
└ Edge Meta Materials [0]   ← SS2D_Material_Edge_Metadata
  └ Edge Material           ← SS2D_Material_Edge
    └ Textures [0]          ← ★ Texture2D 는 여기
```

**해결** — 세 단계가 다 채워진 `.tres` 를 만들어 **`Shape Material` 칸**에 한 번에 떨구게 했다.

### 4. 적용하니 세로 줄무늬로 깨진다

`edge.gd:227~233` 이 엣지 길이에 텍스처를 억지로 맞춘다:

```gdscript
var texture_reps: float = maxf(1.0, roundf(total_length / tex_width))
change_in_length = (texture_full_length / total_length)
```

- `tex_width` = 1024 × `texture_scale` = **1024**
- 도형 변 길이 = **344**
- → `texture_reps = max(1, round(0.336)) = 1` → `change_in_length = 1024/344 =` **2.98**

**1024px 를 344 units 에 3배로 압축**한 것이다.

**해결** — `fit_mode = 1`(**CROP**). `edge.gd:234` 에서 `change_in_length = 1.0` 으로 고정돼
압축이 사라진다. 배율은 `1.0` 을 유지해야 fill 과 벽돌 크기가 맞는다
(0.35 로 낮추면 갓돌 벽돌만 작아져 따로 논다).

### 5. 굵은 직사각형처럼 덮인다

띠가 159 units 인데 외곽선을 **중심으로** 그려지니 절반(약 80)이 벽 위 허공으로 나갔다.

**해결 두 가지**
- 텍스처를 줄눈(y=37)에서 잘라 **159 → 38** 로 얇게 (`edge_top_thin.png`)
- `Edge Meta Materials > [0] > Offset` 을 **`-1.0`** (= 안쪽. `+1.0` 이 바깥)

### 6. 네 변이 모서리에서 겹친다 / 방향도 안 맞는다

네 변을 90°씩 **네 구간으로 쪼개놨던 것**이 원인.
`shape_material.gd:53` 이 변의 법선 각도로 머티리얼을 고르므로 구간이 4개면
엣지가 **런 4개로 끊긴다.** 용접은 런 **안에서만** 일어난다
(`shape.gd:1139` `_weld_quad_array(..., weld_first_and_last)`).
→ 런과 런이 만나는 모서리마다 쿼드가 안 물려 튀어나온다.

직사각형은 네 모서리가 전부 90°라 티가 안 나다가, 모양을 비틀자 드러났다.

**해결** — 네 변이 어차피 같은 그림이니 **구간을 하나로 합쳤다** (`begin 0, distance 360`).
외곽선 전체가 **닫힌 런 하나**가 되어 모든 모서리가 자동 용접된다.

마름모를 래스터화해 픽셀로 비교:

| | 밖으로 삐져나옴 | 안쪽 빈틈 |
|---|---|---|
| 4구간 | **754 px** | 0 |
| 360° 한 런 | **133 px** (둘레 전체에 1px 씩 흩어진 AA) | 0 |

### 7. ★모양을 바꾸면 테두리 두께가 달라진다 — 애드온 결함

가장 깊은 문제였다. `shape.gd` 의 **`weld_quads()`** 가 이음매를
**"이등분선 위에, 중점 기준 대칭인, 길이 `needed_height` 선분"** 으로 다시 만든다.

이등분선은 변의 법선과 어긋나 있어서 실제 **수직 두께**가 `cos(θ/2)` 배로 줄고,
바깥 끝이 꼭지점 밖으로 밀려난다.

- 직각(θ=90°) → `38 × cos45° = 26.9` … **실측 26.00 과 일치**
- 마름모는 모서리 각이 제각각 → **변마다 다른 두께**

띠에 **빨간 단색 텍스처**를 넣어 픽셀로 측정했다:

| | 변별 두께 | 편차 | 밖으로 나감 |
|---|---|---|---|
| **전** 사각형 | 26.00 26.00 26.00 26.00 | 0.0% | 3.50 px |
| **전** 마름모 | 28.74 27.13 28.11 29.76 | **9.2%** | 4.67 px |
| **후** 사각형 | 37.00 37.00 37.00 37.00 | 0.0% | −0.50 px |
| **후** 마름모 | 37.22 37.24 37.24 37.24 | **0.0%** | −0.00 px |

**해결** — 이등분선 위에 선분을 다시 만들지 말고,
**두 쿼드의 바깥선끼리 · 안쪽선끼리를 직접 교차**시킨다 (정식 미터 조인):

```gdscript
var i_out: Variant = Geometry2D.line_intersects_line(
        a.pt_a, a.pt_d - a.pt_a, b.pt_a, b.pt_d - b.pt_a)
var i_in: Variant = Geometry2D.line_intersects_line(
        a.pt_b, a.pt_c - a.pt_b, b.pt_b, b.pt_c - b.pt_b)
```

아주 뾰족한 모서리에서 교차점이 무한히 멀어지므로 **미터 한계**(두께의 4배)를 두고,
넘으면 기존 방식으로 떨어진다.

두께가 설계값 38 로 돌아왔고, **어떤 모양에서도 편차 0%**, 밖으로 나가는 것도 없다.

> **첫 시도는 틀렸다.** 이음매 *길이*만 `1/|이등분선·폭방향|` 로 늘려봤는데
> 편차가 12.1% → 16.5% 로 **오히려 커졌다.** 선분을 이등분선 위에 대칭으로
> 다시 만드는 방식 자체가 문제라, 길이 조절로는 안 된다.

## ▣ 지뢰밭 (다음 사람이 밟을 것)

1. **`fit_mode` 를 CROP 으로 안 하면 짧은 변에서 텍스처가 압축된다.**
   1024px 짜리 고해상도 엣지를 쓰면 변이 1024 보다 짧을 때마다 터진다.
2. **엣지 머티리얼을 각도 구간으로 쪼개면 모서리가 안 물린다.**
   같은 그림이면 0~360° 한 런으로.
3. **띠는 외곽선을 중심으로 그려진다.** `offset` 을 안 주면 절반이 밖으로 나간다.
4. **`uniform_width` 를 안 켜면 모양에 따라 두께가 달라진다.** 액자 테두리는 반드시 켤 것.
5. **새로 만든 PNG 는 `--import` 를 한 번 돌려야 `load()` 가 된다.**
   안 돌리면 머티리얼이 통째로 null 이 되어 화면이 텅 빈다. (한참 헤맸다)
6. **`brick_v2/` 원본을 덮어쓰지 말 것.** `.tres` 8개와 스테이지들이 물고 있다.
