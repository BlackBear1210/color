# 자연형 공중·땅 플랫폼 분리

사용자의 외곽 디자인 구분 요청에 따라 v02에 공중/땅 × 검정/흰색 총 4종 프리팹과 개별 미리보기 재질을 만들었다. 공중은 돌출된 옆면과 높이가 다른 밑면, 땅은 큰 벽체와 절제된 상단 모서리를 사용한다. 비교 씬도 위 공중/아래 땅으로 갱신했다.

하수도_자연발판.gd에 땅지형 속성을 추가하고 전용 셰이더의 ground_platform 유니폼으로 전달한다. 땅의 하단에 공중 발판 같은 음영이 생기지 않게 하기 위한 변경이다. 기본값은 false여서 기존 자연형 얇은 발판의 표현을 유지한다. 셰이더 ASCII 규칙을 지켰다.

프리팹은 SS2D 1개씩이며 상면이 평평하다. 외곽 점과 충돌 점은 동일하다. 공중 외곽의 접촉 영역은 직사각형보다 좌우 최대 5px 늘어난다. 기존 스테이지는 자동 변경하지 않았다. 자세한 활용 제한은 v02 폴더의 공중_땅_사용안내.md에 기록했다.

정적 검증: 리소스 참조, 흑백 동일 외곽, 폴리곤 자기교차 여부, 상면, 반사 선분 한도, 표시/충돌 일치, git diff --check. Godot 실행/132개 색칠사망 검사는 미실행이다.
