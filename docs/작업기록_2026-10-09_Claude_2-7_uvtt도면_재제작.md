## 3. 흐름 (도면 주석 그대로 + 갈 수 있는 순서)

1. **시작 바닥(86)** — 바닥을 오가는 톱(칸 55~70) · 앞을 흰물_2(선반 밑 → 바닥 · 416 폭 · 물받이 출수구)가 막는다.
2. **흰 방** — 공중 지형(흰) → 검은 블록 → 흰 격자 1·2·3 을 흑백 바꿔 오른다(흰물_3 은 흰 몸으로). 팔의 **벨브_1** → 흰물_2 꺼짐(도면 "벨브_1을 돌리면 흰물_2가 비활성화 됨"). 선반 CP.
3. 격자_2 에서 떨어지며 검정 → 검은 격자(꺼진 흰물_2 자리) → 바닥 → 계단 → **점프대 3**(계단 위 · 블록 14 · 블록 17 — 블록 밑엔 가시) → 오른쪽 구조물.
4. **발판_2**(사람 · 홀드) → 오른벽에서 **검은지형_1~5** 가 아래부터 0.45 초 간격으로 나온다. 내리면 2 초 뒤 **_1 부터** 1 초 간격으로 들어간다 → 빨리 올라 **검은 열쇠조각**.
5. 점프대_3 으로 블록 13 → 11 → 흰 틀 위(CP) → 양동이 블록. 양동이를 **검정으로** 쏴 채워 왼끝으로 떨어뜨리고 **발판_1** 홈에 민다 → **뚜껑**이 흰 틀 속으로 → **흰 열쇠조각**.
6. 왼쪽 흑백 공중 지형(일방통행)을 올라 위 바위 → **흰 몬스터**(블록 8·9 위에서 지나가길 기다렸다 뒤로 내려 달린다) → **투명지형**(칠) → 디딤 블록 2 → 도착 지점. 두 조각이 모이면 **도착 문**이 열린다 → 출구(2-8).

## 6. ⚠ 알아 둘 것

- **원근 지형은 본체가 비쳐 보인다** — 벽 속에 숨긴 움직이는 지형(계단 · 뚜껑)의 덮개가 z −1 그릇이어도 벽 위에 그려진다. 2-7 은 `압력버튼.숨는_자리` 로 다 들어가 있는 동안 감춘다. 나오고 들어가는 동안은 벽 속 부분도 보인다(움직이는 1~1.5 초). **2-5 계단(왼벽 속)도 같은 문제가 있을 것**이다 — Codex 가 2-5 에 원근을 켠 뒤 실화면을 안 봤다. 2-5 빌더 `버튼.set("숨는_자리", 0)` 한 줄이면 된다(확인 후).
- 흰 열쇠 구멍의 왼쪽 흰 테두리(칸 42.5~44.5)는 검은 턱(41~42.5 · 32 높음) 옆이라, 흰 몸으로 테두리 왼쪽에 서면 죽는다. 오른쪽(구멍 쪽)에서 뛰어야 한다 — 도면대로 둔 함정.
- 공략 `밀기 … "제자리"` — 양동이가 바닥 끝(턱 바로 앞)에 떨어져 "물체 + 90" 자리가 낭떠러지라, 다가가는 걸음이 자동 점프로 양동이를 넘어가 버렸다.
- 이 파일 쓰기 중 `tools/하수도_주행검사.gd`·빌더에 `cp`/`Copy-Item` 이 가끔 "Permission denied / user-mapped section" 으로 거절됐다(다른 프로그램이 파일을 잡고 있음). 재시도하면 된다. 파이썬 `open(p,'w')` 의 Errno 22 는 여는 단계에서 나서 파일이 비지는 않았다(메모리 규칙대로 스크래치 사본 → 복사로 고쳤다).
