## 2. 새 공통 HUD 씬

`scenes/ui/페인트_HUD.tscn` — **모든 스테이지가 이 파일 하나를 인스턴스한다.**

```
페인트HUD (CanvasLayer, layer 100)      script: scripts/ui/페인트_HUD.gd
└ 루트 (Control, 전체화면, mouse_filter=IGNORE)
  ├ 본체 (Control)                      ← `여백` 이 위치를 정한다
  │ ├ 장식   (Control)                  ← 초상↔게이지 이음쇠 (코드 draw)
  │ ├ 초상   (Control)
  │ │ ├ 초상_뒤   (ColorRect · HUD_구.gdshader back_pass)
  │ │ ├ 초상_마스크 (Polygon2D · clip_children = ONLY)
  │ │ │ └ 초상_그림 (AnimatedSprite2D · assets/p/player_frames.tres)
  │ │ └ 초상_앞   (ColorRect · HUD_구.gdshader rim)
  │ └ 게이지 (Control)
  │   ├ 게이지_뒤   (ColorRect · HUD_구.gdshader back_pass)
  │   ├ 액체_마스크 (Polygon2D · clip_children = ONLY)   ← 액체가 구 밖으로 못 나간다
  │   │ └ 액체     (ColorRect · HUD_액체.gdshader)
  │   ├ 게이지_앞 (ColorRect · HUD_구.gdshader rim)
  │   └ 눈금     (Control)              ← 100/75/50/25/0% (코드 draw · 숫자 없음)
  └ 월드표식 (Control)                  ← E 회수 마커 · 호버 (예전 기능 그대로)
```

### 마스크는 `clip_children` 이다
`Polygon2D.clip_children = CLIP_CHILDREN_ONLY`.
gl_compatibility 렌더러에서 **실제로 동작하는지 먼저 실험해서 확인하고** 채택했다
(NVIDIA MX450 / OpenGL 3.3 에서 원형 클립 정상). Control 의 `clip_contents` 는 사각형이라
원형 그릇에는 못 쓴다.

### 초상은 새로 그린 그림이 아니다
`assets/p/player_frames.tres` — **게임이 실제로 쓰는 그 SpriteFrames** 를 그대로 물린다.
`black_walk` / `white_walk` 를 계속 재생하므로 초상 안에서 캐릭터가 걷는다.
원본 픽셀은 한 점도 안 고쳤고, 얼굴만 동그랗게 오려내지 않았다 —
후드·얼굴·눈·망토 실루엣이 전부 살아 있고 다리만 원반 아래로 잘린다.

실측해서 잡은 값 (`assets/p/black/Walk.png` 5760×640, 640 칸 4 프레임, 내용 x139~433 · y101~566):
`초상_그림.scale = 0.135`, `position = (36.6, 35.6)` — 원반(지름 62px) 안에 후드 꼭지부터
망토까지 들어온다.

### 그릇(프레임)은 왜 셰이더인가
`assets/textures/ui/` 에는 `brush_cursor.svg` **하나뿐**이라 재사용할 UI 아트가
프로젝트에 존재하지 않는다(STEP 1 · 이번에도 다시 확인). 그래서 AI 로 새 픽셀아트를
만들지 않고, 해상도에 안 묶이고 페인트 색에 따라 톤을 뒤집을 수 있는 셰이더로 만들었다.
**원화가 들어오면 씬에서 ColorRect → TextureRect 로 갈아끼우면 끝난다.**

## 3. 색 — 출처는 `자유색` 하나 (STEP 2 결정)

```
player.자유색  (Shift 로만 바뀌는 진짜 상태값)
      │
      └─ player.선택색()   ← ★[신규] 바깥이 읽는 유일한 창구
             │
             ├── 초상 : black_walk ↔ white_walk 시트 교체
             └── 게이지 : liquid_color (검정 잉크 ↔ 흰 잉크)
```

`player_color`(대표색)는 **쓰지 않는다.** 그건 총구가 박힌 조각의 색이라 몸이 색 경계에
걸칠 때마다 매 물리 프레임 덮어써지는 파생값이고, HUD 가 읽으면 경계 지형 위에서
초상·게이지가 깜빡인다. (총알 색은 지금처럼 `얼굴색()` 을 계속 쓴다 — 그건 위치의 함수가 맞다)

`player.gd` 에 **딱 한 함수**를 더했다:

```gdscript
func 선택색() -> int:
    return 자유색
```

⚠ 색깔이 바뀌면 그릇 속 톤이 통째로 뒤집힌다. 안 그러면 검정 잉크가 어두운 유리 속에서
사라지고, 검정 캐릭터가 어두운 원반에서 사라진다. 금속 테는 **안 뒤집는다** —
뒤집으면 초상과 게이지가 한 물건으로 안 읽힌다.

## 5. 공통화 — 생성 경로 두 곳이 같은 씬을 쓴다

```
월드.gd  _HUD_만들기()      → 페인트HUD_씬.instantiate()  ┐
                                                        ├→ scenes/ui/페인트_HUD.tscn
stage_lab.gd  8.2) 절       → 페인트HUD_씬.instantiate()  ┘
```

- 예전에는 둘 다 `페인트HUD_스크립트.new()` 로 **빈 CanvasLayer 를 만들고 안을 코드로 그렸다.**
- 이제 둘 다 같은 씬을 꽂는다. HUD 모양을 고치려면 그 씬 하나만 고치면 된다.
- `여백` 만 다르다 — 프로토 계열은 StageHUD 가 좌상단 한 줄(스테이지 이름·사망 수)을
  쓰므로 `Vector2(30, 52)` 로 내렸다. 스마트월드 계열은 기본값 `(26, 20)`.
- `월드.gd` 의 조작 안내 라벨은 y 58 → **116** 으로 내렸다(새 HUD 가 y 20~108 을 쓴다).

### StageHUD 는 안 지웠다
프로토 계열의 `UI > StageHUD` 는 붓 커서·스테이지 이름·사망 횟수·팝업 메시지·
플랫폼 하이라이트를 담당한다. **페인트 UI 가 아니므로 그대로 뒀다.**
(원래도 타일맵 모드에서는 `회수대기_표시 = false` 로 회수 UI 를 꺼 놓은 상태였다)

## 8. STEP 3 을 위해 미리 깔아 둔 것

`shaders/HUD_액체.gdshader` 에 슬로싱 uniform 을 **미리 뚫어 뒀다.**
STEP 2 에서는 전부 0 이라 수면이 정지해 있다(의도적).

| uniform | 지금 | STEP 3 에서 |
|---|---|---|
| `wave_amplitude` / `wave_frequency` / `wave_speed` | 0 / 2 / 1 | 평상시 잔물결 |
| `slosh_amount` | 0 | 좌우 이동에 따라 수면 기울기 |
| `impact_shock` | 0 | 점프·착지·발사 충격 |

컨트롤러(`페인트_HUD.gd`)가 이미 `_액체.material` 을 인스턴스마다 복제해 들고 있으므로,
STEP 3 은 `재질.set_shader_parameter("slosh_amount", ...)` 한 줄씩만 더하면 된다.

## 9. 다음 사람이 알아야 할 것

1. **HUD 모양을 고치려면** `scenes/ui/페인트_HUD.tscn` 하나만 고친다.
   스테이지 씬에는 HUD 가 한 개도 안 들어 있다(전부 런타임 인스턴스).
2. **초상 프레이밍**은 `초상_그림` 의 `scale` · `position` 두 값이 전부다.
   원반 반지름은 `초상_마스크` 의 폴리곤(중심 32,32 · r 31).
3. **눈금·장식·E 마커**만 코드로 그린다(`페인트_HUD.gd` 의 `_그리기_*`).
   UI 원화가 들어오면 TextureRect 로 갈아끼우면 된다.
4. **검사 도구의 함정** — `월드.gd` 는 페인트 코어를 트리 전체 그룹 검색으로 찾는다.
   앞 씬을 `queue_free` 하자마자 다음 씬을 올리면 죽어가는 코어를 집어 간다.
   `test_HUD_공통.gd` 는 씬 사이에 4프레임을 쉰다(실제 게임은 `change_scene` 이라 무관).
5. **흰색으로 바꾸면 검은 지형 위에서 즉사한다** — 그러면 리스폰이 `코어.리셋()` 을 불러
   탄약이 가득 찬다. 검사에서 색·탄약을 조작할 때는 **색을 먼저, 탄약을 나중에** 세팅한다.
