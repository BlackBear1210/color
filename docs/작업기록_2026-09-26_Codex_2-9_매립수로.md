# 2-9 물받이 매립 수로

사용자가 제공한 단면도의 직사각형 홈 형태를 적용했다. 물의 양옆과 아래를 실제 지형이 감싸도록 `stage_2-9.tscn`의 A_물받이바닥, E_물받이바닥, G_수조바닥을 오목한 8점 다각형으로 바꿨다.

- 기존 물 위치, 폭, 수심 64px, 색, 낙하 받기 설정은 유지했다.
- 물 바깥의 지형 윗면을 64px 올려 수면 높이와 맞췄다. 물 내부에는 기존 바닥 높이를 유지하므로 물 공간이 고체로 채워지지 않는다.
- A는 물 왼쪽에 여유 지형이 없어 왼쪽으로 64px 연장했다. E/G는 기존 바닥 폭 안에 양쪽 턱이 있다.
- SS2D 점 배열과 CollisionPolygon2D를 같은 외곽으로 수정했다. 씬 재생성 도구나 owner 재지정은 사용하지 않았다.
- 수정 이유는 각 지형 노드의 한글 editor_description에 남겼다.

정적 확인: 세 지형의 시각/충돌 좌표 일치, 물 내부 비충돌 공간, 양쪽 턱과 하부 고체 영역, 리소스 ID 유일성과 참조 해결을 확인했다. git diff --check 통과. 수로 밖 바닥이 높아져 해당 구간 보행 높이는 달라진다. 실제 통행과 지형 마감 렌더링은 엔진 미실행으로 미확인이다.

Godot 및 headless 검사 전체는 저장소 안전 규칙으로 미실행. 기존 병합 미해결 상태 때문에 git pull 실패. 기존 병합 상태와 다른 작업 파일은 유지했다. graphify query/update 호출은 유효 출력이 없었고 update 종료 코드 1로 갱신을 확인하지 못했다.
