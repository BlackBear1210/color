# 발판 원근·누름판·승강기 접합 마감 — 2026-10-09 Codex

요청: 현재 지형의 perspective와 맞지 않는 발판 디자인을 수정하고, 게임에 적용했을 때 재질과 지형 마감이 자연스럽게 이어지게 한다.

**상태: 수정 완료·시각 검증 대기.** Godot 편집기·콘솔·headless·빌더는 모두 미실행. 실제 수정 후 엔진 캡처 경로는 없음. 아래 미리보기는 원본 재질과 면 배치의 브라우저 렌더링이며 엔진 검증 이미지가 아니다.

## 원인과 방향

- 기존 누름판 원본에는 양쪽이 대칭인 원근이 이미 그려져 있다. 이미지를 가로로 늘리는 기존 방식으로는 돌 지형의 오른쪽 아래 사선과 일치하지 않는다.
- 격자에는 직전 작업의 원근 표시가 있지만, 고정색 승강기는 같은 격자 원본을 정면 띠로 늘리고 있었다.
- 같은 사선 윗면·앞 단면·왼 단면을 쓰고, 윗면보다 앞 단면을 어둡게 하며 금속의 밝은 테를 낮춘다. 누름판에서는 고정 프레임을 남기고 상판만 움직인다.

## 적용

- `발판_원근그림.gd`: 기존 주철 부품에서 윗면/앞면의 평평한 내부 영역만 샘플링해 기존 대칭 모따기를 제거한다. 지형과 동일한 18px 수평 이동/22px 깊이, 뒤 -4px/앞 +18px를 사용한다. 끝 볼트는 폭을 유지한다. 상판만 최대 3px 올라갔다가 눌리면 프레임에 들어간다. 활성 창은 실제 출력 활성 상태를 사용한다.
- `발판_매립마감.gd`: 프레임 윤곽 안쪽 0.6px에 기존 돌 마감 차집합 API를 적용해 금속 밖의 돌은 보존하고 겹치는 덮개만 걷어낸다. 눌림 애니메이션은 마감을 다시 만들지 않는다. 배치/크기/표시/이웃 배치 변경 때만 갱신한다. 제거·숨김·원근 끄기 시 복원한다. 생성 보조 노드는 owner를 지정하지 않고 저장하지 않는다.
- `압력버튼.gd`: 선택 속성 `챕터1_원근`과 그림 전용 발 깊이 추가. 기존 누름 감지·충돌·상자 동작·동시 버튼·대상 이동·꺼짐 지연 등 함수는 수정 전과 동일하다. 기본값 false.
- `움직이는발판.gd`: 고정색 주철 발판만 기존 격자 원근 생성기를 공유한다. 왕복·위상 초기화·동승·고정색 판정·명중 차단은 그대로다. 기본값 false. 칠하기 가능한 발판은 기존 외관을 유지한다.
- `격자_원근그림.gd`: 윗면 명도를 검정 0.82/흰색 0.88로 낮춰 주변 돌과 밝은 테의 차이를 줄인다. 투명 구멍은 그대로다.
- 선택 속성 적용: 2-4 누름판 1/승강기 1, 2-5 누름판 1, 2-6 누름판 1/이동 발판 1, 2-7 누름판 2. 총 누름판 5개/고정색 이동 발판 2개. 2-1~2-3 씬에는 이번 작업의 새 저장값 변경이 없다.
- `tools/apply_platform_perspective_finish.py`: 씬 전체 재생성 없이 위 선택 속성만 멱등 추가한다. `tools/preview_platform_finish.py`: 기존/변경/눌림 상태의 높이 32px·16px 비교 도식을 만든다.

## 실제 게임에서 남은 확인

같은 스테이지·줌·해상도의 수정 전후 PNG가 필요하다. 돌/금속 경계, 모서리와 겹침, 짧은 16px 버튼, 흑백 명암, 격자 반복 이음새와 투명 구멍, 플레이어 발 그림, 상자 밀기/누름/해제/리스폰, 승강기 동승을 확인한다. 현재 구현이 게임에서 이질감 없이 완성됐다고 단정하지 않는다.
