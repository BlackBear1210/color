# 작업기록 2026-10-01 · Claude · 스테이지 도안 한 장 (2-1)

## 왜

도형님: "맵을 일일이 돌아다니며 보기 힘들다. 한 장 안에 맵 전체 구조와 흐름, 장애물을 보고 싶다."
`tools/맵그래프.py` 는 관계 그래프라 지형이 사각형 · 물이 파란색이어서 도안으로는 안 읽힌다.

## 무엇을 했나

| 파일 | 내용 |
|---|---|
| `tools/도안_스테이지.py` ★신규 | `맵그래프.py` 의 파서(`stage_graph` · `parse_routes`)를 빌려 **실제 지형 폴리곤 그대로** 검정/흰/유령을 칠하고, 물(색·죽는 몸)·웅덩이·가시·레버(→바꾸는 물)·체크포인트·시작·출구와 **주행검사 공략표의 정답/헛걸음 경로**(걷기 실선 · 점프 점선 · 발사 잔 점선 · 번호 · 색 전환 흑백 원)를 한 장 HTML(SVG)로 그린다. 구역 띠(방 A·B·C = 지형 이름 접두어) · 512 격자 좌표 · 화면 한 장(1920×1080) 크기 표시 · 확대 1.8×/3× · 경로·이름표·격자 켜고 끄기 · 마우스를 올리면 노드 이름·값 · 단계 목록에 올리면 지도의 번호가 빛난다. 엔진 불필요 |
| `docs/도안/stage_2-1_도안.html` ★신규 | 위 도구 결과 |

- 구역 설명은 도구 안 `메모` 표(스테이지별)에 적었다 — 2-1 만 채움(출처: 빌더 머리말 · 2026-09-14 재제작 기록).
- ⚠ 2-1 지형은 Codex 의 자연발판(울퉁불퉁한 윗면)이라 수평 변이 거의 없다 → 걷는 경로는 **세로 광선**으로 바닥을 찾는다.
- ⚠ 경로는 공략 명령을 흉내 낸 그림이다(걷기 = 바닥 따라 · 점프 = 포물선). 실제 궤적과 조금 다르다.
- 곁길(헛걸음) 경로는 정답 아래에 가늘게, 번호는 정답과 다른 자리에만 찍는다.

## 사용

```
python tools/도안_스테이지.py stage_2-1            # → docs/도안/stage_2-1_도안.html
python tools/도안_스테이지.py stage_2-2 stage_2-3
```
`맵그래프.py` 의 `SCENES`(2-1~2-4 · 2-6~2-8)만 된다. 아스트라 2-9~2-11 은 씬 구조가 달라 파서를 늘려야 한다.

## 검사

게임 코드·씬을 안 건드렸다(읽기만). 인앱 브라우저로 열어 확인 — 경로가 구덩이 바닥으로 빠지던 것(수평 변 탐색 · 유령 제외) 두 번 고침.

### ★ `tools/맵그래프.py` 버그 수정
`points_of()` 가 `position` 줄이 없는 점을 버렸다. Godot 는 **기본값 (0, 0) 인 점의 position 을 안 적는다** → 원점에서 시작하는 사각형이
삼각형으로 읽혔다(2-9 지형 전부). 없으면 (0, 0) 으로 치고, 점 순서는 `_point_order` 를 따른다. `맵그래프.html` 도 다시 만들었다.

```
python tools/도안_스테이지.py                 # 메모에 있는 스테이지 전부 + 목록
python tools/도안_스테이지.py stage_2-5       # 하나만(목록은 있는 파일 전부로 다시)
```
