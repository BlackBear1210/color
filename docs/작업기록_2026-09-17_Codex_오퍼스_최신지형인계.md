# 오퍼스 최신 지형 인계

사용자 요청에 따라 world_2_클로드 폴더에 `필독_오퍼스_현재지형디자인_인계.md`를 만들었다. 기본 땅/공중 선반, 내부 무늬 양방향, 가로·세로 맞물림, stage_2-1의 적용 노드와 색조합 전용 재질, 배치·페인트·검수·성능 조건을 명시했다.

클로드 프롬프트 앞부분의 v01 안내가 최신 자산 선택과 충돌함을 확인했다. 아스트라·클로드 프롬프트 첫머리에 인계 문서 링크와 masonry_v02/ledge_v03 우선 기준을 넣었다. 과거 설명 자체는 삭제하지 않고 역사적 설명임을 명시했다.

이번 변경은 문서뿐이다. 실제 현재 씬의 참조와 파일 목록을 확인했고 diff 공백 검사를 통과했다. 새 엔진 검사나 게임 변경은 수행하지 않았다. 다른 모델이 문서를 자동으로 읽는다고 보장하지 않으며, 전달 시 이 문서를 읽으라는 지시가 필요하다.
