# 사망 모션 완료 후 체크포인트 부활 — 2026-10-07 · Codex

사용자 요청: 죽는 모션이 끝난 뒤 체크포인트에서 부활. 챕터1 스테이지의 기존 부활 방식 확인.

## 확인된 기존 동작

`scenes/쳅터1/스테이지/`의 14개 씬은 공통 `scripts/스마트월드/월드.gd`를 사용한다. 체크포인트 오브젝트도 배치되어 있다. 그러나 공통 월드는 checkpoint 그룹의 접촉을 저장하지 않았고, 안전한 바닥 위에서 0.45초 머무른 마지막 자리인 `_안전점`으로 즉시 부활했다. 체크포인트 자체의 `_닿음()`은 성수반의 시각적 활성화만 했다. 즉 '체크포인트 부근에서 부활하는 것처럼 보이는 자동 안전지점'과 '마지막으로 닿은 성수반으로 부활'은 달랐다.

## 변경

- 공통 월드에서 자신이 포함하는 checkpoint Area2D의 접촉을 연결하고, 위치와 선택색을 저장한다. 마지막으로 닿은 체크포인트를 우선하며, 아직 없으면 기존 자동 안전지점/시작 위치를 사용한다.
- 사망 진입 시 `_사망중`을 먼저 설정하여 반복 판정/사망 집계/체크포인트 변경을 막는다. 이동·점프·색 전환의 물리를 끄고, 발사 입력·상호작용을 막으며, 플레이어 충돌 레이어를 잠시 끈다.
- 이전의 독립 잔상은 제거했다. 플레이어 본체에서 흑백 death 16프레임/20fps를 재생하고 **animation_finished를 기다린다**. 재생 중에는 사망 위치에 머문다.
- 모션 종료 후 다음 물리 시점에 저장 위치로 이동, 물·페인트·낙하 상태·카메라를 기존 흐름으로 초기화한다. 마지막으로 입력과 원래 충돌/물리 상태를 복구한다. 기존 부활 직후 무적 0.6초를 유지한다.
- 체크포인트의 원래 바닥색을 페인트 초기화 후 읽어 부활색을 맞춘다. 칠한 흰 바닥이 죽음 후 검정으로 돌아가는 경우의 반복 즉사를 막는다. 해당 지형 API가 없는 바닥은 저장했던 선택색을 사용한다.
- 특수 2-5 월드의 색 보정을 `_리스폰()` 호출 직후에서 `_부활_후처리()` 훅으로 옮겼다. 비동기 대기 전에 색 보정이 실행되는 문제를 방지한다.
- 챕터1 연결구는 물리가 꺼진 사망 중 본체의 진입을 무시한다.
