# 흰색 물 v2: 색 구분을 우선하고 착수부를 분리

## 사용자 요청과 반영

기존 전체 영상 확대 방식은 넓은 물막에서 잔털 같은 윤곽을 만들고, 긴 물줄기에서 질감이 늘어났다. 본체와 착수부를 분리한 개선 버전을 만들던 중 사용자가 흰색·회색·검정색을 확실히 구분해야 하며, 투명함보다 게임의 색 규칙이 우선이고 물보라는 강하지 않아도 된다고 추가 지시했다.

**흰색에만 적용했다.** 본체는 밝고 충분히 불투명한 흰색 재질로 따로 그린다. 튀는 부분은 새 힉스필드 영상의 실제 프레임을 작고 은은하게 재생한다. 본체까지 힉스필드 영상을 늘려 그렸다고 보고하지 않는다.

## 적용 방법과 이유

- `scripts/스마트월드/흰물_디자인.gd`: 새 시트를 연결한다. 기존 2-1~2-4 범위 및 흰색 분기는 유지한다. 공중 물방울은 고정 배율로 그려 넓은 물막에서 화면 여백을 과하게 늘리지 않는다.
- `shaders/water_stream_natural.gdshader`: 본체 폭의 윤곽을 매끈하게 고정한다. 본체 내부의 작은 명암만 아래로 이동한다. 높이에 따라 영상이나 질감을 늘리지 않는다.
- 흰색 본체 내부 기준 알파는 최소 0.84, 밝기는 최소 0.92다. 완전히 검정인 배경 위에서도 중심 합성 밝기는 최소 약 0.773이므로 이전의 투명한 회색 중심보다 흰색 판독이 쉽도록 설계했다. 가장자리의 부드러운 부분 및 낙수 진입/종료 마스크는 예외다.
- 착수부는 원본 픽셀당 고정 배율 0.4, 알파 배율 0.72로 작고 은은하게 그린다. 중앙 접촉부만 본체 폭에 맞추고 바깥 공중 물방울의 크기는 유지한다.
- 착수 영상 속 급수 줄기를 제거해 별도 본체와 중복되지 않게 한다. 첫 검토에서 남아 있던 세로 줄기 흔적도 마스크 폭 10~16 원본 셀 픽셀로 넓혀 제거했다.
- 바닥에 붙은 물막은 본체 폭 밖에서 사라진다. 공중 물방울은 바닥 폭 제한 대상이 아니다.
- 흰색만 새 분리 재질을 사용한다. 회색/검정색의 기존 재질과 물색·충돌·사망 판정은 수정하지 않았다. 씬 빌더를 실행하지 않았다.

## 확인 결과

- 원본 영상 해시, 96개 서로 다른 프레임, 흑백 RGB, 투명 셀 가장자리: 통과.
- 24fps 시트 좌표, 네 스테이지 범위, 흰색 분기, 밝은 본체 알파, 고정 착수 배율, 착수부 약화, 도착/종료 조건: 정적 확인 통과.
- 셰이더 한글 없음/중괄호 균형, 추출 도구 Python 구문, `git diff --check`: 통과. 줄바꿈 CRLF→LF 안내는 남아 있다.
- 최종 설치 시트를 읽어 가는/긴 물줄기, 넓고 짧은 물막, 넓고 긴 물막의 분리 렌더 미리보기를 만들고 직접 열어 보았다. 이는 셰이더 수식의 CPU 근사 렌더이며 실제 게임 캡처가 아니다. CPU 미리보기의 착수 샘플링은 정수 픽셀, 게임 셰이더는 선형 샘플링이므로 작은 가장자리 차이가 남을 수 있다.
- `git pull --ff-only`: `FETCH_HEAD` 접근 거부로 미완료. 강제 갱신하지 않았다.
- `graphify query` 및 `graphify update .`: 시도했으나 출력 없이 종료 코드 1이어서 그래프 확인/갱신 미확인.
- `docs/다음작업_프롬프트.md`가 현재 체크아웃에 없어 13개 검사 명령을 읽지 못했다. 엔진 검사 통과로 보고하지 않는다.
