## 2. 06 복도 C — 투명 지형 · 무한 리스폰

### 투명 지형(유령판) 지나가는 법
- 유령판은 **물감을 맞혀야 단단해진다**. 빛 아래 유령판(124~129)은 흰 빛 속이라 흰 몸으로 서야 하므로 **흰 물감**으로 칠한다
  (물감 색 = 얼굴 색 → 흰색일 때 쏜다). 칠한 뒤: 흰 몸으로 유령판 → 공중에서 검정 → 검정 판(114).
- 구조가 검정이 되며 "흰 몸으로 서서 쏠 자리" 가 없어졌다 → 구덩이 앞 바닥 위에 **흰 받침**(추가지형 143~147 · 윗면 29)을 놓았다.
  검사기 경로도 이 받침을 지난다(구조 150 → 흰 받침(흰색) → 검정 판 134 → 칠한 유령판(흰색) → 검정 판 114).

### 무한 리스폰 — 칠한 유령판 위에 자동 안전지점이 저장됐다
- 원인: 자동 안전지점(`_안전점_갱신`)은 "발밑에 땅 0.45초" 만 봤다 → **칠한 유령판 위**가 저장됨 → 죽으면 물감이 전부 회수되어 유령판이 다시 투명 →
  부활 자리가 허공 → 가시로 떨어져 사망 → 같은 자리 부활 …
- 수정(`scripts/스마트월드/월드.gd`):
  - **쳅터1 은 체크포인트를 안 켰으면 입구에서 부활**(`_입구_부활` · export `체크포인트_없으면_입구` · 쳅터1 씬은 경로로 자동 켬). 자동 안전지점을 안 쓴다.
    입구 = 이번에 들어온 길목 안쪽(연결구 `안쪽_위치`) · 직접 실행이면 시작 자리. 부활하면 몸을 **입구 바닥 색**(구조 = 검정)으로 맞춘다.
  - 연결구로 도착할 때도 바닥 색으로 맞춘다(공중으로 길목을 넘어온 흰 몸이 도착하자마자 죽지 않게 · 한 물리 프레임 뒤에 읽는다).
  - 다른 챕터도: **칠해서 굳힌 유령판 위는 자동 안전지점이 아니다**(`_유령판_위인가`).
- 시험: `tools/시험_구조색_입구부활.gd` 17/0.
