# 부드러운 기본 발걸음과 애니메이션 연동

- 요청: 제공한 두 음원 중 챕터 1 집과 챕터 2 하수도에 공통으로 어울리는 소리를 골라 발걸음에 맞춰 적용.
- 선택: `One_isolated,_gentle_#1-1791611523481.mp3`. 음원 분석에서 #3은 저음 중심의 긴 타격(약 0.44초), #1은 짧은 접촉음(약 0.27초)으로 나타났다. 실제 청취에 의한 비교라고 단정하지 않는다.
- `tools/생성_부드러운_발걸음.py`로 원본의 앞 무음 약 1.079초를 제거하고 모노 Vorbis `assets/audio/sfx/걷기_부드러운.ogg`를 만들었다. 짧은 시작/끝 페이드와 최대치 0.5로 부드럽게 조정한다. 원본에서 매번 다시 계산하므로 변환을 반복해도 변화가 누적되지 않는다.
- `scripts/플레이어_효과음.gd`에서 새 음원을 우선 사용한다. 기본 걸음은 일정 시간 타이머 대신 `CharacterSprite.frame_changed`에 연결했다. 부츠 시트를 확인해 0부터 세는 6·14번 디딤 프레임을 사용한다. 현재 16프레임/20fps에서 양발 사이 간격은 0.4초다.
- 바닥 접촉, 실제 수평 이동, 걷기 애니메이션일 때만 재생한다. 공중·정지·사격 모션과 리스폰 직후에는 기본 발소리를 내지 않는다. 음정과 음량 변화 폭을 줄여 선택한 질감을 유지한다. 스프라이트 없는 옛 씬은 기존 시간 간격을 사용한다.
- 하수도 물속 발소리는 기존 물소리 담당 코드가 계속 재생하며 기본 발소리와 중복하지 않는다.

## 확인

- GDScript 정적 문법 파싱 통과. 실제 Godot 타입 검사나 실행 검증을 대신하지 않는다.
- 출력: 48kHz 모노 Vorbis, 약 0.270초, 디코딩 최대치 약 0.488. 무한값/클리핑 없음. 가장 느린 음정에서도 다음 0.4초 발 디딤 전에 끝난다.
- 동일 원본 재변환 후 디코딩 샘플 일치 확인.
- `git diff --check` 통과. 다른 기존 파일의 CRLF 안내만 있었다.
- Godot 실행과 검사 13개는 사용자 명시적 실행 허용이 없어 미실행. 실제 게임에서의 청취·동기화 검증은 대기 상태다.
- 작업 시작 시 `git pull`은 기존 로컬 BGM 변경과 원격 변경이 겹쳐 병합을 중단했다. 로컬 작업과 다른 사용자 파일을 보존했다.
- 흑백 걷기 리소스 모두 16프레임/20fps이며 디딤 프레임 6·14가 유효한 것을 확인했다.
- `graphify update .` 완료: 34,981 노드, 117,222 관계. 그래프 JSON과 보고서를 갱신했고, HTML 시각화는 그래프 크기 제한으로 생략됐다.
