### 폴더 규칙 (팀 합의용 제안)
- **스테이지 추가**: `scenes/world_1/stage_N/stage_N.tscn` — 지형은 `terrain_tileset.tres`로 찍는다.
- **장애물 추가**: `obstacle_template.tscn`을 `scenes/obstacles/이름.tscn`으로 복제 →
  Sprite2D에 디자이너 이미지, 스크립트 슬롯에 프로그래머 코드 부착 → 스테이지 씬에 인스턴스로 배치.
- **타일 이미지**: `assets/textures/tiles/`에 넣고, `terrain_tileset.tres`에 아틀라스로 등록.
- **문서**: 루트에 두지 말고 `docs/`에.

## ⚠ 충돌 났을 때 확인 순서 (팀원용)

1. 충돌 난 파일이 `.tscn`이면 → Godot을 **끄고** 해결할 것 (에디터가 파일을 다시 써버림).
2. `stage_*.tscn` 충돌 → 이 파일 최신 로그에서 도형이 그 스테이지를 건드렸는지 확인.
3. `scripts/*.gd` 충돌 → 도형은 원칙적으로 스크립트를 수정하지 않음(수정 시 이 파일에 기록됨).
   기록이 없으면 프로그래머끼리의 충돌.
4. 해결 기준: **씬 배치·지형 = 도형 버전 / 스크립트 로직 = 프로그래머 버전**이 기본.
5. 판단이 어려우면 그대로 두고 팀 채팅에 파일명 + 충돌 부분 스크린샷 공유.
