# 보행 무릎 굽힘 제거·앞뒤 교대 유지

- 사용자 피드백: 인게임에서 오리걸음처럼 무릎을 굽히고 걷는다. 요청 의도는 뒷발이 고정되는 느낌을 없애고 두 다리가 앞뒤로 움직이게 하는 것.
- 원인: 앞선 보행은 짧은 골반~발목 거리에도 두 뼈 길이 46+52 원화 px를 유지하는 IK를 사용했다. 남는 길이를 무릎의 전방 굽힘으로 흡수해 접지 중에도 깊게 접힌 자세가 나왔다. 회수 발 들기 28px와 몸 상하 이동도 과했다.

## 수정

- `scripts/플레이어_양발보행.gd`: IK 무릎 돌출 계산 제거. 골반~발목 직선의 48% 위치에 무릎을 놓아 허벅지·종아리가 같은 방향으로 펴지도록 변경.
- 두 다리의 반 주기 교대와 앞뒤 이동은 유지. 각 발목의 원화 x 이동 범위 278~362px.
- 회수 발 높이 28 → 6 원화 px. 과한 다리 들기 제거.
- 몸 상하 움직임 4 → 0px. 골반·상체 높이를 낮추거나 들썩이지 않게 고정.
- `scripts/paint_head_anim.gd`: 상체 보행 셰이더 이동값 0으로 고정.
- `tools/검토_양발보행_정적.py`: 수정된 펴진 다리 계산으로 검토 그림 갱신.
- 이동·점프·충돌·색 판정과 원본 PNG 유지.

## 확인

- 흑백 각 다리 257개 위상에서 허벅지·종아리 방향이 일치하는지 확인(dot > 0.999999).
- 몸 높이 이동값 0, 발목 좌표 유한, 각 다리 앞뒤 이동 폭 83px 초과 확인.
- 수정 GDScript 2개와 Python 검토 도구 정적 문법 검사 통과.
- `docs/visual_review/player_walk_20261012/펴진다리_주요자세.png` 직접 열어 흑백 각 4 자세 확인.
- 이전 굽힌 자세 PNG·GIF는 `무릎굽힘_수정전_` 이름으로 보존.
- `docs/visual_review/player_walk_20261012/걷기_무릎펴기_전후.gif`는 엔진 밖에서 느리게 재생한 원화 모션 비교이며 실제 게임 캡처가 아님.
- `graphify update .` 실행 완료. 기존 그래프 축소 보호로 graph.json 덮어쓰기는 거부되어 강제 축소하지 않음.
- Godot·엔진 검사 13개 미실행. 사용자가 인게임 결과를 보고했지만 assistant의 Godot 실행을 명시적으로 요청한 것은 아니므로 기존 실행 안전 규칙 유지.
- 실제 엔진 캡처 경로 없음. **수정 완료·인게임 시각 검증 대기**.
