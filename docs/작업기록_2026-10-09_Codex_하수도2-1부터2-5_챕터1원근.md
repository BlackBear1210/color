- `하수도_자연발판.gd`의 `챕터1_원근`은 기본 false. 해당 다섯 씬의 지형에서만 true를 저장했다. 새 스테이지에서도 같은 프리팹의 설정을 true로 선택한다.
- `하수도_원근마감.gd`는 챕터1 덮개 기하를 재사용. 뒤→앞으로 오른쪽 아래(18/22) 방향, 윗면 -4…18px, 왼쪽 단면 18px, 오른쪽 마감 3px. 기존 작은 모따기는 그림용 복사본에서만 정리해 새 큰 사선과 이중으로 겹치지 않게 했다.
- `목재_상판메시.gd`에 선택적 돌 폭/면 표시/침수 옵션을 추가했다. 기존 목재 호출은 기본값을 유지한다. 돌은 기존 약47px 간격, 목재는 기존 64px 간격이다.
- 셰이더는 기존 하수도 돌 원화의 여러 블록을 샘플링한다. 나무 텍스처·판자 결은 추가하지 않았다. 기존 흑백 변환을 유지하며 앞면 텍스처/UV는 그대로다. 투영 좌표는 정규화한 별도 정점 채널에 넣어 기존 페인트/유령 UV와 분리했다.
- 기존 침수 차집합과 금속 매립 접합 설정을 유지했다. 새 마감에 owner를 부여하거나 저장하지 않는다. 서명이 바뀔 때만 재생성한다.
- 발/체크포인트 그림만 +7px로 정렬하며 플레이어의 몸·물리·충돌은 옮기지 않는다.
- 2-4의 붕괴 4개는 기존 로직을 복사한 `하수도_붕괴발판.gd`에서 하수도 표시를 상속한다. 점멸/소멸 알파를 새 덮개에도 반영한다. 원본 `SS2D_붕괴발판.gd`는 변경하지 않았다. 붕괴 로직을 향후 수정하면 두 파일을 함께 맞춰야 한다.
- 2-1에 이전 작업부터 있던 `[editable]` 뒤 노드 선언을 정리했다. editable 지정을 삭제하지 않고 파일 끝으로 이동했다.
- `tools/apply_sewer_chapter_perspective.py`는 다섯 씬의 표시 설정만 멱등 적용한다. 씬 전체 빌더를 돌리지 않는다.
