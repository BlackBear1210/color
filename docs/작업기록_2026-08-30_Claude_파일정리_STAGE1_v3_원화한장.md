### 3-2. 지형 — 레벨검사가 세 번 구조를 되돌려 세웠다

#### ① 간격 180 → **150**

`레벨검사` 는 표면을 격자로 훑어서 **설계 간격에 최대 +44 를 얹어** 잰다
(설계 180 → 실측 **224**, 한계 204 초과 → 선반 도달 불가).
→ 설계 간격을 **150** 으로. 실측 ~194 로 한계 안에 들어온다.

#### ② 가구 사이 틈이 "바닥까지 뚫린 우물" 이 됐다 (규칙 2)

가구를 전부 바닥에 박힌 **따로따로의 덩어리**로 두고 150 씩 띄웠더니
그 틈이 폭 150 짜리 우물이 되어 빠지면 못 나왔다(**3 곳**).

→ **높이에 따라 두 가지 방식으로 나눠 지었다.**

```
① 낮은 구간(−110 … −440)  한 덩어리 + 얕은 홈
   홈 바닥이 양옆보다 110 아래 → 빠져도 스스로 걸어 나온다
   홈 폭 150 → 뛰어 건널 수도 있다 = 실패해도 손해가 없는 첫 점프
② 높은 구간(−550 … −770)  전부 공중 발판
   아랫면을 −390 위로 올려 바닥이 통째로 뚫려 있게 한다
   떨어지면 그냥 바닥 → 걸어서 되돌아가 다시 오른다. 우물이 생길 자리가 없다
```

#### ③ 가구 덩어리가 **바닥을 좌우로 갈랐다**

바닥에 박힌 덩어리(620~3200)는 바닥 표면을 막는다. 그 오른쪽으로 떨어지면
왼쪽이 440 벽이라 못 올라왔다("바닥 x3228~5244 · 갈 수 있는 곳이 하나도 없다").

→ 덩어리 오른쪽 끝을 **바닥까지 내려오는 계단 3 단**(−330 / −220 / −110)으로 늘렸다.
  ⚠ 이 계단은 창턱 발판(3350~3690 · 아랫면 −390) **밑을 지난다.**
    −220 단 위 머리공간 170(실효 122 > 96) · −110 단 위 280(실효 232) ✔

→ **창빛은 연출로만 남긴다.** 색 퍼즐 본격 도입은 마스터플랜대로 **STAGE 3** 이다.

## 6. ⚠ 작업 중 사고 — 외부에서 `git reset --hard` 가 돌았다

커밋 직전에 이 세션 **밖에서** 저장소가 초기화됐다.

```
reflog
  HEAD@{2}  commit: Update 스테이지_1_2층방.tscn   ← 작업 시작 지점
  HEAD@{1}  reset: moving to HEAD                  ← ★여기서 커밋 안 한 변경 392 개가 사라짐
  HEAD@{0}  pull --ff origin: Fast-forward         → f86cd47
```

CLAUDE.md 규칙대로 `reset --hard` 나 `clean -fd` 는 쓰지 않았다. 스크래치패드에
빌더 조각을 남겨 둔 덕분에 전부 복구했지만, **한 시간 분량이 날아갈 뻔했다.**

**교훈: 큰 삭제는 한 덩어리로 모아 두지 말고 단계마다 커밋한다.**
같은 저장소에서 두 사람이 동시에 일할 때는 특히 그렇다.
