# 작업기록 — 2026-10-08 Codex 삼색 물 프레임과 배관 적용

## 적용 범위와 방식
- 사용자 제공 힉스필드 원본 2장을 기준으로 world_2_클로드 스테이지 2-1~2-4의 물 40개에 적용했다. 승인 원본은 visual_review/water_reference_20261008/source_water.png 및 source_outlet.png에 보관했다.
- 흰색·회색·검정 각각 48프레임, 24fps, 2초 반복. 제공된 정지 이미지의 질감을 아래로 이동시켜 프레임을 만들었으며, 새 힉스필드 영상 생성은 하지 않았다.
- 넓은 물과 좁은 물은 서로 다른 원본 질감으로 구성했다. 물막은 불투명도를 유지하고 가장자리는 폭에 맞춘 완만한 굴곡, 옆 물방울은 양쪽에 드문 간격으로 낙하한다. 넓은 물의 빈틈은 작고 짧게 제한했다.
- 바닥 물은 물막 폭의 120%로 제한했고, 기존 힉스필드 착수 프레임을 약하게 합성했다.
- 독립 낙수 13곳에 정면 원형 배관 또는 넓은 물받이를 배치했다. 호퍼 입구 배관, 호퍼 출구 구조, 밸브·탱크 연결 배관을 보존했다. 2-3은 호퍼 장치이므로 기존 배관 구조 전체를 유지했다.
- 충돌 크기, 기존 물 위치, 색 판정, 호퍼 연결 규칙은 변경하지 않았다. 적용 플래그는 해당 4개 씬에만 켰다.

## 주요 파일
- scripts/스마트월드/유체_흰물v2.gd: 해당 씬에만 새 시각 노드를 연결.
- scripts/스마트월드/물_힉스필드_삼색프레임.gd 및 shaders/water_reference_frames.gdshader: 삼색 프레임, 흐름, 가장자리, 물방울, 착수 표현.
- scripts/스마트월드/물_힉스필드_출수구.gd: 원형 배관과 물받이. 색이 교대되는 같은 위치의 물도 현재 활성 물색을 따른다.
- assets/textures/obstacles/liquid/reference_20261008/: 좁은/넓은 물의 삼색 프레임과 배관 부품.
- tools/build_reference_water_frames.py, apply_reference_water.py: 원본 기반 재생성 및 중복 적용 방지.
- tools/capture_water_reference.gd, test_reference_water.gd, export_water_review.py: 실제 엔진 비교와 움직임 확인.

## 실제 엔진 검증
- Godot 4.6.3-stable, OpenGL Compatibility, 1920×1080, 줌 1.0으로 네 스테이지 적용 전후 PNG를 확보하고 직접 확인했다. 원본 씬 스냅샷을 별도로 보관해 전후 재캡처 시 섞이지 않게 했다.
- 실제 캡처: docs/visual_review/water_reference_20261008/stage_2-1_before.png 및 stage_2-1_after.png. 같은 이름 규칙으로 2-2, 2-3, 2-4도 보관했다.
- 추가 배관 확인: stage_2-4_detail.png.
- 실제 엔진 48프레임: motion/00.png~47.png. 실제 움직임 미리보기: actual_game_motion.webp. 이 파일은 생성형 시안이 아니라 엔진 렌더를 묶은 것이다.
- 전용 검사: 40개 시각 노드 로드와 크기 보존, 삼색 전환, 꺼짐/켜짐과 흐름 경계 검사 오류 0.
- 기존 관련 검사: 꺼진 물 총알 통과 8개, 호퍼 10개, 밸브 세 상태 7개 통과(실패 0).
- 정적 확인: 기존 노드의 위치·크기·호퍼 연결을 보존했고, 셰이더에 한글이 없으며, 삼색 프레임 크기를 확인했다. git 상태에서 삭제된 파일은 없다.

## 남은 차이와 검증 한계
- 시안의 정지 이미지를 프레임과 셰이더로 움직인 구현이다. 새 유체 시뮬레이션이나 생성된 유체 영상과 동일하다고 주장하지 않는다. 넓은 물받이는 기존 스테이지 공간에 맞춰 세로 높이를 줄였다.
- 물에 진입/물 안 이동/재진입/리스폰을 플레이어 입력으로 연속 확인하는 전체 상호작용 검증은 수행하지 않았다.
- AGENTS.md가 지정한 docs/다음작업_프롬프트.md가 저장소에 없어 명령을 확인할 수 없었다. 따라서 지정된 전체 검사 13개는 미실행으로 보고하며, 위 관련 검사와 전용 검사만 통과했다.
- 적용 전후 공통으로 기존 인스턴스의 ColorRect 소실 경고와 한글 고아 노드 이름 출력 관련 메시지가 있었다. 이번 물 셰이더나 전용 검사의 오류는 없었다.
- graphify update .를 실행했다. 노드 수 감소에 따른 덮어쓰기 보호 경고가 있어 강제 갱신하지 않았다. 그래프 전체 갱신이 보장됐다고 보고하지 않는다.
- 작업 전부터 수정돼 있던 흰물_디자인.gd, water_stream_natural.gdshader 및 기존 미추적 파일을 되돌리지 않았다.
