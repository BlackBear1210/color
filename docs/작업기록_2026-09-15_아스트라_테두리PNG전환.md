# 하수도 테두리 PNG 전환 및 다층배경 정적 점검

## 수정 이유와 범위

SS2D가 AtlasTexture의 RID를 직접 사용하면서 편집기에 원본 아틀라스 전체가 표시되는 문제를 해결하기 위해, 기존 top/side/corner의 region 픽셀을 독립 PNG로 무손실 추출했다. 검정·흰색 각 3장, 총 6장이다. 새 아트를 그린 것이 아니라 기존에 의도한 조각을 실제 파일로 분리한 수정이다.

`assets/textures/smartshape/sewer_masonry_v01/masonry_black.tres`와 `masonry_white.tres`의 세 외부 참조를 해당 PNG로 전환했다. 기존 AtlasTexture .tres와 원본 이미지는 보존했다. 두 재질을 사용하는 발판은 크기와 상관없이 변경된 텍스처를 참조한다.

top=284×53, side=278×49, corner=56×56. texture_scale=0.16과 기존 offset을 보존하여 외형 크기나 충돌 범위를 이번 수정으로 바꾸지 않았다. 별도의 10~12px 벽돌 옆면 아트 재디자인은 아직 하지 않았다.

부모 지형.gd의 _짝_찾기는 black/white 폴더의 같은 PNG 파일명을 지원하므로 페인트 짝 찾기를 별도로 수정하지 않았다. 런타임 Atlas 변환 함수는 fill.tres 등 다른 Atlas 리소스에 필요해 유지했다.

## 배경 점검

`scenes/배경/하수도_다층배경_v02.tscn`의 이미지 4장과 셰이더 참조를 확인했다. 반복 크기는 각 원본 크기×Sprite2D 배율과 일치한다. 각 층은 독립 Parallax2D이며 음수 Z로 구성돼 있다.

셰이더의 fragment COLOR에는 텍스처 샘플이 포함되므로, 이를 다시 곱하면 색과 알파가 중복 적용될 수 있었다. vertex에서 modulation만 전달하도록 수정했다. 셰이더의 한글 금지 규약 때문에 코드 주석은 영어로, 수정 이유는 이 문서에 한글로 기록한다.

## 확인 범위

6개 PNG의 픽셀이 원래 Atlas region과 동일함을 확인했다. 흑백 크기 일치, 외부 파일 존재, edge의 Atlas 참조 제거, 반복 크기를 정적으로 확인했다. Godot 편집기·실행·132개 색칠사망 검사·화면 캡처는 미실행이다. 정적 확인을 플레이 검증이나 시각 검증 완료로 간주하지 않는다.

다음 실행 검증에서는 흑백 얇은/두꺼운/경사 발판을 줌 1.0과 확대 상태로 보고, 칠하기·회수·반대색 접촉을 확인한다. 배경은 카메라 양축 이동과 반복 경계, 2-10/2-11 범위 끝에서 빈틈을 확인해야 한다.
