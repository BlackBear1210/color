# 격자 반짝임 및 렌더링 비용 감소

- 통과플랫폼에 unshaded CanvasItemMaterial을 적용해 움직이는 광원이 격자의 고정 흑백 명도를 바꾸지 않게 했다.
- 격자 atlas의 mipmap 생성을 켜고 LINEAR_WITH_MIPMAPS 필터를 사용한다. 얇은 선을 축소하며 발생하는 이동 중 앨리어싱을 줄이는 목적이다. Godot의 다음 자동 재임포트가 필요하다.
- 하수도 지형 근접 반사를 기본 0으로 변경했다. 비활성 상태에서는 플레이어 검색, 경계 계산, 초당 30회 반사 광선 검사와 유니폼 업로드에 진입하지 않는다. 씬의 명시적 반사 세기 override는 검색 결과 없었다.
- 배경 이음새 셰이더는 가장자리에서만 추가 텍스처를 샘플링한다. 내부는 4회 대신 1회이며 기존 이음새 혼합식과 명도는 유지한다.
- 지형의 색 판정·충돌·물 통과·칠하기 금지 및 부모의 물감 처리 코드는 변경하지 않았다.
- git diff --check 통과, 셰이더 한글 없음 확인. graphify query/update는 출력 없이 실패했다.
- Godot은 안전 규칙에 따라 실행하지 않았다. FPS와 실제 반짝임 개선은 측정하지 않았으며 이것만으로 전체 프레임 드롭의 원인을 확정하지 않는다.
