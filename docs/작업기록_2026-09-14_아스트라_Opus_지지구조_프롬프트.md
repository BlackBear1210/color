# Opus용 하수도 지지구조 프롬프트

- 사용자 요청: 쇠사슬·삼각 지지대를 Claude Opus가 구현하도록 목적·동작·사용·관리까지 상세한 프롬프트 작성.
- 작성 파일: `scenes/world_2_클로드/프롬프트_Opus_쇠사슬_삼각지지대_장식키트.md`.
- 참고 이미지: 사용자 첨부 원본을 같은 폴더 `참고_쇠사슬_삼각지지대.png`로 복사했다. 이미지 픽셀은 수정하지 않았다.
- 기존 움직이는발판 씬의 AnimatableBody2D 구조와 스크립트 공개 이동 속성을 확인했다. 기존 SS2D 안내와 경로도 참조했다.
- 문서에는 장식 전용 범위, 정적/동적 체인, 반복 위상, 좌표계, 부모 구성, 브래킷 고정 의미, 색·충돌 경계, 아트 제작, 에디터 설정, 예외/성능, 시험 씬, 20개 검사 항목, 버그 판정, 사용 절차와 유지보수를 포함했다.
- 현재 작업은 문서/참고자료 작성이다. 장식 코드·에셋은 아직 구현하지 않았고 Godot도 실행하지 않았다. 과거 SS2D132개 통과가 이번 장식 검증이 아님을 명시했다.
- graphify 그래프 파일이 없어 소스와 문서를 직접 확인했다. 코드 변경이 없어 그래프 갱신은 수행하지 않았다.
- 경로/문서 구조 정적 확인과 git diff --check 수행. 커밋·푸시·Opus에게 메시지 전송은 하지 않았다.
