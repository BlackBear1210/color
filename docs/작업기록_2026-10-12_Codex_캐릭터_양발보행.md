# 캐릭터 원화 분석·양발 보행 적용

- 날짜: 2026-10-12
- 요청: 현재 스프라이트를 분석하고 한 발로 미끄러지는 듯한 걷기를 두 발이 자연스럽게 교대하는 모션으로 수정.
- 상태: **수정 완료·실제 게임 시각 검증 대기**.

## 원인 분석

현재 `assets/characters/paint_head_a/{black,white}_walk.png`는 640px 프레임 16개로 구성되며, 움직임의 상당 부분에서 같은 쪽 부츠가 뒤에 남고 반대쪽 부츠가 앞에서 흔들린다. 두 다리의 체중 지지·회수·앞으로 통과하는 자세가 명확하게 교대하지 않아 한쪽 발을 끌거나 미끄러지는 인상을 준다.

현재 리소스는 20fps 시간 기반 재생이고 이동은 별도 고정 속도다. 발 디딤 박자와 이동량이 직접 연결되어 있지 않았다. 원본 정리 과정도 매 프레임 전체 실루엣의 중심을 사용했다. 흰색 시트의 원본 x 오프셋은 9~53px로 변해 같은 크기의 머리·몸이 수평으로 흔들릴 여지가 있다.

생성형 걷기 시트 편집을 시도하고 직접 확인했지만 두 다리의 역할 교대가 충분히 명확하지 않았다. 해당 결과는 게임에 적용하지 않았다. 외형을 보존하면서 교대를 확정할 수 있도록 원본 첫 포즈의 다리를 분리해 메시 관절 보행으로 연결했다. 원본 PNG·manifest·탱크 좌표·SpriteFrames는 변경하지 않았다.

## 적용

- `scripts/플레이어_양발보행.gd`: 흑백 원본 첫 포즈의 각 다리 영역을 작은 메시 격자로 나누고 골반·무릎·발목·부츠의 움직임으로 재배치.
- 한 발이 접지하는 동안 반대 발이 무릎을 굽혀 들린 뒤 앞으로 통과. 두 다리는 반 주기 차이로 교대.
- 뒤꿈치 접촉 → 발바닥 지지 → 발끝 밀기 → 발 들어 올리기 → 다음 뒤꿈치 접촉.
- 부츠는 단단한 원화 형태를 유지하고 바지 폭은 관절 길이 변화로 부풀지 않도록 보정. 초기 검토에서 발끝이 찢어지는 변형을 발견해 격자 간격과 부츠 가중치를 수정.
- 접지·공중 회수 경계와 루프 경계에서 발목 높이·위치가 연속하도록 받침점·발각을 보간.
- 상체는 기존 첫 포즈를 유지하면서 두 걸음에 맞춰 작게 상하 이동. 코트와 다리가 만나는 윗줄도 함께 움직이며 발 받침점은 지면에 유지.
- 다리 뒤/앞 그리기 순서를 고정하고 좌우 반전을 본체와 일치시킴.
- `scripts/paint_head_anim.gd`: 걷기 동안만 관절 모션을 켜고 실제 수평 이동량으로 위상 진행. 기본 한 바퀴 거리 140 월드 px는 실제 게임에서 보폭·템포를 비교할 초기값. 리스폰·통로 순간이동의 큰 이동량은 제외.
- `scripts/플레이어_효과음.gd`: 원본 프레임 번호 대신 양발 접촉 신호로 걷기 소리 재생. 기존 시트 캐릭터는 종전 방식 유지. 물·벽 막힘·공중·리스폰 억제 조건 유지.
- `shaders/paint_head.gdshader`: 걷기 동안 원본 다리 부분만 숨기고 상체의 작은 높이 이동을 적용. 새 다리에도 기존 색 경계·물속 픽셀 가림 uniform을 전달. 셰이더는 ASCII 유지.
- 점프·발사·밀기·사망으로 바뀌면 관절 다리를 숨기고 기존 원본 시트 전체 표시를 복원.
- 원래 Player 이동 속도·점프 계산·충돌체·색 접촉 판정은 수정하지 않음.

## 검토·검사

- 원본 흑백 시트와 발 부분 확대를 직접 열어 확인.
- 새 관절 모션의 32 자세를 엔진 밖에서 같은 원화 UV로 렌더. 주요 4 자세를 직접 열어 발 교대·부츠 형태 확인.
- 원본 걷기 PNG가 백업과 SHA-256 일치.
- 다리 UV 영역이 절단선 아래 불투명 원화 픽셀을 100% 포함하는지 확인. 초기 윤곽의 누락 픽셀을 발견해 투명 배경이 포함된 두 영역으로 수정.
- 흑백 각 다리의 1001 위상에서 골반·무릎·발목 좌표가 유한한지 확인.
- 발끝 이륙·루프 전후의 발목 위치 차이가 수치상 0.01 원화 px 미만인지 확인.
- 변경 GDScript 3개 및 정적 검토 도구 문법 검사 통과. 엔진 타입 검사·실행 확인은 아님.
- 색 경계·수중 가림 uniform 이름을 셰이더 선언과 대조해 연결 확인.
- `git diff --check` 통과.
- 기존 수정 파일 보존. 기존 pull은 미추적 `.png.import`와 원격 파일이 겹쳐 중단된 상태이며 임의 삭제·이동으로 해소하지 않음.
- `graphify update .` 실행. 기존 graph.json보다 추출 노드 수가 작아 축소 보호 장치가 JSON 덮어쓰기를 거부했으며 강제 축소하지 않음.
- `docs/다음작업_프롬프트.md`는 현재 체크아웃에서 찾을 수 없음.
- Godot·엔진 검사 13개·빌드·게임 촬영 미실행: 사용자 명시적 실행 허용 없음.
