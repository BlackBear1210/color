1. 위 명령으로 **통과하는 씨앗을 고른다** (5 개에 3 초. 아무것도 안 만든다)
2. 마음에 드는 씨앗으로 씬을 굽는다 → `--씨앗=1003`

4. 그 다음에야 `--적용` 으로 실제 스테이지에 넣는다

| 규칙 | 이유 |
|---|---|
| **같은 씨앗 = 같은 맵** | 버그 재현·맵 공유. 씨앗은 씬 메타(`gen_seed`)와 옆 `.json` 에 남는다 |
| **생성기는 두 번 돌리지 않는다** | 에디터에서 손본 것이 전부 날아간다 (CLAUDE.md §4 와 같은 이유) |
| **`--적용` 은 `.bak.tscn` 을 만든다** | 그래도 그 전에 커밋할 것 |
| **검증을 통과 못 한 씨앗은 굽지 않는다** | 생성기가 알아서 버린다. 사람이 판단할 일이 아니다 |
| **판정선에 딱 맞춰 만들지 않는다** | 틈 ≤ 224(판정 272) · 상승 ≤ 112(판정 128). 실측은 설계값과 몇 px 다르다 |

# ■ 청크 10 종 — 이 게임에서 "한 상황" 이란

청크는 발판 하나가 아니라 **[출발 → 점프 → (조준·사격) → 착지]** 한 묶음이다.
그래서 청크는 **이미 풀 수 있는 상태로 태어난다.** 검증기는 보증이지 설계자가 아니다.

| 종류 | 이름 | 무엇을 하나 | 난이도 |
|---|---|---|---|
| A | 기본 이동 | 같은 높이로 한 번 뛴다 | 1 |
| B | 상승 | 한 층 올라간다 (112 px) | 2 |
| C | 하강 | 한 층 내려간다 | 1 |
| D | **색 반전** | 구간 색이 바뀐다 — 공중에서 색을 바꿔 착지 | 2 |
| E | **공중 사격** | 유령 발판을 쏴서 만들어야 건넌다 | 3 |
| F | **시야(LoS)** | 기둥이 막아서 — 위로 올라가야 쏠 수 있다 | 4 |
| G | 수직 | 지그재그 사다리 3 단 | 3 |
| H | 위험 | 가시를 한 번에 넘는다 | 3 |
| I | **복합** | 색 전환 + 유령 칠하기 | 5 |
| J | 휴식 | 긴 평지. 어려운 청크 뒤 숨 돌릴 자리 | 0 |

## 난이도 곡선 (구간표 · `생성기.gd _구간표()`)

```
도입(10%) → 이동(15%) → 색(18%) → 사격(18%) → 시야(15%) → 복합(17%) → 마무리(7%)
  A A J      B C         D D        E E         F G          I H         J A
  └─ `강제` = 그 구간에 반드시 한 번은 나오는 청크. 씨앗 운에 맡기지 않는다
```

# ■ 검증 — 셋을 따로 보는 이유

맵이 망가지는 방식이 셋이고 **원인이 서로 다르다.** 한 함수에 섞으면 왜 실패했는지 안 나온다.

| 검사 | 무엇을 잡나 | 어떻게 |
|---|---|---|
| **도달성** | 점프로 안 닿는다 · 올라서면 못 나온다 | 발판 윗면을 노드로 BFS. `레벨검사.gd` 와 **완전히 같은 잣대** |
| **보행성** | 걷다가 걸린다 | ㉠ 좁은 발판(<128) ㉡ 1~64 px 단차 ㉢ 0~96 px 틈 ㉣ 머리 위 160 미만 |
| **사격 시야** | 유령 발판을 못 쏜다 | 총알을 **포물선 그대로 시뮬레이션**(탄속 1150·중력 900·1/120 스텝) |

**2 단계로 본다.**
- **생성 중(해석적)** — 청크를 붙일 때마다 그 자리에서. 실패하면 그 청크만 다시 뽑는다(최대 8 번)
- **생성 후(엔진 실측)** — `tools/레벨검사.gd` 로 진짜 물리를 태운다. **이쪽이 최종 권위다**

> ⚠ 해석적 검사는 빠르지만 근사다. 실제로 이것 때문에 한 번 크게 틀렸다 —
> 생성기는 "도달률 100 %" 라 했는데 `레벨검사` 는 "30 개 중 6 개" 라고 했다.
> 원인은 내려가는 점프에 거리 보너스를 준 것이었다(`레벨검사` 는 방향을 안 본다).
> **두 검사기가 다른 말을 하면 생성기는 쓸모가 없다.** 항상 엄격한 쪽에 맞춘다.

`설정.gd` 의 `하수도()` 가 이미 있다. **씨앗 3 개를 뽑아 `레벨검사` 까지 통과하는 것은 확인했다**(2026-09-20 · s2002 = 밟는 지형 28/28 도달). 다만 하수도 고유의 물·호퍼·배관은 아직 안 놓는다 — 지형과 유령 발판까지다.


## 새 챕터(도시 등)를 추가하는 법 — 3 분

1. `설정.gd` 의 `하수도()` 를 복사해 `도시()` 를 만든다
2. 바꾸는 것은 **데이터뿐**:
   ```gdscript
   c.지형_템플릿_검 = "res://scenes/지형/도시/도시_기본지형_검정.tscn"
   c.지형_템플릿_흰 = "res://scenes/지형/도시/도시_기본지형_흰색.tscn"
   c.유령_템플릿   = ""            # 없으면 기본 지형에 `무색일때_통과` 를 켜서 쓴다
   c.층_간격 = 112.0               # ★규격.설계_최대상승 을 넘기지 말 것
   c.최대_층 = 4
   c.청크_가중치 = { "A": 14, ... } # 그 챕터에 어울리는 청크를 올린다
   ```
3. `이름으로()` 의 match 에 `"도시": return 도시()` 한 줄 추가
4. **기하 규칙은 건드릴 필요가 없다** — 격자 16 · 변 90 · 점프 도달성은 `규격.gd` 가 강제한다

# ■ 새 장애물·기믹 추가 (생성기를 안 고치고)

`설정.gd` 의 `위험물` 표에 **줄만 추가**하면 H(위험) 청크가 그걸 꺼내 쓴다.

```gdscript
c.위험물 = {
    "가시":   {"씬": "res://scenes/장애물/가시.tscn",   "폭": 64.0, "높이": 48.0},
    "회전톱": {"씬": "res://scenes/장애물/회전톱.tscn", "폭": 96.0, "높이": 96.0},
}
```

## 새 **청크 종류**를 추가하려면 (기믹이 새 플레이 상황을 만들 때)

1. `청크.gd` 에 `_청크_XX()` 함수를 하나 만든다 (기존 것을 복사)
2. `만들기()` 의 match 에 한 줄
3. `설정.gd` 의 `청크_가중치` 에 그 글자
4. 필요하면 `생성기.gd _구간표()` 의 `강제`·`허용` 에 넣는다

**청크가 지켜야 할 계약은 딱 하나 — 출구 좌표(`출구`: x, y, 색, 층)를 정확히 돌려줄 것.**
나머지(잇기·검사·재시도·씬 굽기)는 생성기가 알아서 한다.

기믹이 "쏴서 열어야 하는 것" 이면 `사격` 배열에 `{자리, 목표, 대상}` 을 넣어라.
그래야 **포물선이 실제로 닿는지** 검증기가 봐 준다. 안 넣으면 검사에서 빠진다.
