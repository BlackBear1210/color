# 2-9 방 연결형 전면 재구축

사용자가 두 번째 이미지의 구역 연결 구조와 왕복 방향 전환을 승인하여, 기존 3층 복도를 새 씬으로 교체했다. 직전 씬/설계 문서는 `scenes/world_2_클로드/보관/stage29_재구축전_2026-09-23/`에 해시별 보관했다.

## 결과

입구→상승 갱도→왼쪽 호퍼실→아래 배수로→오른쪽 기계실→승강→왼쪽 상부 통로→상승→오른쪽 출구. 27개 최신 SS2D 지형, 호퍼/밸브/압력 버튼, 두 개의 왕복 톱, 얕은 물받이, 실패 복귀 경로를 배치했다. 연결/색 규칙과 로비 목적지는 기존 코드를 사용한다.

검수 중 승강기 직접 점프를 줄이도록 기계실 바닥을64px 줄였다. 외곽 최하단에서 갇히지 않도록 복귀 선반을 추가했고 출구를 가로막지 않도록 외벽 상하를 분리했다.

## 검증

기존 참조/선언순서/연결 검사에 새 맵 조건을 추가해 통과. 새 정적 검사는 실제 저장 윤곽/충돌27개와 몸통44×96의 보수적 점프 궤적6개, 호퍼 입출구 정렬, 원웨이 상승, 버튼 연결, 수문 경계/출구를 확인한다. 재생성 바이트 동일.

Godot는 안전 규칙에 따라 실행하지 않았다. 실제 로드/화면/호퍼 혼합/승강/톱 회피/색 접촉은 검증되지 않았으며 클리어를 보장하지 않는다. Graphify는 조회와 갱신 모두 출력 없이 종료1.

새 작업 기준은 `scenes/world_2_클로드/작업/stage_2-9_작업.md`. `tools/rebuild_stage29_rooms.py --apply`는 승인된 재구축용으로 작성했으며 향후 수동 편집 후 자동 재실행하지 않는다. 이전 개편 배치도 링크는 새 배치도로 갱신했다.

후속 검수: 상승 격자는 두께16을 제외한 머리 공간112를 확보하도록 간격128로 조정(가로64). 상승용13개/복귀용9개. 128단차는 거리 예산을 확인했으나 실제 점프는 미검증.
