# 배관 지형 접점과 과대 수조 정리

- 요청: 확대 화면에서 배관이 지형 밖에 뜨고, 수조 테두리에 검은 원본 배경이 남으며, 지형보다 큰 문제 수정.
- 첨부 화면에 해당하는 스테이지 2-7의 `흰물_2`: 물 폭 416, 접점 지형 두께 128. 이전 수조는 폭 520, 깊이 223.6이며 물 원점 아래로 약 133 돌출했다.

## 변경

- `물_힉스필드_출수구.gd`: SS2D 점의 실제 가로 단면을 읽어 물 바로 위의 지형 내부 범위를 계산한다. 오목한 지형은 외곽 사각형으로 판단하지 않는다. 원본 점·씬·충돌을 수정하거나 owner를 설정하지 않는다.
- 충분한 두께와 폭을 확보한 곳은 원형 관을 사용하고 관 아랫변을 물 원점에 붙인다. 기존 10% 아래 돌출 제거.
- 얇거나 넓은 출수부는 지형 안에 들어가는 얕은 배수구로 변경. 2-7 큰 낙수의 장식은 폭 428, 깊이 24. 기존 깊은 수조 및 위에 따로 떠 있던 급수관·급수 물줄기 제거.
- 검은 배경과 다리 잔상이 포함된 `catch_joint_basin`/`basin_overflow` 이미지를 렌더링하지 않는다. 테는 기존 원형 관의 금속 내부 영역만 잘라 사용한다. 관 속의 의도적인 어둠은 테 안에 한정한다. PNG 자체는 수정하지 않았다.
- 지형과 직접 닿지 않는 2-1 두 곳과 2-2 한 곳은 기존 연결관을 다시 표시해 공급 경로를 보존한다. 물의 위치·폭·높이·색과 밸브 대상은 수정하지 않았다. 입구 깊이는 실제 배치에 맞춰 기존 출수 앞끝 설정에 전달한다.
- 삼색 물 본체와 입구는 같은 프레임 재질을 공유한다. 1.4배 무늬 시계 유지.
- `test_water_stage25.gd`의 폐기된 수조/급수 자식 검사를 지형 접점·공유 입구 재질·입구 켜짐 검사로 변경. 실행하지 않음.

## 후속 파서 오류 수정

- 사용자 보고: `draw_texture_rect_region()` 첫 인자에 Rect2를 전달해 Godot 파서 오류 발생.
- 두 호출을 `(Texture2D, Rect2, Rect2)` 순서로 수정하고 한글 이유 주석 추가. 기존 gdtoolkit 구문 분석은 엔진 API 인자 타입을 검사하지 않으므로 앞선 구문 통과만으로 이 오류를 발견하지 못했다.
- 저장소의 동일 함수 호출과 대조해 텍스처를 먼저 전달하는 순서 확인. 정적 지형 배치 검사를 다시 실행. Godot 엔진 실행은 명시적 허용이 없어 계속 미실행.
