# 2-9 배경 노멀 및 지형 뒤 그림자

- 현재 게임의 벽돌배경 v04에 약한 노멀맵을 적용했다. 앞서 생성한 작은 벽돌 디자인 이미지는 합성 초안이며 이번 코드 작업에서 배경 원본을 교체한 것은 아니다.
- wall_normal.png/res: 명도 기반 높이 추정, 768x512로 잔무늬를 줄인 뒤 강도0.8로 노멀 생성. 정확한 배관 기하 복원은 아니므로 표면 음영 강도를0.45로 제한했다.
- 고정 상단 좌측 환경광과 노멀의 내적을 기존 1회 배경 캐시에서 계산한다. 실시간 Light2D 추가 없음. 플레이어 조명과 독립적이다.
- 지형 뒤 그림자는 오른쪽10px/아래12px 외곽 띠, 알파0.16에서0으로 감소. 지형별 단일 메시, 움직임/숨김은 부모를 따라가고 점 변경 시만 다시 만든다. 메시 참조는 노드에 유지한다.
- 격자발판의 unshaded, 색/충돌 규칙 유지. 물 디자인 변경 없음.
- 배경 노드의 표면_입체감, 지형_그림자 속성으로 독립 비활성화 가능. measure_sewer_stage29.gd -- --jump --no-depth 비교 지원.

## 검증
사용자가 허용한 Godot4.6.3/Windows 실제 실행, 오류 대화상자 억제. 초기 중복 선언 및 메시 수명 오류를 발견하여 수정했다. 최종 실행은 ERROR/SCRIPT ERROR 없이 완료했다.

1280x720, B격자 구간 점프900프레임:

| 조건 | 중앙ms | p95ms | p99ms | 최대ms |
|---|---:|---:|---:|---:|
|최종 깊이효과 켬|2.656|10.293|11.595|18.051|
|효과 끔 재측정|2.691|10.882|18.530|20.764|

초기 기준은 중앙19.75ms였으나 재측정은2.691ms로 실행 조건 편차가 컸다. 효과를 켜서 더 빨라졌다고 해석하지 않는다. 전체 프레임 최소60FPS 달성이나 전맵 성능은 보장하지 않는다. 최종 스크린샷 확인 완료. 전체 회귀 검사 묶음은 실행하지 않았고 관련 실제 장면 실행과 정적 검사로 검증했다. graphify update는 출력 없이 실패했다.
