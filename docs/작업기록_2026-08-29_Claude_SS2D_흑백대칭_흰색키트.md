# 작업기록 2026-08-29 · SS2D 색 시스템 흑백 대칭화 + 흰색 키트

> 요청(도형/성진):
> *"기준을 ss2d로 잡고 진행하자. (키트 씬 6개) 디자인은 똑같이 진행하되, 흰색버전으로 만들자."*

앞으로 지형은 **타일맵이 아니라 SS2D 키트**로 찍는다. 그 전제 위에서
"같은 디자인의 흰색 버전"을 만들었고, 그 과정에서 **색 시스템이 흑백 대칭이 아니었다는 것**이
드러나 함께 고쳤다.

---

## 1. 무엇이 막고 있었나 (전부 실행해서 확인한 것)

| # | 증상 | 진짜 원인 |
|---|---|---|
| ① | 벽돌 Template 3종이 **칠해도 윗면 테두리가 검정** | `brick_v2_opaque/white/edge_top_thin.png` 이 없음 → 짝을 못 찾으면 `지형.gd` 가 **셰이더를 아예 안 붙였다** |
| ② | 흰 아트를 든 지형은 **칠할 수가 없다** | `_짝_텍스처()` 가 `black → white` **한 방향뿐**. 코드에 "검정이 원본" 이라는 가정이 박혀 있었다 |
| ③ | `벽돌 계단.tscn` · `벽돌 테스.tscn` 은 **칠하기가 없다** | 스크립트가 `지형.gd` 가 아니라 순수 `SS2D_Shape` 였다 |
| ④ | 색을 갖고 태어난 지형이 **죽으면 무색이 된다** | `되돌리기()`·`강제_초기화()` 가 무조건 무색으로 돌렸다 (`시작상태` 를 안 봤다) |

①은 특히 나쁜 종류의 버그다 — **논리는 흰색인데 화면은 검정**이다.
"몸에 닿은 지형이 내 색과 다르면 즉사" 가 규칙인 게임에서 화면이 거짓말을 하면
플레이어는 이유를 모르고 죽는다. `test_사방재질_칠하기.gd` 가 실패 3으로 잡아내고 있었다.

## 2. 고친 것 — 색 시스템을 **흑백 대칭**으로

### `shaders/지형_페인트.gdshader` — 유니폼 두 개
| 유니폼 | 하는 일 |
|---|---|
| `base_is_white` | 이 조각이 **흰 아트를 기본으로 들었다**. 검정/흰색 매핑을 통째로 뒤집는다 |
| `alt_invert` | 짝 파일이 없을 때 `1.0 - base.r` 로 즉석에서 만든다 (안전망) |

`alt_invert` 의 식은 근사가 아니라 `tools/생성_타일셋_파생.gd _반전()` 과 **같은 식**이다.
진짜 짝 파일이 나중에 들어오면 `_짝_찾기()` 가 파일을 먼저 집으므로 저절로 교체된다.

### `scripts/스마트월드/지형.gd`
- `_짝_텍스처()` → **`_짝_찾기()` (양방향)**. 흑→백뿐 아니라 백→흑도 찾고,
  이 조각이 흰 아트인지(`흰색이_기본`)를 같이 돌려준다.
- 파일명 규칙이 넓어졌다. 예전엔 `begins_with("black_")` 만 봐서
  `brick_black_seamless_341x307.png`(벽돌 계단의 채움)이 규칙 밖으로 빠졌다.
  이제 `_` 로 끊어 **정확히 `black`/`white` 인 토막**을 본다.
- **짝이 없어도 셰이더를 붙인다.** 예전엔 null 을 돌려 조각이 원래 색으로 남았다.
- 투명 캐리어(`투명_256.png`)는 계속 건너뛴다 — 화면에 안 나오므로 붙일 이유가 없다.
- `되돌리기()` · `강제_초기화()` → **`_원래대로()`**. "원래" 는 무색이 아니라 `시작상태` 다.
  ⚠ 기존 씬은 전부 `시작상태 = 무색` 이라 동작이 하나도 안 바뀐다.

### 씬 승격
`벽돌 계단.tscn` · `벽돌 테스.tscn` 의 스크립트를 `지형.gd` 로 바꿨다(각 1줄).
점 배열이 이미 닫혀 있어서(계단은 13점, 마지막 = 첫 점) 그대로 `SS2D_Shape_Closed` 가 된다.

## 3. 만든 것

### 흰색 PNG 짝 5장 — `tools/생성_흰색짝.gd` (신규 · 멱등)
검정 텍스처 115장 중 짝이 없던 **5장**을 찾아 채웠다.
```
brick_v2_opaque/white/edge_top_thin.png
brick_v2_opaque/white/edge_top_mid.png
brick_v2_opaque/taper/white/taper_top_{left,right}_mid.png
assets/tileset/brick_white_seamless_341x307.png
```
전부 **손으로 나중에 추가된 엣지**들이다. `생성_타일셋_파생.gd` 는 마스터 이미지에서
전체를 다시 굽는 도구라, 엣지 한 장을 손으로 늘리면 흰색 짝이 영영 안 생겼다.
그 구멍을 메우는 도구다. 만든 뒤에는 반드시 `--import` 를 한 번 돌린다.

### 흰색 키트 6종 + 흰색 재질 2개 — `tools/생성_흰색키트.gd` (신규 · 멱등)
| 검정 | 흰색 |
|---|---|
| `벽돌 계단.tscn` | `벽돌 계단_흰색.tscn` |
| `벽돌 테스.tscn` | `벽돌 테스_흰색.tscn` |
| `TEMPLATE_GRASS_SOLID` / `_STAIRS` | `..._WHITE` |
| `TEMPLATE_WOOD_SOLID` / `_STAIRS` | `..._WHITE` |

새로 생긴 재질: `지형_벽돌v2_opaque_white_사방.tres`, `지형_나무v2_white_detail_얇은_사방.tres`
(잔디는 `지형_잔디_v4_white_detail.tres` 가 이미 있어서 그대로 썼다.)

**왜 "검정 재질 + 시작상태만 흰색" 으로 안 했나** — 그러면 **에디터에서 검게 보인다.**
페인트 셰이더는 런타임 전용이라(`_ready()` 가 `Engine.is_editor_hint()` 로 막는다)
작업자는 흰 지형을 놓고도 검은 덩어리를 보며 맵을 찍게 된다. 키트의 존재 이유가 사라진다.
→ 흰색 씬은 **흰 아트를 기본으로** 든다. 에디터·런타임 둘 다 희게 보이고,
   `_짝_찾기()` 가 양방향이라 **검정으로 칠하는 것도 그대로 된다.**

## 4. ★지뢰밭 — 새로 밟은 것 두 개

### `.tscn` 의 한글 속성 이름은 **반드시 따옴표**로 쓴다
```
시작상태 = 2      ← 조용히 무시된다 (씬엔 적혀 있는데 노드는 기본값)
"시작상태" = 2    ← 이렇게 써야 한다
```
따옴표가 없으면 Godot 의 텍스트 파서가 이름을 **바이트 단위(Latin-1)로** 읽는다.
`시작상태`(12바이트 UTF-8)에 UTF-8 이 한 번 더 씌워져 **다른 이름**이 되고 무시된다.
Godot 자신도 한글 속성은 따옴표로 저장한다 (`집_2층방.tscn` 의 `"칠하기_허용" = false`).

### `.tscn` 에서 `id="` 를 찾으면 `uid="` 가 먼저 걸린다
속성을 찾을 때는 **앞의 공백까지** 붙여 `' id="'` 로 찾아야 한다.
이것 때문에 지형 스크립트의 id 자리에 uid 문자열을 집어서 `시작상태` 가 한 줄도 안 들어갔다.

## 5. 검사

```
godot --headless --path . -s res://tools/test_사방재질_칠하기.gd   → 통과 57 · 실패 0
```
씬 17개(검정 11 + 흰색 6)를 실제로 세워서 본다. 흰색 씬은 **반대 방향**으로 검사한다 —
태어날 때 흰색인가 / **검정으로** 칠해지는가 / 되돌리면 흰색으로 돌아오는가.

| 검사 | 전 | 후 |
|---|---|---|
| `test_사방재질_칠하기` | 12 통과 · **3 실패** | **57 통과 · 0 실패** |
| `검증_런타임색_타일셋` | 126 / 0 | 126 / 0 |
| `검증_작업자씬` | **스크립트 오류로 중단** | 399 통과 · 17 실패(전부 BRICK · 아래 §6) |
| 기본 검사 14개 | 전부 통과 | **전부 통과** |
| `test_집_칠하기와빛` | 48 / 0 | 48 / 0 |
| `test_색경계_분할` | 53 / 0 | 53 / 0 |
| `검증_씬로드` | exit 0 | exit 0 |

`검증_작업자씬.gd` 도 고쳤다 — 지형이 루트라는 가정 때문에 `벽돌 테스.tscn`(빈 Node2D 아래에
지형이 자식으로 들어 있다)에서 `int(null)` 로 **검사기가 통째로 죽고 있었다.**
이제 지형 노드를 찾아서 보고, `_WHITE`/`_흰색` 씬은 `시작상태 = 흰색` 을 기대한다.

## 6. 남은 것 (넘김 · 전부 이번 작업 **이전부터** 있던 것)

1. **BRICK 재질의 `texture_scale` 이 0.35 가 아니라 1.0** — `검증_작업자씬` 실패 17건이 전부 이것과
   `fill_texture_scale` 이다. 벽돌 두께가 눈에 띄게 달라지는 **아트 판단**이라 손대지 않았다.
   (`지형_벽돌v2_black_detail_얇은_사방.tres` · `지형_벽돌v2_opaque_black_사방.tres`)
2. **`벽돌 테스.tscn` 에 콜리전이 없다** — StaticBody2D/CollisionPolygon2D 가 아예 없어 밟을 수 없다.
   보기용 씬이면 그대로 둬도 되지만, 지형으로 쓸 거면 붙여야 한다.
3. `test_투명블럭_색칠` 23/25 · `test_paint_v3` 30/7 — 2026-08-24 "반대색 덮어쓰기" 규칙 변경 이후
   기대값이 낡은 것. 변경 전후로 결과가 같음을 확인했다(내 변경과 무관).
4. **타일맵 계열(`world_1` · `world_2`)은 그대로 두었다.** SS2D 와 사망 판정·페인트 코어가 달라
   한 씬에 섞을 수 없다. 새로 찍는 지형만 SS2D 키트로 간다.

```
godot --headless --path . -s res://tools/생성_흰색짝.gd -- --폴더=res://assets/textures/smartshape
```
