# 스테이지 2-1~2-8 최신 장치 적용 점검

사용자 요청: 호퍼 상면 유입, 레버, 압력 발판 적용 누락을 찾아 보완.

- 최신 외관 갱신 도구 결과 추가 교체 0개. 호퍼 18개가 주철 어댑터 사용 중이며, 유입이 있는 17개/물줄기27개는 입구 y+12까지 연장 및 `호퍼_유입=true`, 호퍼 z_index=3 적용 상태.
- 단일 공급 중앙 정렬 추가 이동0개. 두 줄기 공급 x 유지. 2-5의 H4는 유체 제어 없는 중립 준비대이므로 새 공급을 만들지 않음.
- 압력 발판8개, 레버/밸브8개는 최신 공통 스크립트 사용. 레버의 별도 스크립트/자식 텍스처 오버라이드 없음.
- 도구 두 개에 `--stages 1 2 3 4 5 6 7 8` 범위 옵션 추가. 해당 범위로 갱신/정렬 및 재실행 확인. 재실행 전후 전체11개 씬 파일 바이트 동일, 제외한2-9~2-11 보존.
- 씬에 추가 변경할 누락이 없어 기존 적용 상태 유지. 정적 확인만 완료했으며 실제 화면/실플레이 및 Godot 파싱은 미실행.
- Graphify query/update는 출력 없이 종료1로 사용 불가.
