## 아스트라에게 붙여 넣을 공통 지시

```
You are producing background LAYER assets for a monochrome 2D dark-fantasy puzzle platformer (Godot).
The player is a small black-or-white figure; terrain is pure black (≈5%) or white (≈90%) wood.
Backgrounds must sit in the MIDDLE grey range so both black and white terrain read clearly.

GLOBAL RULES
- Pure grayscale (R=G=B). No color tint. Victorian mansion interior, old, slightly decayed.
- Straight-on orthographic front view. NO perspective floor, NO vanishing point, NO baked lighting gradient across the image.
- Tone: wallpaper mean ≈ 42% grey (107/255), pattern contrast within ±6%. Wainscot ≈ 32%. Furniture 18–40%, with a thin lighter rim (+10%) on top/left edges only.
- Never use pure white or pure black areas larger than a few pixels (those values belong to gameplay terrain).
- Exact pixel size as listed. PNG. Furniture/decals: transparent background, tight crop, object touching the bottom edge (for "바닥" items) or top edge (for "천장" items).
- Tiles marked "seamless" must tile left/right (and top/bottom if stated) with zero visible seam.
- Scale: 32 px = one game cell; the player is 44×97 px. Furniture must look correct next to a 97 px tall figure.
- No text, no logos, no characters, no watermark.
```
