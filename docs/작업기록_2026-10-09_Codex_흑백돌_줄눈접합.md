# 흑백 돌 줄눈 접합 적용 — 2026-10-09 Codex

사용자가 승인한 윗면 온전한 돌 / 옆·밑면 벽돌 맞물림 시안을 적용했다.

## 적용 범위

- `shaders/sewer_natural_platform.gdshader`: 챕터1 원근을 사용하는 2-1~2-5의 갓돌 샘플링 보정. 원본 그림의 돌마다 폭과 사선이 달랐는데 같은 198px 직사각형으로 잘라 무늬 중간이 경계에 왔다. 각 돌의 실제 뒤/앞 줄눈 좌표를 보간해 원본 원근을 펴고 새 메시 원근에 맞춘다. 기존 돌 그림·흑백 명도·페인트 처리는 유지.
- 2-1 `튜토리얼_흰바닥`, `웅덩이_홈_흰`, `좌하_덩어리`: 공유하는 세 접합선을 기존 작은 앞면 벽돌의 실제 줄눈으로 교체. 흰·검정에 동일한 선을 역순으로 넣어 틈과 겹침을 막는다. 상면 좌표/높이와 전체 지형 합집합은 유지. 내부 색 경계의 SS2D 점과 저장 충돌을 함께 갱신해 그림과 색 판정 경계를 맞춘다.
- 흰 두 조각은 새 전용 재질 `접합_2-1_0.tres`, `접합_2-1_1.tres`로 검정 본체의 기존 UV 기준(2600,1200)을 공유. 원본 검정 본체의 무늬 배치는 보존한다. 아래 돌출은 원래 밑면 아래 첫 한 줄 이내.
- 2-2와 2-5의 기존 수작업 맞물림은 재생성하지 않았다. 2-3/2-4에는 기본 흰 땅 접합이 없다.
- 재현 도구 `tools/apply_stage21_whole_stone_joints.py`: 기본은 정적 검사, `--apply`만 저장. 적용 식별자가 있으면 반복 실행해도 변경하지 않는다. 전체 씬 빌더/엔진은 호출하지 않는다.

## 정적 검증

- 수정 전 씬: `tmp/whole_stone_20261009/stage_2-1.tscn`.
- 공유선 양옆 972 샘플에서 빈틈/겹침 없음. 두 접합부 주변 113,708 지점에서 수정 전후 지형 합집합의 점유 수가 동일. 면적 합 차이는 부동소수 오차 범위(약 1e-10).
- 저장 충돌 3개와 SS2D 점 일치, 나머지 지형 노드 내용 불변, 아래 돌출 22px 미만 확인.
- 2-1~2-5 리소스 선언 순서/참조 검사 통과. 참조 파일 존재, 셰이더 한글 없음, Python 구문 검사, 반복 적용 무변경 확인.
- `graphify update .` AST 갱신 완료.

## 실행 및 시각 검증

**수정 완료·시각 검증 대기.** 사용자에게 Godot 실행을 명시적으로 요청받지 않아 편집기·콘솔·headless·빌더를 실행하지 않았다. 엔진 검사 13개 미실행. 안내된 `docs/다음작업_프롬프트.md`는 현재 체크아웃에서 찾지 못했다.

실제 엔진 수정 후 PNG 경로: 없음. 승인된 생성형 시안은 검증 캡처로 대체하지 않는다. 실행 허가 후 동일 스테이지·줌·해상도에서 윗면의 온전한 돌, 두 흰 조각의 맞물림, 물 밑면, 색칠/회수/사망 판정, 접합 이음새를 확인해야 한다.
