# 2-1 자연형 공중·땅 적용

stage_2-1의 지형 36개에 자연형 v02 텍스처/스크립트를 적용했다. 8개는 공중, 28개는 땅·벽체로 분류했다. 공중: A_L2, A_L3, A_L4_착지대, B_G1_함정발판, B_G2_마른발판, B_S2_유령칸, B_F1_선반, C_G3_검정물_발판. 갤러리 슬래브는 벽과 이어진 구조이므로 땅형으로 유지했다.

공중형은 기존 윗면 좌표와 폭을 유지하고 옆면/하단에 요철을 추가했다. 실제 경계 밖으로 돌출시켜 점프 통로를 좁히지 않도록 기존 사각형 안에서 일부를 깎아 덩어리가 상대적으로 돌출되게 했다. 따라서 공중형 하단/측면 충돌 형태는 변경되며 게임플레이가 완전히 동일하다고 보장하지 않는다. 나머지 지형의 점은 보존했다.

노드별 미리보기 재질에 실제 로컬 경계를 넣어 중앙 원점이나 긴 벽에서도 340×48 비교판의 음영 범위가 남지 않게 했다. texture_scale=0.18로 텍스처 밀도를 유지한다. 땅형은 하단 음영을 끈다. 각 노드에 metadata/terrain_style을 남겼다. 모든 지형은 기존 SS2D 인스턴스 하나씩을 유지한다.

비지형 노드 전체가 변경 전과 동일함을 비교했다. 배경·물·배관·레버·가시·플레이어·카메라 설정을 보존했다. 외부 파일 존재와 중복 연속점 제거, git diff --check를 확인했다. Godot 실행/색칠사망/이동 검사는 미실행이다.
