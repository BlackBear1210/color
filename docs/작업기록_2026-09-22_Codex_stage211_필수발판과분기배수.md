# stage_2-11 필수 발판과 분기 배수

2-10, 2-9의 수정 및 정적 검사 후 순차 진행했다. 방3 물길 우회와 자동 사격을 제거하고, 방5 세 번째 붕괴 발판을 건너뛸 수 없게 도약 간격을 개편했다. 방4 레버는 직선 A/B 배수 전환으로 바꾸었다. Player·시작 위치 일치, 줌1.0·치명 낙하1500을 명시했다.

상세/새 공략은 `scenes/world_2_클로드/작업/stage_2-11_작업.md`. 전체 씬 재생성 없이 선택 노드·윤곽·충돌만 수정했다. 기존 5개 방 사이 연결 계단의 전면 축소는 이번에 수행하지 않았다.
