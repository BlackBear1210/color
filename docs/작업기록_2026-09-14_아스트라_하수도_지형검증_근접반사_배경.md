# 하수도 시험 지형 1~3단계

## 변경

- 검정·흰색 공중 발판 각 3종(얇음·두꺼움·경사)을 공용 지형 규칙에 연결했다. 각 플랫폼은 SS2D 하나다.
- 씬의 한글 속성 키를 따옴표로 감싸 실제 시작 색이 읽히게 했다. 검정 1, 흰색 2이며 회색 지형을 추가하지 않았다.
- 내부·상면·옆면·모서리를 분리한 반복 재질과 흑백 짝을 연결했다. 아틀라스 영역을 런타임 텍스처로 준비하여 칠한 면과 모서리가 함께 바뀐다.
- 고정 검정 테두리 밝기를 낮추고 플레이어 중심 반경 190 안쪽에만 약한 반사를 추가했다. 벽 가림을 물리 레이로 확인한다. 셰이더는 ASCII만 사용한다.
- 먼 벽/가까운 아치·배관을 각각 0.25/0.60 시차로 움직인다. 먼 벽 표시 범위를 넓혔고 가까운 그림 끝은 안개로 흐려 잘린 기둥 밑면이 보이지 않게 했다.
- 플레이 시험 씬의 점프 높이 10칸·거리 20칸, 카메라 줌 1.0, 치명 낙하 1500을 공통 빌더에 맞춰 명시했다.
- 실제 Player 의존 리소스인 `scenes/effects/PaintImpactEffect.tscn`의 두 한글 sub_resource ID를 ASCII로 바꿨다. 선언과 참조만 변경하여 실행 중 리소스 ID 오류를 없앴다.

## 검증 결과

사용자의 1~3번 진행 승인 후 Godot 4.6.3을 `--disable-crash-handler`로 실행했다. 전체 맵 재생성 도구는 실행하지 않았다.

| 실제 렌더링·줌·배경 네 모서리 | GRAPHICS_RESULT failures=0 |
| 반사 켬/끔 픽셀 비교 | 차이는 가까운 발판 상면 407픽셀, 높이 2픽셀 영역에 한정. 최대 채널 차이 20/255 |
| check_스마트월드 | 69개 실패 0 |
| test_지형규칙 | 28/28 |
| test_차오르는물 | 31/31 |

인수인계 문서의 test_낙하사망, test_통로전환, test_카메라연출, test_카메라공간, test_color_death, test_stages, test_빛창문은 현재 저장소에서 파일을 찾을 수 없어 미실행이다. 변경 전 전체 회귀 기준선이 없으므로 회귀가 전혀 없다고 단정하지 않는다. 이번 전용 지형 검사와 공용 검사 결과를 구분한다. 사망·챕터 공용 검사는 새 하수도 지형 스크립트를 사용하지 않는다. 다른 팀원의 집/기존 맵은 이 작업에서 수정하지 않았다.

처음 편집기 임포트에서는 복원된 기존 2-11의 부서지는 발판 중복 신호 경고도 나왔다. 신규 시험 씬의 직접 실행과 별개이며 장애물 작업에서 확인할 항목이다.

## 범위와 후속

시험 씬: `res://scenes/테스트/하수도_지형_v01/색칠_사망_플레이시험.tscn`.
사용법: `docs/아트기준_스테이지2_v01/흑백지형_게임연결_2026-09-14.md`.
로그·엔진 캡처는 `.godot/sewer_*`에 있으며 임시 파일이다.

시험 씬 카메라 범위에서 배경을 확인했다. 기존 stage_2 맵 전체에 배포한 것은 아니다. 서로 다른 크기의 맵에서는 배경 범위와 점프 동선을 다시 확인한다. 부분칠 검사는 코어/지형 호출과 위치 판정 검증이며 전체 수동 플레이 완료를 의미하지 않는다.

전용 페인트 셰이더는 공용 수식 변경을 함께 반영해야 한다. 근접 반사는 현재 외곽 32개 선분까지 처리한다. 실제 양산 전 점이 더 많은 지형의 반사와 성능은 별도 점검한다.

graphify 그래프 파일이 없고 update는 로컬 uv 실행 경로 오류로 실패했다. 지식 그래프 갱신 완료를 주장하지 않는다. 커밋·푸시는 이번 요청 범위에서 하지 않았다.
