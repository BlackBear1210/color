# 점프 이펙트 — 일러스트 v04

사용자 피드백: 이전 약·강 시트는 조각 느낌이 너무 강함. 일러스트로 효과를 표현하고 프로젝트 안에 정리할 것.

## 변경

- 첨부된 이전 시트를 image_gen으로 다시 그렸다. 기존 배치와 약·강 구분을 유지했다.
- 돌·금속처럼 보이는 표면 결, 입체 명암을 제거하고 단순한 곡선 붓선·둥근 점으로 바꿨다.
- 위 약한 점프는 작은 곡선, 아래 강한 점프는 긴 곡선과 내부가 빈 타원 고리.
- 저장: `assets/textures/props/신규기믹_v02/이펙트/일러스트_v04/점프_약강_일러스트_8프레임.png`
- 같은 폴더에 `사용안내.txt`, `생성프롬프트.txt` 저장. v03과 앞선 시트는 비교용으로 보존.
- 세로 잔상 시트·게임 코드·씬은 변경하지 않았다.

## 검증

- 저장한 PNG를 직접 열어 2행×4프레임과 질감 제거를 확인.
- 1536×1024 / 32bit ARGB. 4px 간격 알파 표본 총 98,304점 중 투명 93,532 / 반투명 4,772 / 완전 불투명 0.
- 배경 표본 (0,0), (210,220), (580,560), (210,500)은 모두 알파 0. RGB 미리보기의 밝은 주변색을 불투명 배경으로 오인하지 않도록 실제 알파를 확인했다.
- 명목 프레임 셀은 384×512. 프레임별 정확한 피벗과 애니메이션 연결·실제 게임 밝기는 미검증.
- Godot 실행·엔진 검사·실제 엔진 캡처는 명시 허용 규칙에 따라 미실행. 프로젝트 내 파일 정리 완료이며 게임 연결 완료를 뜻하지 않는다.
- 사용 도구: built-in image_gen. 별도 코드 이미지 편집 없음.
