# 2-9 압력 발판 매립 마감

## 후속 수정 4 — 상판 4px 돌출과 누름

- 사용자 승인: 잘 맞물린 지형/프레임은 유지하면서 상판만 주변 돌보다 4px 높게 배치한다.
- 상판 두께는 유지하고 `4 * (1 - _눌림_표현)`만큼 위로 이동한다. 완전 눌림에서 돌 마감 윗선과 일치하며, 무게가 없어지면 복귀한다. 유지형 출력은 기존 로직대로 유지된다.
- 기존 2px 시각적 눌림 대신 4→0px 스트로크를 사용한다. 상판 아래 내부 음영도 돌출 간격만큼 보강했다.
- 같은 올림 값으로 밟는면 사각 충돌의 윗면/감지 위치를 물리 프레임에서 갱신한다. 충돌 하단은 고정된다. 재구성 시에도 적용되어 에디터 표시와 초기 런타임 충돌이 일치한다.
- 기존 미세 원근 표현(그림 윗선은 충돌면보다 4px 위)은 유지한다. 씬의 폭/위치, 지형 접합 윤곽과 UV, 고정 프레임은 변경하지 않았다.
- 정적 검사: 누름 0/0.5/1에서 올림 4/2/0px, 충돌 하단 고정 및 감지 범위 겹침 확인. 씬 선언 순서 및 diff 공백 검사 통과.
- 엔진 검사/플레이 중 눌림 및 4px 턱 통과 검증은 Godot 실행 금지 규칙에 따라 미실행. graphify update는 종료 코드 1로 실패했다.

## 후속 수정 3 — 양옆 접합용 마감 돌

- 단순 가림 윤곽 수정으로 해결되지 않은 이유: 마감 돌 원본 텍스처 자체에 사선 줄눈이 있어 금속 모따기와 두 갈래로 보였다.
- 매립 발판이 대상 지형에 접합 범위를 등록한다. 지형은 별도 마감 메시 재질에만 최대 8개 접합 범위를 전달하며, 숨김/삭제/대상 교체 시 해제한다.
- 셰이더는 발판 양옆 한 조각씩 텍스처의 가로 샘플 범위를 조정한다. 바깥 줄눈은 기존 시작/끝 샘플을 유지하고, 금속과 닿는 쪽은 줄눈 없는 돌 내부를 사용한다. 실제 안쪽 윤곽은 기존 금속 모양 차집합이 담당한다.
- 접합 정보가 없는 지형은 기본 count=0으로 기존 렌더링을 유지한다. 2-9 발판 크기/위치와 모든 충돌/작동 로직은 그대로다.
- 현재 접합은 수평·회전 없는 3개 돌 폭의 매립 발판용이다. 경사/회전 배치의 범용 접합은 이번 범위가 아니다.
- 정적 확인: 씬 리소스 선언 순서, 셰이더 ASCII, diff 공백 검사 통과. Godot 실행/렌더 검증은 미실행. graphify update 실패(종료 코드 1)는 계속된다.

## 후속 수정 2 — 접합 틈과 밝은 테두리

- 사용자 승인에 따라 금속 상판 명도 배율 0.78, 앞면 0.86을 적용. 활성 표시창은 기존 밝기를 유지한다.
- 원본 아틀라스의 검은 외곽/하단 테두리를 소량 제외해 그린다. 목적 사각형과 씬의 폭/높이/위치는 보존했다.
- 돌 마감 차집합을 좌우/하단 0.6px, 상단 0.4px 안쪽으로 줄여 금속 가장자리와 돌이 미세하게 겹치게 했다. 투명 경계에서 드러나는 틈을 줄이는 목적이다.
- 이번 수정은 매립 발판 스크립트의 렌더링/마감 차집합에 한정. 충돌, 감지, 작동 로직은 변경하지 않았다.
- 씬 리소스 순서 및 diff 공백 검사 통과. Godot 실행과 시각 검증은 사용자 안전 규칙에 따라 미실행. graphify update는 여전히 출력 없이 종료 코드 1을 반환했다.

## 후속 수정 — 검은 여백과 실제 줄눈 규격

- 사용자 화면에서 검은 사각 홈이 상판 모따기 밖으로 드러나는 문제 확인. 외부 1px 여유 및 사각 바탕을 제거하고, 마감 차집합을 금속의 모따기 윤곽으로 변경했다. 검은 바탕은 상판/프레임 내부에만 남긴다.
- 최초의 64px 모듈 가정은 실제 셰이더 마감 돌 규격과 달랐다. `sewer_natural_platform.gdshader`의 `floor(edge_length / (198 * 0.2353) + 0.5)`로 개수를 계산하고 길이를 나눠야 한다.
- C 지형: 608 / 13 = 46.769231px. 3개 폭 140.307692px, 중심 x=978.461538, 줄눈 3→6.
- E 지형: 1088 / 23 = 47.304348px. 3개 폭 141.913043px, 중심 x=3529.739130, 줄눈 19→22.
- 두 버튼의 높이/작동 대상은 유지. 중심 x와 폭에 따라 감지/충돌 수평 범위는 함께 바뀐다.
- 셰이더 공식과 씬의 실제 폭/양끝 정렬 오차 0.00001px 이내 정적 확인 통과. 씬 선언 순서 및 diff 공백 검사 통과.
- Godot 실행/화면 검증은 미실행. graphify update 재시도도 출력 없이 종료 코드 1로 실패.

아래는 최초 적용 기록이며 128px/64px 모듈과 사각 홈 설명은 위 후속 수정으로 대체되었다.

사용자 요청: 참고 이미지처럼 발판이 바닥 상단 마감 한 단을 대신하도록 2-9에 우선 적용.

## 변경

- `압력버튼_매립.gd`를 추가하고 2-9의 두 버튼만 이 파생 스크립트를 사용한다. 공통 압력버튼의 기존 편집 내용은 보존했다.
- C_배수문버튼 → C_배관실왼쪽, E_연결버튼 → E_기계실을 명시적으로 연결했다.
- 기존 112px 폭을 128px로 바꾸어 양끝을 지형 원점 기준 64px 모듈에 맞췄다. 폭 변경에 따라 버튼 충돌/감지 폭도 기존 공식을 따라 늘어난다.
- 지형 윗선 -4px부터 앞면 +24px까지 기존 돌 마감 메시만 차집합으로 제거한다. 기존 `침수마감_설정` API를 재사용하며 지형 본체, 페인트, 충돌 다각형은 바꾸지 않는다.
- 그 자리에 1px 접합 틈과 금속 몸체를 그린다. 투명 텍스처 뒤에는 어두운 홈이 있어 벽돌 비침을 막는다.
- 상판과 프레임 양끝은 높이 기준 비율을 유지하고 중앙만 늘린다. 누름 시 상판만 2px 움직이며 표시창은 기존 활성 상태를 사용한다.
- 편집기 이동/크기/숨김 및 삭제 시 가림을 갱신·복원한다. 같은 가림 영역은 기존 API가 걸러 메시가 매 프레임 다시 생성되지 않는다.

## 확인과 제한

- 작업 전/후 씬 리소스 선언 순서 정적 검사 통과. 변경 후 모든 외부 참조 파일 존재 확인.
- 작업 직전 씬 사본과 비교: 스크립트 참조 1곳, 폭 2곳, 매립 지형 연결 2곳 외 변경 없음. 지형/장치 위치, 수문/연결 발판 이동 대상과 이동량 보존.
- 두 버튼의 밟는 면 = 지형 표면, 시각 상단 = 표면 -4px, 하단 = 표면 +24px, 양끝 64px 모듈 정렬 확인.
- 임시 정적 검사에서 노드 정규식이 첫 줄만 읽어 연결 확인에 실패했다. 파일 결함이 아닌 검사 정규식을 수정한 뒤 재확인했다.
- `git diff --check` 통과, 추적 파일 삭제 없음.
- 사용자 안전 규칙에 따라 Godot 편집기/콘솔/headless/빌드 및 엔진 검사 전부 미실행. 실제 렌더링과 누름 동작은 아직 엔진에서 확인하지 않았다.
- `git pull`은 기존 수정/미추적 파일과 원격 변경이 겹쳐 병합 전 중단됨. 기존 작업을 stash하거나 덮어쓰지 않았다.
- graphify query/update는 설치된 실행기가 출력 없이 종료 코드 1을 반환했다. 기존 graph.json에서 관련 노드를 조회하고 소스를 직접 확인했다. 그래프 갱신은 미완료.
