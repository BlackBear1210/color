# 포물선 착수 물방울

사용자가 그린 아래쪽 도안처럼 낮게 튀고 내려오는 형태로 변경.
- 기존 splash_texture를 착수 함수에서 샘플링하지 않음. 위로 뻗어 계속 남던 분무 이미지 제거.
- 서로 다른 위상과 주기를 가진 12개 짧은 물방울. x는 바깥쪽으로 이동, y는 4*peak*age*(1-age) 포물선으로 상승 후 하강. 전체 곡선을 선으로 그리지 않고 현재 물방울과 짧은 꼬리만 표시.
- 착수 중앙 작은 거품 유지. 비교 모드4의 기존 고정 아치도 제거하여 실제 물줄기와 같은 함수 사용.
- 속도390, 윗면 중앙 착수(뒤깊이의 절반 보정), 맵 배치/충돌/색 규칙 유지.
- 정적 회귀 검사와 궤적 수치 확인. Godot 미실행(기존 충돌). 브라우저 화면 검증도 미실행(앞선 자동 검토 차단). 실제 외관/성능 미검증.

검사 결과: 궤적 수치/셰이더 괄호 검사 통과. 기존 stage21 정적 회귀 검사는 W5 위치가 기대값(7936,1024)과 달라 실패했다. 이번 턴은 씬을 수정하지 않았으며 현재 편집 위치를 보존한다. 검사 통과를 위해 씬을 되돌리지 않았다.
