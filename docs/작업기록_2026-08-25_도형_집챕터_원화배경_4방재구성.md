## 3. ★핵심 규약 — "원화 픽셀로 재고, 배율 한 번만 곱한다"

`실내배경.영역` 을 원화와 **같은 비율**로 잡고 `그림_맞춤 = 늘이기` 로 두면

```
월드좌표 = 영역.position + 원화픽셀 × 배율
```

가 정확히 성립한다. 그래서 빌더의 지형 표는 전부 **원화 위에서 잰 픽셀 값**이다.
(원화에서 침대 윗면이 y=801px 이면 코드에도 그냥 `801` 이라고 적는다)

- 발판이 그림 속 가구 위에 그대로 얹힌다 → "배경 따로 지형 따로" 가 안 생긴다.
- 원화가 갱신되면 다시 재서 숫자만 고친다.
- 방 전체 크기를 바꾸려면 `방배율` 상수 하나만 만진다.

| | 배율 | 영역(월드) | 카메라 줌 | 화면 |
|---|---|---|---|---|
| 가로 방 3 개 | 0.75 | 1601 × 900 | 1.35 | 1422 × 800 |
| 굴뚝 | 0.9 | 1080 × 1921 | 1.85 | 1038 × 584 |

## 4. ★배율이 0.75 인 이유 (1:1 로 지었다가 전부 튕겼다)

플레이어 점프는 **세로 160px · 가로 240px** 인데,
`레벨검사.gd` 가 쓰는 **실효 한계는 세로 128px · 가로 204px** 이다 (여유 0.80 / 0.85).

원화를 1:1(2135×1200)로 깔면 가구 사이 단차가 **139~156px** 이라
"닿을 뻔했는데 못 닿는" 발판이 10 개 나왔다 (첫 레벨검사 결과):

```
책장 → 옷장 로 갈 뻔했다 — 단차 139px (한계 128 · 11 초과)
책상 → 책더미 로 갈 뻔했다 — 단차 156px (한계 128 · 28 초과)
바닥 → 책상  로 갈 뻔했다 — 단차 139px (한계 128 · 11 초과)
```

→ 원화를 **0.75 로 줄이면** 같은 단차가 **104~117px** 이 되어 전부 들어온다.
점프 수치는 하나도 안 건드렸다 (다른 스테이지와 조작감이 갈리면 안 되므로).

## 5. 발판을 놓을 때 실제로 걸린 함정 (전부 레벨검사가 잡았다)

1. **바로 위 발판으로는 못 올라간다** — 머리가 막힌다. 항상 좌우로 어긋나게 둘 것.
   (굴뚝의 지그재그 서까래가 이 원칙을 그대로 쓴 것)
2. **위 발판이 아래 발판을 덮으면 아래가 죽는다** — 겹치는 구간엔 못 서니 아래 발판의
   *노출된 폭*이 최소 70px(플레이어 폭 44 + 여유)은 남아야 한다.
3. **위아래 간격이 96px(플레이어 키) 미만이면 몸이 낀다** — 부엌 조리대 밑 의자가 그랬다.
4. **플레이어가 서 있는 자리는 표면 스캔이 가려진다** — 침대 노출 폭이 88px 뿐이라
   표본(32px 간격) 3 개 중 가운데를 플레이어 몸이 막아, 양 끝 1점짜리가 버려지고
   레벨검사가 **침대를 발판으로 아예 못 잡았다**. 침대머리를 좁혀 노출 폭을 넓혀 해결.

★원화에 그려져 있어도 1~3 에 걸리면 **발판을 안 만들고 그림으로만 둔다.**
닿지 못하는 발판 = 죽은 콘텐츠. 그렇게 뺀 것:
**거실 벽난로 선반**(어디서 뛰어도 209px) · **부엌 냉장고 위** · **부엌 의자** ·
**2층방 창턱**(의자 바로 위 92px).

## 6. `연결통로` 의 구조적 제약 — 레벨 배치가 여기 묶인다

출구는 **+x(오른쪽)로만** 파고들고 입구는 **−x(왼쪽)에서만** 뻗어온다.
그래서 모든 방이 "왼쪽에서 들어와 오른쪽으로 나간다".

- **2층방 원화의 문은 왼쪽**이다 → 문은 그림으로 두고 출구는 오른쪽 벽에 뚫었다.
  원화 그대로 문으로 나가게 하고 싶으면 두 가지 중 하나:
  ① `실내배경.좌우반전` 을 켜고 지형 x 부호를 뒤집는다 (이번에 만들어 둔 스위치)
  ② `연결통로` 에 왼쪽 출구를 지원하게 고친다
- **옆벽은 통로 입구 높이에서 끊어 놨다.** 통으로 세우면 통로가 벽 속에 파묻혀 막힌다.
  (예: 2층방 오른벽은 `y −900 ~ 92.5` 까지만)

## 9. 방별 동선

**집 · 2층 방** — 침대에서 깬다
`침대 → 궤짝 → 바닥` / 왼쪽 오름길 `책상 → 책더미 → 책장 → 옷장`(방 최고점)
/ 오른쪽 창가 `의자 → 탁자` → 오른쪽 벽 통로.
창빛은 원화에 그려진 빛줄기와 같은 각도(149°)로 얹었다.

**집 · 거실** — 왼쪽 통로에서 들어온다
왼쪽 곁길 `화덕 → 화분 → 창턱` / 가운데 `탁자 → 소파 → 계단 1·2·3 → 계단참`(2층으로 오르는 시늉)
/ `곁탁자`(바닥→소파 디딤돌) → 오른쪽 어두운 문간으로 나간다.

**집 · 부엌** — `스툴`이 좌우 두 길을 잇는 **허브**다 (바닥에서 유일하게 올라설 수 있는 발판)
오른쪽 `찬장 → 장식장 / 오른카운터` · 왼쪽 `작업대 → 왼조리대 / 걸이봉 → 벽선반`(방 꼭대기).

**집 · 굴뚝** — 세로 스테이지
굴뚝 몸통이 가운데를 막아 오르는 길은 **왼쪽 한 줄뿐**.
`아궁이상자 → 난간 → 서까래 1~8 지그재그 → 굴뚝 몸통 꼭대기` → 오른쪽 통로(지붕).
같은 쪽 서까래 간격이 220px 라 떨어져도 두 칸 아래가 받아 준다.

## 10. 아직 안 한 것 / 다음에 정할 것

1. **빛기둥이 전부 `모드 = 연출`** — 판정 없는 순수 연출이다.
   색 경계(색 다르면 즉사)로 올리려면 인스펙터에서 `모드` 한 칸만 바꾸면 된다.
   ★2층방 창빛이 바닥에 고이는 자리(원화에 이미 그려져 있다)가 경계로 쓰기 딱 좋다 —
   빛 웅덩이를 피해 가구 위로 돌아가게 만드는 첫 퍼즐.
   다만 `몸 대각선 분할` 설계가 아직 미완이라 이번엔 안 켰다.
2. **`챕터.gd` 스테이지표에 안 넣었다.** 이 4 개는 `연결통로.다음_씬` 으로 직접 이어져 있다.
   표에 넣어 로비 → 시작 흐름에 붙일지는 도형님 결정 사항
   (기존 5·6·7 = 거실·굴뚝·지붕 원본과 어떻게 정리할지가 같이 걸린다).
3. **`치명_낙하거리`를 900(굴뚝 1400)으로 올려 뒀다.** 기본값 520 이면 옷장에서 바닥으로
   내려오는 것만으로 죽는다. 블록아웃 단계라 넉넉히 뒀으니 톤 잡을 때 다시 볼 것.
4. **장애물이 하나도 없다.** 가시·색레이저·통과플랫폼 등은 아직 안 놨다.
   `scenes/집/스마트월드_장애물/` 에서 드래그해 놓으면 된다.
5. **원화 문 위치와 통로 방향 불일치**(§6) — 2층방만 해당. 좌우반전 스위치는 만들어 뒀다.
