# 하수도 얕은 웅덩이 / 낙수 색 적용

## 요청과 적용
- 승인한 검정·흰색·회색 웅덩이 재질을 world_2_클로드의 실제 stage 씬에 적용. 보관 폴더 제외.
- 캐릭터 약 96px 대비 다리 높이를 32px로 정함. 원점(바닥)은 유지하고 수심과 물 접촉 영역을 함께 낮춤.
- 2-1 3개, 2-2 1개, 2-8 5개, 2-9 3개, 2-11 29개: 총 41개. 나머지 stage에는 웅덩이 인스턴스 없음.
- 낙하 완충 기능이 수심 축소로 비활성화되지 않도록 해당 씬의 받아주는_최소수심을 32로 지정.
- 2-1 B_착지_웅덩이의 오른쪽 경사면은 원래 기울기와 바닥 양끝을 보존하도록 폭/중심/안쪽폭을 같이 계산.
- 흰 물은 불투명한 밝은 본체와 어두운 잔물결, 회색 물은 중간 명도와 약한 벽돌 굴절, 검정은 짙은 본체와 가는 반사선.
- 전용 셰이더 선택을 흰물_디자인에 추가. 부모 씬 경로가 하수도 stage인 경우만 선택. 2-9 재질이 갱신 때 기본 v2로 되돌아가는 문제도 수정.
- 하수도 v3 공중 물방울은 자기 색을 유지. 흰색은 0.90~0.98, 회색 0.46~0.62, 검정 0.035~0.16. 접촉부 음영은 별도 유지. 기존 흰 거품을 어둡게 하던 기준보다 최신 사용자 요청을 우선.
- 호퍼 입구 물보라도 수면 음영색 대신 실제 혼합된 입구 물색으로 그림.
- 유체가 도달하는 켜진 웅덩이의 수면을 0.1초 간격으로 확인해 시각적인 낙수 끝과 물보라를 수면에 맞춤. 웅덩이가 꺼지면 원래 바닥 그림 높이 복구. 유체 본체 판정과 호퍼 출구 폭은 유지.
