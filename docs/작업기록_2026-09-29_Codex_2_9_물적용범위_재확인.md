# 2-9 물 적용 범위 재확인

사용자 캡처는 C_검정공급/C_흰공급/C_혼합호퍼/D_호퍼출력 구간이다. 최근 수정한 웅덩이 표면은 이 화면에 없다.

실제 Godot 4.6.3 OpenGL에서 2-9를 다시 로드해 water_recheck_2_9/hopper_2.png를 저장하고 직접 열었다. 사용자 화면과 같은 기존 v3 물줄기 외관이 재현됐다. 최근 물 재질 수정은 웅덩이_하수도29 → sewer_pool_shallow의 stage5_surface 분기에만 적용되었다. 물줄기의 본체는 water_stream_v3의 기존 tone_params/stream 계산을 계속 사용한다. colored_splash는 하수도에 켜져 있지만 이는 착수 물방울의 색 구분이며 본체 재질 교체가 아니다.

따라서 최신 코드 미로딩으로 단정할 근거는 없다. 웅덩이 수정과 낙수 본체 수정의 범위가 다르며, 호퍼 물줄기는 승인 시안에 맞춰 추가 조정이 필요한 상태다. 이번 요청에서는 원인 재현/확인만 수행하고 시각 코드를 임의 변경하지 않았다.

물 검사 30개는 다시 통과했지만 이는 연결·폭·색 옵션·잔물결 등의 기능 검사이며 시안 유사성을 보장하지 않는다. 6단계의 추가 진행 및 승인 확인은 보류한다.
