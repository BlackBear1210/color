# 2-9 벽등 투사 그림자 및 플레이어 그림자 실행 검증

## 변경과 실제 원인
- 사용자에게 Godot 실행을 명시적으로 허용받아 4.6.3 OpenGL Compatibility 렌더링을 실행했다. 최초 승인 검토는 크레딧 오류로 실행되지 않았으나 사용자의 계속 진행 요청 후 정상 실행됐다.
- 기존 광원 shadow_item_cull_mask와 가림막 마스크는 16, 배경 Sprite2D.light_mask는 1이었다. GLES3 렌더러는 수신 CanvasItem.light_mask도 shadow_item_cull_mask와 비교하므로 벽이 그림자를 받지 않았다. 벽에 16 비트를 추가해 해결했다.
- 조사 중 가림막 z 순서를 바꿔 비교했지만 해결 원인이 아니므로 해당 변경은 제거했다.
- 벽등 뒤 하우징을 벽에서 18px 돌출된 타원으로 근사한다. 벽 셰이더 light()에서 각 실제 광원의 위치/높이와 하우징 위치로 벽면 투사를 계산한다. 벽 이미지에 고정된 검은 그림자를 그리지 않으며 해당 광원의 기여만 감쇠한다. 광원 높이가 하우징보다 낮은 경우 과도한 투사를 막도록 비율을 제한한다.
- 화면에 생성된 벽등 최대 32개의 중심과 반경을 매 프레임 전달한다. 현재 1920x1080, 줌 0.8 검사에서는 9개였다. 공유 벽 재질은 복제한다.
- 통행 영역에서 그림자가 너무 희미했던 반경260/energy0.8을 반경320/energy1.15로 조정. 그림자 색 알파0.60. 고정 월드 좌표의 광원은 계속 고정된다.
- 플레이어는 기존 충돌 다각형 가림막을 사용한다. 실제 옷자락 애니메이션과 완전히 동일한 실루엣은 아니다.
- 노멀 세기를 relief_depth uniform으로 노출해 켜짐/꺼짐을 렌더링 비교했다. 기존값0.65 유지.
- 적용 범위는 실시간 벽등을 사용하는 2-9. 다른 스테이지, 물, 충돌 및 색 판정은 변경하지 않았다.

## 실제 렌더링 증거
폴더: `docs/visual_review/lamp_shadow_20260929/`
- `before.png`, `after.png`: 같은 1920x1080, 줌0.8, 플레이어 위치(2130,3712). 두 PNG를 직접 열어 확인했다. 이 위치는 가장 가까운 벽등 반경 밖이므로 플레이어 그림자 증거로 사용하지 않는다.
- `near_right_on/off.png`, `near_left_on/off.png`: 실제 2-9를 로드하고 검사 중에만 플레이어 물리/카메라를 고정한 비교. 플레이어를 광원 좌우로 이동시켰다. 화면 입자는 비교에서만 숨겼다. 그림자는 실제 게임 렌더러가 생성한 것이며 생성형 이미지가 아니다.
- `housing_on/off.png`: 하우징 투사 유무.
- `projection_light_left/right.png`: 검사 중에만 동일 광원을 좌우70px 이동. 벽등은 고정된 상태에서 투사 방향이 반대로 바뀌는 것을 직접 확인했다. 게임의 광원 배치는 변경하지 않았다.
- `normal_on/off.png`: 실제 노멀 반응 확인. 선택한 벽 ROI의 최대 차이는2/255로 미세하다. 노멀 표현 자체가 강해졌다고 주장하지 않는다.
- `comparison.png`: 실제 촬영본을 잘라 나란히 놓은 비교표. 플레이어 왼쪽/오른쪽 투사, 하우징 켜짐/꺼짐, 광원 방향 비교를 직접 열어 확인했다.
- `pixel_comparison.json`: 선택한 그림자 ROI 차이. 플레이어 오른쪽 최대17/255, 왼쪽10/255, 하우징51/255. 그림자는 진한 검정 실루엣보다는 벽의 국소 명암차로 보인다.
- `tools/test_벽등_투사검증.gd`: 재현 가능한 실제 렌더링 비교 도구. 씬을 저장하지 않는다. 부유 위치는 그림자 검사용이며 정상 주행/점프 판정 테스트를 대신하지 않는다.

## 검사 결과 및 한계
- shadow_render.log / after_render.log: SCRIPT ERROR, SHADER ERROR, ERROR 없음. 기존 씬의 사라진 인스턴스 ColorRect 경고와 Unicode 로그 경고는 남아 있다.
- 필수13개 검사 실행 전후 비교: 오류/결과가 모두 동일(`regression_comparison.json`). 전체 통과는 아니다.
- 기존 실패: 사망판정21/25, 챕터전환33/39, 로비30초 시간 초과/Nil→String 오류. 낙하사망·통로전환·카메라연출·카메라공간·color_death·stages 검사 파일은 없음. 스마트월드 검사는 실패0을 출력하지만 stage_2_10_반환격자.gd의 기존 _상태색 파싱 오류가 있어 통과로 간주하지 않는다.
- 지형규칙/페인트v4/paint_system은 종료0이며 전후 동일. 기존 오류들은 이번 벽등 수정 범위 밖이므로 임의 수정하지 않았다.
- 광원 밖에서는 플레이어 그림자가 없고, 광원 아래 바닥에 붙어 있을 때는 그림자가 바닥 지형에 가려질 수 있다. 테스트는 실제 렌더링 및 위치 이동 확인이며 전체 스테이지 완주/성능 벤치마크는 아니다.
- 시안과 완벽히 동일하다고 주장하지 않는다. 이번 완료 범위는 투사 구현, 수신 마스크 버그 수정, 실제 렌더링에서의 움직이는 그림자 확인이다.
