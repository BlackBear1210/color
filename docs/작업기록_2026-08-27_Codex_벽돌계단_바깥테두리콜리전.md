# 작업기록 2026-08-27 · Codex — 벽돌 계단 바깥 테두리 콜리전

## 변경

`scenes/집/스마트 매쉬 assets/BRICK_벽돌/TEMPLATE_BRICK_STAIRS.tscn`에서 다음을 적용했다.

- 재질을 BRICK v2용 불투명 얇은 사방 미터 조인(`지형_벽돌v2_black_detail_얇은_사방.tres`)으로 적용했다.
- `collision_offset = 44.8`을 설정했다.
- 저장된 `CollisionPolygon2D`도 계단 외곽의 각 변에서 44.8px 바깥으로 확장한 좌표로 갱신했다.

## 이유

`brick_v2`의 방향별 엣지·taper·코너 쿼드를 함께 쓰는 재질은 계단의 직각마다 조각이 겹쳐 반투명한 잔상과 두께 불균일을 만들었다. `작업기록_2026-08-25_성진_벽돌v2_불투명엣지_미터조인.md`에서 검증한 불투명 얇은 엣지는 360° 단일 런으로 모든 모서리를 미터 조인한다. 코너·taper 쿼드가 없으므로 겹침과 반투명 코너가 생기지 않는다. 원래 BRICK v2 채움을 유지해 색칠 짝 규칙도 보존한다. 콜리전은 사용자가 요청한 대로 바깥 44.8px 경계를 유지한다.

## 코너 이미지 정정

`docs/이슈_CORNER-SIDE-ROTATION-01.md`의 수정 이력에 따라, BRICK v2의 안쪽 코너는 원격에서 수정 완료된 `corner_inner.png`를 사용해야 한다. 로컬에 남아 있던 서로 다른 두 파일을 재생성하지 않고 현재 `dev_4`의 검증된 원본으로 복원했다. 다만 이번 계단은 코너 쿼드 자체를 쓰지 않는 불투명 사방 재질을 사용하므로, 이 PNG들이 다시 겹침의 원인이 되지 않는다.

- `assets/textures/smartshape/brick_v2/black/corner_inner.png`
- `assets/textures/smartshape/brick_v2/white/corner_inner.png`

이 파일은 계단을 포함한 BRICK v2의 안쪽 꺾임을 담당한다. 다시 베이크하거나 재질을 사방 조인으로 바꾸면 기존 바깥 테두리 디자인이 달라질 수 있으므로, 코너 이상은 먼저 이 두 원본의 변경 여부를 확인한다.

## 얇은 테두리 템플릿 통일

같은 문제를 다른 작업자 템플릿에 남기지 않도록 BRICK·WOOD의 SOLID / HOLLOW / STAIRS 여섯 템플릿을 얇은 사방 재질로 통일했다.

- BRICK은 2026-08-25에 검증한 `edge_top_thin.png`을 360° 단일 런으로 쓰고, SOLID·STAIRS에는 기존 `brick_v2` 채움을 유지했다.
- WOOD는 SOURCE LOCK PNG를 수정하거나 재베이크하지 않았다. 기존 `edge_top.png`의 불투명 목재 띠만 `AtlasTexture`의 `Rect2(0, 68, 1024, 109)`로 읽어 월드 약 38px 두께의 테두리로 사용했다.
- HOLLOW는 채움을 추가하지 않아 빈 내부 기능을 보존했다.
- 네 재질 모두 CROP·`uniform_width`·안쪽 offset을 쓰고, 코너·taper 텍스처를 사용하지 않는다.

따라서 직각마다 테두리 조각이 중첩되거나 반투명해지지 않고, 큰 액자처럼 보이던 깊은 테두리 대신 한 줄의 얇은 테두리로 이어진다.

## 에디터 잔상 제거

`TEMPLATE_WOOD_HOLLOW`처럼 한 템플릿 위에 다른 계단·벽돌이 겹쳐 보이는 현상은 씬 병합이 아니라 SS2D 캔버스 렌더러의 이전 메시 잔상이었다. `지형.gd`는 저장된 `_meshes`를 비웠지만, `_dirty`가 false인 로드 순서에서는 부모가 재굽기를 건너뛰었다.

`super()` 뒤에 `force_update()`를 명시적으로 호출해, 렌더러가 준비된 직후 현재 템플릿의 점 배열로 메시를 새로 굽고 기존 캔버스 RID를 교체하도록 수정했다. 이 수정은 템플릿별 점·콜리전·재질 참조를 합치지 않는다.

## 검증

Godot 헤드리스 검사 실행은 변경 전부터 `signal 11`로 종료되어 Just-In-Time Debugger 창을 열었다. 사용자의 작업을 방해하지 않기 위해 Godot을 다시 실행하지 않았으며, 씬 텍스트의 재질 경로·`collision_offset`·저장된 폴리곤 좌표·각 템플릿의 독립 재질 참조와 렌더러 재생성 경로만 정적 검증했다.
