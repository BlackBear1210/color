# 하수도 지지구조 검수·금속 아트 교체

요청: Claude의 임시 아트 검수와 정식 아트 교체(1~2단계).

- 체인 반복·삼각 지지대·체인 고정구3장을 내장 ImageGen으로 편집 생성했다. 짙은 철재, 작은 마모 하이라이트, 볼트와 표면 요철을 추가했다. PNG 알파를 보존했고 원본 임시 그림을 placeholder_archive에 보관했다.
- 고해상도 교체로 부착점이 이동하지 않도록 지지대 표시96×96, 고정구40×28을 스크립트에서 유지했다. 체인 표시24×48과 연결점20은 그대로다.
- 기존 검사 B02의 텍스처 Scale=1.5라는 전제를 실제 표시144×144 검사로 변경했다. 목적은 배율 상한과 실제 크기 유지이며 검사를 제거한 것이 아니다.
- 별도 아트 화면 도구에서 실제 Parallax2D 배경을 넣고 브래킷 좌우형·체인 반복·승강기 및 카메라 이동을 캡처했다. 기존 시험 씬과 실제 맵은 덮어쓰지 않았다.
- 부착과 반복을 실제 렌더링으로 확인했다. 배경 위의 장식은 지형과 구별되며 실제 충돌은 기존 지형/승강기가 담당한다.
- 에디터 임포트를 실행했다. 종료 시 리소스1개 누수 오류가 남았으므로 프로젝트 전체 오류0을 주장하지 않는다. 에디터 UI에서 직접 인스펙터를 조작하는 검수는 미실행이다. 사용자 제공 에디터 이미지는 변경 전 상태다.
- 기능 검사 결과는 `.godot/support_art_test.log`, 그래픽은 `.godot/support_art_graphics.log`. 오류 경로/텍스처 없음/길이 초과에 대한 의도된 WARNING은 테스트 시나리오다.
- 최종 지지구조 검사17/17 PASS, 기능/그래픽 로그 ERROR/FAIL 없음. 로그와 캡처는 docs/스크린샷_하수도_지지구조_정식아트_2026-09-14에 보관했다.
- graphify update는 uv 경로 오류로 실패했다. git diff --check는 공백 오류 없이 완료했다.
- 상세 프롬프트/해상도/표시 규격은 assets/decorations/sewer_support_v01/asset_notes.md에 기록했다.
- 대형 실제 맵 배포·새 성능 측정은 이번 범위 밖이다. 고해상도 PNG의 메모리 비용은 초판보다 커지므로 양산 시 임포트/최적화 검토가 필요하다.
