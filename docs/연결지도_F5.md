# F5 연결 지도

> `python -X utf8 tools/연결지도.py` 가 만든다(손으로 고치지 말 것). 파일 하나만 보려면 `python -X utf8 tools/연결지도.py <파일이름>`.
> 엔진을 켜지 않고 파일 글자만 읽어서 찾은 연결이다 — 실행 중에 글자를 조립해 만드는 경로는 빠질 수 있다.
