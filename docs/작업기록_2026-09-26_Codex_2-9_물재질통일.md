# 2-9 물 재질 통일

사용자 피드백: 지형과 배경에 비해 물이 매끈해서 따로 붙인 그래픽처럼 보인다.

`sewer_pool_29.gdshader`의 넓은 밝기 그라데이션을 줄이고 낮은 대비의 서로 다른 크기 침전 무늬를 더했다. 미세 입자는 픽셀 좌표에 고정해 시간에 따른 반짝임을 막고, 큰 무늬만 초당 3.5px로 이동한다. 수면 전체에 더하던 밝은 테두리를 제거하고 불규칙한 일부 구간에만 반사광을 남겼다. 벽·바닥 접촉 음영에도 같은 무늬를 써 균일한 절단선을 줄였다. 회색 기본 명도는 유지하되 금속처럼 보이는 강한 상하 대비를 완화했다.

변경 이유는 연결 GDScript의 한글 주석으로 기록했다. 다른 스테이지, 매립 수로 지형, 물 크기/위치/색 판정/낙하 받기는 수정하지 않았다. 화면 텍스처 반사와 추가 이미지 리소스는 사용하지 않는다.

정적 확인: shader ASCII, 중괄호, 고정 미세입자 좌표, 연속 밝은 테두리 제거, 화면 샘플링/루프 미사용 확인. git diff --check 통과. Godot 실행·셰이더 컴파일·실제 화면 검증은 안전 규칙에 따라 미실행. 재질의 최종 조화는 실제 화면에서 추가 확인이 필요하다.

기존 병합 미해결 상태 때문에 git pull은 실패했다. graphify query/update는 유효 출력 없이 종료 코드 1로 실패했다. 기존 작업 및 병합 상태는 유지했다.
