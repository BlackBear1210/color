01 · 2층 시작방
아직 찍지 않은 장면 · 눌러서 들어가기

선택창은 직접 열 때만 클리어 사진과 도장을 보여 줍니다. 예시 버튼은 이 HTML에서만 상태를 바꾸며 게임 저장파일에 접근하지 않습니다. 사진 예시에는 사용자가 제공한 기존 인게임 캡처 한 장만 사용했습니다.

큰 줄기: 2층 시작방 → 복도 A → 복도 B → 복도 C → 무너진 복도 → 중앙 계단 → 현관 복도 → 거실 → 식당 복도 → 하인 복도 → 굴뚝 → 집밖 하수도길
옆방: 서재·썩은 마루 / 침실 / 수납실 / 응접실·숨은 서재 / 거미방. 실제 게임에서는 복도 문 앞에서 E로 들어가 다음 복도에 합류합니다.
체크포인트: 90 → 34개. 아래는 사용자가 보내 준 수정 전 이미지이며, 수정 후 같은 위치의 엔진 캡처는 아직 없습니다.
