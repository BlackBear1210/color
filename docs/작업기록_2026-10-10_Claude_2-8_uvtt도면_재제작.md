## 2. 흐름 — 시작에서 두 갈래로 나뉘고 꼭대기 격자 사다리에서 다시 만난다

1. **시작 바닥**(가운데 가시 구덩이) → 격자 4 장 → 긴 격자.
2. **왼쪽 갈래(흰)** — 흰 계단(**검정 몬스터**) → 작은 흰 발판 → **투명 발판**(칠) → 흰 기둥 밑 CP(흰물_2 · 흰물 웅덩이)
   → 큰 흰 ㄴ: **양동이**를 흰 페인트로 채워 **발판_1**(홀드) 홈에 밀면 2.5 초 뒤 **흰 지형_1** 이 ㄴ 속에서 올라온다(타고 오른다)
   → 가시 발판 → **점프대** 둘 → **밟으면 부서지는 발판 6**(밑 흰 발판에 **검정 사격 몬스터 2**) → 흰 기둥 꼭대기 **흰 열쇠 조각**.
3. **오른쪽 갈래(검)** — 구조물 계단 → 가시 바닥 위 디딤 바위 4 → 흰 몬스터 바닥(**흰 몬스터 2** — 넘는다) → CP 둔덕(검은 물 웅덩이)
   → CP 위 바위 → **투명 지형 2**(칠) → 벨브 바닥: **벨브_1** 로 검정물_2 를 끄면 뒤에 숨어 있던 **벨브_2** 가 보인다 → 흰물_3 끄기
   → **점프대** 둘(바위 14 → 15 → 격자) → 저장소 바위: **저장소**를 검정으로 쏘면 흰물_4 가 검은 물 → 검정물_3 과 함께 검은 몸으로 지난다.
4. **만남** — 위 격자 사다리 → 천장 바위 위 **검은 열쇠 조각** → 도착 지점. 흰 열쇠 조각은 격자_기둥옆(흰)으로 들러 줍는다.
   두 조각이 다 모이면 **도착 문**이 열린다 → 출구(2-9).

## 6. ⚠ 알아 둘 것

- **도형님 도면은 "딱 5 칸(160)" 높이 차가 자주 나온다** — 점프 정점과 같아 못 오른다. 2-7(3 곳)·2-8(2 곳) 모두 0.5~1 칸 내려 맞췄다. 머리 위 공간(천장까지 160 = 몸 97 + 점프 여유)도 같이 볼 것.
- 플레이어 공중 가로 속도 ≈ **320px/s**(걷기 390 보다 느리다 · 점프 거리 320 / 1 초). 같은 쪽으로 가는 몹은 서로 180px/s 라 **넘을 수 없다** — 마주 올 때만 넘는다(`피해가` 주석).
- 흰 몬스터_1 의 왼끝(칸 106)은 CP 위 바위 밑(머리 위 144)이라 거기선 몹을 못 넘는다 — 트인 곳에서 마주 넘어야 한다.
- 점프대 실제 튐이 2-7 공식(속도²/2570)보다 높았다(1030 → 정점 발 ≈1100 · 걸어서 점프대 옆면에 붙으면 먼저 점프해 올라탄 뒤 튄다). 세기를 바꾸면 주행검사로 다시 볼 것.
- 지형 이름과 장치 이름이 같으면 주행검사 `_찾기` 가 먼저 나온 쪽(지형)을 잡는다 — "점프대_바위14" 가 바위와 점프대 둘이었다 → 바위는 `바위_14`.
- **Codex 미커밋 `열쇠.gd` 오류**: `_새_열쇠_그리기` 166 줄 `var 이름들: Array[String] = [...] if … else (…)` 가 실행 중 "Array → Array[String]" 오류(2-7 측정 중 출력). 2-8 열쇠는 `새_디자인` 을 안 켜 영향 없음 — Codex 쪽에서 고칠 것.
- 작업 중 Codex 가 같은 저장소에서 다른 파일(음향·로비·하수도_물소리 …)을 동시에 고치고 있었다. 2-8 파일만 건드렸다.
