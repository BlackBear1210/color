# 사용자 레퍼런스 반영 — 점프 이펙트 v03

## 이번 요청으로 바뀐 기준

- Dash Effect 광고 이미지의 속도선·점·둥근 선두 잔상 구조를 세로 상승 점프에 맞게 재해석한다.
- Double Jump Effect의 빨간 표시 **오른쪽 = 약한 점프**, **왼쪽 = 강한 점프**다.
- 약한 점프는 고리 없는 성긴 작은 조각. 강한 점프는 분리된 얇은 타원과 아래쪽 긴 조각이다. 이전에 생성한 완전한 파문 확장 시트보다 이 지시를 우선한다.
- 만화의 매끈한 흰 광선을 회백색 물감·마른 붓결·검은 미세 결로 바꿨다. 사용자 원본의 광고·캐릭터·로고는 새 결과에 포함하지 않았다.
- 나무 스프링=쳅터1 / 맨홀 재질=world_2_클로드 결정 유지.

## 파일·시각 확인

- 두 결과를 직접 열어 형태를 확인했다. 세로 잔상은 선두가 위, 꼬리가 아래다. 약은 고리가 없고, 강은 별도 타원이 있으며 조각이 더 길다.
- 두 PNG는 **32bit ARGB, 실제 알파 있음**. 배경을 검정으로 굳힌 RGB 시트가 아니다.
- 4px 간격 98,304점 알파 표본 검사: 세로 잔상은 투명 85,533 / 반투명 12,771; 약강은 투명 92,543 / 반투명 5,761. 좌상단은 두 파일 모두 A=0. 이는 알파 존재 검증이며 최종 게임 가독성 통과를 뜻하지 않는다.
- 효과 픽셀도 반투명이므로 화면 배경과 배율에 따른 밝기는 엔진에서 확인해야 한다. 회백색 원화이며 검정 플레이어용 변환은 구현하지 않았다.
- 눈에 보이는 형태 구분은 확인했으나 정확한 프레임별 피벗 정렬, 재생 떨림, 명도 상한 184, 게임 해상도에서의 가독성은 아직 검증하지 않았다. 명목 셀 값만으로 자동 재생 품질을 보장하지 않는다.
- 도구에 요청한 무광·무발광보다 출력의 재질이 거칠고 밝게 보이는 부분이 있다. 실제 크기 확인 때 조정할 후보로 남긴다.
- Godot 실행·엔진 검사·실제 게임 전후 캡처는 **미실행**. 사용자 명시 실행 허용 없이 실행하지 않는 규칙 준수.
- git status 확인 시 삭제(D) 없음. 다른 작업의 기존 코드·씬 변경은 보존.
