# 벽등 본체 입체 구조 수정

사용자 지적: 빛은 괜찮지만 본체가 종이처럼 평평함. 광원 강도/범위는 유지하고 2-9 본체만 교체.

- 기존 단색 타원+격자는 기본 경로로 보존. 2-9 전용 배경에서 입체_본체=true.
- 신규 sewer_lamp_volume.gdshader: 벽 접촉/우하향 그림자, 볼트4개 고정판, 전선관, 오른쪽/아래로 드러난 케이스 두께, 방향성 금속 음영과 미세질감, 오목한 틈, 곡면 유리, 철망 그림자 및 반사선.
- ColorRect 본체2개를 생성하고 기존 그라데이션 번짐은 부모가 그대로 그림. owner 미지정, 마우스 입력 무시. GPU 효과 범위는 각88x110의 작은 사각형.
- 물/게임판정/지형/조명 번짐/벽면 조명 설정은 변경하지 않음.
- GDScript 정적 파싱, 셰이더 ASCII/괄호, 다른 배경에 옵션 비활성 확인. graphify 갱신.
- Godot 실행 허용 미확인으로 엔진 미실행. 실제 작은 화면에서의 입체감 및 셰이더 컴파일은 미검증이며 완료 판정을 주장하지 않음.
