# 스테이지 2-5 삼색 물 프레임과 물받이 적용

## 요청과 변경

- 사용자 요청: 기존에 적용한 물을 world_2_클로드의 2-5에도 적용.
- `scenes/world_2_클로드/stage_2-5.tscn`의 흰색물_1, 흰색물_2에 힉스필드_삼색프레임을 활성화.
- 너비 192 / 160인 두 낙수에 기존 출수구 스크립트를 연결. 정면 원형 배관에서 작은 물줄기가 물받이를 채우고 넓은 물이 넘쳐 떨어지는 구조 사용.
- 기존 흰색, 위치, 물 크기, 충돌과 벨브_1의 대상 유체 연결 유지. 작업 직전 스냅샷과 비교하여 두 플래그, 출수구 리소스 및 두 노드 추가만 확인.
- 기존 48프레임/24fps 자산 재사용. 새로운 힉스필드 영상 생성은 하지 않음.
- 촬영 도구 `capture_water_stage25.gd`, 전용 검사 `test_water_stage25.gd` 추가. 실행 래퍼에서 새 촬영 도구의 before/after 인자 전달 지원.

## 실제 엔진 확인

- Godot 4.6.3, OpenGL Compatibility, 1920×1080, 카메라 줌 1.0.
- 수정 전후 같은 네 카메라 위치에서 실제 게임 PNG 확보. 수정 후 4장과 수정 전 상단 2장을 직접 열어 확인.
- 캡처: `docs/visual_review/water_reference_20261008/stage_2-5_view_1_before.png`부터 `view_4_before.png`, 같은 이름의 `after.png` 4장.
- 두 물받이의 배관 내부 출수, 넓은 낙수 연결, 바닥의 작은 물 튐 확인. 바닥 물 튐은 작게 유지하며 원본 생성형 시안과 완전히 동일하다고 판정하지 않음.
- 전용 엔진 검사 결과 `STAGE25_ERRORS 0`: 두 물의 원래 크기, 삼색 프레임 연결, 흰색/회색/검정의 본체와 출수부 색 동기화, 물 꺼짐과 재시작, 기존 밸브 대상 유지 통과.
- 수정 전후 촬영과 전용 검사 모두 종료 코드 0.
- 전체 플레이 경로 및 입수/재입수/리스폰 효과를 이번 작업에서 별도로 검증하지 않음.

## 저장소 검사와 제한

- 작업 전 git pull --ff-only: 이미 최신 상태.
- git diff --check 통과, 삭제된 추적 파일 없음. 기존 작업 파일 보존.
- 규약에 명시된 `docs/다음작업_프롬프트.md`가 없어 전체 13개 검사 명령을 확인할 수 없었음. 이번 변경의 전용 엔진 검사와 정적 비교로 검증.
- graphify update 실행. 새 노드 수 8980이 기존 9019보다 적다는 보호 경고가 발생하여 강제 덮어쓰기는 하지 않음. 관계 그래프 전체 갱신 완료로 단정하지 않음.
