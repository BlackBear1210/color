## 원인 (실측)

다시 켜면 `collision_layer` 32 · `monitorable` true · 충돌 도형(물_판정_0) 모두 정상으로 돌아오는데도,
**물리 엔진이 이미 끊긴 겹침 쌍을 다시 만들지 않았다.** 실험:

- monitorable 을 다시 껐다 켬 → 여전히 감지 안 됨
- **물의 충돌 도형을 뺐다 다시 담 → 즉시 감지**
- 호퍼 입구의 monitoring 을 껐다 켬 → 감지

플레이어는 영향이 없었다(물 자신의 `monitoring` 이 다시 켜지며 몸과의 겹침은 새로 계산된다 — 고치기 전/후 모두 감지 확인).
문제는 **다른 Area(호퍼 입구)가 이 물을 감지하는 쪽**뿐이었다.
