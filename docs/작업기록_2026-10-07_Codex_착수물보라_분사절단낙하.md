# 작업기록 2026-10-07 · Codex · 착수 물보라 분사·절단·낙하 수정

## 사용자 피드백과 원인

사용자: “물이 튀는 것보단 일렁이는 느낌이 강해. 점액질이 좌우로 흔들리는 것 같아. 물이 튀는 걸 만들라고.”

이전 버전은 힉스필드 생성 원본의 큰 물살 형태를 유지한 채 정현파로 휘었다. 큰 붙은 물살이 계속 남아 있어 물방울 이동보다 전체 덩어리의 흔들림이 눈에 띄었다. 사용자 피드백을 수용해 이 방식은 교체했다. 이전 작업기록의 원본 리그는 현재 연결에서 제외된다.

## 수정

- tools/착수물보라_힉스필드_분사프레임.py: 힉스필드 원본은 흰 물의 명암·반투명 질감으로만 사용한다. 고정된 긴 물살을 제거하고 지면 물막·낮은 충돌 거품을 남겼다.
- 14개 독립 분사 지점에서 짧은 물살이 뻗는다. 약 65ms 뒤 뿌리가 끊어지고, 분사 조각은 약 205ms 안에 소멸한다.
- 같은 분사에서 3개 물방울이 다른 속도·크기로 분리된다. 바깥으로 이동하고 위로 솟았다 중력에 의해 지면으로 떨어져 소멸한다. 다음 분사가 시작되어도 앞서 나온 물방울은 착지할 때까지 유지한다.
- 큰 물막을 정현파로 휘는 코드가 없다. 힉스필드 원본의 물살/물방울 텍스처를 탄도 위치에서 읽어 그린다. 원본 질감을 도형으로 대체하지 않는다.
- 48프레임·30fps·1.6초 루프·384×128 칸·8×6 배열. 프레임 해상도와 지면 기준점은 기존 셰이더와 같다.
- 실제 연결 자산: assets/textures/obstacles/liquid/impact_higgsfield_burst_v2/white_splash_f48_384x128_g8x6_fps30_loop.png.
- scripts/스마트월드/흰물_디자인.gd: 위 자산으로 교체. 경로 변경 시 텍스처 캐시도 바꾸도록 했다. 좁은 물줄기의 바깥 물방울이 잘리지 않도록 새 시트 사용 시 좌우 그리기 여백 최소 170px.
- shaders/water_stream_natural.gdshader: 동작 설명 주석 변경. 30fps 프레임 보간·흰색만 표시·켜짐/꺼짐 게이트는 유지.
- 적용 범위: world_2_클로드 stage_2-1~2-4의 자연물/v3/흰색/착수 켬. 물리 충돌·물 색 혼합·호퍼 유입 판정은 변경하지 않았다.
- 힉스필드 sandbox에서 기존 생성 원본으로 프레임 구성·검토·압축·업로드했다. 이번 수정에서 이미지/영상 생성 모델을 추가 호출하지 않았다. 생성 비용 추가 없음(프레임 후처리).

## 검증

- 새 대표 8프레임(splash_contact.jpg)을 직접 열어 검토. 물살이 나타났다 사라지고 독립 물방울이 여러 위치로 이동함을 확인. 첫 후처리의 낮은 분출 높이를 올리고 물방울의 속도를 분산해 정돈된 줄처럼 붙어 보이는 현상을 줄였다.
- 48프레임이 모두 다름, RGBA·3072×768, RGB 채널 일치, 마젠타 오염 없음.
- 전체 프레임 유효 범위 x22..363/y59..124. 칸 가장자리와 지면 위 110px/아래 32px/좌우 170px 여백 내에 들어온다.
- 반복 검사용 프레임 48과 프레임 0 픽셀 동일. 마지막→처음 변화 4.067 / 인접 프레임 중앙값 4.643(8비트 RGBA 평균 절대 차이).
- 탄도 위치의 수평 이동 증가, 초기 상승·후반 하강, 마지막 지면 귀환, 분사 뿌리 절단/짧은 수명, 프레임별 분사 개수 변화 확인.
- 원본 SHA256·메타데이터 일치. 실제 시트 경로·30fps 재생·4개 스테이지 스크립트 연결·흰색 게이트·켜짐/꺼짐 게이트·임포트 전 PNG 보조 읽기 확인.
- 파이썬 구문 확인 및 git diff --check 통과. 기존 tools/test_sewer_color_modules.py 재확인.
- 기존 사용자 변경(플레이어·총·월드·2-4 씬·빌더 등)은 수정하지 않았다.
- git pull --ff-only: FETCH_HEAD 권한 오류. graphify query/update: 출력 없이 종료 코드 1. docs/다음작업_프롬프트.md가 없어 검사 13개 명령 확인 불가.
