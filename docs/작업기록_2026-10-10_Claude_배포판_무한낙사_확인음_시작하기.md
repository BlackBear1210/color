## 1. 배포판(Gray.exe)에서만 01 시작방이 무한 낙사

**증상**: F5 는 멀쩡, 내보낸 게임은 01 에 들어가자마자 떨어져 죽고 → 입구 부활 → 또 떨어짐.

**실측** (`Godot_console --main-pack Gray.pck --headless -s probe.gd` 로 배포판 그대로 띄움)
- 배포판: 01 의 모든 목재 지형이 `장식_전용 = true` · `구조_판정색 = null` → `_충돌레이어_갱신()` 이 판정을 끔(레이어 0 · disabled)
- 같은 검사를 프로젝트 원본으로: `장식_전용 = false` · `구조_판정색 = 1` · 바닥에 섬
- 배포판 PackedScene 상태를 열어 보니 **원본 .tscn 에 없는 두 값**이 템플릿 `목재_데크_검정.tscn` 루트와 01 의 모든 인스턴스에 박혀 있었다.

**원인**: 내보내기는 씬을 에디터 안에서 다시 묶어 `.godot/exported/` 에 캐시한다. 15:14 머지로 `지형.gd` 에
`구조_판정색`(새 export 변수, `장식_전용` 앞)이 들어왔는데 **에디터를 켠 채**였다. 에디터 안의 옛 스크립트 인스턴스는
멤버를 순서(번호)로 들고 있어서 새 변수가 끼어들자 값이 한 칸씩 밀렸다 → 이웃 bool 의 true 가 `장식_전용` 에,
`구조_판정색` 은 null. 15:29 내보내기가 그 밀린 값을 그대로 구웠다. F5 는 새 프로세스라 디스크의 스크립트를 새로 읽어 멀쩡했다.

**조치**: `.godot/exported/` 캐시 삭제(재생성됨). 코드 수정 없음.

**재발 방지 — 내보내기 전**: `git pull`/머지로 @tool 스크립트(지형.gd 등)가 바뀌었으면 **에디터를 껐다 켠 뒤** 내보낸다.
이상하면 `.godot/exported/` 를 지우고 다시 내보낸다.

## 2. 로비 확인음 "Cannot open file 로비_붓선택.wav"
`타이틀.gd` 가 `AudioStreamWAV.load_from_file()` 로 원본 wav 를 직접 열었다. 배포판에는 원본 대신 임포트된 .sample 만 들어간다.
→ `load()` 로 바꿈. 내보내기 프리셋 포함 필터의 `assets/audio/sfx/로비_붓선택.wav` 는 이제 필요 없다(`*.json` 은 유지).

## 3. 새 게임인데 '이어하기' 가 뜸
01 은 들어가는 순간 방문이 저장돼, 한 번 죽고 나온 새 게임에도 이어하기가 떴다.
→ `게임진행.진행_있나()` = 클리어가 있거나 **01 밖**을 밟았을 때만. 진행이 없으면 메뉴 첫 항목 = **시작하기**(포커스).
`tools/시험_타이틀_보드.gd` 기대값도 '시작하기' 로.
