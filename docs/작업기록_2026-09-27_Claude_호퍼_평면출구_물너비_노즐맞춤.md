# 작업기록 2026-09-27 · Claude · 호퍼 평면 출구 + 출구 물 너비를 노즐에 맞춤

## 왜

- 원화 직하 노즐은 끝이 **아래에서 올려다본 둥근 입구**(안쪽 검은 구멍)였다. 지형·발판·배관은 전부
  정면 옆모습이라 노즐만 시점이 어긋났고, 물이 그 구멍이 아니라 관 아래 허공에서 시작하는 것처럼 보였다.
- 출구 물이 노즐보다 훨씬 넓었다(2-9: 관 ~60 / 물 128 · 작은 호퍼: 관 ~40 / 물 320~448).
- 도형님 결정: **평면 출구**(호퍼와 같은 재질로) + **물 너비를 호퍼 출구에 맞춘다** ("작아도 돼, 상관없어").
  시안 과정: 출구 이펙트 → 입구 물 채움 → 폭 퍼짐(병 모양이라 기각) → 노즐 키움(통조림이라 기각) → 평면 출구.
