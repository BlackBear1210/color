## 최종 프레임과 연결

- tools/착수물보라_힉스필드_프레임화.py: 힉스필드 원본의 마젠타 배경 기여량을 빼 무채색 RGBA로 복원한다. 빈 배경 여백·희미한 배경 무늬도 제거한다.
- 착수 기준점 고정, 지면 위 물살의 작은 변형, 거품 명암 변화, 원본 물방울 조각의 포물선 이동. 대칭 도형·삼각형으로 물살을 다시 그리지 않는다.
- 48프레임 / 30fps / 1.6초 반복 / 각 칸 384×128 / 8×6 배열 / 3072×768 RGBA.
- 게임 자산: assets/textures/obstacles/liquid/impact_higgsfield_v1/white_impact_f48_384x128_g8x6_fps30_loop.png.
- 메타데이터: 같은 폴더 metadata.json. 원본 SHA256, 생성 job, 리그 방식, 반복 경계 수치 포함.
- 힉스필드 sandbox에서 프레임 제작/검토/압축 후 media_upload PUT HTTP 200·media_confirm을 거쳐 프로젝트로 내려받았다.
- scripts/스마트월드/흰물_디자인.gd: 기존 단순 도형 시트 대신 새 시트를 읽는다. 임포트 전에는 ImageTexture로 원본 PNG를 읽는 보조 경로를 추가했다. 노드별 캐시로 크기·색 갱신 때 반복 파일 읽기를 피한다.
- shaders/water_stream_natural.gdshader: 30fps로 재생하며 현재/다음 프레임을 미리 곱한 색으로 보간한다. 마지막 프레임에서 첫 프레임으로도 보간한다. 셰이더에 한글 없음.
- 적용 조건: world_2_클로드/stage_2-1~2-4 + 자연물 + 물줄기_v3 + 흰색 물 + 착수 효과가 켜진 경우. 호퍼 유입의 착수 끄기·머리/꼬리 도달 조건·기존 색 혼합 및 충돌 코드는 유지한다.
- 씬·빌더·충돌·물기둥 본체는 이번 작업에서 변경하지 않았다. 이전 impact_concept_a 자산/생성기는 과거 시도로 보존하고 현재 게임 연결에서는 사용하지 않는다.
