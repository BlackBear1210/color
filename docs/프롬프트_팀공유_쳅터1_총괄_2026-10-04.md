## A. 지금 프로젝트 상태 (60초)

- 게임: 2D 흑백 다크판타지 퍼즐 플랫포머(Godot 4.6.3 · SmartShape2D 지형). 몸 색과 다른 색 지형에 닿으면 죽는다. 물감총으로 칠한다.
- 흐름: 쳅터1 저택(2층 방 → 복도 → 방 … → 중앙 계단 → 거실 → 굴뚝 → 지붕 → 마당 → 하수도 입구) → 쳅터2 하수도.
- **쳅터1 은 2026-10-04 에 새 10 스테이지로 재구성됐다.** 옛 집 스테이지(2층방 등)는 지우지 않고 챕터 표 11~14 에 남겼다.
- 스테이지 사이는 **연결구**(문 없이 길목 + 가까운 전경 그라데이션 + 반딧불이)로 잇고, 들어가면 줌인 → 짧은 암전 → 다음 스테이지에서 자동으로 걸어 나오며 천천히 줌아웃한다. 되돌아가면 이전 스테이지가 떠날 때 그대로 남아 있다.
- 배경은 레이어(벽지·징두리·몰딩·낡음·가구)를 프리셋으로 바꿔 끼운다. 지금 그림은 Claude 가 코드로 그린 임시본 → 아스트라 그림으로 **같은 파일 이름** 덮어쓰기 예정.

## C. 레벨 디자이너(도형)에게 — 쳅터1 만드는 법

1. 규격은 `docs/쳅터1_스테이지_제작규격.md` 하나만 보면 된다. 숫자 출처는 `tools/쳅터1/규격.py`.
   - 1칸 32px · 점프 높이 5칸 · 거리 10칸 · 몸 3칸 · 오르기는 4칸까지 · 같은 높이 틈 8칸까지 · 판 아래 길 4칸 이상
   - **검정 ≤ 70% · 흰 ≤ 30%** · **흰 판 위 8칸·좌우 2칸 비우기** · 큰 덩어리 두께 4~6칸 · 테두리 위5·아래7·좌우5
2. 고치는 파일은 **도안 JSON 하나**(`scenes/쳅터1/도안/<이름>.json`). 씬(`.tscn`)은 생성물이라 손으로 고치지 않는다.
3. 고친 뒤:
   ```bash
   python tools/쳅터1/만들기.py
   ```
   → 도면 PNG 의 초록 바닥선(닿음)/빨간 바닥선(못 닿음) · 길목 ○/× · 색 비율을 본다. 실패가 0 이어야 한다.
4. 엔진으로 한 번에 찍기(창 모드):
   ```bash
   "C:/Users/Public/godot46/Godot_v4.6.3-stable_win64_console.exe" --path . -s res://tools/촬영_스테이지.gd -- res://scenes/쳅터1/스테이지/쳅터1_01_방_시작방.tscn
   ```
   전환 왕복 시험: `-s res://tools/시험_연결전환.gd` · 결과는 `tools/_진단/`.
5. 고를 것(대기 중): 장애물 오더(`docs/장애물_에셋_리서치_2026-10-04.md`) · 나무 윗면 안 A/B/C(`scenes/쳅터1/도안/미리보기/_예시_목재윗면_비교.png`) · 구조 색 중립/검정(`tools/쳅터1/만들기.py` 의 `구조_색`).
