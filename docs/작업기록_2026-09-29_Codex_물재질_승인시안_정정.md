# 승인한 물 재질로 정정

## 사용자 지적과 원인
사용자가 다시 첨부한 BLACK/WHITE/GRAY 시안은 회색 물 뒤로 벽돌이 비치는 반투명 재질이다. 앞선 5단계는 회색 본체0.4대, 알파0.88로 칠해져 불투명 회색 띠처럼 보였고, 짧은 잔물결 기능에 치우쳤다. 시안의 핵심 재질 차이를 반영하지 못한 점을 정정한다.

## 변경 이유와 범위
- 2-9의 stage5_surface 분기만 수정. 다른 스테이지는 기존 기본 분기를 유지한다.
- 검정: 본체0.016, 불투명에 가깝게 유지, 수면에 은빛의 길고 끊긴 반사선.
- 흰색: 본체0.925~0.9, 알파0.99. 회색은 얇은 수면 잔물결에만 사용.
- 회색: 본체0.43, 기본 알파0.34로 실제 뒤 벽과 잠긴 캐릭터가 비치게 한다. 반사선 부위만 알파를 높여 수면 형태를 읽힌다. 불투명 회색 덮개를 제거했다.
- 기존 입수/보행 잔물결과 수심32px는 유지. 사용자가 앞서 지정한 얕은 수심을 첨부 시안의 깊은 수조로 임의 변경하지 않는다.
- 물줄기 v3, 착수 프레임, 호퍼는 이번 수정에서 변경하지 않는다. 기존 colored_splash 경로가 공중 흰 물방울을0.90~0.98로 그리고 접수면의 작은 음영만 어둡게 구분하는 것을 확인했다.
- 검사 출력 경로를 인자로 받을 수 있도록 test_물_5단계.gd를 조정해 이전 캡처를 보존했다.

## 실제 실행 확인
Godot4.6.3 OpenGL,1920x1080,줌0.8에서 실제2-9를 로드해 재촬영했다.
`docs/visual_review/water_reference_fix/pool_comparison.png`를 직접 열어 검정의 반사선, 흰색 불투명 본체, 회색의 벽돌/다리 투과를 확인했다. 세 물색은 검사 중 변경한 비교 조건이며 실제 스테이지의 기본 웅덩이색은 회색 그대로다.
render.log의 WATER_STAGE5_FAILURES=0: 기존30개 검증 통과. 흑/백/혼합 호퍼 상태도 유지된다.
전체13개 회귀검사를 수정 전후 실행했고, 오류·실패·결과 로그의 비교는 13개 모두 동일했다(regression_comparison.json). 새로 추가된 실패는 없다. git diff --check도 통과했다. graphify update . 완료. 이전부터 존재한 검사 파일 누락, 사망판정/챕터전환 실패, 로비 시간초과, 스마트월드의 stage_2_10 파싱 오류는 별도 기존 문제다. 전체 프로젝트 통과 또는 시안과 완전히 동일하다는 주장은 하지 않는다.
