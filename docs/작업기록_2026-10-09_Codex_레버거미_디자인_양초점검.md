## 디자인 판단과 참고

레버는 저택의 목재/등불 옆에서 읽히도록 얕은 철판 두께, 오목한 축, 마모된 둥근 손잡이에 명암을 집중했다. 장식 문양과 과한 발광을 피하고 판 높이 60px 기준을 유지하는 방향이다. 원화 판 높이는 약 628px이므로 약 0.096배가 출발점이다. 막대까지 포함한 전체 폭은 판보다 넓다. 두 셀은 판과 축 위치가 완전히 같지 않으므로 셀 가운데로 단순 정렬하지 말고 축 기준으로 맞춘다.

거미는 연기나 조각 재질 대신 두 몸통과 관절 다리로 읽히게 했다. 자연 구조의 참고는 [Australian Museum · 거미 식별](https://australian.museum/learn/species-identification/ask-an-expert/what-do-spiders-look-like/), 실을 배 아래 기관에서 내는 참고는 [Australian Museum · 실](https://australian.museum/learn/animals/spiders/silk-the-spiders-success-story/)이다. 종을 정확히 재현한 자연사 도판이 아니라 게임용 해석이다. 반딧불은 딱정벌레 및 배의 발광부라는 구조를 [NPS · Synchronous Fireflies](https://home.nps.gov/grsm/learn/nature/fireflies.htm)에서 참고했다. 팔레트·명암·질감은 프로젝트 화면이 우선이다.

거미 6자세는 상태 교체용 키포즈다. 걸음 두 장이 완성된 8프레임 루프를 대체한다고 주장하지 않는다. 양쪽 다리는 시점상 겹쳐 보이며 작은 크기에서의 식별은 엔진 확인이 필요하다. 기존 150px 길이 기준으로 읽히는 외곽선을 의도했다. 셀별 아래끝이 약 5px 달라 연결 시 발 기준 재정렬이 필요하다. 이전 그을음의 잠복 얼룩/재 소멸 시트를 새 거미의 확정 동작으로 자동 재사용하지 않는다.

## 양초 조사 결과

**시간에 따른 축소는 코드와 PNG에 들어 있다. 현재 표현은 네 단계의 그림 교체이며, 연속적으로 녹는 애니메이션은 아니다.**

- `scripts/쳅터1/타이머양초.gd:74` `_process()`가 남은 시간을 차감하고 0 이하에서 `다탐` 신호를 낸다.
- 같은 파일 `:91`이 비율 0.75/0.5/0.25 경계로 그림 0/1/2/3을 고른다. 0보다 크게 남은 마지막 구간에서는 25% 그림이 계속 보인다.
- `scenes/쳅터1/스테이지/쳅터1_17_응접실.tscn:706` 제한시간 30초, `:738` 양초 노드의 시간도 30초다. `레버퍼즐.gd:128`이 제한시간으로 양초를 켜며 `:52`에서 소진 신호를 받는다. 따라서 현재 응접실 설정에서는 분모와 타이머가 일치한다.

### 보완 후보 — Claude에게 전달할 내용

1. **소진 연기**: 4번 연기 그림을 로드하지만 `_draw()`가 사용하지 않고 3→5로 건너뛴다. 시간 판정은 즉시 끝내되 연기는 짧게 별도 표시하는 편이 자연스럽다.
2. **불꽃과 빛 중심**: `_불높이()`는 남은 비율에 따라 150→60px로 연속 이동한다. 원화는 단계별 고정 높이다. 따라서 각 단계가 유지되는 동안 빛 중심과 불꽃 위치의 차이가 바뀐다. 원화별 불꽃 중심을 기준으로 정렬하거나 초 몸/불꽃/받침을 분리해 시간에 따라 표현한다. 초 전체를 비율로 줄이면 받침까지 찌그러지므로 피한다.
3. **다른 시간으로 재사용할 때**: `켜기(초)`가 실제 남은 시간을 받지만 비율 분모는 항상 export `시간`이다. 현재 17번 씬은 둘 다 30이라 일치한다. 다른 호출 시간으로 사용할 경우 실제 시작 시간을 분모로 저장해야 100%에서 시작한다.
4. **낮은 잔량 깜빡임**: 현재 Color 알파를 원화 전체에 적용해 받침과 초도 같이 깜빡인다. 불꽃만 흔들리는 표현을 원하면 불꽃 레이어를 분리해야 한다.

기존 Claude 캡처 `tools/_진단/새스테이지/17_4_책장열림.png`를 열어 양초가 켜진 상태를 확인했다. 사용자가 첨부한 꺼진/짧은 받침 화면과 상태가 다르다. 두 정지 화면만으로 시간 순서·축소·부활을 검증할 수 없고, 이번 세션에서 엔진을 실행해 만든 캡처는 **없다**.

## Claude 원화 연결 안내

아래는 인수인계이며 Codex가 적용한 코드 변경이 아니다. AI·물리·빛 규칙을 유지하고 렌더링 연결만 바꾸는 최소 변경을 권한다.

1. **레버**: `scripts/쳅터1/벽레버.gd:25`에 `그림_경로` export가 있지만 실제 파일에는 load/texture drawing 경로가 없다. 경로 설정만으로는 원화가 나오지 않는다. 두 셀을 자르고 축 기준으로 정렬한 뒤 현재 `켜짐`에 맞춰 선택한다. 목표 판 34×60, 원점은 기존 축 `Vector2(0,-축_높이+7)`에 맞춘다. 두 막대는 현재 코드의 −0.75/+0.75와 같은 위쪽 대각선이며, 기존 문서의 위/아래 설명과 다르다. 시트와 코드의 좌/우 계약을 기준으로 한다. 중간 회전은 이 두 그림만으로 부드럽게 재생되지 않으므로 상태 전환 또는 별도 막대 부품 처리가 필요하다.
2. **거미**: 조사 시점에는 `그을음.gd` 추적/덮침/빛 반응이 기존 AI이고 별도 거미 AI의 최종 연결은 확인되지 않았다. 새 원화를 곧바로 기존 리소스에 덮어씌우지 않는다. 기존 `_자세()`/`_그림_고르기()` 또는 Claude가 추가하는 렌더링 함수를 연결 위치로 삼는다. 3×2 셀은 512×512이고 발 아래끝을 맞춰 최대 폭 약 150px 기준으로 통일한다. 기존 AI를 원화 교체 때문에 다시 만들지 않는다.
3. **거미줄**: `scripts/쳅터1/거미줄.gd`는 현재 `_draw()` 임시 그림과 `가리나()` 선분 판정을 분리하며 플레이어 물리 충돌이 없다. 그림 상단/하단의 실 끝을 로컬 원점과 `나`에 매핑한다. 긴 잔실까지 포함한 전체 알파 경계를 곧바로 앵커로 쓰지 말고 실제 단단히 묶인 끝을 선택한다. 현재 기본 앵커 길이320px, 그림 반폭70px이다. 별도 texture export/load는 아직 없다. 알파 구멍과 주변 실의 폭은 빛 판정 범위를 자동으로 늘리지 않는다.
4. **반딧불**: 장식용 `반딧불이.gd`와 퍼즐용 `반딧불몹.gd`는 다른 책임이다. 새 이미지는 퍼즐 몹용이다. `반딧불몹.gd:119`에서 `몸`/`날개`를 읽지만 `:393`은 붙었을 때 몸 하나만 그린다. 비행 때는 임시 도형이며 `날개.png`는 해당 그림 함수에서 사용하지 않는다. 이번 시트는 네 개의 완성 자세이므로 상태별로 붙음/비행 및 흰/검 이미지를 선택하도록 연결한다. 전체 몸을 0.25배 어둡게 하는 기존 처리 대신 배 끝의 검은 상태 원화를 고르면 셸의 가시성이 남는다. 머리 위·배 아래 기준, 현재 전체 게임 몸은 대략 25×40px 범위이며 원화 그대로 1254px로 넣으면 안 된다.
5. **빛 규칙**: 검은 배 원화는 별도의 흡수/상쇄/음의 광원 규칙을 정하지 않는다. 실제 `빛색`, `빛_도달`, 요구색은 Claude 코드의 기존 계약을 따른다. 광원 부채와 판정은 본체 이미지에 합치지 않는다.

거미줄 코드에는 거미가 빛에 타면 `삭기()`로 줄을 없애는 경로가 있지만 원래 Claude 지시서의 기본은 지속이다. 이것을 이미지 디자인으로 확정하지 않았으며 Claude가 사용자 최신 기획과 대조해야 한다. 마찬가지로 신규 빛 몹의 색 전환/정지시간 정책은 아트 단계에서 바꾸지 않았다.
