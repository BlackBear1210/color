# 2-1 흑백 무늬 배치와 맵 규칙 보강

## 적용

- `stage_2-1.tscn`의 A_바닥: 내부 흰 벽돌 5개 행. x 약2747~3042, y1136~1236.
- A_갤러리_슬래브: 내부 검정 벽돌 4개 행. x 약2748~3025, y562~640.
- A_샤프트_왼벽과 A_샤프트_왼벽_밑채움: 기존 y1536 내부 직선 접합을 불규칙한 줄눈 접합으로 변경. 양쪽에 같은 선을 역순으로 적용.
- 기존 바닥↔갤러리↔샤프트 맞물림은 유지. 위치, 장애물, 공중 발판, 이동 외곽, 공유 경계 끝점은 보존했다.
- Player 점프 높이10칸을 명시. 기존 점프거리20칸, 줌1.0, 낙하1500 유지.
- 내부 무늬 전용 재질 4개로 기존 공유 재질을 보존했다. 기존 지형 노드에 전용 내부벽돌 스크립트를 적용하여 중복 충돌을 만들지 않았다.

## 문서

아스트라·클로드 프롬프트에 점프/단차/간격/머리 공간과 색조합 배치 규칙을 추가했다. 16px 격자·최소 변90px·색 전환 틈 규칙이 이동 외곽과 벽 내부에 무차별 적용되지 않게 구분했다. 벽 내부 무늬는 외곽24px 여유, 실제 접합은 틈0/겹침0, 통행 표면의 색 전환은 기존 도약 설계 유지.

## 검증

- 적용 시 새 접합 주변 9,625점에서 이전 합집합과 동일하고 중복 점유 없음 확인.
- 기존 ㄱ자 접합 980점 통과. 샤프트 아래 채움도 전체 면적 검사에 포함했다(색 영역끼리 면적 이동이 있으므로 3개만 검사하면 잘못 실패한다).
- 저장된 SS2D 점과 콜리전, 리소스 참조, 재질 UV, 자체 교차 검사 통과.
- 내부 무늬의 모서리/중심이 지형 내부이며 경계에서24px 이상임을 확인.
- Godot 실행/시각/페인트/회수/사망/통행/성능 검증은 미실행. 저장소의 명시적 허가 전 엔진 실행 금지 규칙에 따른다.
- 앞서 발견한 꺼진 유체 총알 충돌 문제는 이 작업에서 수정하지 않았다.
