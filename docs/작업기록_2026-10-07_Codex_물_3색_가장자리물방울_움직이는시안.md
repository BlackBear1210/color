# 물 3색 가장자리 물방울: 움직이는 시안만 제작

사용자가 물 옆에 표시한 빨간 점은 물방울 위치 참고다. 빨간 점 자체를 자산에 넣지 않았다. 이전의 '시안만 먼저' 범위를 유지해 게임 코드/셰이더/씬/색 판정을 이번 작업에서 변경하지 않았다. Godot도 실행하지 않았다.

## 제작

- 기존 굴곡/입체감 3색 시안(`a4c07510-d901-4213-b5dc-162523804cca`)을 시작/끝 프레임으로 Seedance 2.5 영상 제작을 시도했다.
- 첫 영상(`04270b11-3df1-4636-a071-b12a6879d6b2`)은 물방울이 바닥 근처에 집중되어 사용자 요청의 중간/상단 물방울이 부족했다. 채택하지 않았다.
- GPT Image 2.5로 양옆 상단/중간/하단에 물방울이 이미 있는 시작 이미지를 만들었다(`4b158221-0e19-4882-bced-ff755ead4aac`). 색에 맞는 작은 물방울, 가는 반사광, 물줄기와의 틈을 요청했다. 실제 이미지에서 확인했다.
- 이 시작 이미지로 Seedance 2.5 영상 재제작(`35f7e9b6-33ed-4ad3-b666-eb15748d9a6a`). 4초, 1080p, 24fps, 무음. 작은 물방울이 양옆 전체 높이에서 아래로 이동하고 굴곡/질감도 아래로 흐르도록 요청했다.
- 영상에서 0.5초 간격 8개 프레임을 추출해 직접 열어 비교했다. 첫 시도와 달리 상단/중간에도 물방울이 있고 프레임마다 위치가 달라지는 점, 흰색·회색·검정색 밝기 차이, 작은 바닥 물보라를 확인했다. 프레임 비교는 모든 물방울의 궤적이나 반복 경계가 완벽함을 보장하지 않는다.
