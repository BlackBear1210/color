# 철판 SS2D 템플릿

## 목적

확정된 검정·흰색 철판 패치워크 이미지를 기존 SmartShape2D 지형과 같은 방식으로 사용할 수 있게 만들었다.

## 구성

- `assets/textures/smartshape/metal_v1/black/fill_patchwork.png`
- `assets/textures/smartshape/metal_v1/white/fill_patchwork.png`
- 각 색의 `edge_top_thin.png`
- 각 색의 `지형_철판v1_*_사방.tres`
- `scenes/집/스마트 매쉬 assets/METAL_철판/`의 Solid·Stairs 검정/흰색 템플릿 4개

## 재질 결정

철판은 벽돌·나무처럼 한 장의 fill과 하나의 공통 edge만 사용한다. SS2D가 그 edge를 회전해서 사방에 적용한다.

잔디처럼 상하좌우 edge와 안·밖 corner, taper를 각각 두지 않았다. 철판은 얇고 균일한 철제 림이 모서리에서 자연스럽게 이어지는 디자인이므로 별도 코너 텍스처가 오히려 이음선과 겹침을 만들 가능성이 크다.

## 2026-08-31 보정

- `edge_top_straight.png`은 각 가로줄의 색을 동일하게 맞춘 직선 경계다. 생성 이미지의 미세한 가로 요철이 SS2D 사방 회전에서 대각선처럼 보이던 문제를 없앤다.
- `texture_scale`은 `0.6`이다. 외곽 림과 철판 이음선의 월드 두께를 이전의 60%로 줄인다.
- `fill_texture_scale`은 **`0.48`** 이다(성진님이 따로 조정한 값). 채움 패턴만 더 크게 보이게 한 것이라
  엣지 배율과 일부러 다르다. 두 값이 다른 것은 실수가 아니므로 한쪽에 맞추지 말 것.
  검사(`tools/검증_작업자씬.gd 배율표`)도 `METAL: [0.6, 0.48]` 로 이 값을 지키고 있다.
- 네 템플릿의 저장된 `_meshes`를 비웠다. SS2D는 저장된 메시가 있으면 재질을 바꿔도 그것을 먼저 그릴 수 있으므로, 다음 씬 로드에서 새 재질·새 배율로 메시를 다시 굽게 하기 위해서다. 점 배열과 콜리전은 건드리지 않았다.

## 확인

- 새 씬의 모든 `res://` 참조 경로가 존재하는 것을 확인했다.
- OpenGL 호환 렌더러로 Godot 에디터 import를 실행했고 종료 코드는 0이었다.
- 실행 환경이 사용자 Godot 캐시에 쓸 권한이 없어 캐시 관련 경고는 있었지만, 철판 파일의 파싱·참조 오류는 없었다.
