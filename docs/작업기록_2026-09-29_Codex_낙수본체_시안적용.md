# 승인 시안의 낙수 본체 적용

## 변경
사용자가 지적한 대상은 웅덩이가 아니라 떨어지는 유체 본체였다. 흰물_디자인.gd에서 world_2_클로드의 낙수에 water_stream_reference.gdshader를 연결했다. 다른 챕터는 기존 v3를 유지한다.

왜: 기존 넓고 매끈한 반사띠는 튜브처럼 보이고 흰 물은 조명에 의해 뭉개졌다. 하수도 낙수 전용 unshaded 재질에서 화면 배경 굴절을 읽고 가늘고 불규칙한 흐름을 덧그린다. 검정은 어두운 본체, 흰색은 밝은 본체와 얇은 음영, 회색은 뒤 벽이 비치는 굴절을 갖는다. 실제 물살은 시간에 따라 움직인다.
착수부에 수명과 포물선 궤적을 갖는 작은 물방울 42개 및 접촉 거품을 추가했다. 흰 공중 물방울은 흰색이며 접수면의 작은 음영만 어둡다. 기존 프레임과 판정, 호퍼가 정하는 노즐 폭, 출구 접점은 유지한다.

## 실제 확인
Godot 4.6.3 OpenGL / 1920x1080 / 줌0.8 / 실제 stage_2-9.
docs/visual_review/stream_reference/before.png는 수정 직전 실제 호퍼 캡처 보존본.
hopper_0/1/2.png는 수정 후 세 상태. before_after.png는 동일 카메라 영역을 원래 픽셀 크기로 자른 비교이며 직접 열어 보았다. 세로선의 반복 점무늬가 보인 첫 결과를 수정해 연속적인 불규칙 흐름으로 조정했다.
물 관련 검사 30개 PASS, WATER_STAGE5_FAILURES=0. 셰이더/스크립트 오류 없음. 기존 Unicode/인스턴스 경고는 남는다.
필수13개 전후 실행. 12개 결과 로그 동일. 스마트월드는 새 셰이더 추가로 103→104개 검사, 실패0으로 증가했으며 기존 파싱 오류는 그대로다. 챕터 검사는 기존33/39 결과 후 비정상 종료(-1073741819)가 다시 관찰돼 전체 통과라고 보고하지 않는다. 로비 시간초과 및 기존 누락/실패도 남는다.
git diff --check 통과, graphify update 완료.

## 남은 차이
시안은 넓은 낙수가 웅덩이에 떨어지는 장면이며 2-9 캡처는 64px 호퍼 노즐 물이 바닥에 떨어지는 구조다. 이 구조와 판정 폭은 바꾸지 않았다. 따라서 시안과 픽셀 단위로 같다는 의미는 아니다. 하수도 공통 분기로 연결했지만 실제 시각 검증 범위는 2-9다. 6단계 확인은 보류한다.
