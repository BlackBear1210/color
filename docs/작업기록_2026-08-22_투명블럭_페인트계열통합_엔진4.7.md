## 1. 투명블럭 (신규)

- `scripts/스마트월드/투명블럭.gd`
- `scenes/집/스마트월드_장애물/투명블럭.tscn`

### 규칙 (도형님 지시)

- 색을 입히지 않으면 **밟거나 부딪칠 수 없다** → 무색이면 `collision_layer = 8`(유령).
  플레이어는 통과하고, **총알은 맞는다**(`총알.gd` 의 `단단한_레이어 = 1 | 8`).
  안 그러면 칠할 방법 자체가 없다.
- 색을 입히면 단단해진다 → `collision_layer = 1`.
- 너무 투명하면 인지가 안 되므로 **모션블러처럼 좌우로 번지게** 그린다.

### ★통과플랫폼과 정반대의 물건이다 — 헷갈리지 말 것

| | 통과플랫폼 | 투명블럭 |
|---|---|---|
| 안 칠했을 때 | **밟힌다** | **못 밟는다** |
| 물이 페인트를 | **못 지운다**(`물에_안지워짐()`) | **지운다** → 발판이 도로 사라진다 |

→ **흰 물 아래의 투명블럭은 흰색으로 칠해야만 남는다.** 검정으로 칠하면 발판이 생겼다가
물에 지워져 사라진다. 이 대비가 하수도 챕터 관문 3의 퍼즐 문법이다(계획서 §4-2).

### 겉모습 — 두 번 실패하고 고쳤다 (같은 실수 반복 방지)

1. **잔상을 몸통과 겹쳐 그렸다** → 알파가 누적돼 불투명한 회색 덩어리가 됐다. 투명이 아니었다.
2. **얇은 사각형을 이어 붙였다** → 이음매마다 알파가 겹쳐 **빗살무늬**가 생겼다.
3. → `draw_polygon` 의 **정점 색 보간**으로 한 번에 그린다. 이음매가 아예 없다.

인스펙터 값: `번짐폭`(34) · `흔들림_주기`(2.6) · `몸통_알파`(0.24).
배경이 밝은 스테이지면 알파를 올린다.

## 2. stage_lab 계열에서 색칠이 안 되던 것 수정

### 증상

`stage_2-1` 에 투명블럭을 넣고 총을 쐈는데 **아무 일도 안 일어났다.**

### 원인

총알이 계열마다 다르다.

| | 스마트월드(`월드.gd`) | stage_lab |
|---|---|---|
| 총알 | `총알.gd` | `proto_bullet.gd` |
| 대상 찾기 | `명중` 메서드가 있는 노드를 **부모로 거슬러 찾음** | `PaintPlatform` **또는** `TileMapLayer` **둘만** |

`proto_bullet.gd` 는 두 갈래뿐이라 하수도 장애물이 **어디에도 안 걸리고** `빗나감()` 으로 흘렀다.
총알은 맞았는데 페인트만 환급되고 끝났다. (레이어 문제가 아니었다 —
`PaintPlatform.유령_레이어비트` 도 8 이라 충돌 자체는 되고 있었다.)

### 고친 것

- **`proto_bullet.gd`** — `_칠할대상_찾기()` 추가. `총알.gd` 와 같은 방식으로 `명중`+`현재색` 을
  가진 노드를 부모로 거슬러 찾는 갈래를 **앞에** 얹었다. 기존 두 갈래는 그대로 →
  `zone_*`·`world_1` 회귀 없음.
- **`tile_paint_map.gd`** — `노드_명중()` 진입점 신설. 규칙은 `페인트_코어.명중_처리()` 를
  그대로 따른다(`painted`/`progress` → 회수줄, `wasted`/`blocked` → 환급, `mixed_gray` → 잠금).
  - E 회수 FIFO 가 타일과 섞이도록 **같은 `_큐`** 에 세운다(`외부칠` 항목).
  - 회색은 큐에서 빠지므로 `_외부_회색` 목록을 따로 든다
    (`페인트_코어` 가 `_회색_목록` 을 드는 것과 같은 이유 — 없으면 죽어도 회색이 안 풀린다).

### ★덤 — 다른 하수도 장애물도 같이 고쳐졌다

`통과플랫폼`·`물저장고`·`호퍼` 도 전부 같은 이유로 stage_lab 씬에서 안 칠해지고 있었다.
이제 된다. **하수도 챕터를 stage_lab 계열로 찍는다면 이게 선행 조건이었다.**

### ⚠ HUD 가 큐 원소를 직접 읽는다 — 한 번 터졌다

`회수줄_요약()`·`대상_발수()`·`대상_좌표()` 가 `_큐` 원소에서 **`플랫폼` 의 필드를 그대로 읽는다.**
`외부칠` 에 그 필드가 없어서 HUD 가 그려지는 순간 `회색` 접근에서 죽었다.
→ `외부칠` 에 `회색`(항상 false)·`좌표`(마지막 명중 지점)를 맞춰 두고,
`대상_좌표()` 만 갈라 봤다(외부 노드는 레이어·셀이 없다).

**교훈: 규칙 검사만 하고 HUD 가 읽는 길을 안 밟으면 또 놓친다.** 검사에 그 경로를 넣었다.
