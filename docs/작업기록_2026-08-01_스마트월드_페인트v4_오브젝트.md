## 2. 페인트 시스템 v4 — 확정 규칙과 구현 위치

**규칙은 [scripts/스마트월드/페인트_코어.gd](../scripts/스마트월드/페인트_코어.gd) 한 파일에만 있다.**
지형·식물·발판은 "내가 무슨 색인지"만 답하고, 발수·회수 순서·회색 판정은 전부 코어가 한다.
→ 규칙이 바뀌면 이 파일 하나만 고치면 전 오브젝트가 따라온다.

| # | 규칙 | 구현 |
|---|---|---|
| 1 | 지형에 쏘면 그 색으로 칠해진다 | 대상의 `명중()` → `"painted"` |
| 2 | 칠해진 색 위에 **반대색** → **회색** | 대상이 `"mixed_gray"` 반환 |
| 3 | 회색은 **수동 회수 불가**, 스테이지 이동 시에만 회수 | 회색은 회수줄에서 제거 → `리셋()`에서만 복구 |
| 4 | 회수는 **FIFO**(먼저 칠한 것부터), 회색은 제외 | `_회수줄` 배열 `pop_front()` |
| 5 | 회색은 **2발** 소모 | 원래 색 1발 + 덮은 1발이 둘 다 `_잠긴_발수` 로 이동 |
| 6 | 빗나감 / 같은 색 덧칠 / 칠 불가 → 즉시 환급 | `"miss"`/`"wasted"`/`"blocked"` → `_환급(1)` |
| 7 | 부분 색칠은 서서히 흐려지다 자동 회수 | `지형.gd` 의 `부분_유지시간`·`부분_감쇠시간` |

### 회색이 2발인 게 왜 자동으로 성립하나
따로 세지 않는다. 검정으로 칠할 때 1발이 잠기며 회수줄에 등록되고, 흰색을 덮으면
또 1발이 잠기면서 **그 항목이 회수줄에서 빠진다**. 결과적으로 두 발 모두 스테이지가
넘어갈 때까지 안 돌아온다 = 규칙 5 와 동일하다.

### 자동 검증
```bash
Godot --headless --path . -s res://tools/test_페인트v4.gd
```
기획서의 예시(1검정 2흰색 3검정 4검정 5회색 6흰색 → 회수 순서 1,2,3,4,6)까지 그대로 검사한다.
**현재 32/32 통과.**

## 3. 지형 — SmartShape2D + 페인트 셰이더

### 파일
- [scripts/스마트월드/지형.gd](../scripts/스마트월드/지형.gd) — `SS2D_Shape_Closed` 를 상속한 `스마트지형`
- [shaders/지형_페인트.gdshader](../shaders/지형_페인트.gdshader) — 흑/백 아트를 얼룩 마스크로 섞는다

### 어떻게 색이 칠해지나
`black_*.png` 와 `white_*.png` 를 **같은 UV 로 두 장 샘플해서 섞는다.**
밝기만 조절해 흉내내면 흰색 지형의 잔디·균열 무늬가 검정과 달라 어색해지기 때문이다.
얼룩은 **노드 로컬 좌표(px)** 기준 원이라 채우기와 테두리에 똑같이 얹힌다.

| 상태 | 화면 |
|---|---|
| 무색(구조물) | 검정 아트 그대로, 불투명 |
| 무색(공중 발판) | **42% 반투명 유령** — 밟을 수 없다 |
| 검정 / 흰색 | 해당 아트로 전체가 덮인다. 실체가 되어 밟을 수 있다 |
| 회색 | 흑·백을 반씩 섞은 중간톤. 다시 못 칠하고 수동 회수도 안 된다 |

### 알아둘 함정 3가지 (실제로 겪은 것들)
1. **`fill_texture_z_index` 기본값이 -10 이다.**
   배경 보정 레이어(z=-7)보다 뒤라서 지형 안쪽이 통째로 가려졌다(테두리만 보이는 상태).
   → 재질에서 **-1** 로 올렸다.
2. **배경과 지형의 명도가 겹치면 실루엣이 먹힌다.**
   바이옴 배경(0.15~0.36)과 `black_fill`(≈0.10)이 거의 같아 화면이 새까맸다.
   → 배경과 지형 **사이**에 밝은 반투명 판(`대기`, z=-7)을 끼워 배경을 0.55 대로 올렸다.
3. **`Node2D.new() + set_script()` 로 만들면 안 된다.**
   `SS2D_Shape._init()` 이 안 돌아 점 배열이 null 이 된다. 항상 `스크립트.new()` 를 쓸 것.

## 5. 테스트 스테이지 구성 (자연 → 물가)

```
①   0~1180  숲 바닥      식물 A 2개, 반딧불 7개
② 1180~1620 구덩이       공중 발판 3개 — 칠해야 실체가 되어 건널 수 있다
③ 1620~2560 물 구역      저장고→배관→호퍼→물줄기 / 갱도(1950~2210) / 통과플랫폼 vs 일반 발판
④ 2560~3200 덤불 구역    식물 B 2개 = 임시 색 지대
⑤ 3200~4300 바람 구역    송풍기 + 연기 + 직선레버 갈래 물줄기 + 가로등 3개
```

**핵심 시연 지점 — 갱도(x≈2080)**
저장고를 흰색으로 칠하면 → 물줄기(위) 켜짐 → 호퍼가 받음 → 물줄기(아래) 켜짐.
그 물줄기 안에 **통과플랫폼**과 **일반 발판**을 나란히 뒀다.
둘 다 검정으로 칠해두면 흰 물이 지날 때 **일반 발판만 색이 지워지고 페인트가 회수된다.**
"왜 통과플랫폼이 필요한가"가 한 화면에서 읽힌다.

배경은 `stage_backdrop.gd` 를 그대로 재사용해 **왼쪽 자연 → 오른쪽 물가**로 흐른다.
각 스테이지의 끝 바이옴 = 다음 스테이지의 시작 바이옴이라, 이어 붙이면 하늘이 계속 이어진다.

## 6. 내가 직접 만드는 법

### 6-1. 지형 다듬기 (가장 자주 할 일)

1. `scenes/스마트월드/스마트월드_테스트.tscn` 을 에디터에서 연다
2. `지형/` 아래 아무 노드나 고른다 → 화면 위에 **SS2D 툴바**가 뜬다
3. 편집
   - **Alt + 좌클릭** : 점 추가
   - 점 드래그 : 이동
   - **Shift + 드래그** : 베지어 곡선 (부드러운 언덕)
   - 점 위에서 **Alt + 클릭** : 삭제
4. 모양을 바꾸면 콜리전은 자동으로 다시 구워진다 (`collision_update_mode = EditorAndRuntime`)

> ⚠ **`tools/build_스마트월드.gd` 를 다시 돌리면 씬이 통째로 덮어써진다.**
> 에디터에서 다듬기 시작했다면 그 뒤로는 돌리지 말 것.
> 지형을 처음부터 새로 뽑고 싶을 때만 쓴다.

### 6-2. 발판 하나 추가하기

1. `지형/` 안의 발판을 하나 복제(Ctrl+D)
2. 위치를 옮기고 점을 다듬는다
3. 인스펙터에서
   - `칠하기_허용` : 끄면 칠할 수 없는 구조물(바닥·벽)
   - `무색일때_통과` : 켜면 **칠해야 생기는 유령 발판**
   - `필요횟수_수동` : 0 이면 크기에서 자동(96px 당 1발), 값을 넣으면 그게 우선
   - `CanvasItem > Texture > Filter` = **Nearest** (픽셀아트라 필수)

### 6-3. 오브젝트 배치하기

`오브젝트/` 안의 같은 종류를 복제하는 게 가장 빠르다. 연결이 필요한 것만 정리하면:

| 오브젝트 | 인스펙터에서 연결할 것 |
|---|---|
| 물 저장고 | `공급_유체` → 색을 공급할 물줄기 노드 |
| 호퍼 | `출구_유체` → 받은 물을 내보낼 아래쪽 물줄기 |
| 배관 | `연결_유체` → 색을 따라갈 물줄기 (비우면 무색 금속) |
| 제어레버(원형) | `대상_유체` → 켜고 끌 물줄기 |
| 제어레버(직선) | `갈래_A`, `갈래_B` → 번갈아 켤 두 물줄기 |

### 6-4. 새 스테이지 만들기

가장 쉬운 방법은 `tools/build_스마트월드.gd` 를 복사해서 고치는 것이다.
지형은 `_바닥_점들()` / `_덩어리_점들()` 두 함수가 다 만들어 준다.

```gdscript
# 바닥 구간을 이렇게 나열하면 그 사이가 구덩이가 된다
var 구간 := [
    [-200.0, 1180.0],
    [1620.0, 1950.0],   # ← 1180~1620 이 구덩이
    [2210.0, 2560.0],   # ← 1950~2210 이 수직 갱도
]
```

**레벨 디자인 안전 수치** (플레이어 점프 성능에서 역산 — 동현 테스트월드제작과 동일 세팅)
- 점프 높이 = 10칸 × 16px = **160px** / 점프 거리 = 20칸 × 16px = **320px**
- → 발판 간격 **≤ 260px**, 단차 **≤ 130px** 로 잡으면 안전하다

### 6-5. 확인 명령 모음

```bash
# 씬 새로 생성 (덮어쓰기 주의)
Godot --headless --path . -s res://tools/build_스마트월드.gd

# 페인트 규칙 자동 검사 (32항목)
Godot --headless --path . -s res://tools/test_페인트v4.gd

# 스크립트 파싱만 검사
Godot --headless --path . -s res://tools/check_스마트월드.gd

# 실제 화면 확인 — 발판 3개를 흰/검/회로 칠하고 물길 실험까지 자동 수행
Godot --path . -s res://tools/shot_페인트_확인.gd -- 결과.png 2080 700 0.75

# 그냥 스크린샷
Godot --path . -s res://tools/screenshot_scene.gd -- res://scenes/스마트월드/스마트월드_테스트.tscn 결과.png
```

## 7. 아트 파이프라인 주의 (2026-08-01 사고 기록)

`.aseprite` 원본은 **옛 크기**인데 PNG 만 32×16 으로 통일된 상태다.
이 상태에서 `tools/aseprite_export.ps1` 을 돌리면 **옛 크기가 덮어써져 작업이 날아간다.**

- PNG 를 직접 손봤다면 → **복사만** 할 것
  ```bash
  Copy-Item "<원본폴더>\*.png" "assets\textures\smartshape\" -Force
  ```
- `.aseprite` 원본까지 최신으로 맞춘 뒤에야 export 스크립트를 쓸 것

새 PNG 를 넣은 뒤에는 항상:
```bash
Godot --headless --path . --import
```
