## 3. 흐름 (도면 주석 그대로)

1. **시작 복도**(칸 17~36 · 바닥 34.5) → **격자 수갱**. 물_1~4(각 160 폭)가 천장(9)에서 낙사존까지. 물_1·물_3 / 물_2·물_4 가 한 묶음 — 한 묶음이 검정이면 다른 묶음은 흰색 · **3 초마다 바뀐다**. 격자는 물을 통과시킨다.
2. 위쪽 격자 3 장(검 → 흰 → 흰)으로 **L 바위**(윗면 33) → **벨브_1** 이 흰물_1(천장 → 호퍼) 을 끈다 → 호퍼 출구 흰물_2(→ 아래 블록)도 멈춘다.
3. 호퍼 위를 걸어 → 오른쪽 바위 → **양옆 세로 가시 블록** → **흰물_3**(2 초 켜짐 / 2 초 꺼짐) 너머 블록 → **흰 공중발판**(흰 몸) → 블록 → 열쇠 복도(**천장 톱** 좌우) → **검정 열쇠** → 도착 문이 열린다(304 위로).
4. 돌아와 흰물_3 받이 블록(50.5)으로 떨어지고 → 아래 블록(92.5)으로 떨어진다(1344 < 치명 1500).
5. **아래 블록**(CP) — **양동이_1** 에 페인트를 쏴 채우고 **발판_1**(홈 · 홀드 · 양동이 전용)에 민다 → **움직이는 발판**이 오른쪽(칸 171)에서 블록 옆(칸 136)으로 온다 → 올라타 **E**(양동이 페인트 회수) → 발판이 풀려 쉬는 자리로 돌아간다(도면: "활성화시켜야 다가오고 비활성화시키면 원래 위치로").
