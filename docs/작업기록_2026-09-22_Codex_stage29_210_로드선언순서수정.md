# 2-9·2-10 로드 오류와 2-11 변경 범위 정정

## 원인과 수정

지난 Codex 부분 패치에서 새 ext_resource 선언이 두 씬의 노드 뒤로 삽입됐다. 2-9의 shortcut_grate는 최초 참조4799행보다 뒤, 2-10의 return_grate도 최초 참조5477행보다 뒤에 있었다(수정 전 줄 번호). 기존 정적 검사는 ID가 파일 어디엔가 존재하면 통과했으므로 Godot의 선언 순서 제약을 검출하지 못했다.

각 선언 한 줄만 기존 외부 리소스 선언부로 옮겼다. 지형/장치 배치는 이번에 변경하지 않았다. `tools/check_tscn_resource_order.mjs`로 외부→내부 리소스→노드→연결→editable 순서, 참조 전 선언, 중복 ID 검사를 추가하고 기존 맵 정적 검사에 연결했다. 정상/선언 후참조 역전/노드 뒤 선언/중복 ID 고장 예제도 검사한다.

## 실제 수행 검사

- 수정 전 신규 검사: 2-9 shortcut_grate, 2-10 return_grate에서 각각 실패하는 것을 확인.
- 수정 후 `tools/test_stage_2_9_11_static.mjs 9 10 11`: 세 판 통과.
- 대상 두 씬 `git diff --check`: 통과.
- 2-11 SHA-256은 이전과 같은 `1F4D5C367311C39C2842B29DD28E40865A01614237D59484D102EEF1D8D19CEA`로 미변경 확인.
- Godot 실행/리소스 실제 로드/플레이/프로젝트 엔진 회귀 검사는 사용자 안전 규칙에 따라 미실행. 정적 통과를 엔진 로드 확인으로 보고하지 않는다.
- graphify 조회는 networkx 누락으로 실패했다. 씬 원문과 직접 참조를 근거로 수정했다.

## 2-11 설명 정정

지난 작업은 방3 우회 격자3개/분사기 제거, 방4 A/B 배수 레버, 방5 착지 바닥256px 연장 방향 변경 및 붕괴3 위치·폭, 스폰/체크포인트/설정 수정이다. 5개 방이 우하향하며 같은 하강 계단을 반복하는 전체 구성과 외관은 바꾸지 않았다. 따라서 사용자가 요청한 눈에 띄는 디자인 개편을 완료했다고 볼 수 없으며, 퍼즐 우회 보정과 전체 레벨 재설계를 구분해야 한다. 이번에는 사용자 질문에 변경 내역을 설명하고 두 씬의 로드 구조 오류를 고치는 범위로 작업했다.
