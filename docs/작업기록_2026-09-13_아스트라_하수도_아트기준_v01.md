사용자가 제안된 순서(기준 화면 → 장치 상태 → 작은 시험 구간 → 맵 하나 적용 → 전체 확대)에 따라 진행하도록 요청했다. 이번 작업은 첫 시각 기준을 검토할 수 있게 만드는 단계다.

산출물은 `docs/아트기준_스테이지2_v01/`에 둔다.

- `기준장면_v01.png`: 생성한 디자인 시안. 실제 플레이 캡처나 완성된 게임용 배경이 아니다.

기존 배경과 장애물 소스를 확인했다. 현재 가시·톱 공통 코드에는 붉은 경고색이 있고, 투명 발판은 모자이크·가로 번짐을 사용한다. 기준안에서는 검흰 기계적 위험 표현과 부드러운 반투명 표현으로 정리했다. 실제 공용 스크립트를 교체한 것은 아니다.

회색 판정인 물체를 검정 그림으로만 바꾸지 않는다는 원칙을 명시했다. 배경 중간 명도와 안전색 물체의 회색은 구분한다. 플레이 공간의 일반적인 회색 안전수는 기준 장면에서 제외한다.
