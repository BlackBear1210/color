# 격자 흑백 대비·챕터2 입구 표시·열쇠 디자인 통일

사용자 요청: 배경에 묻히는 격자 발판의 검정/흰색을 또렷하게 칠하고, 챕터2 시작 시 플레이어를 검은 가림막보다 앞에 표시하며, 챕터1 열쇠 디자인을 챕터2에도 적용한다. 시작 좌표 이동이 아니라 표시 순서 변경이라는 사용자 답변 확인.

## 변경

- `shaders/grate_fixed_color.gdshader`: 기존 주철 아틀라스의 질감과 투명 구멍을 유지하면서 검정 본체 명도 0.012~0.087, 흰 본체 0.78~1.0으로 구분. 화면 공간 약 0.8px 이웃 알파를 이용해 검정에는 회색 가장자리, 흰색에는 어두운 절단선을 준다. 이동 광원과 무관한 unshaded 방식. 셰이더에는 규약에 따라 영문 주석만 사용.
- `scripts/스마트월드/통과플랫폼.gd`: 발판마다 별도 ShaderMaterial에 기존 고정색을 전달. 에디터 색 변경 시에도 재질 갱신. 평면/원근 발판 모두 같은 고정색을 사용하며 충돌·물 통과·명중 차단·색 사망 규칙은 유지.
- `scripts/스마트월드/격자_원근그림.gd`: 윗면 명암 배수 1.0, 앞 단면 0.88. 기존 면 기하·볼트·격자 반복·구멍을 유지하고 흰 윗면이 다시 회색으로 눌리지 않게 조정.
- `scripts/스마트월드/월드.gd`, `연결통로.gd`: 하수도 씬에서 플레이어 z 최소 1, 입구 검은 전경띠 z 0. 출구 전경띠는 z 60을 유지. 시작 좌표/통로 진입 좌표/리스폰은 변경하지 않았다. 챕터1의 통로 표시 순서는 유지.
- `scripts/스마트월드/열쇠.gd`: 새 하수도 열쇠의 기본 디자인을 챕터1과 동일한 원형 열쇠로 지정. 기존 획득·문 이동 규칙은 유지.
- `scenes/world_2_클로드/stage_2-8.tscn`: 검정/흰 조각에 새 디자인 2/3 연결. 2-5·2-6 완성 열쇠 및 2-7 두 조각은 이미 같은 자산을 쓰므로 보존. 현재 하수도 기존 열쇠 6개 모두 같은 디자인을 사용한다.

## 확인

- 시작 전 `git pull` 시도. 최초 샌드박스 쓰기 제한 후 권한이 있는 실행으로 재시도했으나, 기존 미커밋 `월드.gd`·`챕터.gd` 변경과 원격 변경이 겹쳐 병합 중단. 자동 stash/덮어쓰기를 하지 않았다.
- 수정 전 6개 대상 파일을 `tmp/grate_visibility_20261010/` 아래 원래 경로 구조로 백업.
- 기존 로컬 gdtoolkit으로 대상 GDScript 5개 수정 전/후 구문 분석 통과. Godot API나 셰이더 컴파일을 검증하는 검사는 아니다.
- 충돌·고정색·물 통과·명중·시작 위치·리스폰·문/조각 획득 관련 기존 함수 22개가 백업과 동일함 확인.
- 하수도 11개 씬의 수정 전/후 리소스 선언·참조 순서, 참조 파일 존재, 노드 중복 정적 확인 통과. 2-8은 두 그림 속성 추가를 제거하면 백업과 동일.
- 셰이더의 한글 미포함, 원본 알파 보존, unshaded 지정 확인. 기존 원본 아틀라스를 직접 열어 보았으며 자산은 수정하지 않았다.
- `git diff --check` 통과. 기존 음향·로비·몬스터 관련 미커밋 작업 보존. 추적 파일 삭제 없음.
- `docs/다음작업_프롬프트.md`는 현재 체크아웃에 없음. 규정된 엔진 검사 13개는 사용자 Godot 실행 허용이 없어 전후 모두 **미실행**. 위 정적 검사는 이를 대체하지 않는다.
- `graphify update .` 실행: 코드 1,037개 AST 재추출 완료. 새 그래프 14,770개 노드가 기존 graph.json 34,986개보다 작아 덮어쓰기를 거부하는 보호 경고 발생. 강제 덮어쓰기는 하지 않았으며, 기존 graph.json 전체 갱신 완료로 보고하지 않는다. 설치된 CLI는 스킬의 `reflect` 명령을 지원하지 않아 회고 자동 갱신은 미실행.

## 시각 검증 대기

상태: **수정 완료·시각 검증 대기**. Godot 편집기/콘솔/headless/빌더/촬영 도구는 실행하지 않았다.

실제 수정 후 엔진 캡처 경로: **없음**. 첨부 사용자 화면은 문제 확인 자료이며 수정 후 검증 이미지가 아니다.

남은 확인: 같은 스테이지·줌·해상도에서 검정 격자의 몸체와 가장자리가 배경에 분리되는지, 흰 격자가 충분히 흰색으로 읽히는지, 원근 단면·구멍·반복 이음새·착지 발 위치를 확인해야 한다. 챕터2 입구에서 플레이어가 검은 띠 앞에 보이는지와 출구/왕복 전환, 입수·물 안 이동·재진입·리스폰의 물 가림 순서도 실제 실행 확인이 필요하다. 열쇠 6개의 크기·중심·가독성과 두 조각 획득 뒤 문 열림은 아직 엔진에서 확인하지 않았다.
