# 추가 작업기록 — 2026-10-08 Codex 출수부 재구성

사용자 지적: 물이 정면 배관 내부에서 나오지 않고 아래에서 끊겨 시작했다. 원본과 실제 캡처를 비교한 뒤 같은 2-1~2-4 적용 범위에서 출수부를 다시 구성했다.

## 수정
- 원형 구멍 내부의 원본 곡선 출수부를 삼색으로 분리했다. 물이 구멍 안쪽에서 시작해 배관 턱을 넘어 연결되도록 겹침 순서와 투명 마스크를 수정했다.
- 원형 배관 아래를 사각형으로 잘라내던 방식은 새 부품에서 사용하지 않는다. 물막은 출구의 좁은 폭에서 시작해 40px에 걸쳐 기존 폭으로 넓어진다. 기존 충돌 크기는 유지한다.
- 고정 검정 띠가 남지 않도록 출수 이미지 아래 끝을 흐르는 본체에 부드럽게 겹쳤다. 검정 출수부가 회색 판처럼 보이지 않도록 명암을 낮췄다.
- 물받이 높이 제한을 110px에서 원본 비례(상한 310px)로 변경했다. 고인 수면과 앞턱을 넘는 원본 물 층을 복원했다.
- 뒤벽의 공급수 흔적을 지울 때 벽까지 비던 부분은 주변 돌 질감으로 보완했다. 공급수는 뒤벽 앞에 그려 수면까지 이어지도록 수정했다.
- 넓은 물의 프레임 셀을 256×512에서 512×512로 높여 확대 질감의 뭉개짐을 줄였다. 착수 프레임 합성 강도도 조금 올렸다. 호퍼 연결 배관과 게임 판정은 그대로 유지한다.
