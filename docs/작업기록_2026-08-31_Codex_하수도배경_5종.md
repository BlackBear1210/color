# 작업기록 — 하수도 배경 5종

- 날짜: 2026-08-31
- 작업자: Codex
- 목적: 폐수로 스테이지에 사용할 흑백 다크판타지 배경 후보를 추가했다.

## 추가한 에셋

모두 1672×941px 가로 PNG이며, 기존 실내 배경의 저채도 흑백·검은 비네트·희미한 백색광을 기준으로 만들었다. 처음 생성본은 재질 묘사가 지나치게 사실적이어서 교체했다. 현재 파일은 벽돌 한 장 단위의 디테일을 없애고 큰 아치·파이프·수문·기둥 실루엣과 안개만 쓰는 단순한 2D 배경이다.

| 파일 | 장면 역할 |
|---|---|
| `assets/background/stage_2/sewer_01_main_passage.png` | 벽돌 아치와 수로가 이어지는 주 통로 |
| `assets/background/stage_2/sewer_02_entrance.png` | 지하실에서 원형 하수도로 들어가는 입구 |
| `assets/background/sewer_03_pump_chamber.png` | 대형 수문과 파이프가 있는 펌프실 |
| `assets/background/stage_2/sewer_04_cistern.png` | 기둥과 얕은 수로가 있는 저수조 |
| `assets/background/stage_2/sewer_05_outlet.png` | 빛이 새어 들어오는 철창 출구 |

## 사용 메모

- 실제 충돌·발판·퍼즐 기믹은 씬의 지형과 장식이 맡는다. 배경에는 읽기 쉬운 중앙·하단 여백을 남겼다.
- 배경만 추가했으며 씬, 게임 로직, 리소스 참조는 변경하지 않았다.
- 생성 원본은 Codex 이미지 생성 도구로 만들었고, 프로젝트에서 사용할 사본만 위 경로에 추가했다.
- 이 에셋 작업 중 Godot 헤드리스 검사를 실행했을 때 엔진 충돌 창이 떠 즉시 해당 프로세스만 종료했다. 이후 재생성·파일 교체에는 Godot를 실행하지 않았다.

## 3장 전환 배경 추가

아래 이미지는 기존 하수도 배경 사이에 넣어 장면의 구조와 빛의 방향이 끊기지 않도록 만들었다.

| 파일 | 연결 역할 |
|---|---|
| `assets/background/stage_2/sewer_06_cistern_transition.png` | 아치·파이프 통로 → 기둥 저수조 |
| `assets/background/stage_2/sewer_07_service_transition.png` | 기둥 저수조 → 계단·원형 배수구 |
| `assets/background/stage_2/sewer_08_outlet_transition.png` | 원형 배수구 → 철창 출구 |

이 추가 작업에서도 Godot은 실행하지 않았다.
