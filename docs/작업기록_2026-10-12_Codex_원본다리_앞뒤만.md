# 최초 스프라이트 유지·다리 앞뒤 움직임만 적용

- 요청: 처음 스프라이트에서 다리가 앞뒤로 움직이는 것만 남기고 불필요한 추가를 제거.
- 원래 흑백 PNG와 SpriteFrames는 변경하지 않음.
- `paint_head_anim.gd`를 작업 전 동작으로 복원한 뒤 다리 표시 연결 25줄만 추가. 원래 16프레임/20fps 상체·시트 재생을 유지.
- 별도 이동거리 기반 위상, 상체 첫 포즈 고정, 임의 보폭, 직접 발 디딤 신호 제거.
- `플레이어_효과음.gd`는 작업 전 코드로 복원. 원래 6·14 프레임 발소리 유지.
- `플레이어_양발보행.gd`에서 무릎·발목 IK, 뼈 길이 조절, 부츠 회전 보정, 뒤꿈치/발끝 받침 계산, 발 높이 보정 제거.
- 현재 프레임의 원래 다리 그림을 각각 반대 박자로 ±0.28rad 앞뒤 회전시키는 것만 남김. 코트와 맞닿는 윗줄만 고정하고, 나머지 다리는 한 장의 원화로 회전. 다리 길이와 발 모양을 새로 계산하지 않음.
- 메시를 다리마다 꼭짓점 8개·삼각형 6개로 단순화.
- 상체 상하 이동 셰이더 파라미터와 계산 제거. 색 경계·수중 가림 유지.

## 확인

- GDScript 3개 및 검토 도구 정적 문법 검사 통과, 셰이더 ASCII 확인.
- 최초 걷기 PNG 백업과 현재 PNG의 SHA-256 일치.
- 효과음 코드가 작업 전 HEAD와 바이트 일치.
- 주요 4 자세 PNG를 직접 열어 최초 원화 모습 및 두 다리의 앞뒤 변화 확인.
- `git diff --check` 통과.
- `graphify update .` 실행 완료. 기존 graph.json 축소 보호로 덮어쓰기가 거부되어 강제 축소하지 않음.
- 기존 로컬 작업과 앞선 그림자 수정은 보존.
- Godot·엔진 검사 13개 미실행. 명시적 실행 허용 없음.
- 실제 엔진 캡처 경로 없음. **수정 완료·시각 검증 대기**.
