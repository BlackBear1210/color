## 2. ★ SIDE 는 90° 돌려서 그린다 (제일 자주 틀리는 것)

SS2D 는 SIDE 텍스처를 세로 벽에 붙일 때 **master 의 x 축이 벽의 세로 방향**이 되도록
회전시킨다. 그래서 master 에 가로로 그린 줄눈은 실제 벽에서 **세로선**이 된다.

| master 에 이렇게 그리면 | 세로 벽에서 이렇게 보인다 |
|---|---|
| 가로 줄눈 | 세로선 ❌ |
| **세로 이음매** | **가로 켜** ✅ |

→ SIDE master 는 masonry / 판자 / 금속판을 **90° 회전한 상태**로 그린다.
   (벽돌·판자·패널이 세로로 긴 직사각형, 긴 이음매가 세로로 내려간다)

TOP / BOTTOM 은 회전 없이 그대로 붙으므로 평소대로 그린다.

이걸 틀리면 FILL(정상 가로 켜)과 SIDE 띠가 **서로 다른 벽처럼** 보인다.
brick_v1 / sewer_v1 / wood_v1 이 전부 이 상태였다.

## 3. 건축 문법 — 얇은 TOP · 깊은 SIDE

```
        얇은 TOP / CAP
   ┌──────────────────┐
───┘                  │
                      │   깊은 SIDE
                      │
                      └────
```

- TOP: 마젠타 바로 아래에 **이미지 높이의 약 5%** 짜리 얇은 갓돌/캡 보드/캡 플레이트.
  윗선은 직선. 위로 튀어나온 잔해·가지·돌출부 **금지**.
- SIDE: 두께감은 여기서 확보한다. 기둥·필라스터·지배적 오브젝트 **금지**.
- BOTTOM: 얇은 소핏. 매달린 잔해 금지.
- CORNER 는 따로 그리지 않는다 — baker 가 TOP/SIDE 단면에서 합성한다.
  TOP 과 SIDE 가 **같은 깊이 프로파일**(얇은 캡 → 깊은 구조)을 가지면
  코너가 90° 로 접힌 것처럼 이어진다.

## 4. ★ pattern scale — primary 만 센다

`TOP ≈ SIDE ≈ FILL` 이 **월드 px 기준으로 ±5% 이내**여야 한다.
안 맞으면 지형 테두리와 안쪽이 서로 다른 크기의 벽처럼 보인다.

### primary structure (이것만 주기로 센다)

- brick / stone 줄눈
- wood 판자 이음매
- metal 패널 seam

### secondary detail (주기로 세지 않는다)

- 나뭇결 · 긁힘 · 리벳 · 녹 · 실금 · 표면 노이즈

> "가장 많이 반복되는 무늬" 가 아니라
> **"구조를 정의하는 가장 큰 반복 단위"** 를 재야 한다.

실제로 두 번 틀렸다 — 골 개수만 세던 시절 wood TOP 이 나뭇결 때문에 2.2 월드px,
iron TOP 이 리벳 열 때문에 18.4 월드px 로 나왔다. 둘 다 헛것이었다.

### 측정 도구

```bat
%G% --headless --path . -s res://tools/측정_원본_주기.gd -- --재질=brick_v2
```

`primary` / `secondary` 를 나눠 찍는다. 검출은 밝기 프로파일의 골을
**깊이(동적범위의 35%)** 와 **최소 간격(n/25)** 으로 걸러 primary 를 잡고,
느슨한 기준(10% · n/100)으로 secondary 를 잡는다.
BOTTOM 처럼 구간이 짧아 primary 가 2개 미만이면 단계적으로 완화한다.

⚠ BOTTOM 은 쓰이는 구간이 짧아 표본이 적다. **수치만 보지 말고 실제 그림도 같이 본다.**

## 5. 이미지 생성으로 원본을 만들 때

- 프롬프트에 **개수를 명시**한다 (예: "약 19 courses", "약 8 vertical seams").
  모델은 요청보다 20~60% 어긋나게 내놓으므로 **만들고 나서 반드시 측정**한다.
- 원본을 사후에 리샘플해서 주기를 맞추려는 시도는 **하지 말 것.**
  AI 생성물은 타일당 정확한 정수 주기가 아니어서 이음매가 깨진다
  (실측: 감김 차이 비 1.06 → 17.5). `tools/보정_원본_스케일.gd` 에 이음매 검사가 있다.
- 벽돌 텍스처가 콘텐츠 필터에 오탐으로 걸린 적이 있다. 문구를 바꿔 재제출하면 통과한다.
