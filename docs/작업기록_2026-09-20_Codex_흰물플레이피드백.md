# 흰 물 플레이 캡처 피드백 반영

## 요청과 수정

1. 웅덩이가 사각 물 블록처럼 끼워진 느낌: 웅덩이 파생 클래스가 침수 영역을 지형에 전달한다. 하수도_자연발판은 원본 몸통/충돌/페인트를 건드리지 않고, 하수도_마감메시가 침수된 윗면·옆면 마감만 차집합으로 제거한다. 마스크는 수면 아래부터 시작하고 옆면 19px·바닥 25px까지 포함한다. 물의 켜짐·크기·위치가 바뀔 때만 갱신하고 삭제 시 해당 물의 가림을 해제한다. 수면 위 육지 마감은 보존한다. 수중 질감은 낙하수처럼 보이지 않게 더 잔잔한 가로 흐름으로 조정했다.
2. 느린 낙하: stage_2-1 W5_흰물에 흐름속도 390px/s 명시(이전 130의 3배). 세로 거울 반복을 없애고 같은 방향으로 순환하는 두 텍스처 표본을 블렌드했다.
3. 작은 물보라와 반복 사각 띠: 폭 64에서 물보라 폭 128→224px. 밝기 기반 안개 제거 문턱을 높이고 텍스처 네 변을 부드럽게 감쇠한다. 규칙적인 대각 밝기 진동을 제거했다. 그리기 여백 좌우 130/아래 32px로 늘려 확대된 분무가 잘리지 않도록 했다.

## 영향 범위와 검증

침수 가림은 웅덩이_흰물v2가 등록한 경우에만 활성화된다. 다른 지형에는 빈 가림 목록이므로 기존과 같다. 지형 SS2D 점/물리 충돌/물 색과 수심은 변경하지 않았다. 기존 부모 유체/웅덩이 코드도 변경하지 않았다.

tools/test_white_water_stage21_static.py: 씬 변경 범위, W5 속도/위치/크기, 리소스 참조, 폭 8~500 물보라 렌더 경계, 세로 UV 연결 정적 확인. 실제 셰이더 함수의 브라우저 WebGL 미리보기에서 폭64 물보라와 재생 확인. Godot 실행은 사용자 안전 규칙에 따라 미실행이므로 침수 지형 메시와 인게임 물 판정/성능은 실행 검증 전이다.

graphify query/update는 종료1·출력 없음. 커밋/푸시 없음.
