# 2-9 최신 지형 및 점프/타이밍 개편

사용자 승인 범위에서 stage_2-9 저장 씬을 직접 수정. Godot/전체 맵 빌더는 실행하지 않았다.

## 변경

- 최신 SS2D 하수도 흑백 벽돌 51개, 다층 배경 적용. 모든 윤곽에 저장 충돌을 명시하고 사용하지 않는 구형 캐시 리소스 정리.
- 상층 평지 축소, 높낮이 징검4개와 톱 양쪽 관찰대2개 추가. 새 선반은 얇은 상면/불규칙 밑면.
- F1 세로 왕복 톱, 출구 넓은 백수문/주철 밸브, 체크포인트2개 추가.
- 처음의 224px 오르막 틈은 몸폭을 고려하면 여유가5px뿐이어서 192px로 줄이고 착지 발판을224px로 넓힘.
- 기존 압력 발판과 유체는 최신 공통 외관 사용. 승강기/격자 전용 표현과 기능 보존.
- 세부 좌표/설계 의도는 `scenes/world_2_클로드/작업/stage_2-9_작업.md` 최신 절, 저장 좌표 도식은 `docs/stage29_rework_layout.html`.

## 검증/한계

- 작업 전후 기존 stage9 정적 회귀 통과. 새 검사 SS2D/충돌57개 일치, 자산/수문 연결/안전한 밸브 위치, 점프 거리/높이 예산 통과.
- Godot 실행·렌더링·실플레이는 미실행. 정적 포물선 계산은 실제 점프 성공 보증이 아니다. 새 장애물 타이밍/실제 색 사망/추락 복귀는 플레이 검증 필요.
- 백수문은 단순 공중 색2회 전환을 막지만 바닥 칠하기 우회는 허용한다. 필수 조작 보장으로 과장하지 않음.
- Graphify 조회/갱신은 출력 없이 종료1. 저장소 안전 규칙에 따라 엔진 검사를 대체 실행하지 않음.
