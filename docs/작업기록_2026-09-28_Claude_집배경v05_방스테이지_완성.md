## 3. 동작 방식
- 먼 벽(0.12): A1 을 **가로로만** 반복. 모든 방 공유.
- 방마다 한 세트: 가구(0.55) = `(변형 + 방번호) % 6` → 이웃 방이 절대 같지 않다 ·
  방 구조(0.30) = 창/벽난로/창/문 순환 + 창 자리에 광원 · 샹들리에(1.15) · 문간마다 전경 기둥(1.15).
- 시차 그림을 **방 한가운데에서 제자리**로 보이게 역산: `층자리 = 월드 − (카메라기준 − 화면반) × (1 − 시차)`.
  촬영으로 확인 — 가구가 방 한가운데에 선다.

## 4. 촬영하고 나서 고친 것
1. 가구가 주문서 비례(책장 1.8 배)로는 인형 가구 → **가구배율 2.2**.
2. 확대 리샘플 링잉으로 가장자리 명도 0.7 까지 튐 → 원본 최대 명도로 묶고 레이어 마무리에서 ≤ 36 %.
3. 샹들리에가 화면 한가운데를 가림 → 배율 0.55 · 화면 위 1/8 에만.
4. 빈 방 먼지천이 **플레이어 키 높이의 평평한 밝은 판**(= 발판 오해) → 낮고 어둡고 울퉁불퉁하게.
