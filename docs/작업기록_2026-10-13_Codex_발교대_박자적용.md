# 확인한 발 교대와 박자 게임 적용

- 사용자 요청: 최종 박자 시안을 게임에 적용한다.
- 결과: 검정/흰색 걷기만 확인한 발 교대 시트로 교체했다. 원본 640px 프레임 해상도로 32프레임을 저장하고 40fps로 재생한다. 한 주기 0.8초, 좌우 디딤 간격 0.4초. 추가 무릎 굽힘 없이 발목과 신발을 같은 강체로 움직이는 시안의 모양을 유지했다.
- 새 그림: `assets/characters/paint_head_a/black_walk_cross.png`, `white_walk_cross.png` (각 2560×5120, 투명 배경). 원래 black_walk.png/white_walk.png는 보존했다.
- 연결: `assets/characters/paint_head_a/player_frames.tres`의 두 walk 애니메이션만 새 PNG/32프레임/40fps로 교체. 대기/점프/낙하/착지/발사/밀기/사망 애니메이션 정의는 변경 전과 같다.
- `scripts/paint_head_anim.gd`: 이전 다리 덧그리기 생성/갱신을 제거해 이중 변형을 막는다. 새 `walk_cycle_data.gd`의 32개 잉크 수위 좌표를 걷기에만 덮어쓴다. 원본 탱크 상수 표는 복제 후 병합해 변경하지 않는다. 새 발 디딤 프레임 15/31을 제공한다.
- `scripts/플레이어_효과음.gd`: 캐릭터가 제공하는 새 발 디딤 프레임을 사용한다. 구형 캐릭터는 기존 Inspector 프레임을 사용한다. 물속/공중/저속/리스폰 직후 소리 제한은 그대로다.
- `shaders/paint_head.gdshader`: 이전 다리 절단 uniform/discard만 제거했다. 기존 색 분할ㆍ잉크 잔량ㆍ물 가림 로직은 유지했다. 셰이더에는 한글을 넣지 않았다.
- `scripts/플레이어_양발보행.gd`는 원본 기록으로 남겨 두되 실제 캐릭터에서는 더 이상 만들지 않는다.
- 생성: `tools/적용_발교대_시트.py`. Godot을 호출하지 않는 이미지/리소스 생성 도구. 동일 입력에서 프레임과 연결 값을 다시 계산하며 기존 값에 누적하지 않는다.
- 확인: `tools/검사_발교대_적용_정적.py`의 정적 검사 9항목 통과. 기존 동작 정의 보존, 32프레임 범위, 재생 속도, 새 탱크 UV 범위, 상체 픽셀 보존, 원본 PNG 해시 보존, 예전 다리 변형 차단, 발소리 연결, 색 분할/물 가림/ASCII를 확인했다.
- 시안과 비교: 실제 새 PNG를 다시 읽어 축소한 16개 대표 프레임과 승인된 시안의 평균 RGB 차이는 검정 최대 0.0764, 흰색 최대 0.1438 (0~255 범위). 해상도를 원본으로 높여 생긴 경계 샘플링 차이 외에 형태/박자를 유지한다.
- 문법: 로컬 gdtoolkit으로 수정 GDScript 3개(`paint_head_anim.gd`, `플레이어_효과음.gd`, `walk_cycle_data.gd`) 파싱 통과. Godot의 타입/의미 검사를 대신하지는 않는다.
- 직접 확인: 연결된 새 PNG에서 만든 `docs/visual_review/player_walk_20261012/적용검토/적용시트_8자세.png`를 직접 열어 교차/발목 모양 확인. 같은 폴더 `적용시트_재생.gif`는 오프라인 재생 검토용이며 실제 엔진 캡처가 아니다.
- 변경 전 백업: `docs/visual_review/player_walk_20261012/적용검토/before/`에 변경 전 걷기 리소스와 애니메이터/효과음/셰이더 파일 보존.
- 엔진 검사 13개 및 실제 게임 캡처: 명시적 Godot 실행 허용이 없어 미실행. **수정 완료ㆍ엔진 시각 검증 대기.** 실제 게임에서 같은 스테이지/줌/해상도의 전후 PNG는 아직 확보하지 않았다. 이동 속도 대비 발 접지/경사/물/색 경계와 실제 발소리 동기화는 엔진 확인 대상이다.
- graphify query/update 실행. 노드 축소 보호로 graph.json 강제 덮어쓰기하지 않았다.
- git pull은 이번 세션 앞선 시도에서 기존 미추적 PNG.import 충돌로 병합이 중단됐으며 관련 파일을 임의 정리하지 않았다. 다른 사용자의 기존 변경은 보존했다.
