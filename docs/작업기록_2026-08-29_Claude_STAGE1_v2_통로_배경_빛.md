## 2. Corridor 문제 해결 방법 (A)

지시 §3 의 선택지 중 **4번 Background Layer separation** + **실제 벽 개구부**를 썼다.
"큰 검정 사각형 덮기" 는 쓰지 않았다.

```
v1   방 ──[터널이 벽을 관통]── 벽돌 벽 (반투명 너머로 비침)
v2   방 ──[개구부]──[터널]──[벽 속]     벽이 터널을 통째로 품는다
```

1. **벽 두께 240 → 500.** 터널 깊이 420 이 벽 **안에** 완전히 들어간다. 벽 밖으로 안 뚫린다.
2. **벽을 위/아래로 갈라 높이 170 짜리 개구부**를 남긴다 = 진짜 문간.
   왼쪽 벽 개구부 `y −170…0` · 오른쪽 벽 개구부 `y −700…−530`.
   (통로 실효 높이 = 170 − 48 = **122** > 몸 96 ✔)
3. **통로 뒤에 개구부와 똑같은 크기의 어두운 판**(`ColorRect` 500×170 · z −8).
   터널 입구의 반투명 그라데이션(깊이를 만드는 장치라 없애면 안 된다) 너머로
   보이는 것이 "다음 스테이지" 가 아니라 **어둠**이 된다.
   · 화면을 덮지 않는다(개구부 크기) · 배경 레이어에 있다 · 시차를 안 준다
4. **`속빛` 을 거의 검정**(0.035)으로. 저 끝의 빛무리가 사라진다.
   0 으로 두면 입구 윤곽까지 안 보여서 아주 낮은 값만 남겼다.
5. **`어둠 = 1.0`** — 안쪽 끝이 완전한 검정.

## 3. Terrain Overlap 해결 방법 (B)

Z-index 를 만지지 않았다. **누가 무엇을 그리는지 역할을 나눴다.**

```
v1   연결통로가 "주변 암반" 까지 그린다  → 나무·벽돌 위에 검정 판이 얹힌다
v2   주변 구조는 **벽 SS2D** 가 그린다   → 통로는 **구멍 안쪽만** 그린다
```

- `암반_위 = 0` · `암반_아래 = 0` → 지형을 덮던 검정 판이 사라진다
- `두께 90 → 24` → 통로 자신의 바닥/천장 슬래브도 최소로
- 문턱(WOOD)의 오른쪽 끝(x 4790)을 **오른쪽 벽 안쪽 면과 정확히 맞댔다** = 경계 연결

### 천장도 같은 원칙으로 고쳤다

문 앞이 좁아지는 낮은 천장을 처음엔 **기존 천장 위에 덧대어** 만들었다(두께 50).
그러면 ① 두 지형이 겹쳐 텍스처가 중첩되고 ② 두께 50 은 테두리 띠(38px×2)가 겹쳐
**검은 막대**가 된다(`진단_콜리전대_그림` 이 `오른 +3.9` 로 잡았다).
→ **천장을 두 조각으로 나눠 x 4530 에서 맞댔다.** 겹침 0, 두께 350.

**결과: 지형 17 개 전부 `그림 = 콜리전` 0.0px.**

## 4. Light 연출 변경 내용 (C)

### 4-1. ★진짜 원인은 카메라였다

`카메라_공간.gd` 의 `틈새빛_사용`(기본 `true`, `틈새빛_개수 = 6`)이 빛줄기를 그리고,
그 줄기 **끝에 둥근 캡**이 붙는다. 이게 화면의 "빛 쏘는 구슬" 이었다.

원인을 찾기까지 빛기둥 → 발광체 → 창문 프리팹을 하나씩 빼며 재현 촬영했다
(전부 빼도 구슬이 남아서 마지막에 카메라를 의심했다).
→ **`틈새빛_사용 = false`.** 카메라 공간은 줌만 담당한다.

### 4-2. 창문을 **문간과 같은 문법**으로 다시 만들었다

```
문간 = 벽의 구멍 + 배경 레이어의 **어두운** 판
창문 = 벽의 구멍 + 배경 레이어의 **밝은** 판  + 빛기둥
```

구조가 같으니 플레이어는 "저건 벽에 뚫린 것" 이라고 같은 방식으로 읽는다.
빛의 출발점이 **물체가 아니라 개구부**가 된다 = 지시 §8 의 구조 그대로다.

- `창문_방_바깥빛` : 430×420 밝은 판(0.68) — 이 방에서 가장 밝은 면
- `창문_방_{윗틀,아랫틀,왼틀,오른틀,세로살,가로살}` : 검은 창틀·십자 창살
- `창빛_기둥` : `빛기둥(모드=연출)` 한 줄기. 시작폭 200(창 폭) → 끝폭 560, 길이 620
  ⚠ `구멍_그리기 = false` — 창 개구부를 이미 직접 그렸으므로 그 위에 또 그리면 안 된다
- `빛_창문안쪽` · `빛_바닥웅덩이` : 실제 광원(`발광체` · **알갱이 안 그림**)

> ⚠ `창문_배경.tscn`(창문커튼) 프리팹은 **이 스테이지에서 쓰지 않는다.**
> 빛줄기 끝에 둥근 캡을 그려서 같은 구슬 문제가 났고, `빛_기본세기 = 0` 으로 낮춰도
> 캡이 남았다(실측). **다른 스테이지의 커튼 퍼즐에는 그대로 쓸 수 있다** — 지우지 않았다.

### 4-3. 빛이 바닥 아래로 새던 것

`빛_바닥웅덩이` 를 반경 460 · y −40 으로 뒀더니 **바닥(두께 300) 아래로 빛이 새어**
마루 밑에 빛무리가 생겼다. 반경 280 · y −90 으로 줄여 바닥 윗면 위에만 머물게 했다.

## 5. Level Design · Visual Composition 변경 내용 (D · E)

### 5-1. 배경 레이어 (지시 §15 · §16 · §17)

```
z −45  배경_먼    안개층(실내먼지)   Parallax2D scroll 0.35   대기 · 깊이
z −40  배경_방벽  실내배경(이층방)   Parallax2D scroll 0.90   벽지 · 웨인스코팅 · 몰딩
z −30  창문 바깥빛                   (고정)
z −28  창틀 · 창살                   (고정)
z  −8  문간 어둠 ×2                  (고정)
z   0  지형 · 플레이어                                        게임플레이
z +12  전경_어둠  안개층             Parallax2D scroll 1.10   출구 쪽이 어두워진다
```

- Parallax2D 값은 **`스마트월드_1~4` 에서 이미 쓰는 것을 그대로 따랐다**
  (하늘 0.05 · 원경 0.2 · 중경 0.42 · 근경 0.68 · 전경 1.15). 새로 만들지 않았다(지시 §17).
- ⚠ **실내(벽)는 시차를 약하게(0.90).** 벽은 플레이어 바로 뒤의 물건이라 0.4 같은 값을 주면
  5000px 를 걷는 동안 벽이 3000px 밀려 "벽이 미끄러진다". 대기(안개)는 등록 위치가
  없으므로 0.35 로 세게 줘도 안전하다.
- 벽은 `실내배경._이층방()` 의 **절차적 그림**을 쓴다(벽지 세로 패널 · 체어레일 ·
  걸레받이 · 크라운몰딩). ★원화 `room.png` 를 타일링하지 않은 이유: 원화에 침대·책장이
  그려져 있어 8 번 반복하면 **침대가 8 개** 보인다.
- 벽 밝기 0.62 → **0.45**. 0.62 로 찍어 보니 벽지가 나무 가구보다 밝아 실루엣이 묻혔다
  (지시 §15 Visual Hierarchy).

### 5-2. 공간의 리듬 (지시 §11)

```
문간 170  →  방 780  →  (서까래 아래 280)  →  방 780  →  문 앞 200  →  문간 170
좁다         넓다        살짝 눌린다           넓다        조인다        좁다
```

- 서까래 2 개를 `아랫면 −600 → −500` 으로 더 내려 **들보로 읽히게** 했고,
  왼쪽 것은 창문을 가로지르지 않게 `x 1120~1700` 으로 옮겼다.
- **문 앞 천장을 −730 으로 내렸다**(x 4530~4790). 문턱(−530)에서 시각 200 · **실효 152**.
  끼이지는 않지만 "여기선 뛸 수 없다" 가 몸으로 읽힌다.
  ⚠ 점프 착지 구간(4470~4530)은 비워 둬서 문턱으로 뛰어오를 때 천장에 안 박힌다.

### 5-3. 밝기의 진행 (지시 §2 · §10)

```
START(어둡다) → 창가(가장 밝다 · Light Landmark) → 등반(중간) → 문 앞(어둡다) → 문간(검정)
```

출구 쪽은 **광원을 아예 두지 않는 것**으로 어둡게 했다. 어두운 판을 덮지 않았다.
거기에 `전경_어둠`(안개층 · 검정 alpha 0.16)을 앞에 한 겹 흘려 균일한 검정이 아니라
**덩어리진 어둠**이 되게 했다.

## 12. 남아 있는 문제

1. **`출구통로.다음_씬` 이 비어 있다** — STAGE 2 제작 후 연결(STEP 21).
2. **직진 봇으로 이 스테이지의 관통 시간을 못 잰다** — 도구의 한계이지 레벨의 문제가 아니다
   (되돌이 턱을 빼고 재면 같은 지형이 12.2 초에 관통된다). 도구 머리말에 적어 뒀다.
3. **`카메라_공간` 의 `틈새빛` 기본값이 `true`** — 다른 스테이지에서도 같은 구슬이 나올 수 있다.
   이 스테이지에서만 껐다. **기본값을 바꿀지는 도형님 판단이 필요하다**
   (숲·굴뚝처럼 실제로 틈새빛이 어울리는 공간이 있을 수 있다).
4. **`창문_배경.tscn` 프리팹의 빛줄기 캡** — 같은 이유로 이 스테이지에서 안 썼다.
   커튼 퍼즐이 필요한 STAGE 3 에서 쓰려면 그 캡을 먼저 손봐야 한다.
5. **원화 배경 미사용** — `room.png` 는 침대·책장이 그려져 있어 타일링에 안 맞는다.
   전용 크롭을 받거나, 절차적 벽 위에 원화 소품 몇 개만 얹는 방식이 필요하다.
