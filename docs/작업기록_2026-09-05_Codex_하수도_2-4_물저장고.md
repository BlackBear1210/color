# 하수도 2-4 — 색이 흐른다

작업일: 2026-09-05

## 만든 것

- `scenes/world_2_클로드/stage_2-4.tscn`을 추가했다. 시작점은 x=500, 끝도달 검사점은 x=8,200이다.
- 핵심 장치는 물저장고 6개다. 모두 `공급_유체`를 NodePath로 직접 지정해, 씬의 로드 순서나 자동 포트 탐색 결과가 달라도 연결이 바뀌지 않게 했다.
- 보이는 관은 8개 모두 `TEMPLATE_PIPE_OPEN_GRAY` SS2D다. `배관.tscn`은 사용하지 않았다.
- CEMENT 지형은 검정과 흰색만 썼다. 회색 지형은 없고, 회색은 검정·흰 물이 `H4_회색혼합기`에서 만나 생기는 유체에만 있다.

## 관문

1. `T1_첫저장고`를 한 발로 칠하면 `F1_첫출구`가 흐른다.
2. `T2_큰저장고`는 5발이 필요해, 처음으로 탄약량을 보여 준다.
3. `F3_흰조준선`은 검정 총알을 막는 물줄기라 위쪽 각도를 찾아 `T3_우회저장고`를 맞혀야 한다.
4. 검정·흰 저장고의 물이 `H4_회색혼합기`에서 합쳐져 안전한 회색 출구가 된다. 색을 바꿀 때는 색 규칙 밖 장치인 `H5_색전환발판` 위를 쓴다.
5. `T6_FIFO저장고`는 5발이 필요하다. 앞 관문에서 소비한 탄약을 `E`의 FIFO 회수로 되찾는 사용처다.
