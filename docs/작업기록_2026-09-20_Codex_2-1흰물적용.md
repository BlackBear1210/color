# stage_2-1 흰 물 v2 연결

사용자 요청으로 scenes/world_2_클로드/stage_2-1.tscn의 두 인스턴스에 전용 파생 스크립트를 연결했다.

- 장치/W5_흰물: 유체_흰물v2.gd. 위치 (7936,1024), 크기 (64,768), 흰색 1 유지.
- 장치/B_착지_웅덩이: 웅덩이_흰물v2.gd. 위치 (4032,1536), 크기 (384,128), 흰색 1 유지. 새 그림의 원점은 위쪽이므로 -128px 배치해 수면 y=1408 유지.

회색 W1과 검정 물·웅덩이는 변경하지 않았다. 기존 씬은 2개 ext_resource와 2개 script override만 추가했다. 부모 유체/웅덩이 원본 스크립트는 수정하지 않았고 다른 스테이지에는 적용되지 않는다.

유체 파생 클래스는 흰색일 때 기존 AnimatedSprite 두 개를 정지·숨기고 새 아트를 생성한다. 혼합으로 검정/회색이 되면 상위 클래스의 기존 색 프레임으로 복귀한다. 크기와 흐름속도 연동, 켜짐은 부모 visibility/monitoring 동작을 상속한다. 생성 노드 owner를 씬 트리에 다시 지정하지 않는다.

새 물줄기는 이전 이미지의 섬 폴리곤을 사용하지 않는다. 64x768 기준 x=-25..25,y=3..759의 연속 몸통에 보수적인 사각 접촉 판정(면적 37,800)을 둔다. 판정_여유 값은 폭에 반영한다. 외곽 물안개·착수 물보라는 비위험 장식이다. 색 전환 때 판정 갱신은 call_deferred로 미룬다. 매 프레임 충돌 재생성은 하지 않는다. 웅덩이는 기존 크기/바닥 원점의 사각 판정, 색 사망, 낙하받기, 페인트 지우기와 차오름을 상속한다.

정적 검증: scene diff가 지정된 6줄 추가뿐인지, 나머지 모든 씬 속성이 기존 git 내용과 같은지, 리소스 경로와 새 식별자 ASCII 여부 확인. Godot 파서·실행·색 혼합·접촉·차오름 실험과 스크린샷은 명시적인 실행 요청 전 금지 규칙으로 미실행. 실제 장면 검증 완료라고 주장하지 않는다. graphify query/update는 종료 1, 출력 없음.
