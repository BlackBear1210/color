# 작은 돌출부 옆면 시험

- 대상: scenes/world_2_클로드/stage_2-1.tscn의 지형/A_바닥 중 로컬 Rect2(-256,-736,256,128). 월드 x=1616~1872, y=896~1024.
- 범위: 이 돌출부의 좌우 끝만 적용. 기본값은 꺼짐이며 다른 지형으로 확장하지 않는다. 기존 사용자 변경과 공중 플랫폼은 보존한다.
- 하수도_자연발판.gd에 시험_옆면마감(bool), 시험_옆면범위(Rect2) 추가. 런타임과 에디터 미리보기의 동일 유니폼으로 전달한다. 접합 캐시에도 포함해 토글을 반영한다.
- 공통 셰이더의 시험 기능: 기존 석조 텍스처에서 끝돌을 샘플링해 줄마다 12/18px 폭으로 번갈아 붙이고, 외곽 3~5px에 얕은 좌우 명암을 표현한다. 줄눈에서 최대 0.8px 시각적 홈을 만든다. 위 22px는 기존 상단 마감을 보존하고 22~30px에서 섞는다. 바닥에 닿는 y=128에서 종료한다.
- 색칠 전에 검정/흰색 재료에 섞어 페인트 상태를 따른다. 충돌점과 플레이어 높이는 수정하지 않는다. 새 이미지를 생성한 작업이 아니라 기존 텍스처 기반 셰이더 시험이다.
- 정적 확인: A_바닥 한 노드와 전용 미리보기 재질 하나만 활성화, 원래 위치 유지, diff 공백 검사 통과.
- Godot 실행/컴파일/화면/착지/색칠 검사는 미실행. 사용자가 실제 화면에서 줄눈 연결, 기둥처럼 보이는지, 기존 윗면과의 연결을 판단해야 한다. 승인 전 공통 적용 금지.
- 비교법: A_바닥 인스펙터의 시험_옆면마감 체크를 껐다 켠다. 최대 0.5초 갱신 후 비교. 시험 범위는 고정 로컬 좌표이므로 지형 점을 크게 바꾸면 범위도 조정한다.
- Graphify update는 기존 uv trampoline 경로 문제로 실패. 커밋/푸시하지 않았다.
