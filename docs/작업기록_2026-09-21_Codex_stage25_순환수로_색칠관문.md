# stage_2-5 순환 수로와 색칠 관문

2026-09-21 / Codex

## 요청과 변경

사용자가 승인한 레버 기초 → A/B 수로 선택/순환 → 레버+색칠 조합을 `scenes/world_2_클로드/stage_2-5.tscn`에 적용했다.
기존 일렬 레버6개에서4개로 줄이고, 중간에 상부 흰 길과 하부 검정 길을 선택하게 했다. 하부 길에서는 우측 선반을 타고 상부 밸브로 돌아온다.
마지막은 중립 호퍼에서 두 색을 준비하고 유령 발판2개를 각2발로 만들어 건넌다. 떨어지면 아래96px 계단으로 복귀한다.

- 기존 start/전체 우향/끝 x8200 유지, 발밑 기준 y1120으로 정리.
- 하수도 프리팹·Scale1·독립 SS2D 점/저장 콜리전 일치. 점프160/320, 줌1, 치명낙하1500 명시.
- 하수도 다층 배경, 레버→물 연결을 보여주는 배관 안내선, 입구와 stage_2-6 출구 추가.
- 맵 전용 `scripts/스마트월드/stage_2_5_월드.gd`로 고정 체크포인트3개만 저장/활성화. 유령 소멸 위치로 부활하거나 다른 바닥색으로 연속 사망하는 문제를 피한다.
- 주행 도구의 이 맵 공략을 새 경로로 수정하고 상부/실패 복귀 경로를 추가했다. 실행 통과로 간주하지 않는다.
- 시작 시 stage_2-5는 Git clean. 다른 사용자 편집은 보존했으며 빌더·엔진 실행 없음. 새로 삭제된 파일 없음.

## 미실행과 판단 한계

AGENTS.md의 사용자 안전 예외에 따라 Godot 편집기/콘솔/헤드리스/빌더는 실행하지 않았다. 공통 엔진 검사16개, 새 공략2경로, GDScript/씬 실제 파싱, 총알 사격, 색 전환/사망/리스폰, 씬 이동, 화면·성능은 미검증이다.
정적 궤적은 보수적 사각 몸통/240Hz 샘플과 입력 지연을 사용하며 엔진 실행을 대체하지 않는다. 주행 도구의 사격은 직접 명중 처리라 실제 총알 검증도 별도다.
물 설정 폭448px의 몸 높이 단면은 실제97~296px 범위다. 레버를 무조건 강제한다고 주장하지 않으며, 숙련 색 전환/칠하기 우회는 허용 가능성으로 남겼다. 마지막 다리는 기본992px 간격/복귀측384px 벽으로 무사격 단순 직진을 막았다.

구간 좌표·물 소유 관계·검사별 상태·공통규칙 예외는 [맵 작업 문서](../scenes/world_2_클로드/작업/stage_2-5_작업.md)에 기록했다.
