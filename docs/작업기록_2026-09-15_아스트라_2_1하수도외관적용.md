# stage_2-1 하수도 지형과 배경 적용

사용자 요청에 따라 `scenes/world_2_클로드/stage_2-1.tscn`을 직접 수정했다.

기존 WALL 템플릿 인스턴스 36개(검정 26, 흰색 10)에 하수도_벽돌지형.gd와 masonry_black/white.tres를 씬 단위로 오버라이드했다. 다른 스테이지가 사용하는 WALL 템플릿 원본은 수정하지 않았다. 지형을 다시 만들거나 빌더를 실행하지 않았다.

기존 점 리소스 전체가 수정 전과 바이트 수준의 텍스트 비교에서 동일함을 확인했다. 기존 노드 블록에서 새 script/shape_material 오버라이드만 제외하면 모든 속성이 동일함을 비교했다. 위치·시작색·유령발판 통과 설정·레버/물/배관·플레이어·출구·카메라 설정을 보존했다.

`scenes/배경/하수도_다층배경_2_1.tscn`을 별도 배경으로 만들고 스테이지 루트에 인스턴스했다. 9664×2560 카메라 범위에 맞춰 배수 시설 1묶음, 아치 2묶음으로 줄였고 높이를 조정했다. 먼 벽/안개만 반복하며 건축물은 비반복이다. 각 층의 양축 패럴럭스 속도는 공용 v02와 동일하다. 이 파일은 2-1 전용 배치 사본이라 공용 씬의 후속 배치 변경을 자동 상속하지 않지만 이미지와 셰이더는 공유한다.

정적 검증: 원래 노드 속성/점 리소스 보존, 외부 참조 존재, 적용 개수, git diff --check. Godot 실행·132개 검사·플레이 화면 검증은 미실행이다. 실제 실행에서 색칠과 확대 모서리, 배경 대비를 추가 확인해야 한다.
