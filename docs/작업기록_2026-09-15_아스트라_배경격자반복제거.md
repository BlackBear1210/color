# 하수도 배경의 건축물 격자 반복 제거

사용자 캡처에서 아치와 배수구가 조밀한 격자로 반복되는 문제를 확인했다. 패럴럭스 속도가 서로 달라도 같은 큰 구조물을 두 축으로 채우면 공간성이 생기지 않는 배치 오류였다.

내장 이미지 생성 도구로 구멍 없는 저대비 먼 벽 `01_quiet_wall.png`를 생성했다. 기존 다층배경 씬의 먼 벽 참조를 바꾸고 안개 혼합을 높였다. 기존 이미지들은 삭제하지 않았다.

배수시설/가까운아치 Parallax2D에서 repeat_size/repeat_times를 제거했다. 배수 시설 3묶음과 아치 5묶음을 서로 다른 높이와 간격으로 배치했다. 이들은 투명 레이어이며 여백에서는 뒤의 조용한 벽이 보인다. 먼 벽과 안개만 반복한다.

양축 속도는 먼 벽(0.12,0.10), 배수 시설(0.32,0.28), 아치(0.60,0.55), 안개(0.78,0.70)다. 2-10/2-11의 카메라 범위를 고려한 범용 초기 배치이며 개별 플레이 동선의 최종 미술 배치는 아니다. 맵 좌표와 패럴럭스 좌표의 차이, 건축물을 추가하는 방법을 이미지 폴더의 사용안내에 정리했다.

씬 외부 참조와 반복 제거를 정적으로 확인했다. Godot 엔진 실행과 화면 검증은 미실행이다. 기존 스테이지의 사용자 배치는 변경하지 않았다.
