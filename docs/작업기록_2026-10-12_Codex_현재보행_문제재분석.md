# 현재 스프라이트 표시·초기 보행 문제 재분석

- 요청: 현재 스프라이트를 보여 주고 처음 지적한 뒷발 고정·전방 미끄러짐 문제를 분석.
- 게임 코드·원화 수정 없음. 현재 파일과 기존 검토 결과를 읽어 분석.
- 현재 걷기 원본: `assets/characters/paint_head_a/black_walk.png`, `white_walk.png`.
- 현재 게임 표시: 원본 16프레임/20fps 시트에 다리 전체 ±0.28rad 반대 박자 회전 추가. 무릎·발목 보정과 상체 이동은 없음.

## 결과

1. **뒷발 완전 고정은 아님.** 두 다리에 회전이 들어가 실제 그림 변화는 생긴다.
2. **앞뒤 교대가 충분히 읽히지 않음.** 원본 그림의 뒤쪽 다리 구역이 여전히 뒤에 남는다. 16프레임의 부츠 하단(원화 y=530~590, alpha>200) 중심을 추적했을 때 뒤쪽 구역의 중심이 앞쪽 구역의 중심보다 앞으로 나오는 표본이 없다. 구역·시점에 따른 측정이며 해부학적인 걸음 판정이나 실제 지면 접촉 검사는 아니다.
3. **수평 미끄러짐은 남는 구조.** 기본 이동 390 월드 px/s, 한 바퀴 16/20=0.8초이므로 몸은 한 바퀴 312px, 반 바퀴 156px 이동한다. 원화 표시 배율 130/640에서 측정한 부츠 중심의 몸 기준 x 범위는 검정 뒤 10.78px·앞 16.04px, 흰색 뒤 16.16px·앞 15.14px. 접지 시간에 몸의 전방 이동을 상쇄할 만큼 발이 뒤로 움직이지 않는다. 다리가 움직이는 것과 바닥에 고정된 발로 몸이 앞으로 나가는 것은 다른 조건이다.
4. **판정 한계.** 위 수치는 기본 설정과 평지의 변형 없는 배율을 기준으로 한 정적 계산이다. 실제 캐릭터 인스턴스의 이동 속도·줌·프레임 진행·경사 변형·접지 시간은 엔진에서 확인하지 않았다. 중심 이동 범위는 실제 보폭이나 물리 발 접점 측정값이 아니다.

결론: 단순 회전으로 움직임은 추가했지만 초기 보행 문제가 해결되었다고 단정할 수 없다. 다음 수정이 필요하다면 원래 그림·무릎·상체를 유지하면서 양발의 앞뒤 이동 순서와 접지 구간/이동량 관계만 다뤄야 한다. 이번 요청은 표시·분석이므로 새 수정은 적용하지 않았다.
