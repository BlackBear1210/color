## ★ 발견 — 회색 배관 45 개가 원점에 뭉쳐 있었다

저장 때 점이 버려졌다. → 지금까지 게임에서 저장고→호퍼 관, 천장 급수관이 **제자리에 안 보였다.**

(임시 파일은 지웠고 2-4·2-6·2-7 씬이 안 바뀐 것을 git 으로 확인). 결과 `tools/배관경로_빌더추출_2026-09-30.json`.
2-10(1)·2-11(6) 은 경로가 살아 있어(노드 위치 + 템플릿 기본 896 가로 직선) **그 모양 그대로** 옮겼다
— ⚠ 2-11 폭포 급수관 둘씩은 서로 겹친 가로 직선이다(아스트라 배치 그대로). 의도한 모양이 따로 있으면 `점들` 을 고칠 것.
