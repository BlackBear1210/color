## 1. 고정 발판에 지지대 붙이기

1. 발판(SS2D 지형)을 놓는다.
2. `삼각지지대.tscn` 을 **발판의 자식**으로 끌어 넣는다. 발판을 옮기면 같이 따라온다.
3. 지지대 노드의 위치를 **발판 밑면이 벽에 닿는 모서리**에 맞춘다.
   - 원점 왼쪽 위(공중_두꺼운발판 320×120 같은 것): 왼쪽 벽이면 `(0, 120)`, 오른쪽 벽이면 `(320, 120)`.
   - 원점이 가운데인 지형(`하수도_빌더_공통.지형()` 으로 찍은 것): 왼쪽 아래 모서리 = `(−폭/2, +높이/2)`.
4. 인스펙터
   | 속성 | 뜻 | 값 |
   |---|---|---|
   | `방향` | 벽이 어느 쪽인가 | `왼쪽벽` / `오른쪽벽` — 그림이 좌우로 뒤집히고 원점 기준 반대쪽에 앉는다 |
   | `배율` | 균일 확대만 | 0.75 ~ 1.5 (밖의 값은 잘린다). 폭만·높이만 늘리는 건 안 된다 |
   | `부착_오프셋` | 밑면에 맞추는 미세 이동 | 기본 `(0, −4)` = 가로대가 벽돌 밑면 뒤로 4px 들어간다 |
   | `색조` | 이 인스턴스만의 색 | 공유 텍스처는 안 바뀐다 |
5. **넓은 발판은 같은 지지대를 두 개** 놓는다(320 간격 정도). 하나를 늘이지 않는다.
6. 볼트 뒤에 **벽 단서**가 있어야 한다: 발판 옆 기둥(같은 색 지형)이나 배경 벽. 시차(Parallax)가 큰 먼 배경에 박힌 것처럼 그리면 카메라가 움직일 때 미끄러져 보인다 — 지지대·기둥은 발판과 같은 월드 좌표에 둔다.
7. 실행해서 플레이어가 지지대에 안 걸리고, 발판 충돌·색 사망은 그대로인지 본다.

⚠ 승강기(움직이는 발판)에는 붙이지 않는다 — "벽에 박혀 있는데 움직이는" 모순. 승강기는 §2.
⚠ 경사 발판 밑 자동 각도 보정은 **없다.** 수평 밑면에만 붙인다.

## 2. 체인 승강기 만들기

```
시험구간 (Node2D)
├─ 장식/
│  ├─ 천장고정구_L (체인고정구.tscn · 방향=천장)   ← 승강기 밖!
│  ├─ 천장고정구_R (체인고정구.tscn · 방향=천장)
│  ├─ 체인_L (쇠사슬.tscn · 모드=추적)
│  └─ 체인_R (쇠사슬.tscn · 모드=추적)
└─ 장치/승강기 (움직이는발판.tscn · 이동방향=상하)
   ├─ 연결구_L (체인고정구.tscn · 방향=발판 · 위치 (−140, −높이/2))
   └─ 연결구_R (체인고정구.tscn · 방향=발판 · 위치 (+140, −높이/2))
```

1. `움직이는발판.tscn` 을 놓고 `이동방향 = 상하`, `이동거리`, `왕복시간` 을 정한다(기존 그대로).
2. 승강기 **밖**(장식 노드 아래)에 `체인고정구.tscn` 두 개를 천장 밑면에 놓는다(`방향 = 천장`). x 는 승강기 연결구와 같게.
3. 승강기 **안**(자식)에 `체인고정구.tscn` 두 개를 놓는다. `방향 = 발판`, 위치 y = `−크기.y/2`(발판 윗면).
4. `쇠사슬.tscn` 두 개를 장식 아래 놓고, 각각
   | 속성 | 값 |
   |---|---|
   | `모드` | `추적` |
   | `시작점_경로` | 천장 고정구의 **`연결점`** (예: `../천장고정구_L/연결점`) |
   | `끝점_경로` | 승강기 연결구의 **`연결점`** (예: `../../장치/승강기/연결구_L/연결점`) |
   | `끝단_겹침` | 기본 6 — 체인 끝이 고정구 고리 뒤로 숨는다 |
5. 승강기가 내려가면 체인이 길어지고 올라가면 천장으로 감겨 들어간다. 발판 쪽 고리는 늘 제자리다(위상 기준 = 끝점).
6. 확인: 위/중간/아래에서 체인이 두 고정구 사이에 딱 걸리는가, 승강기가 천장 고정구보다 위로 올라가지 않는가(`이동거리` 가 천장까지 닿으면 체인이 뒤집혀 그려진다 — 경고는 안 뜬다, 배치를 고친다).

⚠ 천장 고정구를 승강기 자식에 넣으면 두 점이 같이 움직여 길이가 안 변한다(가장 흔한 실수).
⚠ 좌우 승강기에 매달면 대각선으로 늘어나 보인다. 수직 승강기 전용.

## 3. 고정 체인(움직이지 않는 장식)

`모드 = 고정` 으로 두고 `고정_시작`·`고정_끝` 을 **이 노드의 로컬 좌표**로 적는다(예: `(0,0)` → `(0, 700)`). 매 프레임 계산이 꺼져 비용이 0 에 가깝다.
양 끝에 `체인고정구` 를 놓으면(위: 천장, 아래: 발판) 허공에서 끊겨 보이지 않는다. 시험 씬 4 번 참고.

우선순위: `추적` 모드에서 경로가 유효하면 경로가 이기고, 경로가 비어 있는 쪽은 고정 좌표를 쓴다(끝점만 추적 가능). 경로가 **끊어졌으면**(노드 없음) 그 쪽은 안 그리고 경고 한 번.

## 4. 쇠사슬 인스펙터 전체

| 속성 | 뜻 | 주의 |
|---|---|---|
| `모드` | 고정 / 추적 | 추적이면 `_process` 로 Marker 를 읽는다. 고정이면 값이 바뀔 때만 다시 그린다 |
| `시작점_경로` · `끝점_경로` | Node2D(보통 고정구의 `연결점`) | 비면 고정 좌표. 끊기면 그 쪽 안 그림 + 경고 1 회. 노드가 삭제돼도 오류 없음 |
| `고정_시작` · `고정_끝` | 로컬 좌표 | 월드 좌표가 아니다. 부모 Scale 은 (1,1) 로 |
| `고리_폭` / `고리_간격` | 그려지는 폭 / 반복 단위 길이 | 24 / 48 (텍스처 비율). 둘 다 바꿔야 고리가 안 찌그러진다 |
| `끝단_겹침` | 양 끝을 이만큼 짧게 | 최대 길이의 20 %×2 까지만 |
| `텍스처` | 반복 단위 그림 | 좌우 알파 0 · 세로로 이어지는 그림이어야 한다 |
| `색조` | 인스턴스 색 | 흰 발판보다 어둡게 유지 |
| `최대_길이` | 4000 | 넘으면 끝점에서 이 길이만 그리고 경고 1 회 |

에디터에서도 그려진다(@tool). 추적 모드는 에디터에서 Marker 를 옮기면 따라온다. 에디터에서 노드를 만들거나 저장을 건드리지 않는다.

## 5. 정상인 것 / 버그인 것 (프롬프트 §14)

| 보이는 것 | 판단 |
|---|---|
| 발판을 흰색으로 칠했는데 지지대·체인은 어두운 금속 그대로 | **정상** — 장식은 게임 색 상태가 아니다 |
| 총알이 체인·지지대를 지나 뒤 지형에 맞는다 | **정상** — 뒤 지형까지 통과하면 그때 버그 |
| 흰 몸이 검정 지지대 위로 지나가도 안 죽는다 | **정상** |
| 승강기와 천장점이 같이 움직여 체인 길이가 안 변한다 | 배치 오류 — 천장 고정구가 승강기 자식이다 |
| 고리가 길쭉/납작해졌다 | `고리_폭`·`고리_간격` 비율이 텍스처(24:48)와 다르다 |
| 승강기가 멈췄는데 체인이 튄다 | 버그 후보 — 재현 순서와 함께 기록 |
| 벽 지지대가 승강기와 같이 움직인다 | 부품 선택 오류 — 승강기엔 체인 |
| 지지대 뒤에 받쳐 줄 벽이 없다 | 기능 오류 아님 · 배치 불합격(§1-6) |
