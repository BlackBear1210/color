# 흰물 v2 — 종이 느낌 개선

사용자 요청에 따라 기존 디자인 프리팹을 v2 질감으로 변경했다. image_gen으로 난류 몸통/투명 물보라 두 이미지를 새로 생성해 white_modular_v2에 저장. v1 PNG·셰이더는 보존했다.

셰이더: 서로 다른 속도의 물살 표본, 텍스처에 따른 가장자리 분산, 착수 물보라 및 물방울, 큰 물막의 착수 지점 반복, 웅덩이 깊이 명암. 흰물_디자인.gd에 착수_물보라 토글, 분무를 자르지 않는 그리기 여백 추가. CPU 매 프레임 처리 추가 없음. 실제 GPU 비용은 미측정.

브라우저 미리보기에도 동일 함수와 새 PNG를 연결하고 현재 하수도 벽돌로 비교 환경을 구성했다. 좁은 창에서는 한 열로 확대해 질감을 확인한다. 기존 스테이지/판정 코드는 변경하지 않았다.

검증: 원본 splash RGBA 1536x1024·alpha 0..254, 리소스 참조 정적 확인, WebGL2 렌더링 및 크기 조절 검수. Godot 실행은 명시 요청 전 금지 규칙으로 미실행. Git pull은 이전 턴 FETCH_HEAD 쓰기 권한 제한으로 미실행 상태이며 커밋/푸시 없음.

관련: assets/textures/obstacles/liquid/white_modular_v2/README.md. v1 설명의 자동 착수 물보라 없음은 v2에서 변경됨.
