# world_2_클로드 장치 외관 일괄 교체

범위: stage_2-1~11의 11개 씬. 물줄기72, 웅덩이41, 호퍼18 =131개 대상. 2-1의 기존 최신10개 유지, 나머지121개 script 오버라이드 추가. 원형 밸브7개는 이미 공용 제어레버의 최신 주철 아트 사용(직선5개 유지).

호퍼_주철_기존배치.gd 추가: 기존 원점이 출구 끝이라는 전제로 노즐 포함 아트를 입구 y=-높이와 출구y=0 사이에 맞춤. 기존 좁고 낮은 호퍼는 그 크기에 맞게 압축된다. 새 프리팹의 목 원점 구조를 강제해 물 위치를 옮기지 않았다. 장치색/배치/높이/폭/속도/레버 경로/켜짐/입출구 설정 변경 없음.

tools/update_world2_device_art.py는 대상 씬의 외관 어댑터만 교체하는 멱등 도구. 알 수 없는 커스텀 스크립트는 덮어쓰지 않고 중단. 변경을 역변환하여 입력 파일과 일치하는지 확인한 후 저장. JSON 감사 기록은 첫 변경 기록 보존.

정적 확인:131개 대상 모두 최신 어댑터, 리소스 경로 존재, 두번째 실행시 씬 바이트 동일. 게임 규칙 코드는 수정하지 않았으나 물의 새 외관 어댑터가 연속 몸통 판정을 사용하므로 기존 프레임 기반 판정과 체감차는 실제 검증 필요.

미실행: Godot 파싱/렌더/실플레이/호퍼 혼합/꺼짐 총알통과/성능. 기존 네이티브 충돌 및 현재 실행허가 없음에 따라 실행하지 않음. 좌우 곡선 출수 새 기능은 이번 교체에서 구현하지 않음. graphify query/update는 출력 없이 실패.
