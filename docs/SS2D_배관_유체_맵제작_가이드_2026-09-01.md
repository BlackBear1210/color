# SS2D 배관 · 유체 · 호퍼 · 저장고 맵 제작 가이드

> 2026-09-01 기준. 이 문서는 SS2D 배관 안내, 유체 포트 안내, 이번 작업기록을
> 맵 제작에 필요한 현재 규칙만 남겨 한곳에 정리한 기준 문서다.

## 1. 구성과 역할

| 구성 | 맵에서 하는 일 | 색칠 | 물과의 관계 |
| --- | --- | --- | --- |
| SS2D 배관 | 물길의 모양과 연결 위치를 보이는 장식 경로 | 불가 | 양 끝의 물 포트가 유체 배치 기준점이다. 배관 자체는 충돌·색 전달을 하지 않는다. |
| 유체 | 실제 흐름·색·사망·혼합·페인트 지우기 판정 | 불가 | 원점에서 아래로 흐르는 Area2D다. |
| 호퍼 | 위에서 내려온 물을 모아 아래 출구로 전달하는 밟는 깔때기 | 불가 | 여러 입력 물의 색을 섞어 출구 유체에 전달한다. |
| 물저장고 | 칠한 색을 출구 물에 공급하는 밟는 저장 장치 | 가능 | 무색이면 출구 물이 꺼지고, 칠하면 그 색의 물을 공급한다. |
| 통과플랫폼 | 구멍 난 밟는 플랫폼 | 가능 | 물·연기는 통과하며, 물이 플랫폼의 페인트를 지우지 않는다. |

## 2. 유체 규칙

- 물은 위에서 아래로 흐른다. 충돌로 막지 않고 Area2D 판정으로 통과한다.
- 인스펙터 `색`에서 **흰색 / 회색 / 검정색**을 선택한다.
- 플레이어는 자기 색과 반대인 물에 닿으면 죽는다. 회색 물은 안전하다.
- 유체는 색칠할 수 없고, 반대색 투사체를 막는다. 회색 물은 투사체를 막지 않는다.
- 물은 닿은 지형의 반대색 페인트를 지우고, 지워진 페인트는 회수된다.

### 혼합 규칙

| 입력 A | 입력 B | 결과 |
| --- | --- | --- |
| 검정 | 흰색 | 회색 |
| 검정 | 회색 | 검정 |
| 흰색 | 회색 | 흰색 |
| 같은 색 | 같은 색 | 같은 색 |

## 3. SS2D 배관 배치

사용할 템플릿:

`scenes/집/스마트 매쉬 assets/PIPE_배관/TEMPLATE_PIPE_OPEN_GRAY.tscn`

1. 템플릿을 복제해 스테이지에 놓는다.
2. 자식 `경로`의 점을 움직여 직선·ㄱ자·ㄹ자·지그재그를 만든다. **열린 경로**이므로 마지막 점을 처음 점으로 닫지 않는다.
3. 경로는 수평·수직 90도 꺾기를 기준으로 만든다. 배관의 노드 Scale로 굵기를 바꾸지 않는다.
4. `시작_물_포트`와 `끝_물_포트` Marker2D가 경로 양 끝을 자동으로 따라간다.
   이 마커는 게임에 보이지 않고 2D 편집 화면에서 연결 기준점으로만 쓴다.

기본 재질의 `texture_scale = 0.22`는 월드 배관 굵기를 약 69px로 맞춘다.
양 끝은 본체와 같은 명암의 볼트 없는 이음쇠로 마감된다.

## 4. 포트로 연결하는 법

### 공통 순서

1. SS2D 배관 끝 물 포트와 호퍼 또는 저장고의 `출구_포트`를 2D 화면에서 맞춘다.
2. `유체.tscn`을 배치하고 **유체 루트 원점**을 그 출구 포트에 맞춘다.
   유체 원점이 물이 시작되는 지점이다.
3. 호퍼·저장고의 NodePath 연결 칸을 비우면, 출구 포트에서 기본 36px 안에 있는
   유체 시작점을 자동으로 연결한다.
4. 정확한 한 유체만 쓰고 싶으면 `출구_유체`(호퍼) 또는 `공급_유체`(저장고)에
   NodePath를 넣는다. 수동 연결이 자동 연결보다 우선한다.

포트의 오차 범위는 호퍼·저장고 인스펙터의 `포트_연결거리`에서 조절한다.

## 5. 호퍼 혼합 예시

```text
검정 유체 ──┐
            ├─ 호퍼 입구 ── 회색 유체(출구)
흰색 유체 ──┘
```

1. 검정·흰색 유체 두 개가 호퍼 위 `입구` 감지 범위에 모두 닿게 놓는다.
2. 호퍼 아래 `출구_포트`에 새 유체의 루트 원점을 맞춘다.
3. 호퍼는 두 입력을 매 물리 프레임 합쳐 `검정 + 흰색 = 회색`으로 만들고,
   자동 연결된 출구 유체를 켠다.
4. 입력이 끊기면 출구 유체도 꺼진다.

호퍼는 밟을 수 있지만 색칠할 수 없다.

## 6. 물저장고 사용

1. 저장고 상단 `출구_포트`에 유체 루트 원점을 맞춘다.
2. 저장고를 필요한 횟수만큼 한 색으로 칠하면 저장고 전체가 그 색이 된다.
3. 자동 또는 수동으로 연결된 유체가 켜지고, 저장고의 색으로 바뀐다.
4. 저장고가 무색이면 해당 유체는 꺼진다.

저장고는 밟고 색칠할 수 있다. 회색으로 굳은 저장고는 되돌릴 수 없다.

## 7. 물 애니메이션

`유체.tscn`의 `물_애니메이션`은 AnimatedSprite2D다.

- 흰색·회색·검정색 각각 8프레임
- `흐름` 애니메이션, 8fps 반복
- 유체 색이 바뀌면 같은 프레임 구조의 해당 색 SpriteFrames로 자동 교체
- 유체 인스턴스의 `크기`에 맞춰 애니메이션 폭·높이가 자동 배율
- 연기는 물 애니메이션을 쓰지 않고 기존 코드 그림 또는 별도 아트 슬롯을 유지

프레임 순서는 **기본 낙하 → 약한 접촉 → 넓어짐 → 충격 직전 → 가장 크게 튐 → 회복 시작
→ 가라앉음 → 기본으로 복귀**다. 기존 4프레임은 짝수 번호 프레임으로 원본 파일을 그대로
보존하고, 그 사이에 바닥 물보라만 보간한 4프레임을 추가했다. 바닥 물보라를 덧그리는
시작점에는 32px 알파 페더를 적용해, 물줄기와 물보라의 투명도가 뚝 끊겨 보이지 않게 했다.
이전 좌우 흔들림 전용 `animated_v2`와 4프레임 충격판 `animated_v3`는 보존되며, 현재 유체는
`animated_v4`를 쓴다.

물줄기의 정지된 하이라이트 때문에 흐름이 옆으로만 움직여 보이지 않도록, 별도 상세 레이어가
물줄기 안의 반투명 물방울 네 개를 매 프레임 아래로 이동시킨다. 본체·바닥 물보라 이미지는
바꾸지 않으며, 상세 레이어도 흰색·회색·검정색과 같은 `흐름` 8fps로 함께 재생된다.

리소스 경로:

`assets/textures/obstacles/liquid/animated_v4/`

물줄기 이동 상세 리소스:

`assets/textures/obstacles/liquid/flow_details_v1/`

### 그리는 높이 — 배관을 물 위로 (인스펙터 `깊이`)

★**[2026-09-02 추가]** 배관 인스펙터에 **`깊이`**(z_index) 가 생겼다.
SS2D 배관(`TEMPLATE_PIPE_OPEN_GRAY`)에는 아예 없던 것이고, 옛 배관(`배관.tscn`)은
기본값을 **2 → 3** 으로 올렸다.

유체는 **세 겹**으로 그려진다:

| 노드 | z | 실효 높이 |
|---|---|---|
| `유체` (Area2D 본체) | 0 | **0** |
| └ `물_애니메이션` | +1 | **1** |
| └ `물결_상세_애니메이션` | +2 | **2** |

자식의 z 는 부모에 **더해지는 상대값**이다(`z_as_relative` 기본 켜짐).
그래서 배관이 물 위로 오려면 **3 이상**이어야 한다 — 그게 새 기본값이다.

> ⚠ 예전 기본값 2 가 나빴던 이유: 물결 상세와 **높이가 같아서** 누가 위로 갈지
> **트리 순서**로 갈렸다. 어떤 배관은 물에 깔리고 어떤 것은 안 깔리는,
> 재현이 안 되는 상태였다.

배관에 `깊이` 를 주면 이렇게 퍼진다:

| 부분 | 실효 높이 |
|---|---|
| 배관 본체(`경로`) | `깊이` |
| 끝마개 Sprite 2 개 | `깊이 + 1` |

**값 고르는 법**

| 하고 싶은 것 | `깊이` |
|---|---|
| 물 위로 (기본) | **3** |
| 지형 뒤로 숨기기 (배경처럼) | 음수 (예: -6) |
| 더 앞으로 | 4~28 (플레이어 이펙트가 29~30 을 쓰니 그보단 낮게) |

에디터 2D 화면에서도 바로 반영된다 — `@tool` 이라 값을 바꾸면 그 자리에서 순서가 바뀐다.

### 물 판정 범위

★**[2026-09-02 바뀜]** 예전에는 직사각형 3 개(물줄기 / 중간 물보라 / 바닥 물보라)로
근사했다. 지금은 **그림의 알파 실루엣을 그대로 딴 폴리곤**이 판정이다.
그래서 인스펙터의 "물 판정 범위" 세 칸은 **없어졌다** — 조절할 것이 없다.
그림이 곧 판정이다.

- 프레임 8 장이 **각자 다른 폴리곤**을 갖는다. `물_애니메이션` 의 프레임이 바뀌면
  판정도 같이 바뀐다(8fps · 프레임이 실제로 바뀔 때만 갱신한다).
- 좌표는 0~1 정규화라 유체의 `크기` 를 아무리 바꿔도 그림과 판정이 같이 늘어난다.
- 판정 노드(`물_판정_0`…)는 **씬에 저장되지 않는다.** 스크립트가 런타임에 만든다
  (owner 가 없다). stage 씬이 폴리곤 좌표로 불어나지 않게 하려는 것이다.
- 에디터에서는 그림 위에 **빨간 외곽선**으로 판정이 겹쳐 보인다.
- 예전 버전의 사각형 판정(`모양` · `물줄기_판정` …)이 저장된 인스턴스가 있으면
  자동으로 꺼져 중복 판정하지 않는다.

### 2D 워크스페이스에서 판정 보기 · 만지기

**① 프레임별로 판정을 눈으로 본다 (게임 안 켜고)**

1. 유체 인스턴스를 고르고 → 자식 `물_애니메이션`(AnimatedSprite2D)을 고른다.
2. 인스펙터의 **`Frame`** 을 `0 → 7` 로 바꾼다.
3. 뷰포트의 **빨간 외곽선**이 그 프레임 모양으로 바뀐다. 그게 지금 판정이다.

★ 편집 중에는 애니메이션이 안 돌아가므로 `Frame` 값이 곧 "지금 보고 있는 프레임"이다.
게임을 켜면 8fps 로 흐르고 판정도 같이 흐른다.

**② 게임을 켜고 실시간으로 본다**

`디버그 → 충돌 모양 보이기` (Debug → Visible Collision Shapes) 를 켜고 F5.
물이 출렁이는 대로 판정 폴리곤이 같이 출렁이는 게 보인다.

**③ 만질 수 있는 것 / 없는 것**

| 하고 싶은 것 | 방법 |
|---|---|
| 판정을 조금 **얇게/두껍게** | 유체 인스펙터의 **`판정_여유`** (px). 음수 = 얇게(너그럽게) · 양수 = 두껍게 |
| 물 전체를 크게/작게 | 유체 인스펙터의 **`크기`** (권장) 또는 노드 `Scale` |
| 모양 자체를 바꾸기 | **그림(PNG)을 고치고 다시 굽는다.** 아래 명령 참고 |
| 판정을 더 촘촘하게/뭉툭하게 | 다시 구울 때 `--단순화=3` (촘촘) ~ `--단순화=10` (뭉툭) |
| 물의 흐릿한 가장자리를 판정에 넣기/빼기 | 다시 구울 때 `--문턱=0.2` (넓게) ~ `--문턱=0.6` (좁게) |

⚠ **폴리곤 점을 손으로 끌어서 고칠 수는 없다.** 판정 노드(`물_판정_0`)는 스크립트가
런타임에 만드는 것이라 **씬 트리 독에 안 뜨고**, 값을 고쳐도 다음 프레임에 덮어써진다.
프레임 8 장이 각자 다른 모양이니 손편집은 애초에 8 번 해야 하는 일이기도 하다.
→ 모양은 **그림에서 나온다**. 그림을 고치는 게 정답이다.

표를 다시 구우려면(그림을 새로 그렸을 때):

```bat
%G% --headless --path . -s res://tools/생성_유체_판정폴리곤.gd -- --확인만 --미리보기
%G% --headless --path . -s res://tools/생성_유체_판정폴리곤.gd
%G% --headless --path . -s res://tools/test_유체_판정모양.gd
```

`--미리보기` 는 딴 선을 그림 위에 겹친 PNG 를 `user://유체_판정_미리보기` 에 남긴다.
결과 표는 `scripts/스마트월드/유체_판정모양.gd` 다 — **손으로 고치지 말 것.**

연기(`종류 = 연기`)는 예전대로 직사각형 판정을 쓴다. 물 실루엣은 *떨어지는 물*의
모양이라 위로 퍼지는 기체에 씌우면 오히려 어긋난다.
