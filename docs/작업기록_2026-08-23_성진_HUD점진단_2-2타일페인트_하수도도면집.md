### 2-1. 원인 ① — 검정 플레이어일 때 "찬 점"의 채움이 검정이다

`페인트_HUD.gd:209` 는 설계대로 *찬 점 = 내 색으로 채움 + 반대색 링* 을 그린다.
회색 배경(2-1)에서는 잘 읽힌다. 그런데 **집 스테이지는 배경이 거의 검정**이라
검정 채움이 배경에 녹고 **링만 남아** 빈 점과 모양이 같아진다.
남는 차이가 "링이 흰가 회색인가" 하나뿐이라 한눈에 안 읽힌다.

★작업기록 2026-08-17 은 *반대* 케이스(흰 플레이어의 검은 링이 어두운 받침에 묻힘)만 잡아 뒀다.
**검정 플레이어의 검정 채움**은 안 잡혀 있다.

### 2-2. 원인 ② — 이번 pull 의 비네트가 HUD **위**에 깔렸다

```gdscript
# proto_camera.gd:451
_비네트층.layer = 50    # 게임 위, HUD(100)·전환(200) 아래
```

그런데 **점 HUD 는 100 이 아니라 `layer = 5`** (`페인트_HUD.gd:90`).
작성자가 의도한 "HUD 아래"가 아니라 **HUD 위**에 깔렸고,
방사형 비네트는 하필 **모서리가 가장 어둡다** — 점 줄이 있는 바로 그 자리다.
원인 ① 과 겹쳐서 집 스테이지에서 최악이 된다.

### 2-3. 즉시 확인법

게임 안에서 **Shift 로 흰색 전환** → 찬 점이 흰색으로 채워져 바로 나타난다.

## 3. stage_2-2 에서 HUD 가 아예 안 뜬 이유 — 색칠 자체가 꺼져 있었다

루트 노드에 **`타일맵_페인트` 가 없었다**(기본값 `false`).

```
타일맵_페인트 = false
  → 타일페인트 = null                     (stage_lab.gd:122)
  → 점 HUD 부착 조건 `if 타일페인트 != null` 이 거짓  (stage_lab.gd:226)
```

`stage_2-2.tscn` 에는 **TileMapLayer 는 있고 PaintPlatform 은 0개**다.
즉 타일맵 페인트를 쓰라고 만든 레벨인데 플래그가 꺼져 있어서
**칠할 대상이 어디에도 등록되지 않았다.** HUD 가 안 뜬 건 증상일 뿐,
실제로는 **총을 쏴도 아무것도 안 칠해지는 상태**였다.

→ 이번 커밋에서 `타일맵_페인트 = true` 로 켰다. `stage_2-3` 도 켠 채로 만들었다.

⚠ 같이 볼 값: `타일_최대_탄약`(기본 14). **0 이면 무제한이 되어 탄약 점 줄만 다시 사라진다.**

## 5. ⚠ 남은 것 — 다음 사람이 이어서 할 일

### 5-1. 점 HUD 가 집 스테이지에서 안 읽힌다 (§2)

| | 무엇을 | 효과 |
|---|---|---|
| A | `proto_camera.gd:451` 비네트를 `layer = 50` → **`4`** | 한 줄. 원저자 주석의 의도대로 HUD 아래로 내려간다. 연출상으로도 UI 를 어둡게 할 이유가 없다 |
| B | `페인트_HUD.gd` 의 **받침 원**(`Color(0.04,0.04,0.04,0.55)`)을 찬 점에 한해 크고 밝게 | 검·백 어느 색이든 어느 배경이든 살아남는다. 근본 해결 |
| C | 찬 점 링을 굵게 + 빈 점을 점선으로 | 밝기 대신 **모양**으로 구분 — 색 대비에 안 기댄다 |

**A + B 를 같이** 해야 한다. A 만 하면 집 배경에서 여전히 어둡고, B 만 하면 비네트가 계속 덮는다.

### 5-2. stage_2-2 의 호퍼 8개가 전부 놀고 있다

실행하면 이게 8번 찍힌다.

```
[호퍼:호퍼] 출구_유체가 비어있음 — 이 호퍼는 아무 것도 안 함
```

씬에 **호퍼 8개 · `출구_유체` 연결 0개**. 호퍼는 "위에서 받은 물을 아래 배관으로 내보내는"
장치라 출구가 없으면 존재만 하고 아무 동작도 안 한다.
어느 유체로 내보낼지는 **레벨 디자인 판단**이라 코드로 정할 수 없다.

### 5-3. `챕터.gd` 스테이지표에 2-1 ~ 2-10 이 아직 없다
