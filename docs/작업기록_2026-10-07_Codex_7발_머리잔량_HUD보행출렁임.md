# 7발 용량·머리 잔량·HUD 보행 출렁임 — 2026-10-07 · Codex

사용자 요청: 페인트 총알 최대 7발, 캐릭터 머리 잔량을 7발 기준으로 표시, 좌측 상단 페인트통 내부가 좌우 걷기에 맞춰 물리적으로 흔들리도록 구현, 힉스필드 원화 사용.

## 적용

- 스마트월드 코어의 최대/초기 잔량을 7발로 변경. 프로토 타일맵 코어와 StageLab 기본값도 7발. 기존 씬의 별도 10발/12발 설정 2곳을 7로 수정했다. 무제한 0 설정과 탄약 없는 옛 테스트 경로는 유지한다.
- 집·하수도 생성 도구 4곳의 12발 설정도 7로 바꿔 나중에 생성해도 되돌아가지 않도록 했다. 생성 도구를 실행하지 않았다.
- 머리는 이전에 연결한 실제 `남은_탄약 / 최대_탄약`을 그대로 사용한다. 이제 7/7 → 6/7 → … → 0/7로 변하고, 회수·환급·리스폰 때 다시 찬다. 가득 찼을 때도 통 내부 높이의 12%를 공기층으로 남겨 빈 공간과 수면이 보이도록 했다. 한 발의 수위 차이는 **사용 가능 용량의 1/7**이다.
- HUD도 `가용_탄약()`의 실제 잔량을 사용하므로 머리·숫자·HUD 용량이 같은 데이터에 연결된다. 원형 통은 면적 기준 84% 용량선, 원통 머리는 높이 기준 88% 용량선이므로 공기층 비율은 다르지만 표시 탄수는 같다.
- 기존 출발·제동·방향 전환 관성에 보행 구동을 추가. CharacterSprite의 walk 프레임/진행도에서 한 사이클의 두 발 주기를 읽는다. 일정 속도로 걸어도 수면에 낮은 기울기 변화와 넓은 파동이 생긴다. 시트 없는 검사/구 캐릭터는 이동 거리 기반으로 계산한다.
- 공중/정지 중에는 새 보행 충량을 주지 않고 감쇠시킨다. 기존 점성·느린 벽면 흐름·착지 충격·발사/회수 충격을 유지한다. 통 외곽 테두리는 흔들지 않는다.
- 유체 표현은 **가속도 관성 + 감쇠 진동계 + 33개 수면 스프링** 근사이며 실제 액체 해석은 아니다. 평균 수면 높이/속도 보정은 기존 파동 모델을 사용하고, 실제 탄약을 연출에서 수정하지 않는다.
