# 하수도 2-9~2-11 제작 잠금

요청: 미완성 stage_2-9~stage_2-11은 클리어 기록이 있어도 잠근 상태로 유지하여 플레이어가 들어가지 못하게 한다.

## 적용

- `scripts/진행/게임진행.gd`의 `하수도_제작중` 목록에 세 씬을 명시. 해금과 클리어 표시보다 제작 잠금이 우선한다. 저장 파일의 클리어/방문/시간/사진 데이터는 지우지 않는다. 완성 후 해당 파일명만 목록에서 제거하면 기존 저장 기록을 다시 사용할 수 있다.
- `제작중인가()`와 `입장_경로()`를 공통 정책으로 사용. 잠긴 씬 목적지는 챕터2 지도로 돌린다. 2-8을 정상 완료하면 완료 기록을 남기고 2-9 대신 지도로 돌아간다. 잠긴 맵 이후로 건너뛰지 않는다.
- `scripts/진행/쳅터1_보드표.gd`: 하수도 해금을 게임진행에 위임하여 사진 지도의 선행 클리어 규칙이 제작 잠금을 우회하지 못하게 한다.
- `scripts/ui/퍼즐보드.gd`: 세 칸은 잠김 상태로 표시하며 선택 정보에 “잠김 · 제작 중인 스테이지입니다”를 표시한다. 클릭·키보드 입장은 기존 열림 확인에서 차단된다.
- `scripts/쳅터1/전경전환.gd`: 직접 입장, 왕복 통로, 보관된 씬 경로도 같은 정책으로 검사. 지도로 돌릴 때 이전 입구 노드 이름은 비운다.
- `scripts/proto/stage_transition.gd`: 일반 로비/메뉴의 씬 전환에도 공통 잠금 적용.
- 저장된 이어하기 목적지가 세 맵 중 하나면 지도를 연다. 다른 집·하수도 스테이지의 진입 규칙은 유지한다.
- 스테이지 씬 파일/도안/지형은 수정하지 않았다. Godot 편집기의 직접 F6 실행은 개발용으로 남는다. 플레이어용 지도·메뉴·이어하기·통로 경로를 막았다.

## 확인

- 변경 전 대상 6개 파일을 `tmp/sewer_lock_20261010/`에 원래 경로 구조로 보존.
- 변경 전 기존 정적 검사 13개 통과. 검사 도구의 두 진행 계약을 새 제작 잠금 요구사항에 맞춰 갱신하고, 변경 후 13개 통과. 씬 파일의 실제 목적지를 읽는 정적 이동 모델에서 2-1→2-8→챕터2 지도 경로 확인. 결과는 `docs/visual_review/로비소리_20261010/정적_검사.json`.
- 변경된 GDScript 5개 전후 gdtoolkit 구문 분석 통과. 일반 전환 스크립트의 기존 다중행 셰이더 문자열은 파서 제한 때문에 메모리에서만 삼중 따옴표로 변환했고 파일은 그대로 유지.
- `git diff --check` 통과. 추적 파일 삭제 없음. 기존 작업 보존, 커밋/푸시/저장 파일 초기화는 하지 않음.
- 세션의 `git pull`은 기존 미커밋 `월드.gd`·`챕터.gd` 변경과 겹쳐 중단됐으며 자동 stash/덮어쓰기를 하지 않았다.
- `docs/다음작업_프롬프트.md`가 현재 체크아웃에 없고 Godot 실행 명시적 허용도 없어 원본 엔진 검사 13개는 미실행. 위 13개는 정적 계약이며 엔진 검사를 대체하지 않는다.
- `graphify update .`로 코드 1,055개 AST 재추출 완료. 새 그래프 14,873개가 기존 graph.json 34,996개보다 작아 보호 장치가 덮어쓰기를 거부했다. 강제 축소하지 않았으며 graph.json 전체 갱신 완료로 보고하지 않는다.

## 남은 실행 확인

**수정 완료·시각 검증 대기.** Godot는 실행하지 않았다. 실제 엔진 캡처 경로는 없음.

실행 허용 후: 전체 클리어 기록이 있는 저장에서 세 카드 잠금·제작 중 안내·마우스/Enter 차단, 2-8 완료 기록 및 지도 복귀, 이전 2-9~2-11 이어하기 저장의 지도 진입, 입구 왕복과 지도 복귀 후 조작 가능 여부를 확인한다. 기존 집/하수도 2-1~2-8 해금은 유지되어야 한다.
