# 기본 지형 노출 옆면 전체 적용

- 사용자가 작은 돌출부 마감을 승인하고 다른 지형에도 확대 요청. 접촉면은 제외.
- 공통 shader의 고정 side_trial_bounds를 실제 ground_edges 탐색으로 교체. 수직에 가까운 면(abs(tangent.y)>=0.95)의 안쪽 18px 이내만 검사한다.
- 승인된 12/18px 교차 폭 끝돌, 3~5px 측면 음영, 최대 0.8px 줄눈 홈을 유지한다. 위 22px는 기존 윗면을 보존하고 22~30px에서 섞는다. 면의 실제 길이로 종료하며 일직선 중간 점은 합산한다.
- 이웃 다각형에 접촉/가려진 점은 옆면 마감과 기존 오른쪽 음영에서 제외한다. 부분 가림도 픽셀별로 제외한다. 같은 부모 지형끼리 자동 접합한다.
- 하수도_자연발판.gd의 옆면마감 기본 true. 윗면표시와 독립. 시험 옵션/고정 범위 제거. 선분 한도 초과 시 윗면과 옆면 모두 표시를 중단해 내부 선 발생 방지.
- stage_2-1의 저장된 미리보기 재질도 새 유니폼으로 정리. 기본 지형 프리팹 검정/흰색에 옵션 명시. 기존 점·물리·배치는 이번 변경에서 수정하지 않는다. 공중 프리팹 재질에 저장됐던 옛 시험 유니폼만 정리하며 ground_platform=false인 경우 옆면 기능은 실행되지 않는다.
- 실제 씬의 기본 지형 28개에서 수직면 샘플 204개를 정적 검사: 노출 79개, 접촉/가림 제외 125개. 승인된 작은 돌출부 좌우 샘플 6개 모두 노출 확인. ASCII 및 옛 시험 설정 제거, diff 공백 검사 통과.
- Godot 실행·셰이더 컴파일·실제 화면·성능·착지·색칠·사망 검사는 AGENTS.md 제한에 따라 미실행. 수치 검사는 실제 렌더링 결과를 보증하지 않는다.
- 아스트라/클로드 프롬프트에 확정 사용법과 검수 기준 추가. Graphify update는 uv trampoline 오류. 커밋/푸시 미실행.
