# Fireboy and Watergirl 동선 참고 정리

사용자 제공 이미지6개를 참고/fireboy_watergirl/ref_01..06.png에 원본 그대로 보관했다. .gdignore로 게임 자산 자동 임포트에서 제외했다.
통합 맵제작_공통규칙 §3.1에 관찰 구조6종, 동선 설계 적용법, 검수 기준을 한 번만 추가했다. 맵제작_시작의 선택 자료 표에 안내했다. 모델별 옛 프롬프트/보관본에 중복 복사하지 않았다.
퍼즐 작동 순서는 정지 이미지로 확정하지 않으며 원작 협동/색 규칙 대신 현재 게임 규칙과 이동 수치를 우선한다. 필요할 때만 원본을 읽어 토큰을 절약한다.
검증: 원본 복사 바이트 일치, 문서 이미지 상대 링크6개 확인. 씬/코드 변경 없음, Godot 미실행.
