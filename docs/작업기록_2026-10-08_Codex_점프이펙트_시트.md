# 카드 2 — 점프 이펙트 원화 시트

## 사용자 결정

- 스프링 나무 재질은 쳅터1에 사용.
- 맨홀 뚜껑 재질은 `res://scenes/world_2_클로드/` 스테이지에 사용.
- 이전 스프링 시트의 디자인은 그대로 사용한다. 앞선 작업기록의 재질 재디자인 제안보다 이 결정이 우선한다.
- 이번 요청은 다음 디자인 제작으로 해석하여 카드 2를 제작했다. 이번 턴에서 스테이지에 재질을 연결하지 않았다.

## 저장한 원화

모두 `assets/textures/props/신규기믹_v02/이펙트/`에 저장했다.

| 파일 | 실측 크기 | 구성 |
|---|---|---|
| 점프_약강.png | 1536×1024 | 6열×2행. 위 약 / 아래 강. 각 행 첫 5칸 효과, 마지막 칸 비움. 명목 셀 256×512 |
| 점프대_튕김.png | 1536×1024 | 3열×2행. 접촉 → 확장 → 최대 파문 → 분열 → 소멸 → 잔점. 명목 셀 512×512 |
| 잉크_낱개.png | 1254×1254 | 4열×3행 형태로 줄기 3 + 방울·가시 8. 우하단 비움. 개별 영역으로 잘라 사용 |

생성 도구: built-in image_gen. 생성 프롬프트는 같은 폴더의 `생성프롬프트_20261008.txt`에 보존했다. 최초 요청은 출력 안전 필터에서 잘못 분류되어 실패했고, 간단한 게임 효과 설명으로 재시도했다. 검정 배경으로 나온 중간 결과는 채택하지 않았다.

## 디자인

- 약한 점프: 짧은 잉크 줄기 2개, 소수 방울. 조용한 시작.
- 강한 점프: 긴 줄기 3개, 더 많은 방울. 같은 잉크 재료 안에서 세기 차이를 표현.
- 점프대: 얕은 타원 파문이 옆으로 벌어지고 방울·가시가 아래로 남는다. 위 중앙을 비워 캐릭터 가림을 줄이는 방향.
- 별·번쩍임·문구·캐릭터·점프대 본체는 시트에 포함하지 않았다.
- 약 0.18초 / 강 0.28초 / 점프대 0.35초는 원문 기획값이다. 이번 작업에서 재생 구현이나 시간 검증은 하지 않았다.

## 검사 결과와 사용 한계

- 세 이미지를 직접 확인했다. 약/강 차이, 소멸 순서, 파문 6개, 낱개 11개가 보인다. 눈에 띄는 이미지 바깥 잘림은 없으나 낱개 긴 줄기의 위 여백은 좁다.
- **세 파일 모두 RGB 24bit이며 알파 채널이 없다.** 초록 배경 제거가 필요하다. 그대로 Sprite2D에 넣으면 초록 배경까지 나온다. 디자인 원본으로는 사용할 수 있지만 즉시 적용 가능한 투명 아틀라스라고 보고하지 않는다.
- 배경은 순수 #00FF00가 아니다. 좌상단 실측은 각각 (16,240,17), (17,240,13), (16,241,14). 정확한 단일 RGB 제거보다 색 범위 기반 마스크·경계 검수가 필요하다.
- 약강 시트의 행·열 구성은 맞지만 프레임별 시작점이 완전히 동일하지 않다. 파문의 2행도 1행과 상대 높이가 다소 다르다. 실제 재생 전에 개별 피벗 정렬 필요.
- 낱개 시트는 요청 1024 정사각 대신 1254 정사각으로 출력되었다. 가로 4등분이 정수 픽셀이 아니므로 등분 애니메이션 시트로 사용하지 말고 개별 AtlasTexture 영역을 지정한다.
- 원문과 같이 검정 잉크 원화만 제작했다. 흰색 효과는 명도 상한 184로 후처리·엔진 변환할 후속 범위다.
- 이미지 편집 후처리·게임 코드·씬 수정 없음. Godot 실행·엔진 테스트·실제 엔진 캡처 **미실행**.
- 이번 턴 추가 파일 외 기존 변경은 보존했다. 상태 조회에서 다른 작업의 stage_2-9/2-11 및 전환 시험 변경이 관찰되었으나 수정하지 않았다. 삭제(D)는 없었다.
