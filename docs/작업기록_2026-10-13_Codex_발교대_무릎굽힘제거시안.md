# 발 교대 시안의 무릎 굽힘 제거

- 요청: 교차할 때 무릎을 굽히는 동작을 없애고 두 발이 서로 앞뒤 위치를 바꾸게 한다.
- 이전의 게임 미적용 요청을 유지해 시안 생성 도구만 수정했다. 실제 게임의 스크립트ㆍ씬ㆍ셰이더ㆍ이미지에는 손대지 않았다.
- `tools/시안_발교대_미적용.py`: 무릎에 주던 교차 구간 편향과 발 들기 제거. 모든 위상에서 목표 무릎을 골반과 발목 사이의 직선에 둔다. 두 발의 반대 위상 앞뒤 이동과 상체 고정은 유지한다.
- 결과: `docs/visual_review/player_walk_20261012/발교대_무릎굽힘없음_미적용시안/`의 GIF, 주요 자세 PNG, 검정/흰색 투명 16프레임 시트. 이전 굽힘 시안은 별도 폴더에 보존했다.
- 확인: 주요 자세 PNG를 직접 열어 교차 자세를 확인했다. 검정/흰색 두 발의 앞뒤 순서 반전과 32프레임 전체의 추가 굽힘 0, 발 높이 고정을 확인했다. 게임 파일 전체 해시가 작업 전후 동일함을 확인했다.
- 한계: 원화에 그려진 다리 윤곽 자체를 새로 그린 것은 아니다. Godot 실행 및 엔진 검사 13개는 명시적 허용이 없어 미실행했다. 결과는 게임 캡처가 아닌 오프라인 시안이다.
- graphify query/update 실행. update는 기존 그래프 노드 축소 보호로 graph.json 덮어쓰기가 거부되어 강제하지 않았다.
