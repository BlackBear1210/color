# 3단계: 2-9 배경·지형 명도 조율 (시각 검증 대기)

목표 시안은 사용자 지시에 따라 기존 ver.2로 확정했다. docs/visual_review/ver2_stage29_baseline/approved_ver2_reference.png에 원본 비교 시트 보존(아래 패널이 ver.2).

## 수정
- 2-9만 신규 하수도_벽돌배경_2_9_조정.tscn에 연결. 공유 v05와 다른10개 stage는 이번 단계에서 수정하지 않음.
- 배경 중심명도0.185→0.215, 대비0.72→0.55, 범위0.085~0.32. 어두워서 읽히지 않는 돌의 중간톤을 회복하고 강한 줄눈 대비는 감소.
- 벽돌 크기0.65 및 반복998.4×665.6 유지. 배율만 줄이면 배관/철창까지 작아지고 반복 빈도가 올라가므로 추가 축소하지 않음.
- 지형24개에 시안_명도조율=true. 기본값false로 타 스테이지 보존.
- 자연발판 셰이더에서 페인트 혼합 이전 black*0.82+0.018 / white*0.78+0.08. 질감 대비와 흰색의 과도한 밝기를 낮추며 논리 색값/충돌/페인트 동작은 유지.
- 물·등·카메라·입수 효과는 이번 단계에서 변경하지 않음.

## 검증
- GDScript 정적 구문 파싱 통과, 셰이더 ASCII 확인, diff --check 통과.
- 수정 전2-9 사본과 대조: 배경 경로와24개 명도 옵션을 제거하면 씬 텍스트가 완전히 동일함. 형상/장치/좌표 변경 없음.
- 나머지10개 stage에 옵션 없는 것 확인.
- Godot 미실행: 실행 명시 허용이 아직 없으므로 실제 화면 대조와 셰이더 엔진 컴파일은 대기. 수치 조정은 후보값이며 시안 재현 완료를 주장하지 않는다.
- 반복감은 동일 타일 원화에 구조물이 포함돼 있어 근본적으로 해소되지 않았다. 실제 대조 후 필요하면 배경 구조물을 별도 레이어로 분리해야 한다.
