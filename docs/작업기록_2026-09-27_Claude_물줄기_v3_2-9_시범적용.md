# 작업기록 2026-09-27 · Claude · 물줄기 v3 외관 — 2-9 시범 적용

## 왜

스크린샷에서 물이 **벽돌 재질과 따로 놀았다.** 벽돌·호퍼는 요철·하이라이트·리벳까지 있는데
물은 가장자리가 반듯한 단색 반투명 띠라 "벽의 홈"처럼 읽혔다. 착수점 반응도 없고,
검정 물은 벽 명도와 겹쳐 **판정 색이 한눈에 안 읽혔다**(게임플레이 문제).

시안 두 번(파이썬 목업)을 거쳐 방향을 정했다:
원통 반사선 · 뒤 벽돌 굴절 · 톤별 흐름줄 · 떨어지며 가늘어짐 · 왕관 물막 + 눈물 모양 물방울 · 잔거품 · 바닥 물막/잔물결 · 젖은 벽.
흰 물은 거품을 본체보다 **낮춰**(0.70~0.84 < 0.91) 착수부가 하얗게 뭉개지지 않게 했다(도형님 결정).

`유체_흰물v2._판정_폴리곤들()` 은 손대지 않았다. v3 는 떨어지며 가늘어지는데,

## 알아둘 것

- ⚠ **D_호퍼출력은 폭 128 이라 호퍼 출구 관(약 64)보다 넓다.** 새 외관은 가장자리가 또렷해서 v2 보다 더 눈에 띈다. 판정 폭이라 레벨 쪽 결정 — 좁히면 난이도가 바뀐다.
- `stage_2-9.tscn` 은 이 작업 전부터 git 에서 **UU(병합 미완)** 상태였다. 충돌 표식은 없고, 인덱스는 건드리지 않았다.
- 전 스테이지 적용 = `흰물_디자인.gd`·`유체_흰물v2.gd` 의 `물줄기_v3` 기본값을 `true` 로 바꾸면 끝(씬 파일은 안 건드려도 된다). 2-9 의 4 줄은 그때 지워도 되고 둬도 된다.
- 프레임을 고치려면 PNG 를 손으로 그리지 말고 `python tools/생성_물줄기_v3_프레임.py` 의 입자 표를 고친다. 시트 규격(16·4·384×128·(192,112)·64)을 바꾸면 **셰이더 상수도 같이** 바꿀 것.
- 굴절은 화면 텍스처를 읽는다. 무거우면 셰이더 `refraction` 을 0 으로(인스펙터 노출은 안 했다).

## 추가 — 같은 날 전 스테이지 적용 (도형님 "너가 적용시켜")

- `흰물_디자인.gd`·`유체_흰물v2.gd` 의 `물줄기_v3` **기본값 true**. `world_2_클로드` 11 스테이지의 물 76 개가 전부 `유체_흰물v2.gd` 를 쓰므로 씬 파일은 하나도 안 고쳤다.
  2-9 에 넣었던 `"물줄기_v3" = true` 4 줄은 **백업으로 되돌려 뺐다**(기본값과 같아 불필요 · UU 파일 변경 최소화). → `stage_2-9.tscn` 은 이 작업 전과 바이트까지 같다.
- 옛 `scenes/world_2/`(2-1~2-3)는 `유체.gd`(프레임 스프라이트)라 v3 대상이 아니다.
- ★**바닥 속으로 들어간 물줄기** 발견: 2-5 F1(448 폭 흰 물)은 판정 아랫끝이 바닥 윗면보다 60px 아래라, v3 물막·물보라가 벽돌 속에 그려졌다(v2 도 같은 배치였지만 물막 선이 없어 덜 보였다).
  → `유체_흰물v2._바닥_찾기()`: 실행 중 물리 2 프레임 뒤, 아랫끝에서 위로 4px→1px 씩 **점 질의(레이어 1)** 로 바닥 윗면을 찾아 외관의 `보이는_높이` 로 넘긴다. **그림만 줄고 판정은 그대로.** 파묻힘이 물 높이 절반 또는 240px 를 넘으면 손대지 않는다. 호퍼 유입 물은 건너뛴다.
