## T1 — 식물 A/B 를 새 부품 스프라이트로 교체

**맥락:** 지금 식물은 아트가 없어 `_draw()` 로 그린다(`scripts/스마트월드/식물_a.gd` 머리말이
"나중에 Sprite2D 로 교체해도 로직 그대로" 라고 명시). 새 에셋은 **부품 분리형**이라 텍스처
교체가 아니라 **조립 방식 재작성**이다.

**새 에셋(이미 저장소에 있음):**
```
assets/png/plantA/  bud.png(640²) · flowerpot (black/white).png(640²)
                    leaf (black/white).png(3200×640=5프레임) · stem (left).png(2560×640=4) · stem (right).png(1920×640=3)
assets/png/plantB/  1.png · 2 (black/white).png · 3 (black/white/gray).png  (전부 640²)
```
**할 일:**
1. `식물_a.gd` 의 성장 단계(_단계)에 맞춰 화분→줄기 세그먼트→잎(칠한 색)→최대치에 봉우리/꽃을
   Sprite2D 로 조립. 잎 프레임은 단계 인덱스로 AtlasTexture 잘라 쓴다(가로 640 단위).
   **밟는 발판 콜리전(_잎_만들기)·페인트코어 계약은 건드리지 말 것** — 그림만 스프라이트로.
2. 흑/백 색변주는 플레이어가 칠한 색으로 `flowerpot/leaf (black|white)` 를 고른다.
3. `식물_b.gd` 도 동일 원칙(1·2·3 단계 스프라이트, 3단계는 회색 변주 포함).
4. 구 파일(`assets/plantA/*`, `assets/plantB/*`)은 T7 확정 전까지 삭제 금지(참조 잔존 확인 후).
**검증:** `test_페인트v4`(식물 성장/회수) · `test_사망판정` · 늪(3) 레벨검사 갇힘 0.
스크린샷: `screenshot_scene.gd -- 스마트월드_3.tscn ... <식물 좌표>`.
**완료조건:** 식물이 스프라이트로 보이고, 칠→성장→발판→회수 로직이 검사로 회귀 0.

## T3 — 철/하수구/배관 **타일셋** 리소스 저작

**맥락:** 새 `metal.png`(1152×384) · `drain.png`(128×128) · `pipe.png`(512²)는 **원시 텍스처**다.
지형으로 쓰려면 Godot 의 TileSet(타일별 아틀라스 좌표 + 충돌 폴리곤)을 만들어야 한다.
현재 타일셋은 `assets/tilesets/terrain_tileset.tres`(32×32) 하나뿐.

**할 일(스크립트 저작 권장 — `tools/build_*.gd` 패턴):**
1. 각 PNG 의 타일 크기 확정(대개 32 또는 16). 도형님/디자이너에게 **어떤 셀이 solid 인지**
   타일 맵(가장자리·안쪽·모서리)을 받는다 — 이게 없으면 충돌을 못 정한다.
2. `TileSetAtlasSource` 로 아틀라스 등록 → 각 solid 셀에 `create_tile` + 물리레이어 0 충돌 폴리곤.
   페인트 시스템을 쓰려면 `custom_data_layer "paint_hits"`(terrain_tileset 과 동일) 도 복사.
3. `assets/tilesets/{metal,drain,pipe}_tileset.tres` 로 저장. 하수도 챕터(4/2-x) 씬에서 사용.
**검증:** 헤드리스로 TileSet 로드 + 타일별 충돌 존재 assert 하는 `tools/test_타일셋.gd` 신설.
스크린샷으로 이음새 확인. **완료조건:** 세 타일셋으로 지형을 깔면 통행성 검사 갇힘 0.
