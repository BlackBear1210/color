# 2-9 벽등 곡면 금속 개선 — 시각 검증 대기

## 관찰과 수정 이유
사용자 캡처에서 벽등은 밝은 타원과 가는 선만 보여 벽에 붙인 무늬처럼 보인다. 기존 셰이더는 철망과 테두리에 동일한 타원 노멀을 사용했다. 금속 봉 자체의 둥근 단면이 없었고 작은 부착부도 묻혔다.

## 변경
- 금속 테두리는 고리 단면, 세로 봉은 가로 방향 원통 단면, 가로 띠는 세로 방향 원통 단면으로 각각 NORMAL 계산. light()에서 실제 광원 방향으로 반사 계산.
- 금속은 어둡게 유지하고 반사광으로 단면을 드러내도록 조정. 얇은 타원 철망 형태를 유지하며 상단 연결부와 하단 마감 추가.
- 유리는 중심 발광과 어두운 가장자리로 곡면/안쪽 깊이를 구분. 등 폭을 소폭 늘려 축소 화면에서도 철망이 남도록 함.
- 몸체 뒤 76.8 x 102.4 범위에 알파 0.10의 작은 가산 번짐 추가. 기존 광원의 반경, 에너지 및 동적 그림자는 변경하지 않음.
- 고정 방향 투사 그림자는 추가하지 않음. 유리 가장자리 명도는 재질 표현이며 벽에 드리우는 그림자가 아님.
- 이번 적용은 기존 실시간 벽등이 연결된 2-9만 해당. 물과 지형, 게임 판정은 변경하지 않음.

## 확인 범위
GDScript 파서 및 셰이더 ASCII/기본 구조 검사. Godot 4.6 공식 CanvasItem 문서의 NORMAL/COLOR/LIGHT 쓰기 가능 여부 확인. 정적 검사는 셰이더 컴파일 또는 시각 검증을 대신하지 않는다.
Godot 실행 제한으로 엔진 검사/수정 후 PNG는 미확보. 시안과 같거나 그림자가 정상 동작한다고 판단하지 않음.
실행 확인 시 같은 카메라에서 철망이 흰 유리와 분리되는지, 부착부가 보이는지, 반사가 지나치게 밝지 않은지, 플레이어 이동 시 실제 그림자가 변하는지 비교해야 한다.
