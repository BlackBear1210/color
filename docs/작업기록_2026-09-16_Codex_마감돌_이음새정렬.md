# 상단 마감돌 이음새 정렬

- 사용자 요청: 윗면 사다리꼴은 유지하고 상단 돌이 양끝에서 일부만 잘리지 않도록 이음새 기준으로 맵 제작.
- 공통 sewer_natural_platform.gdshader의 UV를 지형 로컬 X 반복에서 실제 직선 구간 기준 반복으로 변경했다. 직선 구간 길이 / 약 46.6px를 반올림해 정수 개의 돌을 배치한다. 원본 텍스처의 마감돌 구간 x=266~464를 반복한다. 양끝은 같은 이음새 좌표를 사용한다.
- 같은 직선에 추가한 점은 앞뒤 선분을 합쳐 한 구간으로 계산한다. 길이를 변경하면 돌 개수를 다시 계산한다. 충돌·씬 위치는 이번 턴 수정하지 않았다.
- 검정/흰색 공통 적용. 정렬 대상은 상단 마감돌 한 단이며 본체 전체 벽돌 줄의 모서리 아트는 별도 작업이다.
- 아스트라/클로드 맵 제작 프롬프트에 규칙·길이 기준·적용 범위·확인 사항 추가.
- git diff --check 통과. Godot 실행 및 이미지의 실제 이음새 정밀 정렬·반복 품질·성능·플레이 검증은 미실행. AGENTS.md 엔진 실행 제한 준수. 화면에서 최종 확인이 필요하다.
- Graphify update는 uv trampoline 경로 오류로 실패. 커밋/푸시 미실행.
