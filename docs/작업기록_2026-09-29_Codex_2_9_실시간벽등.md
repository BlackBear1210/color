# 2-9 실시간 벽등 전환 (엔진 검증 대기)

## 변경
- 고정 방향 음영의 sewer_lamp_volume 및 배경 조명캐시 경로를 2-9에서 제거. 다른 stage는 기존 경로 유지.
- 얇은 타원 철망/작은 부착부/밝은 유리로 외형 구성. 금속은 NORMAL 곡면 + 실제 LIGHT_DIRECTION 기반 diffuse/specular, 유리만 unshaded 발광.
- 배경은 wall_normal.res를 NORMAL_MAP으로 전달하여 실시간 조명에 반응. 고정 방향 노멀 조명 계산 제거.
- PointLight2D: 반경260, energy0.8, height128, PCF5 그림자, shadow mask16, 그림자 알파0.38.
- 월드 고정 셀 좌표에 등 배치. 기존 벽의 scroll_scale0.88을1로 맞춰 광원과 벽이 어긋나지 않도록 함. 카메라 기준 여백 밖의 등만 생성/해제하며 플레이어 추적광 아님.
- 지형/플레이어의 실제 CollisionPolygon2D에 LightOccluder2D 자식 추가. 플레이어 이동 변환을 따라감. 충돌/판정/물/플레이어 보조광 설정은 변경하지 않음. 기존 보조광의 그림자는 계속 꺼짐.
- 가림막은 충돌 윤곽 기반이므로 옷자락까지 정확한 애니메이션 실루엣과 같지 않음. 실행 중 다각형 자체가 변경되는 경우에는 추가 동기화 검토 필요.

## 검사
GDScript 정적 파싱, 셰이더 ASCII/괄호, 리소스 경로, 고정 음영 경로 제거 확인. graphify update 수행.
Godot은 명시 실행 허용 미확인으로 실행하지 않음. shader light() 컴파일, 자기 그림자, 지형 가림, 광원 수/프레임 비용, 실제 시안 유사도는 미검증. "한 번에 완벽" 또는 엔진 동작 통과를 주장하지 않음.

## 실제 검증 순서
같은 2-9 구간에서 정지/좌우이동/점프를 촬영. 벽등 위치 고정, 플레이어 가림 그림자의 방향 변화, 유리 발광 유지, 금속 반사 변화, 물색 식별, 배경 이음새 및 프레임 시간 확인. 필요하면 광원 에너지/반경과 가림막 마스크를 조절.
