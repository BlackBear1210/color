# 작업기록 — 색 경계 몸 분할·겹침 방지

날짜: 2026-08-23
작업자: Codex
범위: 플레이어가 색 경계를 걸칠 때의 시각·물리 판정, 총구 색, 경계 편집 안전장치

## 결정된 규칙

- 경계 안에 걸친 플레이어는 경계선으로 몸이 실제로 나뉜다. 각 조각은 자신이 들어간 흰색/검정 영역의 색을 쓴다.
- 경계에 몸의 일부라도 걸친 동안에는 수동 색 전환을 할 수 없다. 경계를 완전히 벗어나면 마지막 강제색이 남지 않고 `자유색` 전체로 즉시 돌아온다.
- 회색·무색 영역은 강제색이 아니다.
- 총은 입 높이에 두었다. 총알의 색은 총구가 있는 상체 조각의 색을 사용한다.
- 사망 판정도 같은 몸 조각 단위다. 예를 들어 상체 흰색이 검정 천장에 닿거나, 하체 검정이 흰색 바닥에 닿으면 사망한다.

## 구현

- `scripts/스마트월드/색경계.gd`
  - 모든 경계가 공통으로 제공하는 점별 강제색·폴리곤·몸 분할 계산을 모았다.
  - `면_겹치나()`는 양의 면적만 겹침으로 본다. 변 또는 꼭짓점 접촉은 허용한다.
- `scripts/player.gd`, `scripts/색겹침.gd`, `shaders/색분할.gdshader`
  - 기존 검정/흰색 플레이어 스프라이트 두 장을 겹쳐 놓고, 월드 좌표 경계선으로 각각 잘라 보인다.
  - 별도 색칠 텍스처를 만들지 않아 기존 애니메이션·좌우 반전도 그대로 유지된다.
- `scripts/총_받침.gd`, `scenes/player/Player.tscn`
  - `GunRig`가 플레이어 좌우 반전의 역스케일을 맡고, Gun/Muzzle은 입 위치에 둔다.
- `scripts/스마트월드/월드.gd`
  - 충돌 접점을 전신 대표색 하나로 비교하지 않고, 해당 접점이 속한 몸 조각의 색과 비교한다.

## ColorZone 편집 방법

`scenes/경계/color_zone.gd`가 Godot 2D 워크스페이스에서 다음을 처리한다.

- 꼭짓점 또는 ColorZone 전체를 다른 경계의 변·꼭짓점에서 기본 12px 안으로 가져가면 자석처럼 정확히 붙는다.
- 양의 면적이 겹치면 마지막 안전 배치로 즉시 되돌린다.
- 이미 겹친 오래된 씬을 처음 열어 되돌릴 기준이 없을 때는, 겹친 면을 빨간색으로 그리고 Inspector 경고를 표시한다.
- 이 직접 편집 방지는 `ColorZone`에만 적용한다. 런타임에 형태가 바뀌는 식물B·빛기둥을 에디터에서 되돌리면 연출을 망칠 수 있기 때문이다.
- 대신 `tools/레벨검사.gd`는 모든 `색경계`를 검사한다. 어떤 종류든 양의 면적 겹침이 있으면 종료 코드 1로 실패한다.

## 편집 시 주의

- 셰이더 파일에는 한글을 넣지 않는다. Godot 셰이더 토크나이저가 한글 식별자/주석을 받아들이지 않는다.
- 경계를 새 종류로 만들면 `색경계.그룹`에 넣고 `강제색(월드좌표)`, `경계_폴리곤들()` 계약을 구현해야 한다.
- 겹침이 필요해 보이는 설계도 경계 두 개를 포개지 말고, 변을 맞닿게 하거나 하나의 폴리곤으로 만든다.

## 추가 보정 — 총구와 발사 모션

사용 중 발견한 두 문제를 같은 날 보정했다.

- 총구 기준을 원본 캐릭터 시트의 입 좌표로 다시 실측했다. Player 준비 시마다 회전 중심을 발바닥 기준 `(0, -70)`, 발사 시작 Marker를 `(18, 0)`으로 확정한다. 따라서 씬 인스턴스의 속성 오버라이드가 있어도 총알은 입에서 시작한다.
- `StageLab`의 `ProtoGun`은 예전에 Player의 직접 자식이었다. Player의 비균등 스케일 때문에 의도한 `(18, -70)`이 실제 `(14, -26)`으로 찌그러져 무릎 부근에서 발사됐다. 이제 `GunRig` 아래에 붙여 월드 입 좌표를 유지한다.
- 경계에 걸친 상태에서는 단색 발사 스프라이트가 분할된 본체를 덮지 않는다. 총알은 정상 발사하되, 기존 흑·백 분할 시트가 계속 보인다. 발사 중 경계에 들어가는 경우도 즉시 분할 표시로 되돌린다.

추가 확인: `test_색경계_분할.gd` 49 / 49 통과, 프로젝트 표준 14개 회귀 검사 전부 통과.

## 추가 보정 2 — 발사 모션·좌우 얼굴색

- 분할 색을 지키려고 발사 모션을 생략했던 처리를 제거했다. 발사 전용 스프라이트도 검정/흰색 두 장을 겹치고, 평상시 몸과 같은 분할 셰이더·분할표를 적용한다. 따라서 경계에 걸친 상태에서도 발사 모션과 몸 분할이 동시에 보인다.
- 총알 시작점과 색의 기준을 모두 `입_월드좌표(조준 방향)`으로 통일했다. 조준이 왼쪽이면 왼쪽 얼굴 `(-18, -70)`, 오른쪽이면 오른쪽 얼굴 `(18, -70)`을 쓴다. ProtoGun도 매 프레임 이 좌표를 따라가므로 왼쪽 발사 때 뒤통수에서 나오지 않는다.
- 총알 색은 Gun 회전 중심이나 회전하는 Muzzle이 아니라 **발사 순간 조준 방향 쪽 얼굴색**을 직접 읽는다. 세로 경계·대각 경계에서도 실제 입이 흰 영역이면 흰 총알, 검정 영역이면 검정 총알이 된다.

추가 확인: 좌·우 얼굴 좌표·색 포함 `test_색경계_분할.gd` 53 / 53 통과. 카메라 연출·스테이지·빛창문 검사까지 재실행해 통과했다.
