## 만든 것

- `scenes/world_2_클로드/stage_2-6.tscn`
  - 검정 지대에서 흰 지대로 넘어가는 2-6 하수도 통로와 끝 도달 지점을 만들었다.
  - 모든 지형은 검정 또는 흰색 SS2D 시멘트다. 회색 지형은 쓰지 않았다.
  - 배관은 모두 `TEMPLATE_PIPE_OPEN_GRAY.tscn` SS2D 인스턴스이며 서로 겹치지 않게 배치했다.
- 검정/흰색 색 조건, 채우면 움직이지 않는 디딤대, 물 운반·배출 양동이를 순서대로 놓았다.

- `scenes/집/스마트월드_장애물/양동이.tscn`
- `scripts/스마트월드/양동이.gd`
  - 플레이어가 양옆에서 밀 수 있는 `CharacterBody2D` 양동이다.
  - 플레이어와 양동이의 색이 정확히 같을 때만, 빈 상태부터 바로 밀린다.
  - 물감지 영역은 양동이와 같은 색의 켜진 물줄기에만 반응해 물을 싣는다.
  - 총알 명중은 항상 차단하므로 플레이 중 페인트로 양동이 색이 바뀌지 않는다.
  - `채운뒤_밀수없음`으로 채운 뒤 고정 발판이 되는지, 계속 밀어 운반하는지를 양동이별로 설정할 수 있다.
  - 운반 양동이는 `배출_유체`를 지정하면 가까이서 E로 물을 지정 유체에 비운다.
  - 구덩이에 빠진 양동이는 자기 최초 배치 위치로 되돌아와 진행이 막히지 않는다.

- `scripts/player.gd`
  - 플레이어가 실제 수평 충돌한 양동이에만 밀기 요청을 전달한다.
  - 양동이 위에 착지·점프하는 충돌은 밀기로 처리하지 않아 디딤대 기능을 유지한다.

- `scripts/스마트월드/월드.gd`
  - E 우선순위는 레버 → 물을 실은 양동이 배출 → 기존 페인트 수동 회수다.
  - 빈 양동이 곁에서 E를 눌러도 기존 회수 조작은 소비하지 않는다.
