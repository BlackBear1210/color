# 몬스터 발사 대기와 반대색 페인트 덧칠

- 날짜: 2026-10-10
- 요청: 몬스터가 쏘지 않거나 오래 쉬는 현상을 줄이고, 몬스터가 칠한 지형을 플레이어 색으로 다시 덧칠한다.
- 마지막 음성 문장은 모호해 확인 질문을 남겼으며, 흰 몬스터도 자기 색 페인트를 발사하는 뜻으로 우선 적용했다. 흰 페인트를 피하는 이동 규칙은 변경하지 않았다.

## 변경

- `scripts/장애물/사격몬스터.gd`: 기본 발사 간격 2.2초 → 1초. 첫 발 준비 0.35초 + 최대 0.5초 위상. 실제 발사에 성공한 경우에만 발사 간격을 적용하고, 사거리/높이 범위 밖이나 코어 미준비는 0.1초마다 재확인한다. 사거리 700px, 높이 차 320px 제한은 유지한다.
- 조준 포물선을 계산한 총구 위치에서 실제 탄을 출발시켜 기존 30px 출발 오차를 없앴다.
- `scenes/world_2_클로드/stage_2-8.tscn`: 기존 사격 몬스터 2마리 외 흰 몬스터 2마리와 검정 순찰 몬스터 1마리에도 사격 스크립트를 연결했다.
- `tools/build_하수도_2-8.gd`: 같은 설정을 재생성 도면에도 반영했다. 빌더는 실행하지 않았다.
- `scripts/스마트월드/지형.gd`: 바탕색과 총알색이 같아도 반대색 부분 얼룩이 남아 있으면 부분칠 경로로 진입하도록 했다. 예: 흰 바탕 + 몬스터 검정 부분칠 → 플레이어 흰 페인트 덧칠 가능. 검정 바탕 + 흰 부분칠도 대칭 적용. 조준 미리보기도 동일 조건을 사용한다. 부분칠 유지/감쇠와 기존 탄약 정산은 유지한다.

## 확인

- git pull: 원격 최신 상태 확인.
- 기존 사용자 변경을 보존했으며 파일 삭제 없음.
- 로컬 GDScript 파서: 수정 스크립트 3개 문법 통과. HEAD에 있는 지형/빌더의 수정 전 문법도 통과. 사격 스크립트는 기존부터 미추적 파일이다.
- 2-8 몬스터 5마리의 사격 스크립트 연결과 수정 스크립트의 리터럴 리소스 경로 확인 통과.
- 수정 대상 git diff --check 통과.
- 브리핑이 지정한 docs/다음작업_프롬프트.md는 현재 체크아웃에 없어 13개 검사 명령과 지뢰밭 본문을 읽을 수 없었다.
- Godot 편집기/콘솔/headless 및 엔진 검사 13개: 사용자 실행 허용이 없어 미실행.
- 실제 엔진 캡처: 없음. 생성 이미지로 대체하지 않았다.
- 시각/동작 검증 대기: 같은 카메라에서 발사 주기, 검정→흰 덧칠과 흰→검정 덧칠, 리스폰 초기화, 새 흰 몬스터 사격의 난이도를 확인해야 한다.
