# 격자 발판 주철 아트 적용

- 사용자 요청에 따라 기존 주철 초안을 바탕으로 검정·흰색 게임용 RGBA 아틀라스 생성.
- 생성 원본은 assets/textures/obstacles/grate/cast_iron_v1/grate_atlas.png로 복사했다. 별도 이미지 후처리 없이 원본 투명도를 보존한다.
- 통과플랫폼.gd의 임시 도형 그림을 이미지 렌더링으로 교체. 끝 볼트는 비율을 유지하며 중앙 격자는 발판 폭에 맞춘다.
- 이 스크립트를 사용하는 2-9 및 기존 격자와 검정/흰색 프리셋에 적용된다. 배치, 크기, 원웨이, 고정색/명중 차단 등 동작은 변경하지 않았다. 기존 미지정 고정색은 검정이다.
- 파일의 실제 픽셀 경계를 읽어 아틀라스 좌표 설정. 외부 배경/구멍 alpha=0 확인. 정적 diff 공백 검사 통과.
- Godot 실행/엔진 import/실제 화면 검증은 사용자 안전 규칙에 따라 미실행. graphify update는 출력 없이 종료 코드 1로 실패했다.
