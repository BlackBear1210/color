# 맵 제작 프롬프트 갱신

사용자가 현재 맵은 직접 수정하겠다고 하여 씬·작성 도구는 변경하지 않았다. 이번 작업은 앞으로 사용할 제작 프롬프트와 상세 가이드 갱신이다.

## 반영 내용

- 새 맵 요청 시 시작 위치, 도착 위치, 주 진행 방향, 전체 외곽 형태, 규모·주요 장치를 먼저 질문하고 답을 설계에 반영한다. 이미 받은 답을 다시 묻지 않는다.
- 수평뿐 아니라 수직 상승·하강·대각선·순환 진행을 허용한다. 목적지는 위 중앙 등 사용자가 고르는 위치에 둔다.
- 평행사변형·사다리꼴·세로형·비정형 외곽과 많은 대각선 지형을 허용한다.
- 기존의 가로 폭 10,000px, 경로 25,000px, 아래 구석 시작, 마지막 층 도착을 모든 맵의 고정 규칙으로 사용하지 않도록 수정했다.
- 맨 위·맨 아래·양쪽 끝·모서리에서 외부 빈 배경이 드러나지 않도록 외곽 마감과 실제 카메라 시야를 함께 설계한다. 첨부 화면의 바닥 아래 삼각형 공백도 사례로 반영했다.
- 사용자의 직접 편집분 보존과 Godot 명시 요청 전 미실행 규칙을 프롬프트에 명시했다.

## PPT 확인

`scenes/world_2_클로드/맵 기본 구조 틀.pptx`의 5개 슬라이드 XML에서 텍스트·도형·배치 좌표를 읽었고 내장 썸네일도 확인했다. PowerPoint 앱에서 열거나 PPT를 수정하지 않았다.

1. 왼쪽 중간 시작, 위 중앙·오른쪽 위·오른쪽 아래 목적지 후보.
2. 왼쪽 위 시작, 아래 중앙·오른쪽 중간·오른쪽 아래 목적지 후보.
3. 아래 중앙 시작, 왼쪽 위·오른쪽 위 목적지 후보.
4. 2장과 같은 시작·목적지 위치 구성.
5. 전체 모양 예시: 대각 모서리를 자른 형태·가로형·세로형·사다리꼴.

목적지 표시는 후보 중 하나를 고르는 뜻으로 반영했다. 평행사변형·하강형·위 중앙 목적지 등의 자유도는 사용자 메시지에서 직접 받은 지시다.

## 확인 및 범위

수정 파일은 `프롬프트_아스트라_스테이지2_맵제작.md`, `가이드라인_스테이지2_분기형맵_2026-09-12.md`, 이 기록이다. 문서의 고정 배치·폭 규칙과 새 질문 절차가 충돌하지 않는지 정적으로 확인했다.

현재 씬은 앞선 생성 시점 이후 이미 사용자가 편집한 상태다. `stage_2-9.tscn`과 PPT는 수정 전후 SHA256으로 보존 여부를 확인한다. Godot 실행·엔진 검사·맵 재생성은 미실행. 직전 작업의 git pull은 원격 응답 없이 대기하여 중단되었으며 이번 문서 작업에서 동기화 성공을 주장하지 않는다.
