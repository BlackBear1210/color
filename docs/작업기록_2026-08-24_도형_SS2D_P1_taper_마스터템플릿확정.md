## 1. 원인 (지난 세션에서 규명한 것을 그대로 씀)

- **볼록** = 4방향 띠가 꼭짓점에서 그냥 끊겨 바깥쪽 45×45 월드px 이 빈다.
  코너를 아예 빼면 16.24, 얹으면 13.25 — 코너는 오히려 줄여 주는 쪽이다.
- **오목** = 띠끼리는 이미 잘 이어진다(4.09). 코너 타일이 덮으면서 8.96 이 된다.

즉 필요한 것은 **띠가 코너 자리 직전에서 알파로 사라지는 것** = taper.

## 2. 왜 애드온을 고쳐야 했나

taper 자체는 SS2D 에 이미 있는 기능인데, 두 군데가 고해상도 타일셋과 안 맞았다.

| 문제 | 코드 | 증상 |
|---|---|---|
| 길이가 텍스처 크기에 성분곱으로 묶임 | `offset = delta_normal * taper_size` | 세로 엣지는 길이가 텍스처 **높이**로 정해져서, 길이 45 를 얻으려면 단면 해상도가 45 로 떨어진다 (엣지 본체는 2.84 텍셀/월드) |
| `texture_scale` 미반영 | 같은 줄 | 텍스처 1px = 월드 1px 로 굳음 |
| fit 실패 시 쿼드 전체 교체 | `quad.texture = taper_texture` | 곡선의 짧은 끝쿼드가 통째로 늘어난 **검은 슬래브**가 됨 |

수정 (P1):

```gdscript
+ var taper_length: float = taper_size.x * quad.texture_scale
+ var fit: bool = taper_length <= quad.get_length_average()
+ var offset: Vector2 = delta_normal * taper_length
  ...
- else: quad.is_tapered = true; quad.texture = taper_texture   # 분기 삭제 = 건너뛴다
```

이제 128×256 taper 를 배율 0.35 로 쓰면
길이 **44.8 월드px**(코너 반너비와 일치), 단면 256/90 = **2.84 텍셀/월드**,
가로 128/44.8 = **2.86 텍셀/월드** — **엣지 본체와 해상도가 완전히 같다.**

### 하위호환 증명

```
수정 전 SHA256 7887DB62338A7F25922084C8F97E0F41A76CEF9A5937FD02058062BD78031F61
수정 후 SHA256 7887DB62338A7F25922084C8F97E0F41A76CEF9A5937FD02058062BD78031F61
```
머티리얼 16개 × 도형 8종 = 128 조합, 덤프 2654줄, 파일 diff 도 완전 동일.

이유: 저장소의 머티리얼은 전부 `use_taper_texture = false` 이고
taper 텍스처를 가진 것이 **하나도 없어서** 고친 두 줄에 도달하지 않는다.
(`grep -rl "textures_taper" --include=*.tres .` → 0건)

## 3. taper 텍스처 — 세 판 만들어 고름

| 방식 | 볼록 | 오목 | 판정 |
|---|---|---|---|
| `fade` (행 평균 단면 + 알파 페이드) | 3.53 | 4.38 | 수치는 통과인데 **뭉갠다** |
| `slice` (엣지 실제 그림 그대로) | 8.10 | 3.06 | 디테일은 살지만 볼록이 안 잡힘 |
| **`slicefade`** (slice + 바깥만 알파 페이드) | **최선** | **최선** | ✅ 채택 |

길이·페이드 스윕(전부 배율 반영 후):

| 길이 | 페이드 | 볼록B | 오목B |
|---|---|---|---|
| 96 | 0.55 | 3.92 | 3.23 |
| 112 | 0.55 | 4.19 | 3.15 |
| **128** | **0.35** | **3.63** | **3.03** |
| 128 | 0.55 | 4.43 | 3.04 |
| 128 | 0.70 | 4.76 | 3.03 |
| 144 | 0.30 | 5.69 | 2.93 |
| 160 | 0.75 | 5.06 | 4.73 |

**128 / 0.35 채택.** 128 × 0.35 = 44.8 월드px = 코너 반너비와 정확히 일치한다.

## 8. 이번에 새로 밟은 지뢰

1. **베이크된 테스트 씬은 머티리얼을 바꿔도 안 바뀐다.** `.tscn` 안에 메시가
   sub_resource(1644개)로 저장돼 있다. `build_*.gd` 를 다시 돌려야 반영된다.
   → 처음에 "taper 가 안 먹는다" 로 오판할 뻔했다.
2. **`ResourceSaver.save()` 로 .tres 를 다시 쓰면 `uid://` 가 사라진다.**
   참조하는 곳이 없어 무해했지만 1행 복구해 뒀다.
3. **끝쿼드 길이는 taper 적용 후에 재면 안 된다** (taper 가 쿼드를 줄이므로
   전부 45 로 보인다). taper 없는 쪽에서 재야 한다. 실측 최소 **49.0 월드px**.
