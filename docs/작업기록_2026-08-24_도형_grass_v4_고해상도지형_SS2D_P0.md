## 1. 왜 애드온을 고쳐야 했나

SS2D 는 두 군데서 텍스처 픽셀을 월드 크기에 직결한다.

```gdscript
shape.gd:1567   width_scale * c_scale * tex_size.y      # 띠 두께 = 텍스처 픽셀 높이
edge.gd :216    roundf(total_length / tex.get_size().x) # 반복 주기 = 텍스처 픽셀 폭
```

그리고 `shape.gd:1481` 의 `var c_scale := 1.0` 은 **지역변수 리터럴**이라
어떤 머티리얼 속성에서도 값을 받지 않았다. 즉 조절 손잡이가 아예 없었다.
→ 해상도를 올리면 지형이 물리적으로 커져 버린다.

추가로 `roundf` 에 하한이 없어서, **엣지가 주기의 절반보다 짧으면 reps 가 0** 이 되고
`change_in_length` 가 0 → UV 가 한 줄로 붕괴한다(텍스처 세로 한 컬럼이 엣지 전체에 늘어남).
1024px 텍스처에서는 짧은 엣지마다 터진다.

### P0 수정 (4파일 +58/−4)

| 파일 | 변경 |
|---|---|
| `materials/edge_material.gd` | `texture_scale: float = 1.0` export + setter(`emit_changed()`) |
| `shapes/quad.gd` | `texture_scale` 필드 / `duplicate()` 복사 / `matches_quad()` 비교 |
| `shapes/shape.gd` | `c_scale = edge_material.texture_scale`, 쿼드·코너쿼드에 배율 기입 |
| `shapes/edge.gd` | `tex_width = 폭 × texture_scale` 로 통일, `maxf(1.0, roundf(...))` |

**정적 함수 시그니처는 하나도 안 바꿨다** (외부 호출자 보호).

### 하위호환 — 바이트 단위로 증명함

기존 5개 머티리얼 × 9개 도형의 정점·UV 870줄을 수정 전/후로 덤프해서 비교:

## 2. 코너 — 참고자료의 방식은 SS2D 에서 안 된다

`shape.gd  edge_should_generate_corner()`:

```gdscript
var corner_range := 10.0
var corner_angle := 90.0
if absf(deg) >= corner_angle - corner_range and absf(deg) <= corner_angle + corner_range:
```

- 코너는 **꺾임 80°~100°** 에서만 생성된다. 하드코딩이고 노출 속성이 아니다
  → **45°/135° 코너 타일은 SS2D 가 애초에 안 만든다**
- **T코너 / X교차는 개념 자체가 없다** (닫힌 외곽선 하나를 따라가는 시스템)

### 실측한 코너 생성 조건

| 구성 | 코너 쿼드 |
|---|---|
| 전방향(0~360) 머티리얼 1개 | 사각 OUTER 4 / L자 OUTER 5 + INNER 1 ✅ |
| 4방향 폭 90 (원래 v4) | 0 / 0 ❌ |
| 4방향 폭 200 (겹침) | OUTER 8 — 중복 렌더, 메시 20개 ⚠ |

원인: 코너는 **한 엣지 머티리얼이 담당하는 점 나열 안에서** 꺾일 때만 생긴다.
4방향으로 나누면 90° 모서리가 항상 서로 다른 엣지의 경계라 절대 안 생긴다.

### 해법 — 하이브리드 (코드 수정 0줄)

5번째 "코너 전용" 메타 머티리얼을 얹는다:

```
normal_range 0~360      ← 도형 전체를 엣지 1개로 잡음
textures = [투명_256]    ← 안 보이는 캐리어 (null 이면 코너도 안 생기므로 필요)
use_corner_texture = true
z_index = 1             ← 4방향 엣지 위에 그림
```

투명 캐리어가 **256×256** 인 이유: 코너 쿼드 크기는 엣지 텍스처의 **높이**가 정한다
(`_edge_generate_corner` 가 `tex_size.y` 를 넘김). 256 × 0.35 = 월드 90px = TOP 띠 두께와 정확히 일치.
→ **코너와 엣지의 크기 관계는 배율과 무관하게 자동으로 맞는다.**

### 코너 UV 방향 (진단 텍스처로 픽셀 측정, 추측 아님)

- **OUTER·INNER 모두 UV(1,0) = 지형 바깥, UV(0,1) = 지형 안쪽**
- 회전 0 기준 = **우상(top-right) 코너**
- 텍스처 **왼쪽 열 = TOP 엣지 단면**, **아래 행 = SIDE 엣지 단면(역방향)**

### 코너 텍스처는 그리지 않고 합성했다

이음매 단면이 맞아야 하는데 손으로 그리면 절대 안 맞는다.
엣지 텍스처를 극좌표로 감아서 만든다 (`apply_final.py` `build_corners`):

- OUTER: 중심 UV(0,1), `v_eq = 1 − r/S`
- INNER: 중심 UV(1,0), `v_eq = r/S`
- u 는 **호 길이**에 비례 (각도 비례로 하면 방사형으로 뭉갠다 — 한 번 겪음)
- 각도 블렌드에 smoothstep → 이음매에서 반대쪽 텍스처가 안 섞임

**실측 이음매 오차: 왼쪽 열 1.00/255, 아래 행 0.99/255.**

## 3. texture_scale = 0.35 을 고른 근거

7개 배율(0.15~0.45) × 8개 도형을 실제 게임 프레이밍(줌 0.82)으로 촬영해 비교.

| scale | 띠 | 잔디술 | 주기 | 판정 |
|---|---|---|---|---|
| 0.15 / 0.20 | 38 / 51 | 14 / 19 | 154 / 205 | ❌ 잔디가 노이즈로 뭉개짐 = 일러스트 느낌 상실 |
| 0.25 | 64 | 23 | 256 | △ 잎사귀가 겨우 읽힘 |
| 0.30 | 77 | 28 | 307 | ○ 후보 |
| **0.35** | **90** | **33** | **358** | ✅ 잎사귀·하이라이트 가장 잘 읽힘 |
| 0.40 / 0.45 | 102 / 115 | 38 / 42 | 410 / 461 | △ 솜털 테두리로 기울기 시작 |

보조 근거:
- v4 의 잔디 술은 띠의 **37%** (v3 는 58%) → 같은 띠 두께라도 v4 가 비율상 얇다.
  0.35 의 술 33px 은 v3 의 52px 보다 **얇다**. "너무 두껍다" 는 우려는 수치로 성립하지 않는다.
- 0.35 는 v3 의 월드 두께(90px)와 **정확히 같다** → 기존 레벨 지오메트리가 1:1로 옮겨온다.
- mipmap 이 꺼져 있어(프로젝트 정책) 축소가 클수록 지글거림 위험이 크다 → 큰 배율이 유리.

## 7. 지뢰밭 (전부 실제로 한 번씩 터진 것)

1. **`force_update()` 는 노드가 트리에 없으면 아무것도 안 한다.**
   빌더에서 `root.add_child(_root)` 를 빼먹으면 메시도 코너도 0개로 나온다.
   씬 자체는 로드 시 정상이라 **집계 수치만 조용히 0** 이 되어 오판하기 쉽다.
2. `_도형()` 안에서 `s.force_update()` 를 안 부르면 같은 증상 (dirty 갱신이 deferred).
3. **`shape_closed.gd` 는 `@deprecated`.** `SS2D_Shape` 를 쓰고,
   점은 `get_point_array().add_points()` → `close_shape()` 로 넣는다.
   `set_shape_closed()` 같은 API 는 **없다**(내가 지어냈다가 터졌다).
4. 코너 합성에서 **u 를 각도에 비례시키면 방사형으로 뭉갠다.** 반드시 호 길이 비례.
5. 자기상관으로 반복 검사할 때 **짧은 lag 를 빼지 않으면** 전부 "반복 있음"으로 오판한다.
6. 필 UV 와 엣지 UV 는 **완전히 독립**이다. 이을 코드가 없다.
   유일한 수단은 **톤을 맞추고 엣지 안쪽에 알파 페이드를 주는 것**.
7. PIL 블러/리사이즈는 **순환하지 않는다.** 타일 텍스처를 만들 땐 3×3 으로 깔고 가운데를 잘라야 한다.
8. `test_빛창문.gd:322` 의 `SCRIPT ERROR: Nonexistent 'float' constructor` 는
   **기존 문제다**(baseline 무수정에서도 동일). 내 변경과 무관.
