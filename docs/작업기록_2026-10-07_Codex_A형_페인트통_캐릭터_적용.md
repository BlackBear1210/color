## 변경

- `assets/characters/paint_head_a/`: 승인된 원본을 640px 프레임, 4×4 시트, 발 기준 Y=567로 정렬. 반투명 배경 후광 및 따로 그려진 발사 탄을 연결 덩어리 기준으로 제거. 실제 탄은 기존 총알 노드가 생성한다. 원본 파일명·SHA-256·프레임 정렬·탱크·총구 좌표는 `manifest.json`에 기록했다.
- 발사 원본은 `black_shoot_projectile.png`, `white_shoot_projectile.png`를 사용했다. 이전 분사 버전은 연결하지 않았다.
- `player_frames.tres`: 흑백 각각 idle/walk/jump/fall/land/shoot/push/death. idle은 걷기 첫 포즈, jump/fall/land는 점프 시트의 해당 구간. 발사는 총을 든 4번 원본 포즈부터 회복까지 12프레임/45fps로 재생한다.
- `scenes/player/Player.tscn`: 시트와 모션 컴포넌트 참조 교체. `scripts/player_anim.gd`는 상속만 하여 팀 소유 파일을 수정하지 않았다.
- `scripts/paint_head_anim.gd`: 실제 총의 `fired` 신호를 받아 발사 재생. 탄약 부족·쿨다운 실패에는 재생하지 않는다. 지상 이동 입력과 실제 밀기 대상의 수평 접촉이 있을 때 push 모션을 선택한다.
- `shaders/paint_head.gdshader`: 기존 세계 좌표 색분할과 같은 uniforms/분기식을 보존하고, 머리 내부를 `남은_탄약 / 최대_탄약`으로 표시. 발사 때 감소하고 회수·환급·리스폰 리셋을 즉시 따라간다. 탄약을 쓰지 않는 테스트 씬은 가득 찬 통으로 표시한다. 별도 대형 마스크 텍스처 대신 프레임별 내부 좌표를 사용한다. 셰이더는 ASCII만 사용했다.
- 스마트월드 총·프로토 총·구 테스트 총: 새 그림의 총구를 발사와 조준선의 원점으로 사용한다. 얼굴 좌표와 얼굴색 판정은 그대로 둔다. 실제 탄 속도·중력·탄약 소모·색 규칙·충돌체·점프 수치는 수정하지 않았다.
- 스마트월드: 즉시 리스폰 직전에 사망 위치에 0.8초짜리 흑백 분할 잔상을 남긴다. 리스폰을 지연하지 않는다. 프로토 씬은 기존 사망 중 물리 비활성 흐름에서 death를 재생한다.
- 기존 프로토 발사 오버레이: 새 본체가 발사를 지원하면 제거하여 구 캐릭터 그림이 다시 나타나거나 본체를 숨기지 않게 했다.
