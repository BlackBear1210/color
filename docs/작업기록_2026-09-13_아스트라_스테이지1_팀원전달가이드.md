# 스테이지 1 팀원 전달 가이드 작성

- 사용자 요청: 공통 제작 방식을 다른 팀원에게 전달하되 담당 범위는 스테이지 1 플랫폼과 배경으로 제한.
- 생성 문서: `docs/스테이지1_플랫폼과배경_공통제작가이드_팀원전달.md`.
- 얇은 고정 옆면, 한 연속 플랫폼당 SS2D 하나, 부위별 반복 재질, 흑백 판정 가독성, 레이어 배경과 시차, 근접 반사의 공통 방향을 정리했다.
- 스테이지 2·장애물은 사용자 담당으로 명시했다. 하수도 소재를 스테이지 1에 그대로 옮기는 지시가 아니며, 현행 스테이지 1 장소와 기획을 보존하도록 했다.
- 현재 시험 자산의 미검증 사항과 공용 코드 협업 범위를 명시했다. 팀원에게 바로 전달할 요약 요청문을 포함했다.
- 문서만 추가. 씬·코드·자산 변경 및 Godot 실행 없음. 참조 경로와 diff 공백 정적 확인을 수행했다.
