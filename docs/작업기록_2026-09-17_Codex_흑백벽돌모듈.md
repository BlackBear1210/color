# 흑백 벽돌 모듈 제작

- 사용자 승인: 내부 반대색 무늬는 흑→백/백→흑 모두, 실제 경계는 검흰검/흰검흰 모두. 바닥 잔해 보류.
- 신규 내부 장식 스크립트와 자연발판 셰이더의 초기 표면 합성을 추가했다. 기존 페인트 시드보다 먼저 합성한다. 별도 콜리전은 만들지 않는다.
- 내부 장식 2종, 실제 SS2D 경계 가로/세로 각 2종, 에디터 비교 씬을 생성했다. 기존 스테이지는 이번 작업에서 변경하지 않았다.
- 실제 경계는 같은 선을 역순 공유하며 각 영역에 자체 색/명중/회수/충돌을 유지한다. 줄눈 좌표는 기존 키트의 측정값을 재사용했다.
- 아스트라 및 클로드 맵 제작 프롬프트에 사용 조건과 검수 항목을 추가했다. 상세는 `하수도_흑백벽돌_모듈_사용법.md`.
- 검사: 생성 시 18,644점 영역 분할 통과. 저장된 4종 경계 씬은 총 37,288점 검사. 내부 여유 24px, 리소스 참조, 셰이더 합성 순서 정적 검사 포함.
- 미실행: Godot 파싱/화면/색칠/회수/사망/성능. AGENTS.md의 명시적 엔진 실행 허가 전 실행 금지 규칙을 준수했다.
- 도구 제한: git pull은 FETCH_HEAD 쓰기 권한 오류로 실행 실패. graphify update는 기존 uv trampoline 경로 오류로 실패. 원격 동기화/그래프 갱신 완료라고 보고하지 않는다.
- 주의: 내부 무늬의 에디터 재질 배열과 런타임 export 배열은 생성기가 함께 저장한다. 수동 수정은 둘 다 갱신해야 한다. 모듈 생성기 재실행은 신규 모듈 파일의 수동 편집을 덮는다.
