# 공중 선반 — 윗면 중앙 착지 표현

## 목적과 변경
- 사용자 승인 비교 이미지처럼 발이 뒤쪽 윤곽이 아닌 얕은 윗면 중앙에 놓이게 한다.
- `shaders/sewer_ledge_v03.gdshader`: 충돌 높이 기준 윗면을 -4~+4px로 표시. 원본 PNG의 윗면 290~350행을 사용하고, 발끝 높이에는 320행을 배치한다.
- 버텍스 단계에서 윗쪽 렌더링 영역만 최대 4px 확장한다. SS2D 점·충돌 폴리곤·플레이어 위치는 이동하지 않는다. 위쪽 12px 범위에서 확장량을 부드럽게 줄인다.
- 앞면부터 24px 깊이까지 기존 UV로 복귀하므로 하단 그림 위치를 유지한다. 가로 UV의 끝돌 보존과 중간 반복 방식도 유지한다.
- 확장한 뒤쪽 윗면은 충돌 윗면의 물감 시드 거리를 사용한다. 새로운 충돌·사망 로직은 만들지 않는다.
- `scripts/스마트월드/하수도_자연발판.gd`: 석조선반 런타임 재질에도 `ledge_top_half_depth = 4.0`을 지정한다.
- `scenes/world_2_클로드/stage_2-1.tscn`: 선반 재질 8개에 같은 값을 저장했다. 검정·흰색 모두 공통 셰이더를 사용한다. `scenes/world_2/stage_2-1.tscn`과는 다른 씬이다.
- 공통 선반 셰이더를 사용하는 시험 프리팹에도 적용된다. 땅 지형의 다른 셰이더에는 적용하지 않았다.

## 확인 결과와 한계
- 정적 비교: 스테이지 씬은 시각 설정 8줄 외 HEAD와 동일. 충돌·노드 위치 변경 없음.
- UV 수치 확인: -4/0/+4px가 290/320/350행에 대응하고, 앞면으로 넘어갈 때 좌표 역전 없음.
- 셰이더 ASCII 확인 및 `git diff --check` 통과.
- Godot 실행·셰이더 컴파일·실제 착지·색칠·사망 회귀검사·화면 캡처는 미실행. AGENTS.md의 명시적 엔진 실행 요청 전 실행 금지 규칙에 따라 정적 확인만 했다. 외관 개선 및 플레이 검증 완료로 간주하지 않는다.
- 다음 실행 검증: 검정/흰색 선반 중앙과 양끝 착지, 점프 중 발 가림, 물감 경계, 반대색 사망, 화면 가장자리 렌더링 잘림을 확인한다. 폭 128/192/224/336px 및 SS2D 점 편집 후 동일한 윗면 깊이를 확인한다. Scale은 1 유지.
- Graphify 갱신 시도는 `uv trampoline failed to canonicalize script path`로 실패했다. 그래프 JSON도 없어 이번 변경은 직접 파일로 확인했다.
- Git pull로 최신 원격 변경을 받은 뒤 수정했다. 이번 변경은 커밋/푸시하지 않았다.
