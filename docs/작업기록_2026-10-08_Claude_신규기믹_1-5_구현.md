## 5. ⚠ 작업 중 찾은 것(버그·함정)

1. **`Player > ActionFX` 가 2026-08-25(41da16d) 부터 `visible = false`** — 그 아래 자식은 top_level 이어도 안 보인다 → **옛 점프·착지 먼지는 지금 화면에 안 나오고 있었다.** 다른 작업(몸 치수 정리 커밋)에서 생긴 값이라 건드리지 않고, 새 이펙트·점프대 물감 가시만 현재 씬에 붙였다. 먼지도 다시 보이게 하려면 Player.tscn 의 그 한 줄을 지우면 된다(도형님 결정).
2. 안전지점 자동 저장이 **부서지는 발판 위**에도 저장됐다 → 자동 복구가 없어진 v3 에서는 부활할 때마다 같은 발판에 서서 또 떨어진다 → 제외(`월드._붕괴발판_위인가`).
3. 부활 직후 발판이 **곧바로 다시 무너졌다** — 사망 모션 동안 몸의 물리가 멈춰 `get_slide_collision`·`is_on_floor` 가 죽기 전 값 그대로 → "아직 밟혀 있다" 로 읽음 → 밟힘 판정에 몸의 물리 진행 + 발 위치(윗면 ±12) 확인 추가.
4. 경로재생이 도약대 판정 높이에 민감하다(위 §4 ①) — 도약대 콜리전 윗면을 바꾸면 검사기 `기믹.py 도약대.칸들()` 도 같이 봐야 한다.
5. 하수도 **2-4 부서지는발판_1~4 의 판정 폴리곤이 340×288 인데 176~192 간격** → 이웃과 150px 씩 겹친다(씬 데이터 그대로 · 고치지 않음). 한 발판 가운데를 밟으면 옆 발판이 무너진다. 의도인지 확인 필요.
6. 열쇠가 날아갈 때 TextureRect 기본 `EXPAND_KEEP_SIZE` 라 그림(2배 저장) 크기로 날아갔다 → `EXPAND_IGNORE_SIZE`.
7. 잠긴 문 막이를 처음 문 가운데에 두니 몸이 문 그림 뒤로 반쯤 들어가 가려졌다 → 방 쪽 면으로.
8. `--headless` 에서는 화면 캡처가 안 된다(`시험_연결전환` 은 창 모드 전용).
