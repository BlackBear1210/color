## 3. 2-2 「구멍 난 바닥」 v2 — 갈라지는 수직 갱도 · 통과 플랫폼의 가치

프레임 4,608 × 4,352 · 아래 통로(2560, L0 3584) 시작 → 오른쪽 위(3840, L3 1664) 출구(`stage_2-3`). 층 4 · 간격 640.

```
L3  [탑 천장]   [갱도 위]  ───── L3 복도: 유령(흰 웅덩이가 지운다) vs 격자(안 지워진다) → 출구

    (흰)   │   ↑검정 물(왼끝)  ┃측
L1  탑 l5~9│  허브 호퍼 L1 ←p4  ┃덩   F1 발코니(레버 ⓒ · CP ⓐ · 갱도가 보인다 ⓑ) ← 격자 r2·r3 ← 턱 r1
    l1~4   │   ↑흰 물(왼끝)     ┃어
L0  슬롯   └─ 홀 ─ S01 흰 물(레버) ┃리 ─ 통로 ─ 시작 ─ 오른쪽 방
```

- 갱도 = 층마다 격자 4 장(128 씩 지그재그) + **허브 호퍼**(갱도 전체 폭 · 색 규칙 밖 = 안전한 색 전환 자리).
  S01 흰 물(레버로 끔) · S12 흰 물(항상) · S23 검정 물(항상). 물은 층마다 따로: 위 허브 밑 배관에서 나와 아래 허브에 떨어진다.
- 시작이 갱도 오른쪽 통로인 이유: S01 흰 물이 홀을 가른다 → 먼저 오른쪽 F1 로 가서 밸브를 잠가야 갱도도 탑도 열린다("막다른 길이 열쇠").
- 경로: **정답** F1 → S01(검정) → 허브에서 흰색 · 격자 4 장 칠함 → S12 → 허브에서 검정 → S23 → L3(4 발).

  탑 L1 에서 갱도 S12 로 갈아탈 수도 있다(중간 선택).
- L3 복도 끝: 유령 발판을 검정으로 칠하면 흰 웅덩이가 **바로 지운다**(주행검사 확인: 현재색 −1 로 복귀) → 옆 격자(128)로 256 점프.

## 5. 이번에 밟은 지뢰 (전부 공통 라이브러리/검사기에 박았다)

1. **`instantiate()` 로 만든 인스턴스의 값이 저장 안 된다.** `PackedScene.pack()` 이 스크립트 기본값과 같은 값을 건너뛴다 — `유체.tscn` 기본이 회색이고 스크립트 기본이 흰색이라, 흰 물이 씬에서 **회색으로 살아났다**(2-2 주행검사가 안 죽어서 이상해서 잡음). 격자 `크기` 도 200 으로 되돌아갔다. → 전부 `instantiate(PackedScene.GEN_EDIT_STATE_INSTANCE)`.
2. **지그재그 공중 발판의 두 칸 위 발판이 도약 자리 위에 걸치면 머리가 박힌다**(96 + 160 > 256 − 두께). → 공중 발판·격자·호퍼 밟는 면은 **일방통행**. 대신 검사기의 `_앞에_바닥` 레이가 일방통행을 못 봐 제멋대로 뛰었다 → `test_move` 로 바꿈.
3. **허브로 뛰어오르는 점프의 정점(도약 +195)에서 머리가 다음 층 첫 격자 높이(128 위)에 닿는다.** 흰 몸이 검정 격자에 닿아 죽었다 → 첫 격자를 정점 반대편 열에(층마다 R·L 순서가 다른 이유).
4. **허브 물 기둥을 격자 사이 틈에 두면** 아래층에서 허브로 오르는 몸의 머리가 위층 물에 닿는다 → 허브 물은 호퍼 **왼끝**에. S01(레버 물)만 틈에 두어 지그재그와 홀을 막는다.
5. **호퍼 밟는 면의 실제 윗변 = 원점 − 높이**(−높이+6 이 아니다). 6px 높아진 만큼 128 위 격자 밑면과 머리 사이가 0 이 되어 죽었다. 격자 두께도 26 → 20.
6. **꽉 찬 점프(320)만 하는 검사기**는 128 위 발판을 "내려오는 쪽 포물선(+250)" 에서만 밟는다. 틈 뒤 착지 바닥이 128 이면 넘어가 버린다 → 256 이상. 유령 발판과 건너편 바닥 사이 32px 틈은 몸(44)이 끼어 걸어서 못 넘는다 → 딱 붙인다.
