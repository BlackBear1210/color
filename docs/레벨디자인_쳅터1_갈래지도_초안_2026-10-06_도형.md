## 1. 한 장 요약

- 지금 쳅터1 = **한 줄 14 스테이지**(01 시작방 → … → 14 굴뚝). 복도 7 개가 전부 192×38 칸으로 같은 크기다.
- 바꾸는 것 = **복도가 갈림길(허브)** 이 된다. 복도 오른쪽 벽에 **위 문 / 아래 문** 두 개 → 서로 다른 방 두 개 →
  두 방의 출구가 **다음 복도의 위 문 / 아래 문**으로 다시 모인다(마름모 모양 한 마디).
- 마디마다 두 길의 성격을 다르게 한다: **길고 쉬운 길**(간단한 점프만, 탐색·풍경) ↔ **짧고 어려운 길**(정밀 점프·색 전환).
- 되돌아가기는 그대로 허용 → 막히면 복도로 돌아와 다른 문을 고를 수 있다(쳅터2 지도의 "한쪽이 막히면 다른 길" 과 같은 감각).
- 한 번 통과 = 14 스테이지(갈림길마다 하나씩), 전체 = 20 스테이지(새 방 6 개).

```

                           └─아래─ [15 아이방] ····· 짧고 어려움 ─┴→ (04 복도B)
 (04 복도B) ─┬─위─ [05 침실] ············ 보통(도약대 입문) ─┐

1층(동쪽 → 서쪽)

             └─아래─ [18 음악실] ·········· 짧고 어려움(빛 리듬) ─┴→ (12 복도F)

 (13 복도G) ──── [14 화덕→굴뚝] ──→ (지붕·마당 = 쳅터1 끝 → 쳅터2 지도 열림)
```

### 공통 규칙(변하지 않는 것 — `docs/쳅터1_스테이지_제작규격.md`)
- 축척 1칸 = 32px · 점프 5칸 높이 / 10칸 거리 · 몸 44×97 · 판 아래 길 ≥ 4칸.
- 검정 ≤ 70% · 흰 ≤ 30% · **흰 판 위 8칸 · 좌우 2칸 비움** · 큰 지형 두께 4~6 · 테두리 위5·아래7·좌우5.
- 편한 손(점프 95% · 색 틈 15f) 통과 필수 · 못 닿는 바닥 금지 · 연결 높이 ≤ 96px.
- 큰 구조는 칠하기 금지(조준선에 X) · 묻힌 흰 판 아래는 하수도식 맞물림 무늬(10-06).

### 일부러 다르게 하는 것(방마다 하나 이상)
1. **모양**: 접힌 U자(01) · 탑(17·14) · 넓은 홀(11) · 긴 복도형 방(19) · 작은 상자형(15·16).
2. **발판 크기**: 쉬운 길 = 4~8칸 넓은 판 / 어려운 길 = 1~2칸 작은 판·유령판.
3. **색 전환 수**: 쉬운 길 0~1 회 / 어려운 길 2~4 회.
4. **기믹 하나씩 주인공**: 서재=선반 계단 · 침실=도약대 · 욕실=유령판 · 하인계단=벽 점프 · 음악실=주기빛 · 부엌=흰빛+그을음.
5. **가구 = 지형의 실루엣 근거**: 책장·옷장·식탁·화덕 모양이 발판 배치를 정한다(배경 가구와 발판이 같은 줄에 선다).
