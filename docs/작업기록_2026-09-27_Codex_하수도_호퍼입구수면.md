# 하수도 호퍼 입구 수면과 혼합색 연결

요청: 승인된 물/호퍼 시안을 world_2_클로드 스테이지에 반영하고 입구 착수 수면을 실제 유입색으로 표시한다.

## 반영 사항

- 기존 `유체_흰물v2.gd`와 `흰물_디자인.gd`의 물줄기 v3는 유지했다. 이미 모든 대상 스테이지에서 사용 중이며 이번 작업으로 해당 파일/셰이더/물 아틀라스를 수정하지 않았다.
- 주철 호퍼가 대상 스테이지에서 실행될 때만 `호퍼_입구수면.gd`를 생성한다. 원화 안쪽에 얕은 수면, 실제 유입 x좌표에 작은 착수 왕관/물방울, 파문을 그린다. 착수는 입구 깊이의 앞쪽 78%에 배치하고 앞 금속 띠를 마지막에 다시 그린다.
- 검정만 → 검정, 흰색만 → 흰색, 흑백 동시 → 회색. 회색만 → 회색, 검정+회색 → 검정, 흰색+회색 → 흰색은 기존 순색 흡수 규칙을 유지한다.
- 기존 순차 `유체.섞기()` 누적으로는 검+흰+검이 검정으로 돌아갈 수 있어, 호퍼 입구 전체의 흑/백 존재를 먼저 확인하도록 수정했다. 입구와 출구는 같은 결과를 사용한다. 일반 유체 혼합 규칙 자체는 바꾸지 않았다.
- 출구 없는 대상 호퍼도 입구 수면을 표시한다. 유입 중단은 기존 0.30초 유예를 함께 사용하며 이후 수면/물보라가 사라진다. 무유입 상태에 가짜 물은 표시하지 않는다.
- 직하 호퍼 그림은 아틀라스 y700(실제 포트)에서 잘라 아래쪽 타원 잔여를 제거한다. 기존 평면 출구 아틀라스 파일은 덮어쓰지 않았다.
- 대상 직하 출구 물은 런타임에 실제 포트에 맞추고 기존 바닥 끝을 보존하도록 길이를 보정한다. 예전 2-8 HB의 56px 공중 틈도 이 경로로 보정한다. 폭은 기존 `폭 × 0.2`를 유지한다. 통로/충돌 지형은 바꾸지 않는다.
- 연출 노드에는 owner를 주지 않는다. 원본 씬 재생성, 지형 재배치, 카메라 변경은 하지 않았다.

## 검증과 한계

- 변경 GDScript 5개(호퍼, 주철, 기존배치, 새 수면, 새 검사): gdtoolkit 4.5 정적 파싱 통과. 이것은 Godot 4.6 타입 검사나 실행 검증을 대체하지 않는다.
- 변경 추적 파일 `git diff --check` 통과. 리소스 연결과 대상 11개 스테이지의 스크립트 적용을 텍스트로 확인했다.
- Godot/헤드리스/빌더/주행 검사: 사용자 안전 규약으로 모두 **미실행**. 애니메이션, 실제 겹침, 앞 테두리 가림, 작은 높이 호퍼의 표현은 엔진에서 확인 필요. AI 시안을 실제 엔진 스크린샷으로 간주하지 않는다.
- `tools/test_호퍼_입구수면.gd` 추가: 혼합 순서/중복, 흰 물 거품 명도, 두 호퍼 형식, 출구 미연결, 흑백 전환, 끊김 유예, 포트 정렬 및 바닥 끝 보존을 검사한다. **작성만 했고 실행하지 않았다.**
- 작업 시작 시 이미 병합 미해결 4개가 있었고 git pull --ff-only가 거절됨. 파일 내용에 충돌 마커는 발견되지 않았으나 Git 인덱스 미해결 상태는 그대로 보존했다: stage_2-9.tscn, README_맵제작_인계.md, 프롬프트_클로드_하수도_SS2D_지형배경_적용과검증.md, 하수도_자연발판.gd.
- 시작부터 있던 임시 PPT 잠금 파일 삭제 표시와 다른 미커밋 변경은 건드리지 않았다. 커밋하지 않았다.

## 엔진 실행이 허용된 후 인계 검사

```powershell
godot --headless --path . -s res://tools/test_호퍼_입구수면.gd
godot --headless --path . -s res://tools/test_호퍼_물줄기.gd
godot --headless --path . -s res://tools/진단_호퍼출구_물막.gd -- res://scenes/world_2_클로드/stage_2-8.tscn
godot --headless --path . -s res://tools/진단_호퍼출구_물막.gd -- res://scenes/world_2_클로드/stage_2-9.tscn
```

저장소 기본 회귀 검사 목록은 `docs/다음작업_프롬프트.md` §1을 따른다. 실제 PC의 승인된 Godot 실행 경로를 사용한다.
수동 확인: 2-9 혼합호퍼의 흰 공급 밸브 전환, 2-8 HB 출구 접점, 높이가 낮은 기존배치 호퍼의 수면/금속 가림, 검정/흰색/회색 가독성. 진단에서 우회 위험이 나오면 물을 넓히지 말고 레벨 설계로 해결한다.
