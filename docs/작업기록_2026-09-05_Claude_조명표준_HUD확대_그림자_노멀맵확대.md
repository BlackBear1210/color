## 1. 조명 표준 (Lighting Standard) — `scripts/스마트월드/조명표준.gd`

### 1-1. 실험실을 먼저 만들었다

`scenes/테스트/Lighting_Standard_Lab.tscn` — BRICK · WOOD · GRASS · METAL 을
**같은 크기 · 같은 조명 기하**에 놓고 광원 조건만 바꾸는 대조군 화면.
재질마다 광원을 따로 두었다(하나로 전부 비추면 "재질 차이"인지 "거리 차이"인지 모른다).

F6 조작: `← →` 빛 위치 · `↑ ↓` height · `N` 노멀맵 · `1~4` CanvasModulate · `Q W` energy

### 1-2. ★처음 실험실이 통째로 안 보였던 이유

`PointLight2D` 는 **texture 가 없으면 아무것도 안 비춘다.** 씬을 굽고 화면이 그대로여서
값 문제인 줄 알았는데 광원이 애초에 안 켜져 있었다.
→ `발광체.gd` 와 같은 식(거리 제곱 감쇠) 텍스처를 코드로 만들어 물렸다.

### 1-3. 확정값과 근거 (전부 실화면 비교)

| 항목 | 값 | 왜 |
|---|---|---|
| `PointLight2D.height` | **128** | 32·64 는 벽돌 요철이 거의 안 산다. 256 은 벽돌 테두리가 한 줄로 번들거려 **돌이 아니라 플라스틱**이 된다 |
| `blend_mode` | **ADD** | MIX 는 빛이 닿은 자리가 통째로 회색 판이 된다 = 지시서 §2-3 의 "거대한 회색 얼룩"이 정확히 그 증상 |
| 반경(기준) | **700 px** | 340 은 허공에 흰 구슬이 뜬 것처럼 **광원 자체가 보인다**. 1300 은 방 전체가 고르게 밝아져 "어디서 오는 빛"인지 사라진다 |
| energy(기준) | **1.6** (반경 700) | 더 세면 중앙이 날아간다 |
| CanvasModulate(실내) | **0.62** | 0.45~0.55 는 원화 배경의 형태가 사라지고, 0.72 는 라이트 대비가 거의 안 산다 |
| shadow_filter | PCF13 · smooth 8 | 경계가 픽셀로 딱 끊기면 "잘라낸 종이"처럼 보인다 |
| shadow_color | `Color(0,0,0,0.72)` | 완전한 검정으로 두면 플레이어가 그림자에 통째로 묻힌다 |

### 1-4. ★"노멀맵이 게임에서 안 보이던" 진짜 원인

광원을 만드는 자리가 프로젝트에 **여섯 군데** 흩어져 있었고, **한 곳도 height 를 안 줬다**(=0).
Godot 2D 라이트는 height 0 을 "광원이 표면과 같은 평면"으로 계산해서 화면 밖(+Z)을 향하는
노멀이 빛을 거의 못 받는다.

→ `조명표준.적용(빛)` 한 줄을 여섯 곳에 넣었다:
`발광체.gd` · `연결통로.gd` · `장애물/체크포인트.gd` · `장애물/통로.gd`
· `proto/zone_visuals.gd` · `proto/stage_backdrop.gd`

## 2. HUD — 크기 · 초상 담기 · Help 분리

### 2-1. 크기 (1.0 / 1.25 / 1.5 를 실제로 찍어 비교)

- 씬의 `본체` 는 168×88 px = 1856 화면 가로의 **9 %**. 배경이 어두워 있는지도 모른다.
- 1.5 는 게이지가 안내문 위로 올라타 뭉갠다.
- → **배율 1.35** (`페인트HUD.배율`, 인스펙터에서 조절 가능)
- 씬의 `본체.scale` 이 **(1.0672, 1.0874)** 로 가로세로가 달라 구가 미세한 타원이었다
  → 씬은 (1,1) 로 되돌리고 **등방 배율**만 코드에서 준다.
- 여백 26,20 → **34,26** (키우고 나니 구가 모서리에 붙어 잘린 것처럼 보였다)

### 2-2. ★"얼굴만 동그랗게 떠 있다" 를 고쳤다

원인: 초상 스프라이트의 scale/position 이 씬에 **손으로 박혀** 있었다.
`player_frames.tres` 의 한 칸은 640×640 인데 캐릭터가 그려진 곳은 (139,101)~(434,558) 이라
여백이 사방으로 제각각이고, 그래서 원이 **머리만** 잘라 담았다.

→ `_초상_담기()` 가 실제 그림의 **불투명 영역(used_rect)** 을 재서 원에 맞춘다.
`초상_담을_비율` = 실루엣 세로 중 원에 담을 비율. **0.80** 으로 확정
(1.0 = 전신·작다 / 0.60 = 다시 얼굴만). 아트를 갈아 끼워도 안 깨진다.

### 2-3. Production HUD 와 Gameplay Help 를 갈랐다

안내문이 HUD 바로 아래(28,116)에 있어서 HUD 를 키우니 겹쳤다.
→ **화면 상단 가운데**로 옮기고, 별도 CanvasLayer `게임플레이_안내`(layer 90)에 담았다.
자원 HUD 는 layer 100 그대로. 나중에 안내문을 지울 때 HUD 를 한 글자도 안 건드리게 된다.

## 4. LightOccluder2D (`tools/그림자_가림막.gd`)

```
[지형/벽_왼위_BRICK_01]
 ├ StaticBody2D
 │  └ CollisionPolygon2D      ← 읽기만 한다. 한 점도 안 고친다
 └ 빛가림 (LightOccluder2D)   ← 이 도구가 만든다
```

- 콜리전 점을 **지형 노드 로컬 좌표로 옮겨** OccluderPolygon2D 를 만든다.

## 5. 노멀맵 4 재질 확대

### 5-1. ★재질 .tres 를 복사하지 않았다 — 런타임에 바꿔 낀다

재질이 30 개가 넘고 스테이지 7 개가 제각각 참조한다. 노멀맵 버전을 따로 만들면
**재질이 두 벌**이 되어 앞으로 반드시 한쪽만 고치게 된다.

→ `scripts/스마트월드/노멀맵_표.gd` (diffuse 경로 → CanvasTexture .tres 경로)
→ `지형.gd` 가 `shape_material.duplicate(true)` **직후에** 표를 한 번 물어보고 바꿔 낀다.
   원본 .tres 는 한 글자도 안 바뀐다(진단 도구가 매번 확인한다).
   지형 인스펙터 `연출 > 노멀맵_사용` 으로 지형 하나씩 끌 수 있다.

  폴백으로 떨어진다.
