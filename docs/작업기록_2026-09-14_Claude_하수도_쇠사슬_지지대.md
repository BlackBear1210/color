## 2. 동작 계약 (구현한 것 / 안 한 것)

- 체인 길이 = 두 끝점 거리. 텍스처를 `길이/고리_간격` 만큼 UV 반복(Scale 안 늘림 · 노드 안 만듦). v=0 이 발판 쪽이라 길이가 고리 한 칸을 넘어도 발판 쪽 고리는 제자리, 천장 쪽으로 감겨 들어간다.
- 추적 모드: `_process` 에서 Marker 월드 위치 → `to_local` → 바뀐 프레임에만 `queue_redraw`. 승강기는 `_physics_process` 에서 먼저 움직이므로 한 프레임 늦지 않는다(C03 에서 오차 0.00). **체인은 읽기만 한다.**
- 고정 모드: `_process` 를 끈다(100 개 = +0.19 ms → 0).
- 예외: 경로 없음/끊김/삭제 → 그 쪽 안 그림 + 경고 1 회 · 길이 < 1 → 안 그림 · 텍스처 없음 → 안 그림 + 경고 1 회 · 길이 > 최대(4000) → 끝점에서 최대만 그림 + 경고 1 회.
- 지지대: 그림 한 장 + flip_h. 균일 배율만. 원점 = 밑면 벽 모서리. 발판 자식으로 넣어 따라오게. 승강기용 아님.
- 장식 루트에 CollisionObject/Area/그룹 없음(B01 이 센다). `명중`·`현재색` 같은 게임 메서드 이름을 쓰지 않았다.
- **안 한 것**: 물리 체인 · 장력 · 파괴/매달리기 · 흔들림/물방울 · 기존 맵 배포 · 챕터표 · 경사 발판 보정 · 수평 승강기 연출.

## 5. 밟은 것

- 헤드리스에서 `.png` 를 새로 만들면 `--import` 를 한 번 돌려야 `load()` 된다.
- 비용 측정 첫 판: 기준/장식을 번갈아 만들며 재니 값이 ±3 ms 로 요동쳤다(free 직후 재생성). 같은 프로세스에서 한 번씩 만들고 블록 최소값을 쓰니 안정됐다.
- 발판1(320 폭)은 필요횟수 4 라 총알 한 발은 "progress" — G03 은 흰 발 진행 횟수로 판정한다.
