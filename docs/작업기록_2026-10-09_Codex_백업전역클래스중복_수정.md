# 백업 전역 클래스 중복 수정 — 2026-10-09 Codex

사용자 오류: `Parser Error: Class "압력버튼" hides a global script class.`

## 원인

이전 발판 작업에서 프로젝트 내부 `tmp/platform_finish_20261009/`, `tmp/platform_press_readability_20261009/`에 GDScript 원본을 그대로 백업했다. 백업에 `class_name 압력버튼`이 남아 있었는데 Godot 검색 제외 표식을 만들지 않아 백업도 실제 게임 스크립트로 검색됐다. 작업 도구의 정적 파서 구문 확인은 이 전역 클래스 등록 중복을 검사하지 못했다.

실제 `.godot/global_script_class_cache.cfg`에서 `압력버튼`과 `움직이는발판` 두 전역 클래스가 `scripts/스마트월드/` 원본 대신 `res://tmp/platform_finish_20261009/scripts/스마트월드/` 백업 경로에 등록되어 있었다. 이번 작업에서 만든 백업 관리 실수다.

## 수정

- `tmp/.gdignore` 추가: 작업 백업·검증 도구·임시 브라우저 프로필 등 tmp 전체를 Godot 검색에서 제외. 백업 파일은 삭제하거나 바꾸지 않았다.
- `.gitignore`에 `/tmp/*`와 `!/tmp/.gdignore` 추가: 임시 파일은 로컬에 두고 중복 재발을 막는 Godot 표식은 공유할 수 있게 한다. tmp에는 기존 Git 추적 파일이 없음을 먼저 확인했다.
- 생성된 클래스 캐시에서 위 두 항목의 경로만 `res://scripts/스마트월드/압력버튼.gd`, `res://scripts/스마트월드/움직이는발판.gd`로 복구했다. 캐시 사본은 Godot 제외 폴더의 `tmp/duplicate_class_fix_20261009/global_script_class_cache.before.cfg.bak`에 보존했다.
- 실제 게임 코드·씬·발판 디자인·충돌·기믹 동작은 변경하지 않았다. Godot와 외부 브라우저는 실행하지 않았다.

## 확인

- `git pull`: Already up to date. 삭제 상태 파일 없음. 커밋/푸시 없음.
- 게임 코드/씬/셰이더/리소스/project.godot에 `res://tmp/` 참조가 없음을 확인해 검색 제외가 실제 게임 참조를 끊지 않는지 확인했다.
- `.gdignore`가 있는 폴더를 제외한 GDScript 461개를 읽어 전역 클래스 135개를 검사했다. 중복 전역 클래스 0개. 압력버튼·움직이는발판 선언은 각각 정식 원본 한 곳만 남는다.
- 클래스 캐시에 `res://tmp/` 경로가 남지 않음, 복구 대상 원본 존재 확인.
- Git은 백업 GDScript를 무시하고 `tmp/.gdignore`는 무시하지 않음을 확인. `.gitignore` 공백 검사 통과.
- 안내된 검사 13개 문서는 현재 체크아웃에 없다. 엔진 검사는 사용자 안전 규칙에 따라 미실행. 실제 편집기 재검색/스크립트 재로드에서 오류 소멸 확인은 아직 하지 않았다.

앞으로 프로젝트 내부에 `.gd`, `.tscn`, `.tres` 백업/검증 파일을 둘 때는 Godot가 검색하지 않는 폴더를 먼저 확보한다. 단순 Git 무시는 Godot의 검색 제외를 대신하지 않는다.
