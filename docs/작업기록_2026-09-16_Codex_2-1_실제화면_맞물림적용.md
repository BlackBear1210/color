# 2-1 실제 화면의 흑백 경계 적용

사용자가 재확인한 화면은 2-1 A구간이었다. 이전에는 2-2에만 적용돼 있었다. 이번에는 명시적인 적용 지시에 따라 `scenes/world_2_클로드/stage_2-1.tscn`을 수정했다.

- 가로: A_바닥 ↔ A_갤러리_슬래브, (3136,704)~(3520,704).
- 세로: A_바닥 ↔ A_샤프트_왼벽, (3520,704)~(3520,1536).
- 양끝/플레이 영역의 외곽은 유지하고 내부 공유선을 줄눈 기준으로 맞물리게 변경했다.
- 세 지형의 점과 저장 충돌 다각형을 함께 변경했다. 각 노드의 옛 `_meshes` 캐시 override를 제거해 SS2D가 새 점으로 그리게 했다.
- 세 지형 전용 맞물림_2-1_*.tres로 UV 기준(3136,640.1)과 scale=.18을 통일했다. 미리보기 재질에도 새 윤곽과 주변 가림 선분을 저장했다.
- 자체 선분 수는 108/28/76개이므로 공통 자연발판 스크립트와 셰이더의 자체 선분 한도를 함께 128로 올렸다. 주변 가림 한도는 256 그대로이다. 반복 횟수는 실제 선분 수를 사용한다.
- 기존 색칠/회수/사망 로직 변경 없음. 세 노드에 위치별_판정=true 명시. 시작상태는 전용 흑백 프리팹을 상속한다.

`tools/apply_stage21_masonry_joint.py`는 지정된 세 노드만 패치한다. --apply 없으면 검사만 하며, 이미 적용돼 있으면 다시 덮어쓰지 않는다. 기존 외곽이 예상과 다르면 중단한다. 기존 맵 전체 빌더를 실행하지 않았다.

정적 검사: `tools/test_stage21_masonry_joint.py`로 980개 경계 표본의 빈틈/겹침 없음, 합산 면적 보존, 자기 교차, 저장 충돌 일치, 구형 메시 캐시 제거, UV/리소스 참조/색칠 설정/배열 한도를 검사한다. 2-2 정적 검사도 회귀 실행한다.

엔진 실행은 AGENTS.md 안전 예외에 따라 미실행. 화면 캡처/셰이더 컴파일/실제 총알 색칠/회수/플레이어 사망/프레임 비용은 아직 실행 검증되지 않았다. 실행 허가 후 이번 세 지형에 대한 실제 플레이 검증이 필요하다. 저장된 씬을 다시 열거나 F6로 새 실행해야 이미 실행 중인 게임에 새 데이터가 반영된다.

Git 커밋/푸시 없음. 앞선 사용자 미커밋 작업과 2-2 적용분 보존.

검사 결과: 2-1 전용 정적 검사와 재적용 무변경 확인 통과. 2-2의 1,092 경계 표본은 통과했으나, 현재 2-2 파일에는 지난 작업의 명시적 CollisionPolygon2D override가 없어 기존 검사기가 해당 항목에서 중단했다. 현재 2-2는 플레이어 위치 등도 변경되어 있어 외부 편집분을 덮어쓰지 않았다. 2-2 회귀 전체 통과로 보고하지 않는다.
