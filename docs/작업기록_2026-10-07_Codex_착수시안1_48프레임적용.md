# 작업기록 2026-10-07 · Codex · 착수 시안 1의 48프레임 적용

## 요청

스테이지 2-3 화면에서 앞선 적용의 물보라가 약하게 보였다. 사용자 요청은 1번 시안 방향을 그대로 진행하며 움직이는 프레임까지 구현/적용하는 것.

## 변경

- `tools/생성_착수물보라_시안1.py`: 낮은 물막의 팽창→파열→분리와 포물선 물방울/짧은 물살/착수 거품/바닥 흐름을 48프레임으로 굽는다. 384×128 한 칸, 8×6 시트(3072×768), 60FPS 기준 0.8초 반복. 고정 씨앗이라 멱등. 엔진이나 씬 빌더를 실행하지 않는다.
- `assets/textures/obstacles/liquid/impact_concept_a/impact_a_48.png`: 게임에서 실제 사용하는 RGBA 프레임 시트.
- `shaders/water_stream_natural.gdshader`: 기존의 약한 점 입자 루프 대신 위 시트를 읽는다. 현재/다음 프레임의 알파와 색을 보간하고 마지막→첫 프레임도 보간한다. 물줄기 양옆에 물살을 배치하며 중간 거품 부분만 폭에 맞춰 늘려 좁은 물에서도 효과가 작아지지 않게 했다.
- `scripts/스마트월드/흰물_디자인.gd`: 시트 재질 연결. 임포트 전 리소스 실패 시 기존 착수 효과를 유지한다. 한글 설명 주석 포함. 시간은 기존 게임 중 `_process`의 `anim_time`을 사용하며 에디터에서 계속 애니메이션을 돌리지 않는다.
- 범위: world_2_클로드 stage_2-1~2-4의 흰색 물. 기존 흰색/스테이지 조건을 유지한다. 충돌, 색 혼합, 켜짐/꺼짐 머리·꼬리 조건, 호퍼 유입의 물보라 끄기는 유지했다.
- 물줄기 본체와 씬은 변경하지 않았다. 동작 프레임은 1번 생성형 시안의 방향을 구현한 별도 제작물이며 원본 생성 이미지를 그대로 애니메이션으로 변환한 것은 아니다.

## 확인

- 48개 시트 칸이 생성한 각 프레임과 일치함을 확인.
- 0프레임과 한 주기 뒤 48프레임은 픽셀까지 동일. 인접 프레임 변화의 평균 3.500/최대 4.839, 마지막→첫 변화 4.075(8비트 RGBA 채널 평균 절대 차이). 반복 경계에 특별히 큰 불연속 없음.
- 모든 프레임의 유효 픽셀이 기존 좌우 그리기 여백과 착수 높이 영역 내에 있음을 확인.
- 셰이더 괄호 중첩/한글 없음, 흰색·스테이지 범위, 실제 시트/게임 시간 연결, 기존 켜짐/꺼짐 조건 확인. `git diff --check` 통과.
- 프레임 12개를 모은 `docs/visual_review/water_impact_white_20261007/시안1_동작_12프레임.png`를 직접 열어 검토했다. 초기의 곡선 느낌을 낮은 쐐기형 물살과 짧은 파편으로 다듬었다.
- 동작 미리보기: `docs/visual_review/water_impact_white_20261007/시안1_동작_프레임미리보기.webp`. 단순 배경/기준 물줄기에 합성한 프레임 전용 미리보기이며 실제 게임 캡처가 아니다.

## 남은 검증

- 수정 완료·시각 검증 대기. Godot 실행 명시적 요청이 없어 편집기/콘솔/headless/빌드 실행과 엔진 검사 13개는 미실행. 실제 엔진 캡처 경로 없음.
- 같은 스테이지·줌·해상도에서 1번 시안과 비교하고, 좁은/넓은 물, 꺼짐·재켜짐, 리스폰, 호퍼 유입, GPU 비용을 실제 게임에서 확인해야 한다. 시안과 정확히 같다고 단정하지 않는다.
- `git pull --ff-only`는 FETCH_HEAD 권한 오류로 실패해 현재 작업 파일을 기준으로 수정했다. graphify query/update 호출은 출력 없이 종료되어 갱신 완료를 확인하지 못했다.
