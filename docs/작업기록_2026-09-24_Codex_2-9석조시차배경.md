# 2-9 석조 시차 배경 적용

- 사용자 요청에 따라 방금 제작한 석조 아치 시안 스타일을 2-9에 시범 적용했다.
- imagegen으로 먼 터널, 중간 기둥, 가까운 벽의 레이어를 각각 제작하여 프로젝트에 저장했다. 중간/가까운 레이어의 아치 내부 alpha=0 확인.
- 새 하수도_다층배경_v03.tscn에 Parallax2D 세 층 구성. 가로 비율 0.2/0.5/0.85, 세로 0.15/0.4/0.75. 배관은 벽과 함께 이동한다.
- 지형보다 뒤에 그리도록 z=-100/-90/-80 설정. 먼 배경은 불투명으로 채우고 앞쪽 아치를 통해 깊은 층이 보인다. 기존 반복 경계 완화 셰이더를 재사용한다.
- 2-9 씬에서 배경 PackedScene 참조만 v02→v03으로 교체. 다른 스테이지와 지형/장치/충돌/플레이어 설정은 이번 작업에서 변경하지 않았다.
- 정적 검증: 리소스 선언 순서, 참조 파일 존재, 3개 레이어 및 이미지 배율과 반복 크기 일치, diff 공백 검사 통과.
- Godot 실행/엔진 import/실제 렌더·이동 검증은 사용자 안전 규칙에 따라 미실행. 반복 경계 및 지형과의 밝기 대비는 실제 화면에서 추가 확인이 필요하다.
- graphify query/update는 출력 없이 종료 코드 1로 실패하여 소스로 확인했다.
