## 1. 이 게임이 뭔지 (아트 결정의 근거)

**GRAY** — 흑백 반전 2D 퍼즐 플랫포머.

- 플레이어는 **검정 상태 / 흰색 상태**를 Shift 로 전환한다.
- **자기 색과 반대인 지형을 밟으면 즉사**한다. (검정인데 흰 발판을 밟으면 죽음)
- 물감을 쏴서 **회색(무색) 발판을 자기 색으로 칠하면**, 그 발판이 실체가 되어 밟을 수 있다.
- 칠해진 발판에 **반대색을 맞히면 영구 회색**이 되어 다시는 못 칠한다. (되돌릴 수 없는 실수)

→ 즉 **"이 발판이 지금 무슨 색인가"가 플레이어의 생사를 가른다.**
아트는 아름다움보다 **이 판단을 1/10초 안에 하게 만드는 것**이 최우선입니다.

**톤 레퍼런스**: LIMBO / INSIDE / 리틀 나이트메어 / 레인월드
(어둡고 축축하고 거대한 세계 안의 작은 존재. 화려하지 않고 무겁습니다.)

## 2. ★명도 규칙표 — 이건 규칙이지 취향이 아닙니다

| 요소 | 명도 (0=검정, 100=흰색) | 왜 |
|---|---|---|
| **검정 지형** | **0 ~ 10%** | 플레이어가 "검정"으로 읽어야 함 |
| **흰 지형** | **90 ~ 100%** | 〃 "흰색" |
| **회색(죽은 지형)** | **45 ~ 55%** | ⚠**이 대역은 회색 지형 전용.** 배경이 절대 침범 금지 |
| 무색(칠 가능) 지형 | 65 ~ 75% + 점선 테두리 | "여긴 칠할 수 있다" 신호 |
| **배경 전체** | **8 ~ 40%** | 45~55% 를 피해서 아래쪽 대역만 사용 |
| 배경 원경 | 30 ~ 40% | 멀수록 밝고 흐리게(공기원근) |
| 배경 중경 | 20 ~ 30% | |
| 배경 근경 | 12 ~ 22% | |
| 배경 전경(플레이어 앞) | 8 ~ 15% | 거의 검은 실루엣 |
| 위험물(가시·톱) | 코어 90% + 외곽선 5% | 어느 지형 위에서도 보이도록 **2겹** |

### 왜 45~55% 를 비워야 하나
회색 발판은 **"영구히 죽은 지형"** 이라는 뜻입니다. 플레이어는 이걸 즉시 알아봐야 하는데,
배경에도 같은 명도가 깔려 있으면 **회색 발판이 배경에 묻혀 안 보입니다.**
실제로 이번 주에 이 문제가 발생해서 배경 명도를 전부 내렸습니다.

### 위험물은 왜 2겹인가
지형이 순흑 아니면 순백이라, 가시를 흰색으로만 그리면 **흰 지형 위에서 사라집니다.**
반대도 마찬가지입니다. 그래서 **어두운 외곽선 + 밝은 코어**로 그려야 양쪽에서 다 보입니다.

## 3. 1순위 — 지형 타일셋 (가장 중요)

### 3-1. 현재 상태

이미 올려주신 `assets/tileset/` 의 brick / wood / rock / soil / grass 를 **그대로 게임에 넣었습니다.**
구조를 실측해서 코드에 반영했으니, **같은 규격으로만 주시면 자동으로 반영**됩니다.

### 3-2. 규격 (이대로 유지해주세요)

```
· 한 칸 = 384 × 384 px
· 실제 그림은 그 안에서 약 350 × 350 px (바깥 17px 는 투명 여백 = 뜯긴 가장자리용)
· 한 PNG 안에 [흑 버전][백 버전] 을 가로로 나란히
· 배경 투명 (알파 채널 필수)
· 파일명 그대로 덮어쓰기 → 코드 수정 없이 전 스테이지 반영
```

### 3-3. ★★가장 중요한 제약: 흑/백 쌍은 **실루엣이 완전히 같아야** 합니다

게임이 발판을 칠할 때, **같은 자리에서 흑 텍스처 ↔ 백 텍스처를 픽셀 단위로 섞습니다.**
두 버전의 외곽선이 다르면 칠하는 중간에 **가장자리가 덜덜 떨리거나 어긋나 보입니다.**

✅ 올바른 방법: 흑 버전을 그린 뒤, **같은 레이어를 복제해서 명암만 반전**
❌ 잘못된 방법: 흑 버전과 백 버전을 따로 그리기

### 3-4. 추가로 필요한 재질 3종

| 이름 | 파일명 | 어디에 쓰나 | 그림 요청 |
|---|---|---|---|
| **금속판** | `metal.png` | 도심·고층 스테이지의 발판 | 리벳 박힌 강철판. 모서리 녹슨 자국. 가장자리는 찢긴 철판처럼 |
| **콘크리트** | `concrete.png` | 판자촌 바닥·벽 | 거친 콘크리트. 잔금·부서진 모서리·노출 철근 몇 가닥 |
| **나무판자(낡음)** | `plank.png` | 판자촌 발판·다리 | 못이 삐져나온 낡은 판자. 틈새 벌어짐. 끝이 부러진 형태 |

### 3-5. 기존 5종에 보강 요청

- **가운데가 너무 비어 있습니다.** 현재 벽돌/나무는 가장자리에 디테일이 몰려 있고 중앙이 평평합니다.
  게임에서는 **가로 12칸(384px)까지 늘려 쓰기 때문에** 가운데가 반복될 때 밋밋해 보입니다.
  → 가운데에도 **저대비 디테일**(벽돌 균열, 나뭇결 옹이, 이끼 자국)을 넣어주세요.
  단, 명도 차이는 **10% 이내**로. 너무 튀면 "칠해진 부분"과 헷갈립니다.
- **윗면(발 딛는 면)을 명확하게.** 지금은 위아래 구분이 약합니다.
  윗면 5~8px 에 밝은 캡(검정 버전) / 어두운 캡(흰 버전)을 넣어주시면
  **어디를 밟을 수 있는지가 훨씬 잘 읽힙니다.**

## 4. 2순위 — 배경 실루엣 프롭 (바이옴 4종)

### 4-1. 스토리 진행에 따른 배경 흐름

```
스테이지 1        2         3         4          5
   자연 ──────→ 물가 ──────→ 판자촌 ──────→ 도심 ──────→ 고층
  (동물·식물)  (물감 지움)   (도시 외곽)   (중심부)    (위로 상승)
```

**핵심**: 스테이지가 바뀔 때 배경이 뚝 끊기면 안 됩니다.
지금 구현은 **한 스테이지 안에서 왼쪽→오른쪽으로 서서히 다음 바이옴으로 변합니다.**
(예: 스테이지 3 왼쪽은 아직 물가, 오른쪽으로 갈수록 판잣집이 늘어남)
그래서 **바이옴 사이에 "섞이는 구간"이 있어도 어색하지 않은 디자인**이면 좋습니다.

### 4-2. 규격

```
· PNG 또는 SVG, 배경 투명
· 세로 크기: 원경 300~500px / 중경 200~350px / 근경 80~200px
· ★밝은 회색(#f0f0f0 정도)으로 그려주세요 — 게임이 레이어별로 어둡게 낮춥니다
  (어둡게 그리면 곱해질 때 새까맣게 뭉개집니다. 실제로 이 문제가 있었습니다)
· 내부 디테일은 #cfcfcf 정도로 아주 약하게
· 원근/음영 금지. 평평한 실루엣만.
```

## 5. 3순위 — 게임 오브젝트 2종 (이건 지금 제일 급합니다)

### 5-1. 🚇 통로 (스테이지 연결부)

**지금 상태**: 제가 코드로 그린 아치형 구멍입니다. 임시입니다.

**의도**: 스테이지와 스테이지를 잇는 **터널 입구**. "포탈"이 아니라 **공간**이어야 합니다.
플레이어는 문을 여는 게 아니라 **그냥 걸어 들어갑니다.**

**요청**:
- 지형에서 **파낸 듯한** 터널 입구. 벽돌/콘크리트 단면이 보이면 좋음
- 안쪽은 깊고 어둡게, **저 끝에서 빛이 새어나오는** 느낌 (빛 색은 코드가 넣습니다)
- 바이옴별로 다른 버전이면 최고: 자연=바위 굴 / 물가=수문 / 도시=하수관·지하도 입구
- 크기 약 200 × 260px, 아랫변이 지면에 닿는 기준

### 5-2. 🏮 등불 (체크포인트)

**지금 상태**: 제가 그린 간단한 랜턴입니다.

**의도**: 원래 "깃발"이었는데, **깃발은 이 세계의 물건이 아니라 UI 기호**라 톤이 깨졌습니다.
→ **꺼져 있던 등불에 불이 들어오는 것**으로 바꿨습니다.
"여기서부터 안전하다"를 아이콘이 아니라 **화면이 밝아지는 것**으로 알립니다.
지나온 길을 돌아보면 켜둔 등불이 줄줄이 보입니다 = 진행 기록이 세계 안에 남음.

**요청**:
- **꺼진 상태 / 켜진 상태 2장** (같은 실루엣, 유리 부분만 다름)
- 낡고 그을린 기름등 느낌. 매달 수 있는 고리 있으면 좋음
- 크기 약 60 × 110px
- 바이옴별 변주(자연=나뭇가지에 매단 등 / 물가=부표등 / 도시=가로등 갓)이면 최고

## 6. 4순위 — 하늘/원경 판 일러스트

바이옴마다 **가로로 긴 원경 일러스트 1장**씩. 실루엣 프롭으로 부족한 "깊이"를 채웁니다.

```
· 가로 2048px 이상 (좌우 이어붙임 가능하면 더 좋음)
· 세로 1024px 정도
· 명도 8 ~ 35% 안에서만
· 위쪽이 밝고 아래쪽이 어두운 세로 그라데이션 기본
```
