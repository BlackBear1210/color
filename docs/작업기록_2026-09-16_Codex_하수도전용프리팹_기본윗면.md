# 하수도 전용 프리팹 연결 및 기본 지형 윗면

## 원인과 해결
- stage_2-1의 외곽_왼벽은 기존 TEMPLATE_WALL_SOLID 인스턴스에 새 스크립트·재질·점을 덮어쓴 상태였다. 외형은 새 것이어도 원본 씬을 열면 집 템플릿이 열리는 것이 원인이었다.
- scenes/지형/하수도/에 하수도_기본지형_검정.tscn, 하수도_기본지형_흰색.tscn, 하수도_공중선반_검정.tscn, 하수도_공중선반_흰색.tscn을 독립 SS2D 프리팹으로 만들었다. 기존 자연형 시험 프리팹을 기반으로 하며 집 템플릿을 상속하지 않는다.
- scenes/world_2_클로드/stage_2-1.tscn의 기본 지형은 새 기본 프리팹, 석조선반 8개는 새 공중 프리팹에 연결했다. 스테이지에 저장된 점·배치·재질 덮어쓰기는 보존했다. 원본 열기는 공통 프리팹을 열며 해당 스테이지의 개별 외곽 크기를 여는 동작은 아니다. 개별 크기는 스테이지 내 SS2D 점을 수정한다.

## 윗면
- sewer_natural_platform.gdshader: 지형 폴리곤에서 위를 향하는 면을 찾아 그림만 최대 4px 위로 확장한다. 계단과 경사도 각 선분을 기준으로 계산한다.
- 얕은 윗면은 충돌면 기준 약 -4~+4px. 원본 선반 텍스처의 290~350행을 쓰며 앞쪽 수직면은 그 아래로 이어진다. 경사는 선분의 법선 방향 거리로 샘플링하므로 실제 화면상 깊이는 각도에 따라 조금 다르다.
- 앞면 하단 24px에서 기존 채움에 합쳐지고 기존 좌우 음영을 유지한다. 물감 시드는 원래 메시 좌표를 사용한다. 충돌·사망 로직은 수정하지 않았다.
- 하수도_자연발판.gd가 런타임에도 ground_top_half_depth=4.0을 전달한다. 에디터 재질은 동일한 셰이더 기본값을 사용한다.

## 사용과 검증
- 새 배치는 scenes/지형/하수도/ 프리팹 사용. Scale=1을 유지하고 SS2D 점으로 크기를 편집한다.
- stage_2-1의 리소스 연결과 이전 턴의 공중 선반 설정을 제외하면 HEAD와 동일함을 정적 비교했다. 점·메시·게임 설정 보존.
- 신규 프리팹 4개의 리소스 파일 존재 및 독립 씬 여부, 셰이더 ASCII, git diff --check 확인.
- Godot 실행·셰이더 컴파일·화면·착지·색칠·사망 검사는 미실행. AGENTS.md의 엔진 실행 제한을 따랐다. 실행 시 씬을 다시 열어 외곽_왼벽의 원본 연결, 흑백 윗면, 계단 안쪽 모서리, 경사 양끝, 색칠 경계를 확인해야 한다.
- Graphify update는 uv trampoline 경로 오류로 실패했다.
- 사용자 변경으로 보이는 공중_경사발판.tscn 수정은 건드리지 않았다. 이번 작업은 커밋/푸시하지 않았다.
