# 2-9 잔물결과 젖은 벽돌 경계

사용자 캡처에서 물속 밝은 얼룩이 안개처럼 보이고 바닥과의 경계가 직선으로 분리돼 보였다.

- 셰이더의 큰 침전 얼룩 대비를 약 1/3로 낮추고 넓은 밝은 얼룩 항을 제거했다.
- 깊이별로 어긋나는 짧은 가로 반사선을 추가했다. 두께는 약 1px이고 깊어지며 사라진다.
- 물 안쪽 바닥 접촉 음영을 1.5~3.5px의 불규칙한 폭으로 좁혔다.
- 2-9 전용 웅덩이 스크립트에서 양쪽 벽과 바닥 바깥으로 1.5~5.5px의 반투명 어두운 띠를 그린다. 원래 벽돌 무늬와 페인트는 비쳐 보이고 수면 위로 띠가 올라가지 않는다. 물이 꺼지면 그리지 않는다.
- 이 띠는 기존 상태 변경 시 재그리기를 이용하며 매 프레임 메시를 만들지 않는다. 충돌, 수심, 매립 수로 좌표는 수정하지 않았다.

정적 확인: shader ASCII/중괄호, 넓은 반사 얼룩 제거, 세 웅덩이 크기에 대한 젖은 띠 폭 범위, 꺼짐 조건 및 물리 함수 미변경 확인. git diff --check 통과. Godot 실행·엔진 검사·실제 렌더링 확인은 저장소 안전 규칙으로 미실행이다.

기존 병합 미해결 상태로 git pull 실패. graphify query/update는 출력 없이 종료 코드 1로 실패하여 갱신되지 않았다.
