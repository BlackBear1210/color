## 3. ★규칙 — 여기가 이 장애물의 전부다

```
플레이어 총알 : 탄약 1발 소모 → 회수줄(FIFO)에 쌓임 → E 로 회수하면 1발 돌아옴
장치  페인트  : 탄약 안 씀    → 회수줄에 안 들어감  → E 로 회수 불가
```

**왜 이렇게 했나**

- 회수줄에 넣으면 분사기 앞에 서서 **E 를 연타하는 것만으로 탄약이 무한**이 된다.
- 회수를 막으면 반대로 압박이 생긴다 — **분사기가 칠한 색을 지우는 방법은 내 물감으로 덮어쓰는 것뿐이다.**
  맵분석(§4-1)이 지적한 "후반 다섯 판에서 총을 한 발도 안 쏜다"를 정면으로 되돌리는 장치다.

**따라오는 규칙 3개**

| 상황 | 결과 | 왜 |
|---|---|---|
| 부분 칠이 4초 뒤 흐려짐 | 장치 몫은 **환급 안 됨**, 플레이어 몫만 돌아옴 | 안 그러면 가만히 서 있는 것만으로 탄약이 는다 |
| 죽음 / 스테이지 리셋 | 장치가 칠한 것도 **원래 색으로 돌아감** | 안 그러면 여러 번 죽는 사이 분사기가 맵 전체를 덮는다 |
| 장치끼리 회색이 됨 | 회색 목록에 들어가되 `_잠긴_발수` 는 안 늘어남 | 플레이어가 낸 발이 아니다 |

## 4. 물리는 플레이어 총알과 **완전히 같다**

`총알.gd` 를 그대로 쓴다(복사하지 않았다). 그래서 공짜로 따라오는 것:

- 탄낙차(포물선) · 송풍기 바람 · **반대색 물이 막는다** · 얇은 발판 터널링 방지 레이캐스트
- ★같은 물리를 쓰는 게 중요하다. 조금이라도 다르면 플레이어가 눈으로 익힌
  "저건 저기 떨어진다"가 어긋나서 **화면을 읽는 재미가 죽는다.**

**플레이어를 직접 죽이지 않는다.** 투사체는 몸을 그냥 통과한다(총알은 물리 레이어 0).
죽음은 **칠해진 지형을 밟았을 때** 색 규칙으로 일어난다.
→ "맞으면 죽는 총알"이 아니라 **"땅을 바꾸는 총알"** 이다. 성격이 다르다.

## 5. 배치 요령 (2-8 에서 쓸 때)

1. **들어서기 전에 보여야 공정하다.** 장치 한가운데에 지금 쏘는 색이 동그라미로 찍힌다.
   갈래점에서 분사기가 보이도록 놓을 것 — 안 보이면 갈래가 아니라 도박이 된다.
2. **에디터에서 예상 궤적이 점선으로 보인다.** 실행하지 않고 탄착점을 잡을 수 있다.
   (게임 중에는 안 그린다 — 정답 노출이라서)
3. **여러 대를 놓을 땐 `위상` 을 엇갈린다.** 안 그러면 전부 동시에 쏴서 리듬이 한 박자가 된다.
4. **분사기 + 통과 플랫폼** 조합이 가장 잘 맞는다. 통과 플랫폼은 물이 못 지우지만
   분사기 페인트는 닿는다 — "안전한 발판"의 정의가 하나 더 늘어난다.
5. ⚠ **소프트락 주의.** 분사기가 유일 경로를 계속 반대색으로 덮으면 지나갈 방법이 없어진다.
   `레벨디자인_가이드.md` §2 소프트락 금지 3규칙을 그대로 적용할 것 —
   **탄약 0 으로도 지나갈 수 있는 길이 항상 하나** 있어야 한다.
