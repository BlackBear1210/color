# 2026-10-15 · Codex — 열쇠 HUD 좌우 배치

사용자가 첨부한 세 번째 이미지에 맞춰 미완성 열쇠 두 조각을 위아래에서 **좌우 배치**로 변경했다.
브랜치는 `dev_1`이며 이번 후속 수정은 `scripts/ui/열쇠_HUD.gd`에만 적용했다.

- 검정 반쪽은 왼쪽, 흰 반쪽은 오른쪽에 같은 높이로 표시한다.
- 아직 없는 조각은 반쪽 점선, 획득한 조각은 해당 모양에 잉크가 차오른다.
- 두 조각의 채움이 끝나면 가운데로 이동해 원본의 같은 캔버스 위치에 포개진다.
  이때 완성된 열쇠 하나의 전체 실선 윤곽을 표시한다.
- 두 조각을 이미 가진 저장 상태로 들어오면 처음부터 완성 열쇠 하나를 표시한다.
- 조각이 날아오는 목표와 완성 열쇠가 문으로 떠나는 중심은 기존 위치 계산을 따라 새 배치에 맞는다.
- 0.6배 기준 HUD 영역은 가로 72px·세로 85.8px이다. 합친 열쇠 자체는 기존 48×85.8px을 유지한다.

검증: 수정한 HUD의 gdtoolkit 문법 검사 통과, 기존 챕터1 정적 검사 오류 0, `git diff --check` 통과.
이전 작업에서 확인한 graphify 실행기 부재는 그대로이며, 엔진 기반 13개 검사는 안전 규칙에 따라 미실행이다.

Godot은 실행하지 않았다. 첨부 이미지는 수정 전 상태/목표의 참고 자료이며 이번 변경의 검증 캡처로 사용하지 않는다.
**수정 완료·시각 검증 대기.** 실제 엔진의 수정 후 캡처는 없으며, 좌우 간격·합체 연출의 최종 화면 차이는 미측정이다.
