# 2-9 회색 웅덩이 외관 수정

## 목적과 적용

화면 아래의 회색 물이 평평한 금속 판처럼 보이는 문제를 줄였다. 2-9의 A/E/G 낙하물받이 3개가 참조하는 pool_art만 새 `웅덩이_하수도29.gd`로 교체했다. 다른 스테이지의 공용 재질은 수정하지 않았다.

- 수면에 약 1px 높이의 서로 다른 두 잔물결을 합성한다.
- 끊어진 은회색 반사선이 천천히 오른쪽으로 흐른다.
- 중간 회색 수면에서 어두운 회색 바닥으로 내려가며 내부 흐름을 약하게 표시한다.
- 양 끝의 7px 범위에 젖은 음영과 1.5px 경계 완화를 넣었다. 수로 벽을 새로 만들거나 물의 폭을 줄인 것은 아니다.
- 셰이더는 픽셀 좌표를 사용하므로 폭이 다른 세 웅덩이에서도 무늬가 늘어나지 않는다. 텍스처 샘플링, 화면 반사, 매 프레임 메시 재생성은 추가하지 않았다.

기존 웅덩이 v2를 상속해 인스턴스별 시각 재질만 바꾼다. 크기, 위치, 회색 값 2, 낙하 받기, 색 판정, 침수 마감은 유지한다. 입수 물보라·플레이어 파문·기포는 이번 기본 수면 수정에 포함하지 않았다.

## 확인과 한계

- 작업 전 기존 씬의 충돌 표식 부재와 물 연결을 확인했고 `git diff --check`에 오류가 없었다.
- 작업 후 세 웅덩이 연결, 원래 수심/폭/색, 신규 리소스 경로, 셰이더 ASCII/중괄호를 정적으로 확인했다. `git diff --check` 통과.
- 저장소 안전 규칙에 따라 Godot 편집기/콘솔/headless와 엔진 검사 전체는 미실행. 실제 화면과 셰이더 엔진 컴파일은 미확인이다.
- 작업 시작부터 Git 인덱스에 2-9 및 문서의 미해결 병합 상태가 있었다. `git pull`은 이 때문에 실패했다. 기존 병합 상태를 임의로 해결하거나 stage하지 않았다.
- 기존 삭제 파일 `~$맵 기본 구조 틀.pptx`는 작업 전부터 있었으며 건드리지 않았다.
- `graphify query`와 `graphify update .`를 호출했으나 출력이 없었고 graph.json의 수정 시각도 갱신되지 않아 그래프 갱신 성공은 확인하지 못했다.
