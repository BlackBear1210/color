# 2026-10-09 · Codex · 로비 사진 지도와 갈림길 정비

## 요청과 작업 범위

로비를 GRAY의 회백색 물감·낡은 집 분위기로 상세화하고, 퍼즐 조각을 사진 카드로 교체했다. 챕터1은 주경로와 복도에서 나오는 옆방 갈림길을 분리했다. 일시정지 오류 원인과 클리어 뒤 선택창으로 돌아가던 흐름을 수정하고, 과다 체크포인트와 목재 접합부·캐릭터 발 접지를 정리했다.

시작 시 `git pull` 결과는 Already up to date였다. 기존 Claude 작업이 많은 공유 체크아웃에서 해당 계약과 필요한 씬 노드만 수정했다. 몹 AI를 교체하지 않았다. 커밋·푸시는 하지 않았다.

## 원화와 UI

원화는 built-in image_gen으로 제작했다. 프롬프트·참조·출력 경로는 `visual_review/로비_사진지도_20261009/이미지_프롬프트.json`에 보관했다.

| 적용 파일 | 용도 |
|---|---|
| `assets/ui/로비/타이틀/배경_물감_v02.png` | 폐가 계단, 시계, 샹들리에, 물감통 머리 주인공이 있는 로비 배경 |
| `assets/ui/로비/타이틀/메뉴_붓_물감_v02.png` | 버튼·제목의 투명 회백색 붓칠 |
| `assets/ui/로비/보드/배경_물감_v02.png` | 사진 지도용 어두운 물감 바탕 |
| `assets/ui/로비/조각/사진_틀_v02.png` | 테이프가 붙은 투명 사진 틀 |

타이틀·사진 지도는 1920×1080 기준 캔버스를 균일하게 축소하고 중앙 배치한다. 게임 카메라 줌은 변경하지 않았다. 버튼 글씨는 이미지에 굽지 않고 실제 버튼으로 남겼다. 챕터2도 기존 하수도 연결 표를 읽어 같은 사진 UI를 사용한다.

사진은 기존 실제 플레이 스냅 시스템을 사용한다. 사진 영역은 중앙 크롭이며 HUD는 제외한다. 완료 기록의 시간·사망 수와 도장을 종이 아래쪽에 표시한다. 아직 사진이 없는 스테이지는 어두운 빈 사진으로 표시하며 생성형 배경을 플레이 사진으로 사용하지 않는다. 숨은 서재는 발견 전 숨기고 발견 뒤 점선으로 나타낸다.

`visual_review/로비_사진지도_20261009/로비_사진지도_미리보기.html`은 원화와 배치를 확인하는 독립 미리보기다. 예시 도장·기록·발견 토글은 저장 데이터를 건드리지 않는다. 실제 엔진 화면 검증 자료가 아니다.

## 진행과 오류 수정

- 일시정지 메뉴가 씬 이동 뒤 분리된 상태에서 `get_viewport().get_visible_rect()`를 호출하던 경로에 이동 중·트리·노드·viewport 확인을 추가했다. 스테이지 선택으로 이동한 뒤 기존 메뉴 배치를 계속 호출하지 않는다.
- 집·하수도 클리어는 기록·스냅을 남기고 기존 다음 씬으로 전환한다. 자동 선택창 이동은 제거했다. 도장 연출은 사용자가 선택창을 열었을 때 재생한다.
- 이어하기는 실제 최근 방문 씬을 기억한다. 캐시된 씬 재입장도 방문 기록을 갱신한다.
- 옆방 배경 문은 가까이에서 E를 눌러 들어간다. 바닥에 서 있을 때만 작동하며 옆방 도착 시 자동 옆걸음을 하지 않는다. 기존 통로는 자연스러운 이동 연출을 유지한다.

## 챕터1 실제 연결과 체크포인트

주경로: **01 → 02 → 04 → 06 → 08 → 09 → 10 → 11 → 12 → 13 → 14 → 15 → 하수도 stage_2-1**.
시작방에서 복도·중앙 계단·거실·굴뚝·집 밖 하수도길로 이어진다.

| 갈림길 진입 | 옆방 길 | 주경로 합류 |
|---|---|---|
| 02 복도 A | 03 서재 → 16 썩은 마루 | 04 복도 B |
| 04 복도 B | 05 침실 | 06 복도 C |
| 06 복도 C | 07 수납실 | 08 복도 D |
| 11 거실 | 17 응접실, 기존 18 숨은 서재 유지 | 12 복도 F |
| 13 복도 G | 19 거미방 | 14 굴뚝 |

왕복 가능한 옆방 출입문 10개를 기존 바닥 위에 배치했다. 실제 SS2D 다각형 좌표로 발밑 바닥과 몸 공간을 확인했다. 상세 위치는 `visual_review/로비_사진지도_20261009/배치_결과.json`, `지형_정적확인.json`에 있다.

체크포인트는 **90 → 34개**, 스테이지당 **1~3개**로 줄였다. 입구·출구 부근의 중복 지점을 줄이고 시작 지점과 긴 점프·퍼즐·그을음·거미 구간의 안전 지점을 남겼다. 이 배치의 난이도 적절성은 실제 플레이 확인이 필요하다.

`tools/쳅터1/사진지도_정비.py`는 도안 JSON과 실제 씬의 체크포인트·연결 속성·옆방 문만 맞추는 멱등 도구다. 씬 전체 재생성 도구와 Godot을 실행하지 않는다. `tools/쳅터1/만들기.py`에는 향후 옆방 문 생성 지원만 추가했으며 실행하지 않았다.

새 스테이지를 확장하려면 해당 씬/도안을 만든 뒤 `scenes/lobby/퍼즐보드_쳅터1.json`에 id·씬·이름·위치·앞·입구·출구를 추가하고 실제 통로/문 목적지를 맞춘다. UI 사진은 실제 스테이지 플레이 캡처를 자동으로 읽는다. 고정 19개를 검사하는 이번 정적 검사도 확장 시 갱신해야 한다.

## 지형과 발 접지

목재 데크의 이웃 탐색이 같은 부모에만 제한되어 기본 지형과 추가 지형의 상판 경계를 놓치는 부분을 수정했다. `지형`·`추가지형` 양쪽의 이웃을 조회하고 점·노드 순서 변경에 재계산한다. 실제 충돌 다각형과 흑백 사망 규칙은 변경하지 않았다.

캐릭터의 기존 발 그림 좌표와 시각 깊이를 사용해 바닥에 서 있을 때 작은 접촉 그림자를 그린다. 공중·사망 상태에서는 숨긴다. 체크포인트 바닥 탐색은 플레이어 RID를 제외하여 플레이어 몸에 등불을 붙이지 않는다.

19개 씬의 실제 지형 다각형을 32px 격자 중심으로 검사한 결과 샘플 겹침은 없었다. 이 검사는 화면에 투영되는 상판 겹침이나 미세 겹침이 없다는 증명이 아니다. 상판 경계와 접지는 엔진 전후 캡처로 최종 확인해야 한다.

## 검사와 남은 확인

- `tools/쳅터1/검사_사진지도_정적.py`: **13개 정적 계약 검사 통과**. 리소스·목적지·노드 중복·도안/씬 일치·전체 도달·체크 수·자동 지도 전환 제거·Python 문법·멱등성을 확인했다.
- gdtoolkit parser: **수정 GDScript 17개 문법 파싱 통과**. Godot의 타입 검사·리소스 import·실행 검사를 대신하지 않는다.
- HTML JavaScript 문법 검사 통과. 지도 카드 사각형 간 겹침을 좌표로 확인했다.
- Git 삭제 목록 없음. 기존 사용자·Claude 변경을 포함하는 체크아웃이므로 전체 diff를 이번 작업만의 변경이라고 보고하지 않는다.
- `graphify-out/graph.json` 없음. `graphify update .`는 실행 파일 부재로 수행하지 못했다.
- `docs/다음작업_프롬프트.md` 부재로 기존 규정의 13개 원본 검사 명령을 읽을 수 없었다. 이번 13개 정적 검사는 별도 계약 검사이며 원본 엔진 검사를 대체하지 않는다.

**Godot은 미실행이다.** AGENTS.md의 명시적 실행 허용 규칙을 따랐다. 실행 허용 질문은 전달했으나 아직 응답이 없어 엔진을 시작하지 않았다. 이 작업에서 확보한 새 실제 엔진 전후 PNG는 없다.

사용자 제공 수정 전 이미지는 `visual_review/로비_사진지도_20261009/기존_상판접지.png`, `기존_체크포인트.png`로 보관했다. 생성형 원화나 HTML은 실제 엔진 검증 이미지로 간주하지 않는다.

실행 허용 뒤 확인할 사항: 같은 스테이지·카메라 줌·해상도로 상판/발 접지/등불 전후 캡처, 02 스테이지에서 일시정지 및 선택창 이동, 주경로 자연 연결, 옆방 5갈래 왕복과 기존 숨은 입구, 도장 표시 시점과 사진 저장, 작은 창에서 버튼·지도 조작, 체크포인트 축소 뒤 실제 플레이 난이도.
