# §1. ★새 구조 — 「끝 · 반복 베이 · 끝」

긴 실내를 2D 로 만드는 표준 방법이다. 방 하나를 통으로 그리지 않고 **세 조각**으로 그린다.

```
 ┌──────────┬───────────┬───────────┬──────────┐
 │  왼쪽 끝  │  반복 베이 │  반복 베이 │  오른쪽 끝 │   ← L1 방 셸 (불투명)
 │  (창)    │  (벽 기둥) │  (벽 기둥) │   (문)    │
 └──────────┴───────────┴───────────┴──────────┘
      책장        소파         피아노      괘종시계        ← L2 가구 (낱장 · 알파)
   ─────────────────────────────────────────────
        기둥 · 커튼 · 보 · 샹들리에(꺼짐)                  ← L3 전경 (낱장 · 알파)
```

- **반복 베이**를 가로로 n 번 이어 붙여 방의 길이를 자유롭게 늘린다.
- **끝 조각**이 방의 성격을 정한다 — 창이 있는 끝, 문이 있는 끝, 계단이 있는 끝.
- **가구를 낱장**으로 받아야 방마다 다르게 놓을 수 있다(도형님 요구의 핵심).

이러면 **같은 파일 세트로 방 7 개**가 나온다. v02 처럼 통짜면 방 1 개다.

# §2. ★크기 계약 — 이 숫자를 모든 그림에 똑같이 적용한다

지금까지 그림마다 사람 크기가 달랐다. 아래를 **고정 기준**으로 삼으면 나중에 섞어 써도 안 어긋난다.

```
캔버스 1536 × 1024  →  게임 월드 1920 × 1280 px (배율 1.25)
화면에 보이는 범위    =  월드 1920 × 1080 px

★ 사람 키          =  월드 96 px  =  캔버스 77 px  =  캔버스 높이의 7.5 %
★ 한 층 높이        =  월드 480 px =  캔버스 384 px =  캔버스 높이의 37.5 %
★ 걸어 올라가는 턱   =  월드 96 px  =  캔버스 77 px   (사람 키와 같다)
```

**작업 요령**: 그리기 전에 캔버스 높이의 7.5 % 짜리 사람 실루엣을 옆에 세워 두고,
가구·문·계단을 그 사람 기준으로 그린다. 제출할 때 그 실루엣은 지운다.

- 문은 사람의 **1.2 배**(캔버스 높이 9 %)가 현실 비율, **2~4 배**면 저택 대공간 느낌이다.
  이 게임은 **후자**를 쓴다(레퍼런스가 그렇다). 다만 **한 세트 안에서는 일정해야** 한다.
- 소파는 사람 키의 0.5 배, 책장은 1.8 배, 괘종시계는 1.3 배 — 이 정도를 지키면 방이 방으로 보인다.

# §7. ⚠ 배경보다 먼저 정해야 할 것 (도형님 결정 사항 — 아스트라 작업 아님)

집-1 은 지금 **동굴 생성기가 판 굴**이다(22,272 × 5,760 px, 바위를 파서 만든 통로).
방 배경은 **방 모양 스테이지**를 전제한다. 둘은 서로 다른 공간이다.

| 안 | 내용 | 대가 |
|---|---|---|
| **A. 스테이지를 방으로** | 방 하나 ≈ 화면 2×2 (3840×2160) 짜리 작은 스테이지를 문으로 이어 붙인다. 도형님이 말한 "방→복도→방→복도"가 그대로 나온다 | 동굴 생성기를 방 생성기로 바꿔야 한다 |
| **B. 배경을 동굴로** | 지금 스테이지를 살리고 배경을 동굴·지하실 톤으로 다시 만든다 | 레퍼런스의 저택 느낌을 버린다 |

**권고: A.** 도형님 기획(문으로 나가면 다음 방)과 레퍼런스가 둘 다 A 를 가리킨다.
v03 키트는 A 를 전제로 설계했다 — 반복 베이 2~3 장이면 방 하나가 딱 찬다.
