## 소리 손질 — `tools/생성_플레이어_효과음.py`(멱등)
- 원본은 Ogg **Opus** → Godot 4.6 이 못 읽는다 → Vorbis 로 다시 구웠다.
- 원본 앞에 0.45~1.32 초 무음 → 소리 시작 5 ms 전부터 자름 · 꼬리 80 ms · 페이드(딸깍 방지).
- 걷기 원본은 발소리 2 번(0.58 초 · 1.94 초) → 둘로 나눔. 최대 음량 0.06 → 0.6 으로 올림.
- 원본 .opus 는 다운로드 폴더에 그대로 둠. 변환에 `soundfile`(libsndfile 1.2.2) 필요.

## 코드
- 신규 `scripts/플레이어_효과음.gd` — `Player.tscn` 자식 `효과음`(Node). 음량·판정 값은 인스펙터.
  load 를 쓴다(preload 면 .import 가 생기기 전 헤드리스 검사가 파싱부터 실패).
- `player.gd` 점프·착지 자리에 호출 한 줄씩(ActionFX 먼지와 같은 자리).
- `월드.gd` `_리스폰()` 맨 앞 — 순간이동 **전에** 불러야 리스폰 자리 착지를 소리로 안 읽는다.
- `하수도_물소리.gd` — 마른 바닥 돌 발소리는 이제 쉰다(효과음 노드가 있으면). 웅덩이 찰박은 그대로.
  `발이_물속()` 공개 → 효과음 노드는 물속이면 쉰다. 한 걸음에 두 번 울리지 않게.

## 확인 안 한 것 ⚠
- **Godot 미실행.** 에디터를 한 번 열어야 .ogg 의 .import 가 생긴다(그 전엔 소리만 빠지고 오류는 없다).
- 검사 13 개 · 실제 청감(음량 균형) 미확인.
- `player.gd` 를 직접 쓰는 씬(집_거실·집_부엌·Lighting_Standard_Lab 등 Player.tscn 이 아닌 곳)엔 효과음 노드가 없다 → 소리 없음.
- `stage_lab.gd`(proto) 사망은 `_리스폰()` 을 안 거쳐 죽음 소리 없음.
