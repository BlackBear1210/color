# 물 너비와 퍼즐 우회 규칙

사용자 요구: 얇은 물은 유지 가능. 필수 레버 퍼즐은 점프 중 물색으로 전환하고 통과 후 바닥색으로 되돌리는 방식으로 우회하지 못하도록 물 너비와 공간을 조정한다.

아스트라·클로드 맵 제작 프롬프트에 우회 허용형/필수형 분류, 물별 설계표, 실제 판정 폭/애니메이션/출발착지 높이 검사, 색칠·낙하·플랫폼 우회 검토, 장치 전후 통과 검수를 추가했다. 448px는 같은 높이 조건의 초기 설계 후보일 뿐 차단 보장값이 아니라고 명시했다.

이번 작업은 규칙 추가다. 기존 씬의 물 크기를 일괄 수정하지 않았다. 엔진 실행·통과 검사 미실행. 문서 diff 정적 확인만 수행했다.
