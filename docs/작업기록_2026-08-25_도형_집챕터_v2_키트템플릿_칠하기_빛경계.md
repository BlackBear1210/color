## 2. Template 을 인스턴스로 쓸 때의 함정 두 개 (실제로 터진 것)

### `_meshes` 를 안 비우면 점을 바꿔도 모양이 안 바뀐다
`SS2D_Shape.force_update()` 는 `if not _first_update or not _meshes:` 일 때만 메시를 다시 굽습니다.
로드 직후는 `_first_update == true` 라서, Template 의 구운 메시가 남아 있으면
**점을 갈아 끼워도 Template 크기(512×192) 그대로 렌더**됩니다.
→ 점을 바꾼 뒤 `지형.set("_meshes", [])` 로 비워야 런타임에 새 모양으로 다시 굽습니다.

### 스마트지형을 활성 트리에 넣으면 안 된다
`_ready` 가 `shape_material` 을 깊은 복사해 페인트 셰이더를 붙입니다.
빌더가 트리에 넣으면 Template 과의 재질 공유가 깨진 채로 저장됩니다. → 오프라인 조립만 합니다.

## 3. ★레벨 기하 — 반드시 지켜야 하는 네 가지 숫자

레벨검사가 잡아낸 것들입니다. 앞으로 이 챕터를 손볼 때 그대로 씁니다.

| 값 | 숫자 | 왜 |
|---|---|---|
| 실제 점프 | 세로 **160px** · 가로 240px | 게이트는 이걸 넘겨야 "절대 못 넘는다"가 보장된다 |
| 레벨검사 실효 한계 | 세로 **128px** · 가로 204px | 여유 0.80 / 0.85. 이걸 넘으면 "도달 불가" |
| 필요한 머리 공간 | **104px** (키 96 + 여유 8) | 이보다 좁으면 발판을 **아예 못 잡는다** |
| SS2D 콜리전 부풀림 | **24px** (`collision_size`) | 도형 바깥으로 부풀어 굽는다 → **실효 간격이 24px 줄어든다** |

**따라서 같은 줄 위아래 간격 ≥ 두께 140 + 부풀림 24 + 머리 104 = 268px.**

굴뚝 서까래를 **세 줄**(A·B·C)로 돌린 이유가 이것입니다.
두 줄로 번갈아 오르면 같은 줄 간격 = 단차 × 2 → 단차 134px 이 필요한데 실효 한계 128px 을 넘습니다.
세 줄이면 단차 120px 으로 같은 줄 간격 360px 이 나와 여유 196px.
(두 줄 240px 로 지었더니 레벨검사가 서까래 11 개 중 **1 개도** 못 잡았습니다.)

### 파생 규칙
- **140px 두께 발판을 어떤 넓은 면 위 120px 에 놓으면 반드시 그 면을 파고든다** (140 > 120).
  → 굴뚝 아래를 불구덩이(빈 공간)로 비운 이유. 부엌 조리대를 오른쪽 절반에만 둔 이유.
- **위 발판이 아래 발판을 덮으면 아래가 죽는다.** 노출 폭 70px 이상 남길 것.
- **플레이어가 서 있는 자리는 표면 스캔(32px 간격)이 가려진다.** 시작 발판이 좁으면
  그 발판 자체가 "없는 것"으로 잡힌다.

## 5. 검사

### 새로 만든 것 — `tools/test_집_칠하기와빛.gd`
`레벨검사.gd` 는 **지형의 모양**만 봅니다. 색·빛은 안 봅니다.
그래서 v1 은 "검사 전부 통과"인데 게임의 핵심 규칙이 하나도 안 돌고 있었습니다.
→ **규칙**을 재는 검사를 따로 만들었습니다. 방마다 12 항목:

1. 유령 발판이 무색일 때 통과(콜리전 레이어 8 · 반투명 0.42)
2. 총알을 맞으면 색이 실제로 바뀐다
3. 칠한 뒤 밟을 수 있게 된다
4. 페인트 셰이더가 붙었다 (흑↔백 짝 텍스처 5 벌) ← 안 붙으면 색이 바뀌어도 화면은 그대로
5. 빛기둥이 `빛경계`·`색경계` 그룹에 들어갔다
6. 유령 발판 윗면이 **빛 다각형 안**이다
7. 다 물든 뒤 그 자리의 강제색이 흰색이다
8. 같은 발판을 검정으로도 칠할 수 있다
9. 검정으로 칠하면 흰 빛 안의 몸에게 치명적이다 = 퍼즐 성립

```
godot --headless --path . -s res://tools/test_집_칠하기와빛.gd
→ 통과 48 · 실패 0
```

## 7. 남은 것

1. **`챕터.gd` 스테이지표에 안 넣었다.** 네 방은 `연결통로.다음_씬` 으로 직결돼 있습니다.
   로비 → 시작 흐름에 붙일지는 기존 5·6·7(거실/굴뚝/지붕 원본) 정리와 함께 결정할 사항입니다.
2. **장애물 미배치.** 가시·색레이저·통과플랫폼 등은 아직 없습니다.
   `scenes/집/스마트월드_장애물/` 에서 드래그하면 됩니다.
3. **2층방 원화의 문은 왼쪽인데 출구는 오른쪽 벽**입니다.
   `연결통로` 가 구조상 +x 로만 파고들기 때문입니다. 뒤집으려면 `실내배경.좌우반전`.
4. **치명_낙하거리를 900(굴뚝 1400)으로 올려 뒀습니다.** 기본 520 이면 가구에서 내려오다 죽습니다.
