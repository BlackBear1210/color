# 빈 배관 입구와 물 흐름 40% 가속 — 2026-10-09 Codex

사용자 승인: 꺼진 배관을 물 없는 빈 입구로 정리하고 물 흐름을 현재보다 40% 빠르게.

## 적용

- 기존 `pipe_joint_dry.png`에 남아 있던 회색 물 끝과 검정 사각 꼬리를 제거한 `assets/textures/obstacles/liquid/reference_20261008/pipe_joint_dry_v2.png`를 생성했다. 이미지 편집 스킬의 내장 image_gen을 사용. 바깥은 투명, 안쪽은 어두운 빈 구멍이며 기존 거친 테두리와 볼트 스타일을 따른다. 원본 파일은 보존했다.
- `물_힉스필드_출수구.gd`는 새 빈 배관을 사용한다. 입구 물은 기존대로 대상 유체가 켜진 경우에만 별도 표시한다. 켤 때 연결부의 아랫끝을 본체의 흐름 머리에 맞춰 잘라 물이 본체보다 먼저 아래로 튀어나오는 것을 방지한다. 같은 자리 교대색 처리와 물받이는 유지한다.
- `water_reference_frames.gdshader`에서 공통 애니메이션 시간만 1.4배 처리한다. 무늬/윤곽/물방울/착수 애니메이션에 같은 배속을 적용하고, 기존 개별 흐름속도와 정지 미리보기 위상은 보존한다.
- `유체_흰물v2.gd`는 켜짐/꺼짐의 머리·꼬리 진행 시간도 1.4배 처리한다. 도달 시간은 기존의 약 71.43%가 된다. 물 판정은 기존처럼 보이는 머리까지만 갱신하고 꺼짐 즉시 위험/총알 감지를 해제한다.

## 확인

- 생성 결과를 직접 열어 빈 입구와 사각 꼬리 제거를 확인했다. 투명 바깥과 어두운 입구의 저장 픽셀도 검사했다. 생성물은 1254×1254이며 실제 배관의 기존 Rect2에 맞춰 표시한다.
- 꺼짐 상태의 물 표시 조건, 새 파일 참조, 시간 배속의 단일 적용, 여러 출수 지름/머리 위치에서 연결부가 머리를 넘지 않는지 정적으로 확인했다.
- 공백 검사 통과. graphify AST 갱신 완료.
- 수정 전 코드 백업: `tmp/pipe_flow_20261009/`.
- 최종 이미지 요청 요지: 원본 빈 배관 테두리 위치·질감·볼트·밝기 유지, 입구 아래 물 흔적/사각 꼬리 제거, 빈 어두운 내부, 배경은 실제 알파 투명, 물/추가 장식 없음. 내장 image_gen 편집 사용.

## 남은 검증

**수정 완료·시각 검증 대기.** Godot 실행에 대한 명시적 요청이 없어 엔진·headless·빌더를 실행하지 않았다. 엔진 검사 13개 미실행. 실제 엔진 수정 후 PNG 경로는 없음이며 생성 이미지로 실행 검증을 대체하지 않는다.

실행 허가 후 동일 스테이지/줌/해상도에서 꺼진 빈 입구, 켜는 첫 순간의 물 연결, 흑백·회색 교대, 껐을 때 꼬리 소멸, 실제 체감 흐름 속도와 색 판정을 확인해야 한다. 생성된 테두리가 기존 물 연결층과 픽셀 단위로 맞는지는 아직 게임 화면으로 확인하지 못했다.
