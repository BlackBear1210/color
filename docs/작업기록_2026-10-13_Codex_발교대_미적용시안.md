# 발 교대 미적용 시안

- 요청: 뒷발이 앞으로, 앞발이 뒤로 이동하고 발 교차 때만 무릎을 살짝 굽히는 시안을 만들되 게임에는 아직 적용하지 않는다.
- 결과: `docs/visual_review/player_walk_20261012/발교대_미적용시안/`에 검정/흰색 캐릭터의 GIF, 주요 자세 PNG, 투명 16프레임 시트를 별도로 만들었다.
- 원본 걷기 시트 첫 프레임의 상체와 다리 그림을 사용했다. 다리 그림을 오프라인에서 변형하며 상체 자세와 높이는 고정했다. 게임의 애니메이션 연결과 자산은 변경하지 않았다.
- A/B는 같은 발을 추적하는 관찰 표시다. A가 뒤에 있던 시작 자세에서 반 주기 후 A가 앞, B가 뒤로 바뀐다. 확대 화면의 하늘색/노란색 점은 검토용이며 투명 시트에는 없다.
- 무릎의 추가 굽힘은 회복하는 발이 교차하는 짧은 구간에만 적용한다. 양 끝 자세에서는 목표 관절이 직선이다. 다리 길이를 고정하는 IK는 쓰지 않았다.
- 육안 검토: 주요 자세 PNG를 직접 열어 앞뒤 교대와 교차 자세를 확인했다. 원화 조각을 변형한 시안이므로 코트 아래 접합부와 교차 시 실루엣은 실제 적용 전 추가 검토 대상이다. 걷기 중 이동 속도와 접지 동기화는 이번 시안에서 검증하지 않았다.
- 정적 확인: 검정/흰색 각각 두 발의 X 순서 반전, 양 끝 자세의 추가 무릎 굽힘 0을 확인했다. 실행 전후 `assets`, `scripts`, `scenes`, `shaders`, `project.godot` 전체 파일 해시가 동일했다. `검토.json`에 결과를 남겼다.
- Godot 및 엔진 검사 13개: 사용자 명시적 실행 허용이 없어 미실행. 이 결과는 게임 캡처가 아닌 오프라인 시안이다.
- graphify: query 실행. update도 실행했으나 노드 축소 보호(기존 34996, 새 14904)로 graph.json 덮어쓰기는 거부되었다. 강제 갱신하지 않았다.
- 재생성: 번들 Python으로 `tools/시안_발교대_미적용.py` 실행. 게임 파일을 쓰지 않는다.
