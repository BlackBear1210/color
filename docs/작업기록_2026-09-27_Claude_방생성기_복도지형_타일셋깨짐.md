## 3. 왜 바닥이 한 줄이어야 하나 (이번 작업의 핵심)

`동굴층.gd`(층 4 겹)와 `계단층.gd`(내려감)는 **카메라가 세로로 크게 움직인다.**
그러면 시차 배경도 세로로 흘러야 한다. 그런데 방 그림은 "방 한 칸"이라
세로로 흐르면 **같은 방이 위아래로 복제**된다. 도형님 말 그대로 "위반되는 행동"이다.

→ `방층.gd` 는 **모든 방과 복도가 같은 바닥 y 를 쓴다.**
   높낮이는 바닥이 아니라 **방 안 선반(가구)** 에서만 나온다. 올라갔다 내려온다.
   카메라 세로 이동이 한 방 높이(최대 1,920 px) 안에 갇히고, 배경 한 장이 그걸 덮는다.

실측: 맵 세로가 5,760 → **2,496 px** 로 줄었다(방). 복도는 **1,728 px**.

## 5. ★타일셋 깨짐 — 원인은 지형 크기가 아니었다

도형님 지시대로 **재기 위한 도구를 먼저 만들었다**(`tools/진단_타일셋_깨짐.gd`).

### 무엇을 재나

SS2D 는 지형 둘레에 **일정한 두께의 테두리 띠**를 붙인다. 지형이 얇으면 위아래 띠가 만나
채우기가 사라진다. 띠 두께 = **테두리 텍스처 세로 × texture_scale**.

```
edge_top_thin.png = 1024 × 109 px · texture_scale 0.35  →  띠 = 38.15 px
발판 두께 112 px  −  띠 38 × 2  =  채우기 36 px  =  32 %
```

### 실측 결과

| | 고치기 전 | 고친 뒤 |
|---|---|---|
| 방 스테이지 | 지형 39 개 중 **38 개 ✖** | **0 개** |
| 복도 스테이지 | 지형 5 개 중 **4 개 ✖** | **0 개** |

### 어떻게 고쳤나

얇은 지형 전용 재질을 만들어(`texture_scale 0.18` → 띠 19.6 px) **짧은 변이 256 px 미만인
칠할 수 있는 지형에만** 갈아 끼운다(`조립2.gd _폴리곤_노드()`).
껍데기·벽 같은 두꺼운 구조는 **그대로 둔다** — 거기서는 38 px 띠가 알맞은 마감이다.

```
채우기 32 % → 65 %
```

★덤: 2026-09-25 에 보고된 **"발판 안쪽이 다 안 칠해진다"** 의 절반이 이것이었다.
채우기가 32 % 밖에 없으니 칠해도 심지만 물드는 것처럼 보였다. 이제 65 % 가 물든다.
