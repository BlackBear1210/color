# 편집기 잔여 오류 정리

- 첨부 로그에 기존 Parse Error는 없으며, 사라진 ColorRect 경고 7개와 data.tree null 145회가 남았다.
- stage_2-8의 자동 번호 ColorRect override 7개가 로그와 정확히 일치한다. SS2D 클릭 보조 노드의 저장 잔재만 제거했다. 지형 위치 및 충돌 polygon은 HEAD와 동일함을 정적 비교했다.
- 압력버튼의 export setter가 씬 트리 진입 전 보조 노드를 만들며 get_tree()를 호출할 수 있었다. owner 지정 전에 is_inside_tree()를 확인하도록 수정했다. 기존 노드 owner는 변경하지 않는다.
- Unicode 오류 코드들은 경고에 포함된 지형/유령/끝의 한글 문자와 일치한다. 경고 출력 과정의 동반 오류로 추정하나 실행 검증하지 않았다.
- git diff --check 통과. Godot 실행 검사는 안전 규칙으로 미실행. data.tree 오류 전체가 이 경로에서 발생했는지는 호출 스택이 없어 확정하지 않았다.
- graphify query/update는 출력 없이 exit 1로 실패하여 직접 파일을 확인했다.
