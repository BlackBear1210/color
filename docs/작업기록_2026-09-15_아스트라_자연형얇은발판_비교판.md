# 자연형 얇은 발판 비교판

## 목적과 범위

사용자가 승인한 검정·흰색 얇은 발판 각 1종을 별도의 v02 비교판으로 제작했다. stage_2-1이나 기존 v01 재질은 이번에 변경하지 않았다. 새 배경 위에 기존/신규를 같은 크기로 놓은 `scenes/테스트/하수도_지형_v02/기존_자연형_비교.tscn`을 만들었다.

## 달라진 점

- 사방의 반복 edge 재질을 사용하지 않는다. 각 발판은 SS2D 1개와 충돌체 1개다.
- 340×48 범위의 양 끝/하단에 2~5px 작은 깨짐을 넣었다. 밟는 상면은 y=0으로 평평하게 유지했다. 표시 외곽과 충돌 외곽은 같은 점을 사용한다. 따라서 새 비교판의 모서리 충돌은 기존 사각형과 조금 다르다.
- 새 흑백 석조 PNG를 생성했다. 같은 벽돌 배치를 기준으로 흰색을 편집했으나 생성 결과의 모든 세부 픽셀이 정확하게 일치한다고 보장하지 않는다.
- 새 셰이더는 상면 3~6px, 오른쪽 2~6px, 하단 1~9px 범위에 명암을 준다. 고정 흰 윤곽선을 추가하지 않는다. 생성 이미지의 미세한 색조는 셰이더에서 무채색으로 바꾼다.
- 표면 명암은 페인트 합성 뒤에 적용한다. 색 짝은 black/fill.png ↔ white/fill.png다. 기존 하수도 지형 스크립트를 상속하며 충돌과 색 판정 함수를 새로 구현하지 않았다.

## 관리

새 스크립트: `scripts/스마트월드/하수도_자연발판.gd`.
새 셰이더: `shaders/sewer_natural_platform.gdshader`.
새 재질/이미지: `assets/textures/smartshape/sewer_masonry_v02/`.

새 셰이더는 기존 하수도 페인트 셰이더의 비교판용 사본이다. 공용 페인트 로직 변경 시 동기화가 필요하다. 최종 채택 시 공통 include로 분리하는 편이 좋다. 현재 shader의 주석은 규약대로 ASCII로 기록하고 이유는 이 문서에 한글로 남긴다.

길이는 SS2D 점으로 수정한다. 텍스처 배율은 0.18로 고정한다. 런타임에서 표면 음영 범위는 충돌 폴리곤 경계로 계산한다. 에디터의 미리보기 재질 경계 기본값은 340×48이므로 다른 크기의 에디터 미리보기에는 surface_bounds도 맞춰야 한다. 경사·오목한 큰 지형의 방향별 음영을 해결하는 범용 셰이더는 아니며 이번 얇은 수평 비교판에 한정한다.

## 생성 프롬프트

내장 image_gen 사용. 검정: seamless opaque1536×1024 front-face charcoal sewer masonry, roughly12 bricks across and8 rows, chipped stones, fine mortar, no frame/bevel/platform outline, soft ambient lighting. 흰색: edit black reference to aged white limestone, preserve brick layout/cracks/chips, albedo change only, no glow/frame, opaque PNG. 실제 생성 결과는 약8개 벽돌이 가로로 놓인 더 큰 석재 구성이며 그대로 검토용으로 채택했다.

## 확인

PNG 해상도/외부 참조/흑백 짝 존재, 외곽 점 수와 충돌 일치, edge 없음, shader ASCII를 정적으로 확인한다. Godot 편집기/실행/화면 캡처/132개 검사는 미실행이다. 이 비교씬에는 플레이어가 없으며 플레이 검증 완료를 뜻하지 않는다. 그림의 최종 자연스러움과 작은 단차의 이동 영향은 엔진 화면 확인 후 판단해야 한다.
