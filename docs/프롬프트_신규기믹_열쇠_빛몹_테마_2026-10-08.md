> 이 문서는 **사람이 읽어도, AI 에게 그대로 붙여 넣어도** 되게 썼다. 같은 날 오전판(v1)을 이 파일에서 갱신했다.
> - **도형** = 기획 결정 · 아스트라에게 시안 받기 · 고르기 · 레벨 배치 · 최종 컨펌
> - **아스트라(GPT)** = 2D 디자인(시안 → 확정 그림 → 부품/스프라이트 시트) → **§5 작업 카드**를 하나씩 붙여 넣는다
> - **Claude** = 시스템 프로그래밍 · 그림 자르기·정렬·명도 검수 · 엔진 연결 · 시험 · 화면 확인 → **§6 지시서**

> 읽는 순서: §1(내가 이해한 것) → §2(작업 순서) → 지금 단계의 §5 카드 → 결과를 Claude 에게.

## 0. 작업 루프 — 디자인 하나를 게임 오브젝트로 만드는 방법

```
① Claude: 작업 카드(§5)를 준다 — 목적 · 원하는 느낌 · 시안 프롬프트 · 확정 프롬프트 · 저장 위치
② 도형 → 아스트라: 카드 0(공통 스타일)을 대화 처음에 한 번 붙이고, 해당 카드의 [시안 프롬프트] + 참고 그림 첨부
③ 아스트라: 시안 3~4장 → 도형이 고른다(고르는 기준은 카드에 있다). 마음에 안 들면 [고칠 때 쓰는 말]로 다시
④ 도형 → 아스트라: 고른 시안을 붙인 채 [확정 프롬프트] → 부품 시트 / 프레임 시트
⑤ 도형: 파일을 카드의 저장 위치에 넣고 Claude 에게 [Claude 에게 보낼 말] 양식으로 알린다
⑥ Claude: 배경 제거·자르기·바닥선 맞춤·명도 검수 → 게임 시스템에 연결(애니메이션은 대부분 코드로) → 시험 → 실제 게임 화면 캡처
⑦ 도형: 화면 보고 컨펌 / 수정 요청 → 필요하면 ③으로
```

**왜 "부품 시트 + 코드 애니메이션"을 기본으로 하나**
GPT 이미지는 한 장 안의 프레임끼리 모양·크기·바닥선이 조금씩 어긋난다(프레임 시트는 실제 게임에서 떨림으로 보인다).
그래서 **스프링·열쇠·자물쇠 같은 사물은 부품(판·코일·받침 / 반쪽·반쪽)으로 받고 Claude 가 코드로 움직인다**(늘이기·탄성·트윈·파티클).
프레임 시트는 **모양 자체가 변하는 것**(이펙트의 번짐·몹의 동작)에만 쓴다. 그때도 Claude 가 칸마다 중심·바닥선을 다시 맞춘다.

**아스트라 출력 규칙(매번 확인)**: 캔버스는 1024×1024 · 1536×1024 · 1024×1536 중 하나. 투명 배경이 안 되면 **단색 크로마키 초록(#00FF00) 배경**으로 — 이 게임은 흑백이라 초록은 Claude 가 깨끗하게 지운다.

### 1-2. 오늘 오후 (v2 요청 — 이 판에서 추가)
| # | 도형님 말 | Claude 이해 |
|---|---|---|
| 1 | 점프할 때 대쉬 이펙트 같은 효과 | 레퍼런스(Dash Effect)의 **구조**만 가져온다 — 몸 뒤로 짧게 남는 속도 줄 + 작은 점. 우리 버전은 **발밑에서 아래로 남는 잉크 붓질 줄기 + 물감 방울**, 플레이어 색, 0.25초. 모든 점프에 나오므로 **작고 빨리 사라지게** |
| 2 | 점프대를 탔을 때 더블 점프 이펙트 같은 효과 | 레퍼런스(Double Jump Effect)의 **구조** — 발밑에서 옆으로 퍼지는 날개형 파문 + 아래로 튀는 조각. 우리 버전은 **스프링 판 위에서 옆으로 퍼지는 잉크 고리 + 아래로 튀는 물감 가시**, 0.35초 + 솟구치는 동안 짧은 속도 줄 |
| 3 | 우리 게임 분위기·방향성에 맞게 새로 | 레퍼런스의 만화풍(굵은 외곽선·채도·광택)은 쓰지 않는다. **흑백 · 잉크/물감 · 낡은 재질 · 작은 빛** 문법으로 다시 그린다 |
| 4 | 기존 점프대 이미지·디자인을 스프링으로 | 지금 도약대(코드로 그린 버섯형)를 **코일 스프링 + 받침판**으로 교체. 집 = 낡은 침대 매트리스 코일 + 나무/놋쇠 판, 하수도 = 녹슨 주철 코일 + 맨홀형 판 |

| 7 | 출구를 찾아도 못 지나가게 자물쇠 이미지 또는 가상의 벽, 열쇠를 쓰면 열린다 | 출구 길목(연결구/통로) 앞에 **자물쇠 빗장**(세계 안 사물) — 열쇠가 있으면 다가갈 때 HUD 열쇠가 날아가 꽂히고 풀린다. 없으면 막힘 + HUD 실루엣이 흔들림. 자물쇠를 둘 자리가 없는 곳은 **잉크 막(가상의 벽)** |

## 3. 게임 정체성 · 분위기 (모든 작업의 기준)

- **2D 흑백 다크판타지 퍼즐 플랫포머.** Godot 4.6.3 · SmartShape2D 지형 · 브랜치 dev_4.
- 핵심 규칙: **몸에 닿은 지형이 내 색과 다르면 즉사.** 안 칠한 지형은 검정. 회색만 안전. Shift = 내 색 전환. 물감총으로 칠한다. 빛도 색 규칙 안에 있다.
- 세계관(「수정된 세계」): 신이 "색은 오류"라며 **표백**했다 — 위로 갈수록 희고, 아래로 갈수록 그을려 검다. 소년은 색이 봉인된 페인트 건을 들고 오른다. → 이펙트의 재료는 **잉크·물감**(소년의 힘), 적의 재료는 **그을음·표백**.
- 쳅터1 = 밤의 빅토리아풍 저택 15 스테이지(연결구로 이어짐, 체크포인트 = 촛불등). 쳅터2 = 하수도 11 스테이지(거미줄 지도, 장치는 주철).
- 레퍼런스 톤: LIMBO · INSIDE · Little Nightmares · Rain World. **포탈 금지**, UI 아이콘보다 세계 안의 사물로 알린다.

## 4. 기능 기획 상세

### A. 반반 열쇠 · HUD 실루엣 (v2 개정)

**모양**: 오래된 장식 열쇠(skeleton key)가 **대각선 금**으로 둘로 갈라져 있다 — 도형님 레퍼런스처럼 고리(손잡이) 쪽 반 / 축·이빨 쪽 반.
기본 배정(§7-2 확정): **고리 쪽 = 검정 반쪽 · 이빨 쪽 = 흰 반쪽.** 금은 톱니처럼 맞물리는 모양이라 두 반쪽이 "원래 하나"로 읽힌다.

**규칙**
1. 열쇠 스테이지에 들어오면 HUD(페인트 게이지 오른쪽)에 **점선 테두리 열쇠 실루엣**이 뜬다. 대각선 금도 점선으로 보인다. 열쇠가 없는 스테이지에는 아무것도 안 뜬다 → 실루엣 자체가 "이 스테이지는 잠겨 있다"는 신호.
2. 검정 반쪽은 **플레이어가 검정일 때만 보이고 주울 수 있다.** 흰 반쪽은 흰색일 때만. (보임 기준 = `선택색()` — 대표색은 경계에서 깜빡인다)
3. 반쪽을 주우면 HUD 실루엣의 그 반쪽이 **잉크가 차오르듯 0.4초 동안 채워진다**(검정 반쪽 = 검정 잉크, 흰 반쪽 = 흰 물감). 세계의 반쪽은 HUD 로 날아가 들어간다(0.35초 곡선).
4. 두 반쪽이 다 차면 HUD 에서 금이 한 번 빛나며 **맞물리는 연출**(0.6초) → 점선이 실선이 된다 = 열쇠 완성.
5. 보이는 순간 연출: Shift 할 때 0.15초 페이드. 보일 때 **은은한 후광 + 가는 밝은 테두리**(검정 반쪽이 검정 화면에 묻히지 않게).
6. 픽셀 찾기 방지: 반쪽 근처에 세계 안 단서(빈 열쇠걸이 · 먼지 자국 · 반딧불이) — 레벨 디자인 규칙.
7. 죽어도 주운 반쪽은 유지(추천 — §7). 스테이지별 "열쇠 얻음"은 `user://진행.cfg` 에 저장 → 쳅터2 지도 칸에 작은 열쇠 표식.
8. 공중 Shift 줍기: 흰 반쪽이 검정 지형 위 허공에 떠 있으면, 검정으로 점프 → 공중에서 흰색으로 바꿔 줍기 → 착지 전 검정. 반쪽 배치의 핵심 재미.

**레벨 디자인 규칙**: 반쪽은 그 색 몸으로 살아서 닿는 자리(공중 줍기 의도 제외) · 주 경로에서 한 갈래 벗어난 곳 · 출구 바로 앞 금지 · 첫 등장은 보이는 색 반쪽부터.

### B. 출구 잠금 — 자물쇠 빗장 / 잉크 막 (v2 개정)

- **자물쇠 빗장(기본)**: 출구 길목(쳅터1 연결구 · 쳅터2 연결통로) 입구에 걸린 사물.
  - 집 = 길목을 가로지른 **낡은 나무 빗장 + 굵은 쇠사슬 + 놋쇠 자물쇠**(자물쇠 몸통에 반반 열쇠 모양 열쇠 구멍).
  - 하수도 = 통로 입구의 **주철 격자문 + 맹꽁이 자물쇠**(하수도 장치 계열).
- **열쇠 없이 다가가면**: 막혀 있고(콜리전), 자물쇠가 덜컥 흔들리는 소리 + HUD 실루엣이 흔들림 → "열쇠가 필요하다". 길목의 반딧불이는 자물쇠 주변에서만 맴돈다(길은 저기다, 하지만 잠겼다).
- **열쇠를 가지고 다가가면**: 조작 잠깐 유지한 채 HUD 열쇠가 자물쇠로 날아가 꽂힘(0.4초) → 한 바퀴 돌고 → 사슬이 풀려 떨어짐 → 빗장이 옆으로 걷힘(0.6초) → 콜리전 해제. 걸어가던 그대로 연결구 전환으로 이어진다.
- **잉크 막(가상의 벽, 대안)**: 자물쇠를 둘 공간이 없을 때 — 길목을 덮은 **반투명 잉크 막**(검·흰이 소용돌이). 열쇠가 닿으면 막이 가운데부터 갈라져 걷힌다. 색 규칙과 무관(막은 지형이 아니다).
- 원칙: 잠금은 **출구 한 곳에만**. 스테이지 안의 새 길은 빛 장치(D)로 연다 — 도형님 원칙 "막힌 출구보다 새 길"과 역할을 나눈다.

### F. 빛 몹 「그을음」 · G. 빛 장치 · H. 부서지는 발판 · I. 스테이지 테마 (v1 그대로)

- **그을음**: 표백을 피해 그을려 가라앉은 것들의 찌꺼기. 잠복(그을음 얼룩, 흰 눈 깜빡) → 깨어남(8칸 · 어둠 · 0.5초 예고) → 추적(달리기의 0.6~0.75배 · 14칸 밖이면 포기) → 덮침(2칸 · 0.3초 예고) → **빛에 닿으면 0.4초 지글거리다 재**(둥지에서 6초 뒤 다시). 닿으면 색 무관 즉사 · 물감총 안 통함 · **빛 안은 안전지대**. 태우는 빛 = 창문빛·빛기둥·반사빛길·켜진 촛불등·빛 장치(플레이어 보조광 제외). 둘레에 연기 같은 회색 가장자리 + 흰 눈(검정 위에서 읽히게). 한 화면 최대 3.

## 7. 도형님 결정이 필요한 것 (괄호 = Claude 추천)

1. 열쇠 = 항상 반반(검+흰)? 쉬운 도입용 "온전한 열쇠 1개"도 둘까? (반반이 기본 + 온전한 열쇠는 첫 등장 스테이지에만)
2. 반쪽 배정: 고리 쪽 = 검정, 이빨 쪽 = 흰색? (예 — 레퍼런스 구도 그대로)
3. 죽으면 주운 반쪽 유지? (유지)
4. 출구 잠금 = 자물쇠 빗장 / 잉크 막? (자물쇠 빗장 기본, 자리가 없을 때만 잉크 막)
5. 열쇠 쓰는 방법 = 다가가면 자동 / E 키? (자동 — 흐름이 끊기지 않게)
6. 스프링 최대 늘어남 1.28배 · 대기 숨쉬기 ±3% 괜찮은가? (예 — 화면 보고 조정)
7. 점프 이펙트를 모든 점프에? (예, 작게. 너무 많으면 '착지 후 첫 점프에만'으로 줄일 수 있게 @export)
8. 타임어택 구간형 · 표백 · 그을음 물감총 무반응 · 부서지는 발판 칠하면 단단 (v1 추천 그대로)
9. 하수도 길목 안내 = 반딧불이 그대로 / 물방울 반짝임으로 바꿀까? (화면상 문제는 없음 — 하수도 작업자 의견 듣고 결정)
10. 하수도 지형의 **직사각형 통로 구멍**을 쳅터1 처럼 얇은 벽으로 다듬을지 · 2-9~2-11 에 **입구 통로 추가**할지 — 씬 수정이라 하수도 작업자와 협의 (다듬는 것 추천)
