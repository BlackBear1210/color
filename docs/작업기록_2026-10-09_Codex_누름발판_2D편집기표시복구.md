# 누름 발판 2D 편집기 표시 복구 — 2026-10-09 Codex

## 요청과 확인한 문제
- 사용자: 2D 작업창에서도 누름 발판이 안 보이고 지형의 발판 자리만 빠져 보임.
- 2-4~2-7의 직접 생성한 압력 버튼 5개에서 `챕터1_원근` 설정이 `script` 연결보다 앞에 저장되어 있었다. 이때 기본 AnimatableBody2D에는 해당 전용 속성이 없어 새 디자인 설정이 적용되지 않는다.
- Godot 4.6.3의 SceneState는 속성을 저장 순서대로 적용한다. 확인한 원본: https://github.com/godotengine/godot/blob/4.6.3-stable/scene/resources/packed_scene.cpp (339~456행).
- 기존 매립 마감은 발판 그림이 생성되었는지 확인하지 않고 지형 마감부터 걷어냈다. 현재 열린 편집기의 오류 수정/스크립트 재연결 뒤 그림 복구 경로도 없었다.
- 실제 화면을 열어 원인을 재현한 것은 아니다. 위 내용은 파일에서 확인한 결함이며 화면 문제의 완전한 해결 여부는 엔진 확인이 필요하다.

## 수정
- `tools/apply_platform_perspective_finish.py`: 직접 버튼의 새 디자인 설정을 반드시 script 다음에 배치한다. 기존에 앞쪽에 적힌 설정도 이동하고 LF/CRLF를 보존한다.
- 2-1~2-7에 멱등 적용. 2-1~2-3 대상 없음, 2-4 버튼 1/승강기 1, 2-5 버튼 1, 2-6 버튼 1/승강기 1, 2-7 버튼 2. 버튼 5개의 설정 순서를 수정했다.
- `압력버튼.gd`: 편집기에서 속성 변경/스크립트 재연결 후 한 번만 그림과 보조 노드를 복구한다. 동일한 모양을 매 프레임 다시 그리지 않는다.
- `발판_매립마감.gd`: 원근 그림의 생성이 끝난 버튼에만 지형 마감을 잘라 적용한다. 준비 전에는 마감을 복원하여 빈 구멍만 남지 않게 한다.
- @tool의 편집기 물리 처리가 연결 지형을 이동하거나 숨기지 않도록 조기 반환했다. 게임의 실제 누름/이동 동작은 유지한다.
- 씬 전체 재생성, 기존 노드 owner 재지정, 실행 중인 앱 조작은 하지 않았다.

## 확인
- 7개 씬 재적용 시 바이트 변화 없음: 통과.
- 5개 직접 버튼 script→원근 설정 순서와 설정 중복 없음: 통과.
- 신규 적용/잘못 저장된 설정 이동의 LF 및 CRLF 확인: 통과. 좌표와 다른 속성 보존 확인.
- 압력버튼/발판_매립마감/발판_원근그림의 로컬 gdtoolkit 문법 검사: 통과. Godot 의미/실행 검사를 대신하지 않는다.
- git diff --check: 통과. 삭제 파일 없음.
- 지정된 검사 13개 문서 `docs/다음작업_프롬프트.md`는 현재 체크아웃에 없어 실행할 수 없었다.
- 사용자 안전 규칙에 따라 Godot 편집기/콘솔/headless/빌드: 미실행.
- 실제 엔진 캡처: 없음. 수정 완료, 2D 작업창 및 실제 게임 시각 검증 대기. 열린 씬은 디스크 변경을 다시 불러와야 저장 순서 수정이 반영된다.
- graphify update 실행: 새 그래프 11,426노드가 기존 17,399노드보다 작아 덮어쓰기를 거부했다. 기존 그래프는 강제로 교체하지 않았다.
