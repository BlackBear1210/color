## 🔎 "누가 뭘 했는지" 깃에서 확인하는 법

```
REM 최근 바뀐 파일 한눈에
git status --short

REM 최근 커밋 목록(누가·언제·무엇)
git log --oneline -20

REM 특정 사람 작업만
git log --author=<이름> --oneline -20

REM 파일 하나를 누가 마지막에 고쳤나
git log -1 --format="%an %ad %s" -- <파일경로>

REM 아직 커밋 안 된 내 변경 내용 보기
git diff -- <파일경로>
```

- ⚠ **커밋 전 반드시** `git status` 로 **내가 안 지운 파일이 `D`(삭제)로 잡혀 있는지** 확인.
  남아 있으면 그건 남의 미커밋 작업일 수 있다 — 그대로 커밋하면 그 사람 작업이 사라진다
  (2026-08-07 에 55개 유실 사고 있었음). 헷갈리면 커밋 말고 물어볼 것.
