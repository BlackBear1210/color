# 플레이어가 색 경계에 걸칠 때의 규칙

## 핵심 원칙

플레이어는 한 가지 색으로 취급되지 않는다. 경계선이 몸을 가르면 경계선 그대로 몸이 여러 조각으로 나뉘고, 각 조각은 자기 위치의 강제색 또는 자유색을 사용한다.

예: 수평 흰색 경계가 플레이어 허리를 지나면 상체는 흰색, 하체는 검정일 수 있다.

```text
      흰색 경계 영역
          머리  = 흰색
    ───── 경계선 ─────
          다리  = 검정 (자유색)
      경계 밖 영역
```

## 색 결정 순서

1. 몸의 각 지점이 검정 또는 흰색 경계 안인지 확인한다.
2. 경계 안이면 그 경계의 색으로 해당 몸 조각을 강제한다.
3. 어느 경계에도 속하지 않으면 `자유색`을 쓴다.
4. 회색·무색은 강제색이 아니므로 `자유색`을 쓴다.

`자유색`은 플레이어가 경계 밖에서 수동 색 전환으로 바꾸는 유일한 저장값이다. 강제색은 위치에서 계산되는 값이며 저장되지 않는다.

## 수동 색 전환

- 몸의 일부라도 검정·흰색 경계에 들어가 있으면 수동 색 전환은 막힌다.
- 상체만 경계 안이고 하체가 자유색이어도 막힌다. 몸 전체가 경계 영향에서 완전히 벗어나야 한다.
- 완전히 벗어나면 마지막 강제색은 남지 않는다. 몸 전체가 현재 `자유색`으로 즉시 돌아간다.

이 규칙은 경계에 걸친 상태에서 상체와 하체를 따로 바꿔 판정을 모호하게 만드는 일을 막는다.

## 사망 판정

플레이어는 닿은 지형을 해당 접점이 속한 몸 조각의 색으로 판정한다.

| 상황 | 결과 |
|---|---|
| 흰색 상체가 검정 천장에 닿음 | 사망 |
| 검정 하체가 흰색 발판을 밟음 | 사망 |
| 흰색 상체가 흰색 천장에 닿음 | 안전 |
| 검정 하체가 검정 발판을 밟음 | 안전 |
| 회색·무색 지형에 닿음 | 안전 |

따라서 “상체는 흰색인데 흰 발판을 밟았으니 안전”이 아니다. 발판을 밟은 하체가 검정이면 흰 발판과 색이 달라 사망한다.

## 그림 표시

검정·흰색 원본 플레이어 스프라이트를 겹친 뒤, 실제 경계선으로 각 시트를 자른다. 단순히 한 스프라이트를 회색조로 바꾸는 방식이 아니므로 양쪽 원본의 외곽선·명암·애니메이션을 유지한다.

평상시 이동 애니메이션뿐 아니라 발사 애니메이션도 같은 분할선을 사용한다. 경계에 걸친 채 총을 쏴도 발사 모션은 보이고, 몸의 상체·하체 분할은 풀리지 않는다.

## 총알의 시작점과 색

총알은 조준 방향 쪽의 실제 입에서 시작한다.

```text
왼쪽 조준  → 왼쪽 입  (-18, -70)
오른쪽 조준 → 오른쪽 입  (18, -70)
```

좌표는 발바닥을 `(0, 0)`으로 본 월드 픽셀 기준이다. 입 높이는 고정하고 좌·우만 조준 방향에 따라 바뀐다. 그래서 왼쪽 조준 때 뒤통수에서 발사되지 않는다.

총알 색도 같은 입 위치의 색을 발사 순간에 읽는다.

- 왼쪽 얼굴이 흰 경계 안이면 왼쪽 발사 총알은 흰색이다.
- 오른쪽 얼굴이 검정 자유 영역이면 오른쪽 발사 총알은 검정이다.
- 위·아래를 겨눠도 입의 높이 기준은 변하지 않으므로 조준 각도만으로 총알색이 흔들리지 않는다.

## 구현 위치

- 색·몸 분할·얼굴색: `scripts/player.gd`
- 일반 총: `scripts/gun.gd`
- 스마트월드 총: `scripts/스마트월드/총.gd`
- 프로토 총: `scripts/proto/proto_gun.gd`
- 분할 발사 모션: `scripts/proto/player_shoot_anim.gd`
- 분할 셰이더: `shaders/색분할.gdshader`

## 자동 검사 항목

`tools/test_색경계_분할.gd`는 다음을 검사한다.

- 가로·세로·대각선 경계에서 몸이 올바르게 분할되는지
- 경계 안에서 수동 전환이 잠기는지와, 밖에서 자유색으로 복귀하는지
- 몸 조각별 사망 판정이 맞는지
- 입 높이·좌우 입 위치·총알색이 얼굴색을 따르는지
- 그림 분할선과 물리 판정 분할선이 같은지
