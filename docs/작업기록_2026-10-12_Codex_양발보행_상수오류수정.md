# 양발 보행 도안 상수 오류 수정

- 사용자 보고: `플레이어_양발보행.gd` 8행의 `Assigned value for constant "도안" isn't a constant expression.`
- 원인: `도안` 안의 `PackedVector2Array` 생성자가 Godot 상수식으로 허용되지 않는데 `const`로 선언했다. 앞선 외부 문법 검사는 엔진의 상수식 의미 검사를 수행하지 못했다.
- 수정: `const 도안 :=`을 `var 도안: Dictionary =`로 바꿔 컴포넌트 인스턴스 초기화 때 한 번 구성하도록 했다. 수정 이유 한글 주석 추가. 도안 값과 보행 계산은 유지.
- 같은 보행·연결 파일의 다른 상수는 preload 리소스와 문자열 목록이며 같은 배열 생성 문제는 없음.
- 수정 후 보행 및 연결 GDScript 2개 정적 문법 검사 통과. 엔진 검사는 아님.
- Godot 실행·검사 13개: 미실행. 사용자 명시적 실행 요청 없음.
- 실제 엔진 캡처: 없음.
- `graphify update .` 실행 완료. 기존 그래프 축소 보호로 graph.json 덮어쓰기는 거부되어 강제 갱신하지 않았다.
