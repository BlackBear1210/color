# 작업기록 — SS2D 전용 충돌 경로 복구

날짜: 2026-09-02
작업자: Codex

## 증상

`stage_2-1.tscn`의 시멘트 SmartShape2D가 보이는 면을 통과했다. SS2D 인스턴스가
다른 인스턴스의 `CollisionPolygon2D`를 참조하면, 자기 물리는 비고 이웃 물리를
덮어쓰게 된다.

## 변경

- `stage_2-1.tscn`의 `TEMPLATE_CEMENT_SOLID2`에 저장된 이웃 충돌 경로 오버라이드를 제거했다.
- `scripts/스마트월드/지형.gd`에 모든 스마트지형이 자기 직계
  `StaticBody2D/CollisionPolygon2D`를 확인·복구하는 안전장치를 추가했다.
  이 보정은 부모 SS2D가 충돌을 bake하기 전에 실행되므로 잘못된 지형에 폴리곤을
  덮어쓰지 않는다.

## 확인

- 정적 확인: `stage_2-1.tscn`의 외부 인스턴스 충돌 경로 오버라이드가 제거됐고,
  공통 스크립트가 독립 충돌 경로를 강제한다.
- Godot 실행·헤드리스 검사는 사용자 안전 규약에 따라 실행하지 않았다.

## 추가 변경 — 부분 칠 범위

- `부분_칠_범위_배율`의 기본값을 `2.2`로 추가했다.
- Player의 실제 충돌 높이 약 96px를 기준으로, 부분 칠 지름은 약 211px
  (반지름 약 106px)보다 커지지 않는다.
- 얼룩 문양·번짐은 유지하고, 지형 면적 때문에 부분 칠이 과도하게 커지는 것만 제한했다.

## 추가 변경 — 시작색·반대색도 부분 칠로 통일

- 흰색/검정색으로 시작한 SS2D에 반대색을 맞힐 때의 즉시 전체 덮어쓰기 경로를 없앴다.
- 원래 색의 전면 시드는 원본 텍스처가 같은 색을 이미 표현하므로 첫 반대색 발에만 비운다.
  따라서 반대색 첫 발에 화면 전체가 번쩍이지 않고, 이후 부분 얼룩은 계속 누적된다.
- 모든 SS2D는 같은 부분 시드 누적 경로를 사용한다. 같은 지점을 연속 명중하면
  플레이어 기준 범위 안에서 발수에 맞춰 반경이 커지고, 필요 발수의 마지막에만
  현재 얼룩 크기를 이어받아 전체로 퍼진다.

## 추가 변경 — 큰 지형의 부분 칠과 유기적 물감

- `전체_색칠_최대긴변`을 추가했다. 기본값은 576px(96px당 한 발 기준 6발)이며,
  이를 넘는 SS2D는 탄약이 한정된 플레이에서 절대 전체 색으로 승격되지 않는다.
  부분 얼룩은 유지시간 뒤 자동 회수되어 탄약을 돌려준다. `0`으로 두면 제한을 끈다.
- 기존 기본 얼룩은 찌그러진 원 아래에 길고 비슷한 가닥이 붙는 방식이었다.
  2층방에서 검증했던 유기적 방식(비대칭 둥근 덩어리 + 명중마다 길이·굵기·휨이 다른
  짧은 1~3가닥 흐름)을 공통 SS2D 기본으로 올렸다.
- 유기적 모양의 결정 시드를 각 명중 얼룩에 저장하고 자리별 판정에도 같은 값을 써서,
  보이는 얼룩 본체와 사망 판정의 경계가 달라지지 않게 했다. 흐름 길이 기본값은
  74px에서 42px로 줄여, 원에 긴 꼬리 하나만 붙는 실루엣을 피했다.
