# 주철 호퍼 제작

승인된 초안을 built-in image_gen으로 만든3셀 아틀라스, 직하/좌하/우하 프리팹, 호퍼_주철_비교.tscn을 추가했다. assets/textures/obstacles/hopper/cast_iron_v1/README.md에 프롬프트와 사용법을 기록했다.
호퍼_주철.gd는 기존 호퍼.gd를 상속해 혼합과 끊김 유예를 유지한다. 아트와 노즐 끝 출구 포트만 변경. 기존 맵은 수정하지 않았다. 새 호퍼 기본폭200/높이164, 출구물폭-1로 유체값 보존.
좌우 곡선 출수 판정과 신규 밸브 원격 조작은 아직 구현하지 않았다. 실제 물을 연결해 기존 혼합 동작도 재검증해야 한다.
검증: 리소스 연결 모두 존재. PNG1536x1024 RGBA, 3개 아트의 유의미한 알파(>32) 영역은 셀내x25~486/y259~715로 렌더영역(y240~720)에 포함. 처음 엄격한 알파>0 검사에서는 셀2/3 바깥 알파1 잡음으로 실패; 확인 결과 그 잡음은 렌더영역 밖이므로 잘린다. 원본 이미지 편집은 하지 않았다.
Godot는 기존 충돌/실행제한에 따라 미실행. 실제 렌더/게임판정 검증 미완료. graphify query/update는 출력 없이 실패.
