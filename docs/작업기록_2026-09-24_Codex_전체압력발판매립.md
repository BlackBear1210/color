# 전체 스테이지 압력 발판 매립·돌출 적용

## 적용 범위

- 현재 활성 scenes의 압력버튼 스크립트 참조를 전수 검색했다. 2-7 6개, 2-8 2개, 2-9 2개, 2-10 1개, 2-11 2개로 총 13개다.
- 이미 적용된 2-9는 보존하고 다른 11개를 압력버튼_매립.gd로 전환했다. 이전 스크립트 UID는 제거하여 새 경로와 충돌하지 않게 했다.
- 고정 프레임 높이 24px, 상판 4px 돌출/누르면 원위치, 같은 값으로 충돌·감지 갱신, 양옆 접합용 마감 돌을 공통 사용한다.
- 각 지형의 실제 수평 변 길이에 셰이더의 돌 개수 공식을 적용해 3개 돌 폭(약 137.6~144px)으로 맞췄다. 양끝은 줄눈에 정렬한다. x 이동은 최대 24px다.

## 기존 홈 처리

- 2-7·2-8에는 기존 버튼 아래에 32px 깊이의 실제 홈이 8곳 있었다. 홈 바닥 꼭짓점 2개씩만 점 목록/순서에서 제외하여 주변 보행면을 연결했다. 폐곡선 끝점과 제약 키는 보존했다.
- 이 부분은 2-9와 같은 평평한 지형 위의 시각적 매립 방식으로 바뀐다. SS2D가 새 점 목록으로 지형/충돌을 생성한다. 버튼 높이를 32→24px로 바꾸고 y도 8px 올려 기존 보행면 기준을 유지했다.
- 모든 버튼의 누름 그룹(player/박스/양동이), 유지/순간 방식, 동시 버튼 연결, 대상 경로, 이동량/속도는 작업 직전 사본과 비교해 동일함을 확인했다.

## 도구와 확인

- tools/apply_pressure_insets.mjs: 기본 조사, --apply 적용, --check 저장 결과의 멱등 확인. 씬 전체 재빌드 없이 필요한 노드/리소스 블록만 바꾼다. 내용이 같으면 파일에 쓰지 않는다.
- 적용 전후 씬 리소스 선언 순서 통과. 지형 점 순서/참조와 제약 키, 매립 대상 NodePath 확인 통과. 재계산 후 저장 텍스트가 동일한지 확인 통과.
- 재쓰기 검증 도중 2-8 파일에서 일시적인 UNKNOWN 쓰기 오류 발생. 이후 쓰기가 필요 없는 멱등 검사로 네 씬 모두 적용 완료 상태 확인. 오류를 회피하기 위한 파일 교체나 삭제는 하지 않았다.
- diff 공백 검사 통과. 추적 파일 삭제 없음.
- Godot 실행/헤드리스/엔진 검사 모두 미실행(사용자 안전 규칙). 따라서 실제 렌더링 및 물체가 누르는 동작은 미확인이다.
- graphify update는 출력 없이 종료 코드 1로 실패. git pull은 앞선 시도의 로컬 편집 충돌 상태를 보존하고 강제 병합하지 않았다.
