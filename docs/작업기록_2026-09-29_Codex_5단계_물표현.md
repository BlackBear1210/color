# 5단계 물 표현 — 2-9 적용 및 실제 렌더링 확인

## 변경
- 2-9의 세 웅덩이(A/E/G)에 사용하는 웅덩이_하수도29.gd에서 수면 시각 노드를 z=2로 배치했다. 이전에는 물이 플레이어 뒤에 그려져 수심32px여도 물 위에 서 있는 것처럼 보였다. 잠긴 부분에 물색이 겹쳐지도록 수정했다.
- 해당 컨트롤러에서만 stage5_surface 셰이더 옵션을 켠다. 공용 셰이더의 기본값은 false이므로 다른 스테이지는 기존 표현을 유지한다.
- 끊긴 수면 반사선을 보강하고, 실제 플레이어 원점(발 기준)이 물 영역에 진입하거나22px 이상 이동할 때 타원 잔물결을 추가했다. 최대6개, 1.2초 내 소멸, 30Hz 상태 갱신. 물을 끄면 삭제, 다시 켜면 반응. 180px 이상 순간이동은 기존 자국을 비운다.
- 검정/흰색 수면은 불투명에 가깝게, 회색은 잠긴 다리가 약하게 보이도록 설정했다. 흰 수면의 어두운 잔물결과 공중에 튀는 흰 물방울은 구분한다.
- 물줄기 v3 외관 코드·호퍼 외형·낙수 프레임은 이번에 수정하지 않았다. 기존 물색/혼합/출구 연결을 실제 실행으로 검증했다.
- 세 웅덩이 수심32px와 최소 낙하받이 수심32px, 씬 배치, 충돌과 색 판정은 그대로다. 서 있는 기본 자세에서 다리 부근까지 잠기며 애니메이션 자세에 따라 겹쳐지는 신체 범위는 달라진다.
