## 1. 유령 발판 블러가 테두리/안쪽이 다르게 보이던 문제 ✅

### 원인 (스크린샷에서 지적한 그대로)
`shaders/지형_페인트.gdshader` 의 GHOST MODE 가 모자이크 격자를 **`TEXTURE_PIXEL_SIZE`**
(= 1/텍스처폭) 로 끊었다. SS2D 지형은 **테두리 메시와 채우기 메시가 서로 다른 텍스처**를
쓰므로, 같은 "12 텍스처px" 라도 물리적 블록 크기가 **메시마다 달랐다.**
→ 발판 경계에서 두 격자가 어긋나 "테두리와 안쪽 블러가 다른" 상태.

### 고침 — 노드-로컬 px 격자로 통일
`local_pos`(VERTEX, 두 메시가 **동일**한 노드-로컬 좌표)를 격자로 끊고, 그 스냅을
화면 미분(`fwidth(UV)/fwidth(local_pos)`)으로 UV 에 되돌린다. 이제 테두리·안쪽이
**같은 격자·같은 번짐폭**을 쓴다. 좌우 번짐(`ghost_smear`)도 로컬 px 로 통일.

- 단위가 텍스처px → 노드-로컬px 로 바뀌어서 `지형.gd` 기본값도 조정:
  `유령_블록` 12 → **26**, `유령_번짐` 7 → **16** (범위도 넓혔다).
- 검증: `_ghost_fix.png` 도식 — BEFORE(어긋남) vs AFTER(정렬).

## 2. 전경(L1)이 플레이어를 가리는 문제 + 긴 발판 ✅

### 도형님 질문 "의도인지 실수인지?" → **둘 다 조금씩.**
전경 뒤로 플레이어가 잠깐 사라지는 것 자체는 **좋은 연출**(도형님도 "나쁘지 않다").
문제는 **착지하자마자 완전히 사라져** 위치를 카메라로만 알게 된 것 — 이건 두 실수 탓:
1. **발판이 짧았다**(폭 480). 착지점이 곧 전경 뒤라 걸어 나올 여백이 없었다.
2. **L1 이 너무 빨랐다**(scroll 1.35). 문틀이 화면을 빠르게 쓸어 가림이 길어졌다.

### 레퍼런스 리서치 — 이런 전환을 쓰는 게임
- **INSIDE / LIMBO (Playdead)**: 전경은 **화면 가장자리의 좁은 실루엣**(문틀·기둥·풀)
  이고, 플레이어가 그 뒤를 지나는 건 **짧은 순간**이다. 큰 전경 뒤로 완전히 들어가는
  구간은 **일부러 만든 "가림→드러남" 비트**이며, 그 직후 넓은 밝은 공간에서 다시 보인다.
- **Little Nightmares**: 전경 가구 사이를 누비지만 **밟는 발판은 절대 완전히 안 가린다.**
- 공통 규칙: **① 전경은 가끔·짧게 가린다 ② 착지·조작하는 지형은 전경 밖으로 이어진다
  ③ 방↔방 경계(문틀)에서만 전경이 화면을 "쓸어(wipe)" 전환처럼 쓴다.**

### 이 규칙대로 테스트 씬을 고쳤다
- **발판 폭 480 → 760** 으로 늘렸다(방1~3 전부). 플레이어가 문틀 뒤에 착지해도
  **걸어 나오면 발판 위에서 다시 보인다.** (상승 145 ≤ 점프 160 유지)
- **L1 scroll 1.35 → 1.15**, 그림 알파 0.9. 문틀이 방 경계 근처에 붙어 **경계에서만
  쓸고 지나가는 wipe** 로 읽힌다(레퍼런스 ③).
- 검증: `_ingame_mock.png` — 문틀 뒤 착지 → 긴 발판 위로 걸어 나오는 순간.

> ⚠ 다음 단계 제안: 진짜 아트가 오면 L1 은 **방 경계마다 배치한 개별 문틀 스프라이트**로
>   두는 게 가장 INSIDE 답다(지금은 방 폭마다 반복하는 타일 레이어라 근사치).

## 3. 페인트가 "블럭 날아가는 느낌" → 물 스플래시 ✅

### 도형님 지시
"water 5,6,7,8 이펙트처럼 페인트가 지형에 닿으면 랜덤한 이펙트를 가져와서 퍼지는 느낌을
매번 다르게." (Water 05 물방울 · 06 가시버스트 · 07 넓은 스플래시 · 08 별폭발)

### 만든 것 — `scripts/스마트월드/물감_스플래시.gd` (신규 노드)
명중 지점에서 **매번 다른 물줄기 스플래시**를 그린다. 파티클이 아니라 손으로 그린 이유:
물 이펙트의 핵심은 "모양이 매번 다른 물줄기"인데 파티클은 형태를 못 만든다.

**4 원형을 매 명중마다 랜덤으로 하나 고른다:**
| 원형 | 레퍼런스 | 특징 |
|---|---|---|
| 별폭발 | Water 08 | 사방으로 뻗는 가시 |
| 부채 | Water 06·07 | 튕긴 방향으로 몰린 다발 |
| 왕관 | Water 03·12 | 위로 솟는 물기둥 + 방울 |
| 잔뿌림 | Water 05·16 | 가늘고 많은 잔줄기 |

같은 원형이라도 씨앗이 매번 달라 굵기·길이·각도·끝방울이 전부 다르다. 물줄기는
0.4초 동안 자랐다 스며들 듯 사라진다. 색은 물감색 그대로(검정/흰색) + 반대색 얇은 테두리.

- 배선: `player_action_fx.gd 명중()` 이 스플래시 노드를 스폰. **큰 타원 얼룩(블럭처럼
  보이던 것)은 제거**하고 잔점 파티클만 남겼다(물줄기 사이 물보라).
- 검증: `_splash_sheet.png` — 4 원형 × 3 씨앗, 전부 다른 물버스트.

## 4. 좌상단 HUD → D/OLD 스타일 캡슐 바 (흑백 스위치) ✅

### 도형님 지시
"D나OLD 같은 이미지로 좌상단 표시를 바꿔라. 플레이어가 색을 바꾸면 흑/백 버전이 따로
존재해서 UI 색도 같이 바뀌어 시각 확인 가능하게."

### 만든 것 — `scripts/ui/페인트_HUD.gd` 캡슐 렌더러
점(pip) 흩뿌리기 → **캡슐 게이지 + 후드 캐릭터 얼굴 배지**(D/OLD 레이아웃).
이미지 생성은 못 하므로 **셰이더 없이 절차적으로** 그렸다(디자이너 PNG 오면 교체 가능).

**★핵심: 껍데기(shell)와 채움(ink)이 플레이어 색에 따라 통째로 뒤집힌다.**
- 흰색 차례 → **어두운 껍데기 + 흰 세그먼트** (= 흰 페인트 게이지)
- 검정 차례 → **밝은 껍데기 + 검정 세그먼트** (= 검정 페인트 게이지)
- Shift 로 색 전환 시 HUD 가 흑↔백으로 뒤집혀 **"지금 무슨 색을 쏘나"가 한눈에** 보인다.
- 세그먼트 상태(찬/진행/빈/잠김/빈칸)는 예전 pip 정보를 그대로 담는다(회수·잠김 규칙 유지).
- 얼굴 배지 = 스크린샷 플레이어(뾰족 후드)를 단순화. 껍데기 톤 위에 잉크색 후드.
- 어느 배경에서도 읽히게 배지·캡슐에 어두운 받침 링을 깔았다.
- 검증: `_hud_sheet.png` — 검정/흰색 × 밝은/어두운 배경 4 행. 흑백 스위치가 확실히 보인다.
