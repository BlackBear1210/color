A방 A · 입구 · 갈래점

입구는 가운데 층 왼쪽. 승강기(1600~1856)를 타면 위층 L3, 구멍(2000~2192)으로 떨어지면 아래층 L1, 그냥 걸으면 L2. 어느 길로 가도 끝 방에서 만난다.

B방 B · L3 — 물 위 격자 · 톱 · 검정 커튼

흰 웅덩이 위 검정 격자 4 → 세로 회전톱 2 → 슬롯(흰) → 흰 구간: 원형 레버로 검정 물 커튼을 끈다 · 선반 3 장을 오르면 막다른 곳(CP) → 슬롯(검정) → 가시 구덩이 위 선반 → 구멍으로 끝 방.

C방 C · L2 — 유령 · 저장고 · 발판 · 양동이

가시 구덩이 위 유령(2 발) → 저장고(2 발)로 천장 호퍼 흰 물을 회색으로 → 흰 웅덩이 위를 움직이는 발판으로 → 슬롯(흰) → 흰 양동이를 흰 물에서 채워 버튼에 두면 흰 문이 열린다 → 슬롯(검정) → 끝 방.

D방 D · L1 — 물길

흰 웅덩이 위 검정 격자 → 검정 웅덩이(그냥 걷는다) + 세로 톱 → 직선 레버로 흰 커튼을 옆 구덩이로 돌린다 → 검정 양동이를 채워 배출구에서 E → 굴뚝 호퍼가 회색 → 격자 사다리로 끝 방.

E방 E · 끝 방 — 종합

흰 웅덩이 위 격자 + 유령(2 발) → 박스를 버튼에 → 문 → 출구.
