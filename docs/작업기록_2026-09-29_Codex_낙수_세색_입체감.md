# 세 물색 낙수 본체의 입체감 재작업

## 원인과 변경
직전 낙수 재질은 검정/흰색/회색 모두 연결돼 있었으나 일정한 밝기의 본체 위에 평행선을 추가한 방식이라 종이 띠처럼 보였다. 사용자 지적은 적용 누락이 아니라 재질 품질 문제다.

water_stream_reference.gdshader의 본체 계산을 교체했다. 서로 다른 크기의 흐름 노이즈를 결합하고 흐름 좌표를 왜곡하여 일정한 평행선을 없앴다. 넓은 물살의 밝고 어두운 면, 좁은 반사광, 작은 표면 변화를 분리했다. 횡단면 두께에 따른 가장자리 음영/부드러움을 추가했다.
검정: 어두운 본체와 국소적인 은색 반사. 흰색: 밝은 본체 안의 물살 음영과 반사. 회색: 기존 배경 굴절과 반투명한 명암.
하수도 공통 재질로 세 색 모두 적용된다. 충돌, 호퍼 출구 폭, 색판정, 웅덩이 깊이는 바꾸지 않았다. 흰 공중 물방울의 흰색도 유지했다. 6단계 확인은 보류한다.
