## 3. 흐름 (도면 주석 그대로 · 아래 → 위)

1. **시작 방** — 격자 5 장 → 긴 격자(가운데 방 바닥)를 밑에서 뚫는다. 오른쪽 벽에서 흰색물_2.
2. **가운데 방** — 격자 2 → **투명발판 2** 칠(2 발) → 블록 · CP.
3. **양동이**를 쏴 채우고(1 발) **발판_1**(홀드 · 양동이 전용) 홈에 민다 → **검은지형_1~5** 가 왼벽에서 0.45 초 간격으로 튀어나와 큰 계단.
   E 로 양동이 페인트를 회수하면(FIFO — 투명발판 다음) 발판이 풀려 계단이 들어간다.
4. 계단 꼭대기 → 왼쪽 턱 → **격자 배관**을 밑에서 뚫고 복도. 땅에 박힌 톱(좌우 · 816~1168).
5. 가시 위 **검·흰·검·흰 공중 지형** — 칸마다 공중 색 전환 → 흰 격자 2 → **흰색 지형**.
6. (곁길) 낙사 존 위 발판 2 + **상하 톱 2** → **검은 열쇠** → 도착 문이 열린다 → 되돌아온다.
7. 윗방 바닥을 거슬러 → **벨브_1** 로 흰색물_1 을 끈다 → 격자 검·흰·검·흰·검 → 디딤돌 → 바위 윗면 → **도착 문** → 출구(2-6).

## 6. ⚠ 알아 둘 것

- 도면을 고치면: `python tools/도면_2-5_지형추출.py` → `build_하수도_2-5.gd` → 주행검사.
- **에디터에 옛 2-5 가 열려 있었다면 저장하지 말 것** — 새 씬을 옛 것으로 덮는다. 다시 열 것.
- 검은지형·도착 문은 Node2D 그릇 + 지형(2-4 덮개와 같은 짜임) — 검산·색 비율에서 빠진다. 숨은 계단은 z −1(왼벽 바위 뒤) · 문은 z 1(출구 통로 그림 앞).
- 양동이를 쏘는 페인트는 회수줄 FIFO 에 들어간다 — 투명발판을 먼저 칠했으면 E 두 번까지는 투명발판이 돌아온다.
- 죽으면 페인트 리셋으로 양동이도 빈다 → 계단이 들어간다(블록 CP 에서 다시 쏜다). 열쇠·벨브는 그대로.
- `stage_2_5_월드.gd`(옛 2-5 전용 월드)와 Codex 정적 검사 `tools/test_stage25_static.py` 는 이제 옛 판용이다 — 새 씬은 공통 `월드.gd`.
