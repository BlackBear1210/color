도형님: "체크포인트 모양을 바꿔야 할 거 같은데" → 시안 3 종(성수반 · 매달린 등불 · 벽 문장) 중 **A 성수반** 확정.
추가 지시: "불이 꺼져 있다가 플레이어랑 닿으면 불빛이 나면서 흰색 잉크가 채워지게".

## 왜 바꿨나
- 옛 잉크 등불(`lantern.svg`)은 꺼지면 회색 항아리처럼 보였다.
- 하수도 벽마다 철창 벽등(장식)이 있어 "빛 = 체크포인트" 신호가 겹쳤다.
- 성수반은 벽등·쇠사슬 승강기·밸브 어느 것과도 실루엣이 안 겹친다. 윗단이 호퍼 입구와 같은 상자 테라 하수도 기물과 한 벌.

## 무엇을 했나
- 그림: `tools/생성_체크포인트_성수반.py` → `assets/textures/props/checkpoint_font/font_body.png` (96×108, 게임 1:1).
  가시 도구(`생성_가시_주철.py`)의 주철 재료(호퍼 원화 금속 결·리벳·외곽선/그림자)를 빌려 굽는다. 기둥에 후드 문장 새김. 씨앗 고정 → 멱등.
  ⚠ 새 PNG 는 임포트가 필요하다(`--import` 또는 에디터 포커스). 임포트 전에는 `ResourceLoader.exists` 가 false 라 옛 등불이 나온다(실측).
- `scripts/장애물/체크포인트.gd`
  - `모양`(0 = 성수반 · 기본 / 1 = 옛 등불) · `잉크_색_기억`(기본 끔 = 항상 흰 잉크, 켜면 닿은 순간 `선택색()`).
  - **닿으면 스스로 켠다**(`body_entered` · player 그룹만). 하수도 `월드.gd` 는 체크포인트를 켜 주지 않아서(부활은 자동 안전지점) 지금까지 하수도 체크포인트는 지나가도 안 켜지는 장식이었다. stage_lab·2-5 월드의 `켜기()` 와 겹쳐도 `활성` 으로 한 번만.
  - 부활 위치·색 기억 로직은 안 건드렸다.
  - 연출: 꺼짐 = 대야 0.50 명도 · 켜기 = 빛 링 + 광원(1.1 → 0.7, 잉크 수면 40 위, 차가운 흰빛) + 대야 0.72 + 0.08 초 뒤 0.9 초에 걸쳐 홈에 잉크 차오름 → 가득 차면 오른쪽 테 끝에서 1.7 초 주기 방울 + 바닥 튐 + 수면 반짝임.
  - ★실측 조정: 처음엔 등불 값(대야 1.0 · 빛 1.6)으로 켰더니 주철이 하얗게 날아가 흰 잉크와 한 덩어리가 됐다 → 위 값으로 낮춤.
  - 켜진 성수반만 화면에 보일 때 매 프레임 다시 그린다(에디터에서는 안 돈다).
- 확인: `tools/촬영_체크포인트_성수반.gd`(창 모드) → `docs/스크린샷_2026-09-30_체크포인트_성수반/` — 활성 false → 닿은 뒤 true · 채움 1.0 · 잉크색 흰.

## 주의
- 체크포인트 씬은 **모든 챕터 공용**이다. 기본이 성수반이 됐으니 집 챕터에서도 성수반이 선다. 집에 등불이 맞으면 그 인스턴스만 `모양 = 등불`.
- 성수반은 `걸이높이` 를 무시하고 늘 바닥에 선다.
- 흰 잉크 고정이라 검정 몸으로 지나가도 흰 잉크가 찬다 — 부활 색은 여전히 월드가 정한다. 색을 보여 주고 싶으면 `잉크_색_기억`.
