# 레벨 디자인 상세 설계 — 집 안 / 하수도 / 도시 / 스팀펑크

> 작성: 2026-08-17 · 도형
> 요청: "각 스테이지별 상세 레벨 디자인 구조와 기믹 배치를 설계해줘"
> 기존 문서와의 관계: [레벨디자인_가이드.md](레벨디자인_가이드.md) 는 **규칙표**(물감 이코노미·소프트락 금지),
> 이 문서는 **이 4개 스테이지의 구체적 배치**다. 수치는 전부 `scripts/스마트월드/지형규칙.gd` 상수에서 가져왔다.

## 0. 먼저 — 지금 프로젝트의 챕터표와 어긋나는 부분 (결정 필요)

요청하신 4스테이지는 지금 `scripts/스마트월드/챕터.gd` 의 챕터표와 **다릅니다.**

| 요청 | 지금 프로젝트 | 판단 |
|---|---|---|
| 1. 집 안 | (없음) | **새로 추가.** 챕터 0 = 튜토리얼 |
| 2. 하수도 | 챕터 2 "지워지는 물" · 스마트월드_4 폐수로 | **이미 있다.** 재활용 가능 |
| 3. 벽을 넘어 도시로 | 챕터 3 "올라가는 도시" (팔레트·BGM만 준비됨, 씬 없음) | 이 문서대로 만들면 된다 |
| 4. 스팀펑크 | (없음) | **새로 추가.** 챕터 4 |
| — | 챕터 1 "잠식된 숲" (스마트월드_1·2·3) | 요청에 없다 → **버릴지 유지할지 결정 필요** |

> ★권장: 숲(챕터1)을 버리지 말고 **집 안 → 하수도 → 숲 → 도시 → 스팀펑크** 로 두는 것.
> 이미 4개 스테이지가 플레이 가능한 상태이고, "집에서 나와 하수도를 지나 벽 밖(자연)을 본 뒤
> 도시로 들어간다" 는 흐름이 요청하신 3번("벽을 넘어 도시 안으로")과도 맞습니다.
> 순서를 바꾸는 작업은 `챕터.gd` 표의 **줄 순서만** 고치면 끝납니다(씬은 안 건드림).

## 1. 공통 — 이 게임의 물리에서 역산한 설계 격자

레벨을 그리기 전에 이 숫자를 옆에 두어야 합니다. 전부 실측값입니다.

| 항목 | 값 | 출처 / 의미 |
|---|---|---|
| 플레이어 폭 × 키 | 44 × 97 px | 실측 |
| 점프 높이 / 거리 | 160 / 160 px | `Player.tscn` 기본 (씬마다 튜닝 다름 ⚠) |
| **안전 오름 단차** | **128 px** | 점프 높이의 80%. 이걸 넘으면 "이론상 가능, 실제로는 못 넘음" |
| **안전 건널 간격** | **128 px** | 같은 이유 |
| 최소 통로 높이 | 128 px | 키 97 + 여유 |
| 최소 발판 폭 | 64 px | 폭 44 + 여유 |
| 지형 점 최소 간격 / 최대 단차 / 최대 경사 | 64 px / 48 px / 40° | `지형규칙.gd` — 새 지형은 반드시 통과시킬 것 |
| **치명 낙하 거리** | **520 px** | 이보다 한 번에 떨어지면 즉사 = "구멍 = 죽음" |
| **1화면** | **2341 × 1317 px** | 1920×1080 ÷ 줌 0.82. 페이싱을 "몇 화면" 으로 세면 편하다 |

**페이싱을 화면 수로 세는 습관을 권합니다.** 아래 설계는 전부 "몇 화면짜리 구간" 단위입니다.
장애물 간격을 px 로 세면 화면 밖 상황을 상상하기 어렵습니다.

### 원칙 → 이 프로젝트에서의 구체적 규칙

| 요청하신 원칙 | 이 프로젝트에서 지킬 형태 |
|---|---|
| 얇은 1차원 플랫폼 금지 | 모든 발판은 **아래로 뿌리가 있어야** 한다. `tools/지형_다듬기.gd` 로 검사 → 뜬 것 0 |
| 묵직한 덩어리 지형 | 바닥 폴리곤은 화면 아래까지 닫는다(`바닥끝y`). 방은 "덩어리에서 파낸 공간" |
| 장애물 다닥다닥 금지 | 같은 종류 기믹은 **최소 1.5화면(3500px)** 띄운다 |
| 무의미한 긴 텀 금지 | 도전 없는 구간은 **최대 1화면**. 그 이상이면 볼 것(전경·연출)을 준다 |
| 같은 행동 연속 금지 | 동일 동작 반복은 **3회까지**. 4회째에는 반드시 변형을 넣는다 |
| 신규 기믹 1개 | 스테이지당 신규 1개. 조합은 **각각을 따로 소개한 뒤에만** |
| 목표를 먼저 보여준다 | 스테이지 시작 지점에서 **목표가 화면 안에 있거나**, 첫 1화면 안에 실루엣으로 보인다 |
| 파도형 난이도 | 아래 각 스테이지의 강도표(1~5)가 오르내리는지 확인 |

## 2. 1스테이지 — 집 안 (튜토리얼 · 수직 상승)

### (1) 도입 메커니즘 — **딱 1개: 물감총으로 칠하면 밟을 수 있다**

무색 발판(`무색일때_통과 = true`)이 이 스테이지의 유일한 신규 요소입니다.
색 전환(Shift)·회수(E)·회색 리스크는 **여기서 가르치지 않습니다.** 2스테이지 몫입니다.

> 근거: 지금 코드에서 "회색이 되면 되돌릴 수 없다"(`페인트_코어.잠긴_발수`)가
> 가장 가혹한 규칙입니다. 첫 스테이지에서 그걸 만나면 튜토리얼에서 소프트락이 납니다.

### (2) 시작과 끝

- **시작**: 거실 바닥 왼쪽. 소파·탁자 실루엣 사이에서 깨어난다.
- **★목표를 먼저 보여준다**: 시작 지점에서 화면 오른쪽 위에 **굴뚝 입구**가 보인다.
  굴뚝 안쪽에서 빛이 새어 나오고, 그 빛이 거실 바닥에 사선으로 떨어진다.
  → "저기로 올라가야 해" 가 UI 없이 읽힌다.
- **끝**: 굴뚝을 타고 올라가 지붕 밖으로 나간다 → 카메라가 줌 아웃되며 도시의 벽이 보인다
  → 2스테이지(하수도) 입구가 화면 아래쪽에 보인다 = **다음 목표를 미리 심는다**.

### (3) 템포

| 구간 | 길이 | 강도 | 내용 | 지형 형태 |
|---|---|---|---|---|
| A 깨어남 | 1화면 | **0** | 조작만. 낙사·장애물 없음 | 통짜 바닥 하나. 벽에 박힌 두꺼운 걸레받이 |
| B 첫 칠하기 | 0.7화면 | **2** | 탁자에 오르려면 무색 발판 1장을 칠해야 한다. 실패해도 안 죽는다 | 탁자 = 바닥까지 다리가 내려온 덩어리 |
| C 탐색/휴식 | 1화면 | **1** | 책장·난로. **선택적 챌린지 ①** (책장 위 비밀 열쇠) | 책장은 벽과 하나의 매스 |
| D 3연속 칠하기 | 1.2화면 | **3** | 발판 3장을 칠해 오른다. 3회까지만 — 4회째 없음 | 계단식 덩어리 |
| E 해소 | 0.6화면 | **1** | 창문. 밖의 도시 벽이 보인다(세계관 예고) | 창틀이 벽 매스를 파낸 구멍 |
| F 굴뚝 진입 | 0.5화면 | **2** | 난로 안으로 들어간다 → **카메라가 조여든다**(§카메라) | 굴뚝 좌우 벽 = 두꺼운 벽돌 매스 |
| G 굴뚝 등반 | 3화면(수직) | **4** | 좌우 엇갈린 벽돌 선반. 무색 발판 2장 포함 | 선반은 전부 벽에서 자라난다 |
| H 탈출 | 0.4화면 | **1** | 지붕. 줌 아웃 · 전경 공개 | — |

**기복 확인**: 0 → 2 → 1 → 3 → 1 → 2 → 4 → 1. 파도형 ✔
**같은 행동 반복 확인**: 칠하기 최대 3연속(D), 이후 굴뚝은 "오르기" 로 동작이 바뀐다 ✔

### (4) 지형 — "공중에 붙이지 않는" 구체적 형태

```
   ┌── 굴뚝 (안쪽 320~400px) ──┐        ← 좌우 벽은 두께 200px 이상
   │  ▄▄▄            ← 선반은 벽에서 자란다 (브래킷으로 이어짐)
   │        ▄▄▄
   │  ▄▄▄
   ╞═══════════════════════════╡
   │ 거실                      │
   │   ┌───┐    ┌──────┐       │        ← 가구는 전부 바닥까지 내려온다
   │   │탁자│    │ 책장 │       │
   ███████████████████████████████      ← 바닥은 화면 밖까지 통짜
```

- 탁자·책장·소파는 **바닥에 닿는 덩어리**로 만든다. 공중에 뜬 판자 금지.
- 굴뚝 선반은 반드시 벽과 이어 붙인다(`지형_다듬기.gd` 의 **버팀대**가 자동으로 해준다).

### (5) 이펙트

| 요소 | 값/방법 | 왜 |
|---|---|---|
| 굴뚝 빛기둥 | `카메라공간.틈새빛` 6개, 위로 갈수록 강 (u²) | "출구는 위" 를 명암으로 말한다 |
| 먼지 | 빛기둥 안에서만 떠다니는 입자 | 빛에 근거를 준다. 빛만 있으면 판판해 보인다 |
| 난로 잔불 | `발광체` 1개, 아주 느린 맥동 | 유일한 따뜻한 광원 = 떠나는 곳이라는 감정 |
| 창밖 안개 | `안개층` 3겹, 전경만 빠르게 | 밖이 위험하다는 예고 |
| 전체 톤 | 챕터 팔레트 신규(집) — 갈회색, 안개 약하게 | 유일하게 "안전한" 스테이지라 대비를 만든다 |

### (6) 카메라 (요청하신 심리스 연결)

구현 완료된 시스템을 그대로 씁니다 → [카메라_공간전환_가이드.md](카메라_공간전환_가이드.md)

1. 거실: 줌 0.82 (넓게, 방 구조 파악)
2. 난로/굴뚝 입구에 몸이 들어가는 순간: 0.65초에 걸쳐 줌 1.10 · 리밋이 굴뚝 좌우 벽으로 좁혀짐
3. 등반 중: 룩어헤드 0 · 세로 추적 강화 · 올라갈수록 시선이 위로

## 3. 2스테이지 — 하수도 (습하고 어두움 · **아래로**)

### (1) 도입 메커니즘 — **딱 1개: 색 전환(Shift)과 반대색 즉사**

1스테이지에서 "칠하면 밟힌다"를 배웠으니, 여기서 "**내 색과 다른 지형에 닿으면 죽는다**"를 가르칩니다.
새 이동 기믹이 필요하다면 **움직이는 발판(유량으로 흐르는 뗏목)** 하나까지만.
(`통과플랫폼.gd` · `움직이는발판.gd` 가 이미 있습니다)

> ⚠ 회색(반대색 덮어쓰기 = 영구 손실)은 **3스테이지로 미룹니다.** 한 스테이지 1기믹 원칙.

### (2) 시작과 끝

- **시작**: 하수구 뚜껑 아래. 위에서 들어온 빛기둥 하나가 착지점을 비춘다.
- **★패턴의 반전**: 1스테이지가 위로 올라갔다면 여기는 **계속 아래로 내려간다.**
  시작 지점에서 아래를 내려다보면 **3~4층 아래의 수문(목표)**이 흐릿하게 보인다.
  (`낙하 룩다운` 이 이미 구현돼 있어 아래를 미리 보여준다)
- **끝**: 수문을 열고 물살에 밀려 나간다 → 벽 밖(3스테이지)으로.

### (3) 템포

| 구간 | 길이 | 강도 | 내용 |
|---|---|---|---|
| A 착지 | 0.5화면 | **0** | 빛기둥 아래. 안전 |
| B 색 소개 | 1화면 | **2** | 흰 지형 / 검정 지형이 **넓게 떨어져** 배치. 죽어도 바로 옆이 체크포인트 |
| C 첫 전환 강제 | 0.8화면 | **3** | 검정 통로 → 흰 통로. Shift 없이는 못 지난다 |
| D 하강 1 | 1.5화면(수직) | **3** | 계단식 하강. 한 단 128px 이하 (한 번에 520px 떨어지면 즉사) |
| E **휴식/탐색** | 1화면 | **1** | 물이 고인 넓은 방. **선택적 챌린지 ②** (수면 아래 발판 → 추가 물감 상한) |

| H 수문 | 0.6화면 | **2** | 레버(`제어레버`) 조작. 긴장 해소 |

**기복**: 0 → 2 → 3 → 3 → **1** → 4 → 4 → 2 ✔ (E의 휴식이 중요)

### (4) 지형

- **수직 갱도형**: 좌우 벽 사이를 엇갈린 선반으로 내려간다.
  → 스마트월드_4 의 `갱도선반_1~7` 구조가 그대로 참고가 됩니다(2026-08-17 에 벽으로 이어 붙였습니다).
- 천장을 반드시 깐다(`천장_점들`). 하수도는 "관 속" 이라 위가 막혀 있어야 한다.
- 방 높이를 **650 ↔ 200px** 로 번갈아 (넓은 홀 ↔ 기어가는 관). 레인월드 문법이자
  요청하신 "집중 구간 → 해소 구간" 의 지형적 표현.

### (5) 이펙트

| 요소 | 방법 | 왜 |

| 물방울 | 천장 부착점에서 떨어지는 입자 (`장식배치` 의 천장 앵커 재사용) | "습하다" 는 소리 없이 그림으로 |
| 수면 반사 | `유체.gd` 의 흔들리는 윗면 + 아래로 번지는 어두운 그라데이션 | 물 = 위험(반대색이면 즉사)이라는 신호 |

| BGM | 기음 43.65Hz(F1) · 떨림 0.13 | 이미 챕터표에 준비돼 있다 |

## 4. 3스테이지 — 벽을 넘어 도시 안으로 (개방 · 수평→수직)

### (1) 도입 메커니즘 — **딱 1개: 회색 (되돌릴 수 없는 실수)**

반대색을 덮어쓰면 회색이 되고 **다시 칠할 수도, 회수할 수도 없습니다.**
개방된 도시는 길이 여러 갈래라 "잘못 칠해도 다른 길이 있다"가 성립하므로
이 규칙을 처음 가르치기에 가장 안전한 곳입니다.

> 소프트락 금지 3규칙([레벨디자인_가이드.md](레벨디자인_가이드.md) §2)을 여기서 특히 엄격히 지켜야 합니다.

### (2) 시작과 끝

- **★진입 방식의 다양화**: 앞 스테이지들이 "옆에서 걸어 들어갔다"면 여기는 **위에서 아래로 떨어져** 들어옵니다.
  수문에서 물살에 밀려 벽 위로 튀어나오고, 낙하하면서 **도시 전경을 통째로 한 번 봅니다.**
  (낙하 중에는 조작이 제한되므로 "보여주기" 에만 쓰는 1.5초 — 컷신이 아니라 플레이 중입니다)
- **목표**: 낙하 중에 화면 오른쪽 끝, 판자촌 위로 솟은 **거대한 굴뚝/철탑**이 보인다. 그게 4스테이지 입구.
- **끝**: 판자촌을 딛고 올라가 철탑 안으로 들어간다.

### (3) 템포

| 구간 | 길이 | 강도 | 내용 |
|---|---|---|---|
| A 낙하 진입 | 1.5초 | **1** | 전경 공개. 조작 없음에 가깝다 |
| B 골목 | 1.2화면 | **2** | 좁고 어두운 골목. 앞 스테이지 문법 복습(전환·칠하기) |
| C 광장 | 1.5화면 | **1** | **개방.** 갈림길 3개가 눈에 다 보인다 = 경로 계획 |
| D 회색 소개 | 1화면 | **3** | 회색을 만들 수 있는 배치. 만들어도 **다른 길로 갈 수 있다** |
| E 회색 함정 | 1.2화면 | **4** | 조준선 상에 반대색이 겹친다. 신중히 쏴야 한다 |
| F **해소** | 0.8화면 | **1** | 옥상. 도시 전경 · 지나온 벽이 보인다 |
| G 수직 상승 | 2.5화면(수직) | **4** | 외벽 파이프·무너지는 계단(`무너지는바위`)으로 오른다 |
| H 철탑 진입 | 0.5화면 | **2** | 카메라 공간 재사용(굴뚝과 같은 문법) |

### (4) 지형

- **수평 → 수직 전환**이 이 스테이지의 성격입니다(챕터표 3번의 기획 문구 그대로).
  A~F 는 수평, G 에서 성격이 바뀝니다. **한 스테이지 안에서 축이 바뀌는 것 자체가 기복**입니다.
- 판자촌: 다닥다닥 붙은 집들을 **하나의 큰 계단 매스**로 만든다. 집 하나하나를 떼어 놓으면
  공중에 뜬 상자가 수십 개 생긴다(스마트월드_1 에서 실제로 그렇게 됐다 — §아래 작업기록 참고).
- 옥상 사이 간격은 **128px 이하**. 그 이상은 도약대나 파이프로 잇는다.

### (5) 이펙트

## 5. 스팀펑크 스테이지 — 기계 · 동적 요소 중심

### (1) 도입 메커니즘 — **딱 1개: 움직이는 것 위에서의 색 규칙**

지금까지 지형은 **가만히 있었습니다.** 여기서는 지형이 움직입니다.
- 스윙 플랫폼(추처럼 흔들리는 발판) · 왕복 승강기 · 회전 톱니(`회전톱.gd`)
- ★핵심: **움직이는 발판의 색을 칠하려면 조준이 예측 사격이 된다.**
  총알이 날아가는 동안 발판이 이동하므로, 지금까지의 "멈춰 있는 표적" 문법이 깨집니다.

> 이건 신규 기믹 1개가 맞습니다 — "움직임" 이라는 한 축이 추가되는 것이고,
> 스윙/승강기/톱니는 그 축의 **변형**입니다. 다만 **각각을 안전한 곳에서 따로 소개**해야 합니다.

### (2) 시작과 끝

- **시작**: 철탑 내부. 거대한 톱니바퀴가 천천히 도는 소리. 화면 위쪽에 **최종 목표(중앙 동력부)**가 보인다.
- **끝**: 동력부에 도달.

### (3) 템포 — ★여기가 가장 조심할 스테이지

동적 요소는 **기다리는 시간**을 만듭니다. 기다림이 겹치면 "지루한 긴 텀" 이 되고,
겹치지 않게 두면 "쉴 틈 없음" 이 됩니다.

| 구간 | 길이 | 강도 | 내용 | 기다림 |
|---|---|---|---|---|
| A 승강기 소개 | 0.8화면 | **1** | 타면 올라간다. 실패 불가 | 3초 |
| B 스윙 1 | 1화면 | **3** | 스윙 발판 1개를 타고 건넌다 | 2초 주기 |
| C 톱니 통과 | 1화면 | **3** | 회전 톱니 사이를 지난다. 색 규칙 없음(순수 타이밍) | 1.5초 주기 |
| D **해소·탐색** | 1.2화면 | **1** | 멈춘 기계실. **선택적 챌린지 ③** (밸브를 잠가야 열리는 비밀방) | 없음 |
| E 예측 사격 | 1.2화면 | **4** | 움직이는 발판을 칠한다 = 이 스테이지의 진짜 주제 | 2초 주기 |
| F 조합 | 1.5화면 | **5** | 스윙 + 예측 사격. **최고 강도** | 2초 |
| G 하강 반전 | 1화면 | **3** | 갑자기 아래로. 승강기가 추락한다 | 없음 |
| H 동력부 | 0.8화면 | **4** | 종합 시험 | 혼합 |

**기다림 규칙**: 같은 주기를 연속으로 두지 않습니다(2초 → 1.5초 → 없음 → 2초).
같은 주기가 3번 겹치면 플레이어는 "박자를 세는 게임" 으로 인식하고 흥미를 잃습니다.

### (4) 지형

- 스팀펑크는 **직선과 원**입니다. 앞 스테이지의 유기적 암반과 대비되어야 합니다.
  → `지형규칙.gd` 의 평탄 구간을 길게(5점) 잡고 경사는 짧게(1점) → 각진 계단.
- ★**움직이는 것도 뿌리가 있어야 합니다.** 스윙 발판은 천장의 축에, 승강기는
  레일에 붙어 있어야 합니다. 축·레일 없는 스윙 발판은 허공의 막대기와 같습니다.
- 배경에 **거대한 톱니와 피스톤**을 넣습니다(움직이는 배경). 플레이에 관여하지 않지만
  "이 세계 전체가 기계다" 를 말해줍니다.

### (5) 이펙트

| 요소 | 방법 |
|---|---|
| 증기 | 파이프 이음새에서 주기적으로 뿜는다. **플레이어를 밀지 않는다**(장식과 위험을 섞지 말 것) |
| 불티 | 톱니 접촉면에서 튄다. 위험 지점을 저절로 표시한다 |
| 조명 | 회전하는 경고등(붉은끼 없는 흑백이므로 **점멸 주기**로 구분) |
| 화면 흔들림 | 큰 기계가 작동할 때 `add_trauma(0.15)` — 이미 구현돼 있다 |
| 톤 | 챕터 4 신규. 도시(3)보다 밝기를 올리고 떨림은 0에 가깝게(기계적) |

## 6. 선택적 챌린지 3개 (요청: "메커니즘을 활용한 선택적 챌린지")

| # | 위치 | 조건 | 보상 |
|---|---|---|---|
| ① | 1스테이지 C 책장 위 | 무색 발판을 **위쪽으로** 칠해야 한다(정규 루트는 아래쪽만) | 열쇠 1 — 최종 스테이지의 문 |
| ② | 2스테이지 E 수면 아래 | 잠깐 잠기며 색 전환 → 반대색 물을 통과 | 물감 상한 +2 |
| ③ | 4스테이지 D 기계실 | 밸브 3개를 **순서대로** 잠근다(FIFO 회수 순서 응용) | 열쇠 2 |

전부 **정규 루트에서 눈에 보이지만 그냥 지나칠 수 있는** 자리에 둡니다.
보이지 않으면 "숨긴 것" 이 아니라 "없는 것" 입니다.

## 7. 만들기 전 체크리스트 (그레이박스 후 반드시)

```bat
:: 1) 지형 점이 규칙을 지키나
Godot --headless --path . -s res://tools/test_지형규칙.gd

:: 2) 통행 가능한가 — 도달률 80% 이상 · 갇히는 곳 0
Godot --headless --path . -s res://tools/레벨검사.gd -- res://scenes/스마트월드/스마트월드_N.tscn

:: 3) ★공중에 뜬 지형이 없나 (요청: "지형 오브젝트를 공중에 붙이지 말 것")
Godot --headless --path . -s res://tools/지형_다듬기.gd -- --씬 res://scenes/스마트월드/스마트월드_N.tscn
::    → "공중에 뜬 것 0개" 가 목표. 0 이 아니면 --적용 으로 뿌리를 내린다

:: 4) 카메라 공간이 붙었나 (수직 구간이 있는 스테이지)
Godot --headless --path . -s res://tools/카메라공간_배치.gd -- --조사
```
