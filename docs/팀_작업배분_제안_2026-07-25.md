## 1. ★먼저 팀이 결정해야 할 것 3가지 (이거 없이는 아래 작업이 겉돕니다)

### 결정 ① — 무색 발판은 "유령"인가 "안전한 징검다리"인가

문서 2건이 정면으로 반대입니다.

| 문서 | 서술 |
|---|---|
| `레벨디자인_가이드.md` §3 V1 | "무색 발판 = **칠해야만 밟을 수 있음**" |
| `기획서_규칙_플로우차트.md` 1-5 | "무색(칠 가능) 발판 = **안전**" |

**후자를 따르면 색칠할 이유 자체가 없어집니다.** (무색이 안전하면 물감을 안 써도 됨)
현재는 전자(유령)로 구현해뒀습니다 — `PaintPlatform.무색일때_통과 = true`.
**어느 쪽이든 이 한 줄만 바꾸면 전 스테이지가 따라옵니다. 정한 뒤 문서 한쪽을 고쳐야 합니다.**

### 결정 ② — 색칠 표현: 스며듦(zone_04) vs 물감 얼룩(zone_05)

두 존은 **지형·규칙이 픽셀 단위로 동일**하고 표현만 다릅니다. 직접 번갈아 보고 정하면 됩니다.
(도형님 1차 의견: "zone5 쪽이 물감 같아서 좋은데 너무 튄다" → 튀던 원인 2건은 오늘 수정 완료)

### 결정 ③ — 챕터 분량과 마감

현재 5스테이지 = 약 8~12분 분량. 30구역 목표 대비 1/6.
**"몇 스테이지를 완성도 있게" vs "몇 스테이지를 그레이박스로"** 를 지금 정해야
LD 2명의 작업 밀도가 결정됩니다.

## 3. 맵 / 레벨디자인 2명

> **작업 방식**: `scenes/장애물/*.tscn` 을 스테이지 씬에 **끌어다 놓고 인스펙터만 조절**하면 됩니다.
> 사용법: `docs/장애물_카탈로그.md` / 수치 기준: `docs/레벨디자인_가이드.md`
> ⚠ `scenes/스테이지/스테이지_N.tscn` 은 생성물이라 직접 편집하면 다음 빌드에 날아갑니다.
> **LD용 신규 스테이지는 `scenes/스테이지/LD_*.tscn` 처럼 새 파일로 만들어주세요.** (P-B 1번 작업이 끝나면 이 제약이 사라집니다)

### LD-A — 챕터 1 다듬기 (기존 5스테이지)

| 순위 | 작업 |
|---|---|
| 1 | **스테이지 1~5 실플레이 튜닝.** 아래 §5 미검증 목록을 하나씩 체감하고 숫자를 고쳐주세요 |
| 2 | 각 스테이지에 **"휴식 구역" 1곳씩** 추가 (걷기만 하는 구간 + 등불). 지금은 긴장이 계속됨 (LD가이드 §1-3) |
| 3 | 회색 함정(V4) 배치 재검토 — 지금 스테이지 3·4 에 1곳씩. 의도대로 "실수를 유도"하는지 |
| 4 | 체크포인트 간격 조정 — 스테이지 4·5 는 낙사가 있어서 지금 간격이 적절한지 확인 필요 |
| 5 | 스테이지별 **"이 방이 가르치는 것" 1문장** 확정 → 안내문 문구 다듬기 |

### LD-B — 챕터 2 신규 제작 (스테이지 6~10)

| 순위 | 작업 |
|---|---|
| 1 | **부품 조합표 작성** — 지금 있는 10종으로 만들 수 있는 상황을 전부 나열 (조합 3개 이상은 각각 소개된 뒤에만) |
| 2 | 스테이지 6~10 그레이박스 — 바이옴은 **판자촌 → 도심 → 고층** 구간 |
| 3 | ★**세로 스테이지** 실험 — 지금 5개는 전부 가로 진행. 고층 구간은 위로 올라가야 스토리와 맞음 |
| 4 | 신규 부품 제안 (필요하면 P-A/P-B 에 요청) — 예: 물에 잠기는 발판, 색을 강제 전환시키는 구역(ColorZone 재활용) |
| 5 | 30구역 골격(LD가이드 §4) 을 현실 분량으로 재조정 |

**두 사람 공통 규칙 (LD가이드 §1)**
- 한 구역 = 한 아이디어. 새 요소는 **낙사 없는 안전한 곳**에서 처음 등장
- 기승전결 배치. 긴장 구간 뒤에는 반드시 휴식 구간
- **소프트락 금지 3규칙** 절대 준수
- 점프 한계: **간격 ≤ 6칸(192px), 단차 ≤ 3칸(96px)** (물리 최대는 10칸/4.6칸이지만 여유를 남길 것)
