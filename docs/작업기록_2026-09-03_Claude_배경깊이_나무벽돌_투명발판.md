## 1. 배경이 앞으로 나오던 문제

### 무엇이 원인이었나

`실내배경.gd` 의 깊이는 체크박스 하나(`앞에_그리기`)로 **−60(맨 뒤) 아니면 +40(플레이어 앞)**
두 값뿐이었습니다. 원화의 "앞바닥 띠" 를 2.5D 전경으로 쓰려고 +40 에 둔 노드가 있었고
(STAGE 2 의 `앞바닥_1층`), 그러면 그 앞쪽에 바닥 지형을 놓는 족족 배경이 그 위를 덮습니다.
**"벽 원화보다는 앞, 지형보다는 뒤"** 라는 가운데 자리를 잡을 방법이 아예 없었습니다.

> STAGE 1 은 2026-08-30 에 이미 이 문제를 만나 **앞바닥 띠를 통째로 없애는** 쪽으로
> 해결했습니다(`build_스테이지_1_2층방.gd` §앞바닥). 이번에는 지우지 말고
> "뒤로 빼 달라" 는 지시라 깊이를 조절할 수 있게 만들었습니다.

### 무엇을 고쳤나

`scripts/스마트월드/실내배경.gd`

```gdscript
@export_range(-100, 100) var 깊이: int = -60      # ★신규. z_index 를 직접 적는다
```

지형(SS2D)은 z 0 이라 **음수를 넣으면 무조건 지형 뒤**입니다.

| 값 | 자리 |
|---|---|
| −60 | 맨 뒤 — 방 벽 원화. 기본값 |
| −59 ~ −20 | 벽 원화 앞 · **지형 뒤**. 앞바닥 띠는 여기 |
| −8 ~ −1 | 지형 바로 뒤 |
| +40 | 플레이어 앞(2.5D 전경) ⚠ 지형을 가린다 |

`앞에_그리기` 체크박스는 **지우지 않았습니다.** 이제 `깊이` 에 −60/+40 을 넣어 주는
편의 스위치입니다. ⚠ 선언 순서가 `앞에_그리기` **다음**이어야 합니다 —
씬은 선언 순서대로 값을 되살리므로 뒤에 오는 `깊이` 가 항상 이깁니다.

### 어디가 바뀌었나 (씬 6 · 빌더 2)

- `scenes/집/스테이지_2_복도계단.tscn` — `앞바닥_1층` z 40 → **−20**
- `scenes/집/집_{2층방,거실,굴뚝,부엌,복도계단}.tscn` — 앞바닥 노드 z 40 → **−20** (옛 씬들도 같이)
- `tools/build_집_복도계단.gd` · `tools/build_집_배경스테이지.gd` — 다시 구워도 같은 값이 나오게

> ⚠ 앞바닥 띠의 원래 목적은 "바닥 지형(두께 300)의 민낯이 원화 마룻바닥을 덮는 것을 가리기"
> 였습니다. 뒤로 뺐으니 **그 가림 효과는 없어집니다.** 실행해 보시고 지형 민낯이 거슬리면
> STAGE 1 처럼 띠를 아예 지우거나, 바닥 지형을 얇게 만드는 쪽이 정답입니다.

바로 그 `.tres` 입니다. 잔디·시멘트·철판은 한 군데도 안 씁니다. 바꿀 것이 없었습니다.

**완전히 같은 파일**이라 그림은 한 픽셀도 안 바뀝니다.

## 3. 투명 발판 (유령 발판) 키트 — 신규

### 무엇이 이미 있었고, 무엇이 없었나

**"안 칠하면 못 밟는다" 는 이미 있었습니다** — `지형.gd` 의 `무색일때_통과`.
없던 것은 **생김새**뿐입니다. 예전에는 노드 전체를 `modulate.a = 0.42` 로
흐리게 만드는 것이 전부라, 어두운 배경에서는 그냥 **검은 판**으로 보였습니다.
(그래서 `투명블럭.gd` 가 사각형을 따로 그리고 있었던 것입니다)

### 셰이더 — `shaders/지형_페인트.gdshader` 의 GHOST MODE

그 지형이 **실제로 든 타일셋 그림**(나무결·벽돌 줄눈)을 이렇게 그립니다.

1. UV 를 `ghost_mosaic` px 격자로 끊어 샘플 → **모자이크**
2. 그 샘플을 가로로 5 번 떠서 평균 → **모션블러(좌우 번짐)**
3. 차가운 회청색 틴트를 30% 섞어 "아직 실체가 아니다" 를 알린다
4. 알파를 `ghost_alpha` 로 낮춘다

★핵심은 가중치가 **`(1 − 칠해진정도)`** 라는 점입니다.
칠해진 얼룩 자리는 가중치 0 → **또렷한 실체**로 남습니다.
총을 쏘는 대로 발판이 한 덩어리씩 "생겨납니다."

- `ghost_amount = 0` 이 기본값이라 **기존 지형은 하나도 안 바뀝니다.**
- 셰이더 안에는 한글을 안 썼습니다(AGENTS.md §7). 주석은 전부 영어입니다.
- sampler 를 함수 인자로 넘기지 않고 `fragment()` 안에 직접 썼습니다(이식성).

### 인스펙터 — `지형.gd` 의 새 그룹 "유령 발판"

| 값 | 기본 | 뜻 |
|---|---|---|
| `유령_모자이크` | 켬 | 끄면 예전처럼 노드째 흐려지기만 한다 |
| `유령_세기` | 1.0 | 0 = 원래 그림 · 1 = 완전히 유령 |
| `유령_블록` | 12 | 모자이크 한 칸(타일셋 px) |
| `유령_번짐` | 7 | 좌우 번짐 폭(타일셋 px) |
| `유령_반투명도` | 0.42 | 안 칠한 자리의 불투명도 |

★**반투명을 누가 거는지가 두 갈래**가 됐습니다 (`_충돌레이어_갱신()`).

- 모자이크 ON → **셰이더가 픽셀마다** 건다. `modulate.a` 는 1.0
- 모자이크 OFF (또는 셰이더가 아직 없음) → 예전처럼 노드째 흐리게

둘 다 걸면 알파가 곱해져 0.42 × 0.42 ≈ 0.18 이 되고, 무엇보다 방금 칠한 얼룩까지
같이 흐려져 연출이 통째로 죽습니다. 그래서 배타적으로 갈랐습니다.

### 씬 — `scenes/집/스마트 매쉬 assets/GHOST_투명발판/`

작업자가 복제해서 점만 끌면 되는 Template 3 개입니다.

| `TEMPLATE_GHOST_WOOD.tscn` | `TEMPLATE_WOOD_SOLID` | 방 안의 보통 투명 발판 **(기본)** |

## 4. "칠하기 허용" 체크박스

**이미 있었습니다.** `지형.gd` 의 `@export var 칠하기_허용: bool = true` 이고,
에디터에서 지형 노드를 고르면 **인스펙터 > 색칠 > 칠하기 허용** 으로 뜹니다.
`명중()` 첫 줄에서 `"blocked"` 를 돌려주고 페인트코어가 탄약을 환급합니다.

없던 것은 **문서**였습니다. `README_지형찍기.md` §12 표와
`README_투명발판.md` §4 에 적었습니다.

> ⚠ 투명 발판에서 이걸 끄면 **유령이 아니라 그냥 단단한 발판**이 됩니다.
> 칠할 방법이 없는데 "안 칠하면 못 밟는" 발판은 영영 못 지나가는 벽이라,
> `밟을_수_있나()` 가 알아서 단단한 지형으로 되돌립니다.
> 즉 이 체크박스 하나로 **투명 발판 ↔ 보통 발판**을 오갈 수 있습니다.

### `test_집_칠하기와빛.gd` 를 고친 이유

예전 검사는 `modulate.a ≈ 0.42` 를 봤습니다. 이제 기본값에서는 셰이더가 알파를 걸고

→ "modulate 가 0.42 인가" 가 아니라 **"어느 쪽이든 반투명한가"** 라는 규칙을 봅니다.
덤으로 "둘 다 걸리지는 않았는가"(이중 알파) 검사를 한 줄 더 넣었습니다.
