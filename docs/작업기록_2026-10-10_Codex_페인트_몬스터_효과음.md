# 2026-10-10 · Codex · 페인트·몬스터 효과음 5종 적용

## 요청과 적용

사용자가 Downloads에서 지정한 ElevenLabs Opus 효과음 5개를 게임용 모노 Ogg Vorbis로 변환했다. 다운로드 원본은 변경하지 않았다.

| 출력 (`assets/audio/sfx/`) | 길이 | 적용 |
|---|---:|---|
| 플레이어_페인트발사.ogg | 0.312초 | 스마트월드·프로토·구형 총의 실제 발사, 덤불 직접 칠하기 |
| 플레이어_페인트명중.ogg | 0.255초 | 각 투사체의 실제 지형·양동이 등 물체 충돌, 덤불 직접 칠하기 |
| 몬스터_걷기.ogg | 0.388초 | 순찰몬스터 실제 이동 중 0.4초 간격 |
| 몬스터_페인트발사.ogg | 0.825초 | 현재 적 페인트 공격 장치인 페인트분사기, 다발당 한 번 |
| 몬스터_페인트명중.ogg | 0.293초 | 분사기 총알의 실제 지형·물체 충돌 |

현재 `순찰몬스터.gd`에는 걷기만 있고 페인트 발사 행동은 없다. 공격 행동을 새로 추가하지 않았으며, 몬스터용 발사·명중음은 기존 `페인트분사기.gd`와 `총알.gd`의 `장치발` 분기에 연결했다. 앞으로 몬스터 공격을 구현할 때 같은 음원을 사용할 수 있다.

## 처리와 코드

- `tools/생성_페인트_몬스터_효과음.py`: 원본을 다시 읽는 멱등 변환. 무음 제거·모노화·최대치 0.8 정규화·짧은 페이드. 여러 발걸음/명중이 들어 있는 원본에서 한 동작 구간을 선택했다.
- 실행: `python tools/생성_페인트_몬스터_효과음.py` (numpy, soundfile 필요). 기본 원본 폴더는 사용자 Downloads이며 `--source`로 지정 가능.
- `scripts/페인트_효과음.gd`: 실제 사건 위치에서 AudioStreamPlayer2D로 재생. 거리 감쇠, 종료 시 자동 삭제, 씬 변경 시 정리. 총알 대신 현재 씬에 붙여 명중음 꼬리를 보존한다. 새 음원은 런타임 load로 읽어 에디터 임포트 전 파싱 실패를 피한다.
- 발사 -10dB, 플레이어·장치 명중 -12dB, 장치 발사 -13dB, 몬스터 발걸음 -16dB. 발걸음 높낮이 0.96~1.04로 반복감을 줄였다.
- 공중 수명 만료는 명중음을 내지 않는다. 삭제 예약/종료 플래그로 중복 충돌 소리를 막았다. 플레이어 ActionFX 유무와 별개로 소리가 난다.
- 씬·색 규칙·탄약 계약·몬스터 공격 패턴은 변경하지 않았다. 양동이 전용 금속 음원은 이번 첨부에 없어 플레이어 물감 명중음을 공통 사용한다.
