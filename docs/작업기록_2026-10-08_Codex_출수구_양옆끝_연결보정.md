# 작업기록 — 2026-10-08 Codex 출수구 양옆 끝 연결 보정

## 사용자 지적과 원인
사용자가 표시한 배관 아래 양옆은 돌 테두리가 뾰족하게 끊기고 물이 곧바로 벌어져 어깨가 생겼다. 배관 지름을 물폭의 1.7배로 잡은 반면 승인 원본의 실제 출수 폭은 배관 지름의 약 42%였다. 원본에서 추출한 출수 부분과 본체 폭이 일치하지 않는 상태였다.

## 변경
- scripts/스마트월드/물_힉스필드_출수구.gd: 좁은 독립 낙수의 배관 지름을 물폭 / 0.42으로 맞췄다(56~360px 제한). 원본의 원형 비율을 유지하며 가로로 늘리지 않는다.
- 물 본체의 출구 폭을 73%에서 시작해 40px 안에 벌리던 보정을 제거했다. 원본 출수부와 물 본체가 동일한 폭으로 이어진다.
- shaders/water_reference_frames.gdshader: 출구 바로 아래는 가장자리 흔들림이 약하게 시작하고 아래로 갈수록 자연스러운 굴곡이 나타나게 해 접합부의 미세한 갈라짐을 줄였다.
- 기존 물폭/충돌/색 판정, 호퍼 배관, 넓은 물받이의 공급관 지름은 유지한다. 앞선 범위와 동일하게 2-1~2-4에 연결된 새 출수구에 적용된다.

## 실제 확인
- 사용자가 이미 허용한 Godot 4.6.3에서 같은 카메라, 줌 1.0, 1920×1080으로 다시 캡처했다.
- 수정 전 실제 상세 이미지: docs/visual_review/water_reference_20261008/nozzle_edge_before.png.
- 수정 후 실제 상세 이미지: docs/visual_review/water_reference_20261008/stage_2-4_detail.png.
- 확대 전후 비교: docs/visual_review/water_reference_20261008/nozzle_edge_before_after.png. 왼쪽은 이번 지적 전, 오른쪽은 이번 수정 후이며 둘 다 실제 게임 렌더다.
- 네 스테이지의 after PNG 및 실제 엔진 48프레임 움직임을 다시 확보했다. 전용 검사 결과는 reference_check_final.log에 기록한다.
- 전체 입수/재진입/리스폰 플레이 검증과 지정된 전체 검사 13개는 이번 작업에서 수행하지 않았다. 관련 지침 문서가 없는 상태는 이전 기록과 동일하다.
- 원본과 같은 비례와 연결을 목표로 보정했으며 생성형 원본과 완전히 동일한 유체 시뮬레이션이라고 주장하지 않는다.
추가 보정: tools/rebuild_water_joints.py에서 물에 맞닿는 돌 테두리의 양옆 작은 삼각형 꼭지를 둥근 접선 마스크로 마감했다. 기존 원본 돌 질감을 유지하며, 마지막 1px 안팎의 마스크 경계만 부드럽게 처리한다.
