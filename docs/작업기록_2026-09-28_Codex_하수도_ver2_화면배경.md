## 배경
- 기존 brick_wall_v04/wall.png 원화 재사용: 시안과 동일 계열의 거친 벽돌·주철 배관·철창이 이미 포함되어 있음.

- 벽등 2개를 벽돌벽 Parallax2D 자식으로 배치하여 벽과 같은 비율로 이동/반복. 번짐은 광원 주변36px에만 정적인 반투명 원으로 구현. 전체 화면 블룸을 쓰지 않아 물과 흰 지형이 번지지 않음.
- 배경 z=-100로 실제 지형 뒤에 위치. 표면 입체감/고정 지형 그림자 캐시 동작 유지.

- 하수도_화면효과_v2.tscn: CanvasLayer5. 페인트HUD100 아래. Control과 ColorRect 모두 mouse_filter IGNORE.
