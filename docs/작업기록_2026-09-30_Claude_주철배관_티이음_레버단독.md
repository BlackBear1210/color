# 작업기록 2026-09-30 · Claude — 주철 배관 · 티 이음 · 레버 단독 (2-5)

## 요청 흐름 (도형님)
1. 2-5 밸브 연결선(Line2D 5 개)이 "프로토타입 급" → 가진 배관(회색 SS2D 키트)을 쓰면?
2. 키트는 게임 분위기와 다르다 → 문제점을 보완한 배관을 만들어 시안으로.
3. 디자인·재질·색감 좋음. 레버·밸브가 관 끝과 연결 안 됨 → 해결.
4. 갈라지는 부분이 끊겨 보인다 → 자연스럽게, 앞으로 다른 스테이지도 자동으로.
   밸브는 관 위에 두면 된다. 레버는? → **레버는 관 없이 호퍼/물 가까운 지형 위에 단독**. 2-5 첫 밸브 자리는 레버로.

## 회색 키트의 문제 → 보완
| 문제 | 보완 |
|---|---|
| 밝은 균일 회색이 장치보다 튄다 | 배경 원화 검은 주철관보다 **한 단계만 밝은** 어두운 주철 |
| 매끈한 강관 + 같은 간격 띠 | 호퍼 주철 결 · 볼트 귀 달린 **벽 고정 밴드**(256 마다) · 끝 **플랜지** |
| SS2D 가 모서리를 칼로 자른 직각 | **둥근 엘보**(4 방향 따로 구움 — 돌려 쓰면 빛 방향이 돌아간다) |
| 조명 무반응 | 원통 법선을 해석적으로 계산해 **노멀맵** 동시 굽기(CanvasTexture) |

## 만든 것
- `tools/생성_주철배관.py` → `assets/textures/obstacles/pipe/cast_iron_v1/` : straight_h/v · elbow_pp/pn/np/nn · band_h/v · flange_h/v · **tee_l/r/u/d · tee_x** + 각 `_n` 노멀맵.
  금속 결은 `생성_가시_주철.plate_metal`(호퍼 원화). ⚠ 결을 그대로 쓰면 네모 블록 반복이 보여서 블러 + 세로 섞기.
  ⚠ 티 허브 반길이 1.25r 은 네모 상자로 보였다 → 1.65r.
- `scripts/스마트월드/하수도_주철배관.gd` (@tool, 그림뿐 · 충돌/색 없음)
  - `점들`(수평·수직) → 직관 · 엘보 · 밴드 · 플랜지 자동.
  - `시작_장치`/`끝_장치` : `배관_포트()` 가 있는 장치(제어레버)면 포트에, `크기` 가 있는 물이면 윗면 가운데에 **스스로 붙는다**. 다음 꺾임점을 같은 줄로 당겨 직각 유지. 장치 쪽 끝은 8 더 밀어 넣어 몸체가 덮고, 칼라 자리에 플랜지.
  - **이음점 자동**: 같은 부모 아래 주철배관들을 모아 한 점에 3 방향 → 티, 4 방향 → 십자. 끝점이 다른 관의 곧은 구간 한가운데 놓여도 이음점. 그 점에서는 엘보·끝 플랜지 생략. 이음쇠는 나무 순서상 **가장 뒤의 관**이 한 번만 그린다(앞 관이 그리면 뒤 관이 덮는다).
- `scripts/스마트월드/제어레버.gd`
  - `배관_포트()` — 원형: 축 아래 끝(+32 + `배관_아래_연장`)에서 위로, 칼라는 바퀴 위아래. 직선: 받침 옆면(±29, +6), `배관_방향` 좌/우.
  - `배관_연결됨` — 켜지면 원형 밸브의 옛 가는 축(18px) 그림을 감춘다(굵은 관이 대신 지나간다).
  - `배관_아래_연장` — 바닥이 축 끝보다 낮을 때 관을 바닥까지.
- 레버 역할 정리(코드 기준): 원형 = 물 하나 켜기/끄기(멈춤) · 직선 = 갈래 A/B 맞바꿈(항상 하나만). **직선에 갈래_A 만 주면 켜기/끄기 스위치**(빈 경로는 건너뜀) — 코드 수정 없이 첫 밸브를 레버로 바꿀 수 있었다.
