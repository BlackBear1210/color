| 항목 | 값 |

| Range | 300 |
| Height | 128 |
| Blend | ADD |

| 색 | 중립 `Color(0.92,0.92,0.95)` — BLACK/WHITE 와 **연결하지 않음** |

- 플레이어가 선 `테스트_플랫폼` 은 환경광에서 멀어 **환경광만일 때 어둡다.**
- 보조광을 켜면 그 발판의 나뭇결과 테두리가 살아난다.
- **후광(원형 빛)은 안 보인다.** 판 하나가 살짝 밝아지는 정도.

## 5. Shadow

- Occluder 2 개 (`테스트_브릭` · `테스트_벽`) — **프로덕션과 같은 도구**
  `tools/그림자_가림막.gd` 가 CollisionPolygon2D 를 **읽기만** 해서 만든다.
  랩 전용 그림자 코드를 따로 두지 않았다.
- 그림자를 만드는 것은 **환경광 하나뿐**. 보조광은 항상 shadow OFF.
- 화면 결과: LEFT 광원 → `테스트_벽` → `테스트_브릭` 순서라 **벽돌 벽의 왼쪽 절반이 어두워진다.**

### ⚠ 한 번 헛짚었다 (기록해 둔다)
처음에는 가림막을 **빛이 안 닿는 자리**에 세워서 그림자를 켜도 화면이 안 바뀌었다.
그림자는 "빛이 닿던 면"이 어두워지는 것이라, **광원 → 가림막 → 밝은 면** 순서가
성립하지 않으면 아무 일도 안 일어난다. 그래서 벽 위치를 광원과 벽돌 벽 사이로 옮겼다.

## 6. CanvasModulate / HUD / BLACK·WHITE

- CanvasModulate = **0.62** (프로덕션 표준과 동일). 테스트 씬만 밝게 만들지 않았다.
- HUD 는 **게임과 같은** `scenes/ui/페인트_HUD.tscn` 을 쓴다(layer 100, 좌상단 구석).
  가짜 HUD 를 따로 만들면 "랩에서는 됐는데 게임에서 다르다"가 생긴다.
  그 아래에 작은 디버그 라벨(CanvasLayer 80)만 따로 둔다 — 게임 HUD 와 섞지 않았다.
- Shift 로 BLACK ↔ WHITE 전환 확인: 초상·게이지·플레이어 실루엣이 같이 뒤집히고,
  **보조광 색은 그대로**다(중립광 유지).

### ⚠ 광원 반경만 랩에서 올릴 수 있게 뒀다
판 하나(512 px)짜리 재질 넷 + 벽 + 발판 둘은 **반경 700 짜리 pool 하나에 다 안 들어간다.**
그래서 `광원_반경` 을 인스펙터에 노출했다(기본값은 표준 700).
네 재질을 한 화면에서 나란히 볼 때만 1300 쯤으로 올린다.
**energy · height · blend · CanvasModulate 는 절대 안 올린다** — 그쪽을 올리면
테스트 씬만 밝게 만들어 노멀맵이 좋아 보이게 하는 것이 된다(지시서 §10 금지).
