# 기본 지형의 얇은 상면·옆면 적용

사용자 요청에 따라 stage_2-1의 땅·벽체 28개에 공중 선반과 같은 상면 돌 마감을 적용했다. 기존 자연형 셰이더에 실제 외곽 선분 최대64개를 보내며, 위를 향하는 각 면의 안쪽18~24px에 선반 원본의 윗돌 부분을 반복한다. 넓은 윗면은 제외한 원본 영역을 사용하며 추가 밝기는 안쪽2~4px에만 준다. 오른쪽 면에는2~7px의 약한 음영을 넣고 하단 테두리는 만들지 않는다.

지형의 전체 사각 경계만 사용하던 방식과 달리, 계단과 꺾인 외곽의 각 윗면에 적용된다. 수직 면과 상면을 구분하기 위해 외곽 법선을 사용한다. 이번 스테이지의 대상28개가 양의 면적 방향이며64개 이하 선분임을 확인했다. 다른 프리팹의 점 순서를 뒤집거나 복잡한 경사를 만들 때는 별도 검토가 필요하다.

검정/흰색 마감은 공중 선반의 검정 원본을 같은 명암 변환식으로 사용한다. 페인트 합성 전에 흑백 기본 재질에 적용하므로 색칠/회수와 연결되며, 추가 충돌체나 SS2D를 겹치지 않았다. stage_2-1 노드 속성·점·충돌·상태·공중 발판·장치·배경은 변경 전과 동일하다. 변경은28개 미리보기 재질의 유니폼이며 실행 초기에는 하수도_자연발판.gd가 실제 충돌 외곽으로 준비한다.

재사용 흑백 땅 프리팹의 미리보기 재질도 갱신했다. 에디터에서 외곽을 새로 편집한 경우 저장된 미리보기 선분은 자동 갱신되지 않으므로 재질의 ground_edges를 함께 갱신해야 한다. 실행 초기값은 실제 폴리곤에서 계산된다.

검증: 파일 참조,28개 적용 수,외곽 방향/선분 한도,노드 블록 불변,계단 상면 거리 계산,shader ASCII,git diff --check. Godot 실행/실제 화면/성능/색칠사망 검사는 미실행이다. 셰이더의 면별 거리 계산이 추가되므로 실제 해상도 성능도 후속 확인이 필요하다.
