# §0. 왜 또 바뀌었나 — 한 문단

v03 까지는 "긴 방을 끝·반복 베이·끝으로 쪼개자" 였다. 방향은 맞다.
그런데 지형 생성기가 완성되면서 방의 **뼈대가 숫자로 확정**됐다.
방은 이제 **한쪽 벽에 선반(갤러리)이 차곡차곡 쌓인 홀**이고, 층 간격·선반 두께·
계단 폭이 전부 고정값이다. 배경은 이 격자에 **딱 맞아떨어져야** 한다.
맞지 않으면 그림과 밟는 지형이 어긋나서, 플레이어가 "있는 것처럼 보이는데 못 밟는"
자리를 계속 만난다(이 게임에서 제일 치명적인 오해다).

# §1. ★확정된 방 뼈대 (이 숫자에 맞춰 그린다)

```
        │ ← 홀(빈 공간, 위로 트여 있다) →
 e12 ───│ [ 선반 3 ▓▓▓▓▓▓▓▓ (문) ]
        │                     ↑ 계단 1,152
 e8  ───│ [ 선반 2 ▓▓▓▓▓▓▓▓▓▓▓▓▓ (문) ]
        │                              ↑ 계단 1,152
 e4  ───│ [ 선반 1 ▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓ (문) ]
 e0  ───│ 마루 ──────────────── J 구덩이 ─── 계단밑 통로 ──[계단]
        └───────────────────── 5,760 px (작은 방) ─────────────────────
```

| 값 | px | 설명 |
|---|---|---|
| 격자 한 칸 | **96** | 모든 치수는 96 의 배수다 |
| 층 간격(층 표면 사이) | **384** | e0 → e4 → e8 → e12 |
| 선반(바닥판) 두께 | **192** | 그림에서 **선반 단면**으로 읽혀야 한다 |
| 층 통로 천장 높이 | **192** | 384 − 192. 플레이어 96 px → 천장이 낮은 **서가 통로** |
| 계단 한 단 | 가로 **192** · 세로 **96** | 디딤이 서로 붙은 3 단 |
| 한 층계 계단 전체 | 가로 **1,152** | 이만큼 선반이 짧아진다(위층일수록 짧다) |
| 내려가는 구멍 | 가로 **192** | 선반 바닥에 뚫린 구멍(아래층으로 떨어진다) |
| J 구덩이 | 가로 **192** · 깊이 **192** | 마루에 난 가시 구덩이 |
| 문(연결통로) | 높이 **150** · 안쪽 깊이 **420** | 층마다 **벽 끝**에 하나 |
| 방 크기(작은) | **5,760 × 2,304** (+외곽 벽 768) | 전체 월드 7,296 × 3,840 |
| 방 크기(표준) | **6,912 × 3,456** | 층 4 개 |
| 플레이어 | 44 × **97** | 비율 기준 |

**중요**: 선반은 위로 갈수록 짧아진다(계단 몫 1,152 px씩). 즉 **계단식 피라미드**다.
왼쪽/오른쪽 어느 벽에 붙을지는 시드가 정한다 → 그림은 **좌우 대칭으로 뒤집어 쓸 수 있게**
그려야 한다(비대칭 글자·간판 금지).

# §3. ★절대 규칙 (어기면 다시 그려야 한다)

1. **완성된 방을 위아래로 복제하지 않는다.** 반복하는 것은 `L1_홀바탕` 과 `L2_층베이` 뿐이다.
   바닥 마감·천장 마감은 **실제 경계에 한 번만** 온다(#3·#4·#6 이 그 역할).
2. **발광체 금지.** 이 게임은 굳은 빛을 **실제로 밟는다.** 배경에 켜진 등·촛불·창의
   밝은 빛기둥이 있으면 플레이어가 밟으려다 죽는다. 등은 **꺼진 상태**로 그린다.
3. **후광(밝은 윤곽) 금지.** 물체 둘레의 밝은 테두리는 **밟을 수 있는 발판**으로 읽힌다.
   원본 알파 + 흰/검정/체커 세 바탕에 합성해서 확인해 달라. 검정 바탕을 투명으로 착각하지 말 것.
4. **밝기는 검정 지형에 맞춘다.** 밟는 지형(검정)의 실측 명도는 **0.055 ~ 0.09** 다.
   배경은 그보다 밝되, **흰 지형(칠한 지형)보다는 반드시 어둡게**. 무채색 유지(채도 0 에 가깝게).
5. **밟히는 것과 장식을 섞지 않는다.** 플레이어가 밟는 선반·계단은 **지형이 그린다.**
   배경의 책장·계단 그림이 밟을 수 있는 것처럼 보이면 안 된다 → 배경 쪽 계단·선반은
   **홀 반대편(먼 쪽)에만**, 시차로 확실히 멀어 보이게.
6. **좌우 대칭 사용 가능해야 한다.** 시드가 방을 거울로 뒤집는다. 글자·시계 문자판·
   한쪽으로만 흐르는 그림자는 넣지 말 것.
7. **월드 고정 소품**(L3 중 지형과 같은 자리에 오는 것)은 시차 **1.0** 으로 쓴다.
   그 그림은 지형 격자(96)에 **정확히** 맞아야 한다. 멀리 흐르는 층에 콜리전을 붙이는 일은 없다.

# §4. 커버리지 — 카메라가 끝까지 가도 그림 밖이 안 드러나게

작은 방(월드 7,296 × 3,840 · 화면 1,920 × 1,080 · 카메라 이동 5,376 × 2,760 · 여유 192) 기준,
층별로 **최소 이만큼**은 타일이 깔려야 한다. (1 차 추정식 `V + |s|·D + 2M`)

| 층 | 시차 s | 필요 폭 | 필요 높이 |
|---|---|---|---|
| L1 먼 바탕 | 0.15 | 3,110 | 1,878 |
| L2 먼 건축 | 0.35 | 4,186 | 2,430 |
| L3 중경 소품 | 0.70 | 6,067 | 3,396 |
| L4 전경 | 1.25 | 9,024 | 4,914 |

→ **전경(L4)이 제일 크다.** "전경이니까 여유 필요 없다" 는 반대다.
→ 이 숫자는 **타일을 몇 장 깔지** 계산용이다. 그림 한 장을 이 크기로 늘리라는 뜻이 아니다.

# §5. 검수 방법 (아스트라가 같이 보내 줄 것)

1. **접합 검수 이미지** — A→B→C→A 가로 4 장, 그리고 `L2_층베이` 상하 3 장.
   이음매에 선이 보이면 실패다.
2. **알파 검수** — 원본 + 흰 바탕 + 검정 바탕 + 체커 바탕 4 종 합성.
3. **밝기 검수** — 밟는 지형 검정(0.055~0.09) 패치를 그림 옆에 붙인 비교 이미지.
4. **격자 검수** — 96 px 격자를 얹은 이미지. 선반 단면 192 / 층 pitch 384 가
   격자에 **정확히** 맞는지 눈으로 보이게.
5. 게임에 넣을 **원본 파일과 검수 합성본은 분리**해서 보낼 것(합성본을 게임에 넣지 않는다).
