# 기본 지형 윗면 바깥 모서리 마감

- 요청: 빨간 표시의 볼록한 좌우 끝부터 수정. 모든 새 하수도 기본 지형에 공통 적용하고 맵 제작 프롬프트에 주의사항 명시.
- sewer_natural_platform.gdshader에 ground_top_corner_mask 추가. 실제 ground_edges의 앞뒤 선분 방향으로 볼록/오목/일직선을 구분한다. 닫힌 폴리곤의 중복 끝점은 건너뛴다.
- 윗면 뒤쪽(-4px)은 최대 6px 안쪽, 앞쪽(+4px)은 0px 안쪽으로 알파 마감한다. 따라서 양끝 외곽이 짧은 대각선이 된다. 작은 선분은 길이의 20%로 제한한다. 앞면 아래쪽은 잘라내지 않는다.
- 기본 지형 공통 셰이더이므로 검정/흰색 전용 프리팹과 stage_2-1 기본 지형에 함께 적용된다. 다른 셰이더를 쓰는 옛 집 지형까지 변경하는 의미는 아니다.
- SS2D 점·충돌·플레이어 위치는 수정하지 않았다. 공중 선반 셰이더는 이번 턴에 수정하지 않았다. 노란색/파란색 안쪽 접합부는 이번 범위에서 제외했다.
- 아스트라 맵 제작 및 클로드 SS2D 적용/검증 프롬프트에 전용 프리팹 경로, 사다리꼴 마감, Scale=1, 바깥/안쪽 구분, 저장된 ground_edges 확인, 화면·기능 검증 주의를 추가했다.
- 정적 수치 확인 33개: 폭 16/32/128/192/224/336/1024px의 마감 폭 제한·앞뒤 변화, 좌우 볼록/오목/일직선 구분 통과. git diff --check 통과.
- Godot 컴파일/화면/성능/착지·색칠·사망 테스트는 미실행(AGENTS.md 엔진 실행 제한). 실제 화면의 좌우 끝과 계단 돌출부 확인이 남아 있다. 여러 선분을 검사하는 셰이더이므로 긴 복합 지형에서는 실행 성능도 확인한다.
- Graphify는 기존 uv trampoline 경로 오류로 갱신 불가. 이번 작업은 커밋/푸시하지 않았다.
