# ver.2 시안 차이 수정 및 시각 검증 기준

사용자 실제 스크린샷에서 작은 벽등, 강한 배경 질감과 재질 차이가 확인됨. 이전 정적 검사만으로 시각 적용 완료를 보고한 문제를 수정한다.

## 파일 수정
- AGENTS.md에 시각 작업 완료 조건 추가: 동일 카메라/해상도 실제 캡처, 시안 대조, 입수 시간 검증, 검증 미실행 시 완료 주장 금지.
- 하수도_벽등.gd: 16x28 사각형 외관에서 약30x52 세로형 타원 철망 벽등. 동심원 대신256px 방사형 그라데이션, 주변200x220px 범위에 작은 조명.
- v05 배경: 원화 배율0.75→0.65, 반복998.4x665.6 일치. 명도 중심0.22→0.185, 대비0.9→0.72, 제한0.055~0.30. 플레이 지형과 다른 재질 크기 및 과한 배경 대비 완화 목적. 효과를 전체적으로 더 어둡게 쌓는 방식은 쓰지 않음.
- tools/test_하수도_ver2_시각검증.gd 준비. 실제1920x1080 게임 캡처, 물방울 단위 호출0.12초/소멸 캡처, 개수3~5/수명0.3~0.5 검사. 실제 입수 트리거 및 시각적 일치 판정은 별도 필요.

## 상태
- git pull 최신. GDScript2개 정적 파싱, 반복치 산술 검사 통과.
- Godot 실행 허용을 비동기 질문으로 요청했으며 답변 전에는 실행하지 않음. 사용자 AGENTS.md의 명시적 허용 규칙을 준수.
- 실제 렌더링 미검증. 시안과 동일하거나 완벽하다고 보고할 수 없음.
- 검증 허용 후 실제 캡처를 열고 배경 명도/등 크기/광원/물색/경계/HUD를 대조하고 추가 조정해야 한다.
