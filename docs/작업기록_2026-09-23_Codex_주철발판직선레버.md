# 주철 압력 발판 / 직선 레버 제작

- 승인된 시안을 바탕으로 built-in image_gen에서 투명 부품 아틀라스 제작. 원본을 `assets/textures/obstacles/switch/cast_iron_v1/parts.png`에 복사하고 생성 프롬프트는 같은 폴더 README에 기록.
- `압력버튼.gd`: 고정 프레임+별도 상판. 기존 위로 솟던 눌림을 아래 최대3px로 수정하고 움직이는 매 프레임 다시 그린다. 표시창은 출력 활성, 상판은 실제 무게를 표시하므로 유지형 버튼에서 내린 뒤에도 상태를 이해할 수 있다.
- `제어레버.gd`: 직선형 주철 받침+회전 손잡이. 기존 받침 바닥 y=26 보존. 초기 실제 갈래와 손잡이 각도를 일치시킴. 원형 밸브 아트 및 별도 아트슬롯 우선 규칙 유지.
- 공통 스크립트 변경이므로 world_2_클로드와 동일 스크립트를 사용하는 다른 씬에도 외관 적용. 씬 위치/연결/충돌 파일은 수정하지 않음.
- 정적 확인: 아틀라스 RGBA 1254×1254/투명 배경, 영역 경계 확인. 변경 직전 파일과 충돌·감지·대상 이동·레버 조작/출력 함수 본문 동일 확인. 참조 자산 존재 및 git diff --check 확인.
- Godot 편집기/헤드리스/실플레이 검사는 사용자 안전 예외에 따라 미실행. 실제 지형 접합과 작은 화면에서 가독성, 애니메이션은 엔진 검수 필요. 정적 비교를 엔진 파싱 통과로 간주하지 않음.
- git pull은 FETCH_HEAD 권한 오류, graphify query/update는 출력 없이 종료1. 원격 동기화와 그래프 갱신 미완료.
