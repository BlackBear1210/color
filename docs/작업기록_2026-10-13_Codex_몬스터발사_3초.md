# 몬스터 발사 주기 3초

- 요청: 몬스터 총알을 3초에 한 번씩 발사한다.
- 변경: `scripts/장애물/사격몬스터.gd`의 기본 발사간격을 1.0초에서 3.0초로 바꿨다. 발사 성공 후 쿨다운을 이 값으로 설정하는 기존 동작을 사용한다.
- 적용 범위: 현재 씬에서 이 스크립트를 사용하는 2-8의 몬스터 5개 모두 별도 발사간격 덮어쓰기가 없어 새 기본값을 따른다. 첫 발 준비 시간과 몬스터별 위상 차이, 사거리/높이 조건은 유지했다. 페인트분사기와 플레이어 총은 변경하지 않았다.
- 정적 확인: 씬의 스크립트 연결과 발사간격 덮어쓰기 여부, 성공 후 쿨다운 경로 확인. 수정 GDScript를 로컬 문법 검사기로 파싱했다.
- graphify query/update 실행. 노드 축소 보호가 발생하면 기존 graph.json을 강제로 덮어쓰지 않는다.
- Godot 및 엔진 검사 13개: 명시적 실행 허용이 없어 미실행. 실제 게임 발사 간격 확인은 대기 상태다.
