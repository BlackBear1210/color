# 탐색방 → 수평 복도 → 탐색방 연결

2026-09-28 · Codex

## 범위와 상태

사용자에게 인계받은 통합본 위에서 다음 순서의 첫 항목을 구현했다.
새 진입점 `tools/생성_탐색사슬.gd`가 탐색방 두 개와 `방층.gd`의 수평 복도 하나를 조립한다.
**소스 구현과 정적 확인까지 완료. 이번 변경으로 씬을 굽거나 실제 장면 전환을 실행하지 않았다.**

인계받은 작은 방 10/10·표준 방 6/6 및 엔진 진단 통과는 이전 통합본의 결과다.
이번 변경의 엔진 통과 근거로 재사용하지 않는다. 실행 허가가 없으므로 규약의 사전·사후 엔진 검사도 모두 미실행이다.

## 변경

- `tools/생성_탐색사슬.gd` 신규: 방 → 수평 복도 → 방. 기본 씨앗 1,2.
  - 복도는 내부 약60칸의 수평 연결 시험용이다. 기존 `집_복도()` 설정 객체를 복사해 크기만 조절하고 `방층.파기()`를 사용한다.
  - 연결 시험에 불필요한 복도 선반·관문은 배치하지 않는다. 완성된 복도 콘텐츠를 새로 설계한 것은 아니다.
  - 출구 방향으로 복도를 통과하고 다음 방에 들어오도록 다음 방만 필요할 때 추가 반전한다.
  - 기본 씨앗 생성과 사슬 배치 변환을 구분해 `사슬반전`/`chain_mirror`를 기록한다.
  - 마지막 방은 기본적으로 시험 종점이다. 외부 목적지는 `--다음`으로 지정한다.
  - 생성 결과는 `scenes/집/생성/탐색/사슬/` 아래. PNG·씬·연결 JSON을 생성하도록 구현했다.
  - 모든 방의 검증, 연결 정보, 개구부, 최종 통로 여유 검사 후 저장한다. 실패 시 종료 코드 1.
- `tools/생성기/탐색연결.gd` 신규: 출력 경로 제한, 문 개구부, 사슬 연결 검증.
  - 선택된 두 통로의 외벽에 깊이420을 담는 5칸·높이150을 담는 2칸을 판다.
  - 원본 격자를 수정하지 않고 복사본에 적용한다. 기존 지지면이 없는 통로는 거부한다.
  - 최종 껍데기·섬 폴리곤과 통로 내부 사각형의 교집합으로 막힌 입구를 거부한다.
- `tools/생성기/조립2.gd`: 역할별 기본 방향을 반영한다.
  - 입구 기본=-1, 출구 기본=+1. 따라서 `반대방향 = 요청방향 != 기본방향`이다.
  - 기존 `요청방향 < 0`은 왼쪽 입구를 오른쪽으로, 오른쪽 입구를 왼쪽으로 만들었다.
  - 통로 스펙이 있을 때만 적용한다. 기존 통로 없는 생성 경로는 동일하다.
  - 탐색방 통로 장식 암반은 위·아래 연장을 0으로 지정해 윗층을 가리지 않게 한다.
- `tools/생성_탐색방.gd`: 동일 개구부/최종 통로 여유 검사 적용.
  - `--출력`은 정규화까지 확인해 탐색 폴더 밖으로 나갈 수 없게 한다.
  - 모르는 옵션, 없는 다음 씬, 검증·윤곽·PNG·씬 저장 실패를 실패로 처리한다.
  - 새 씬 루트를 저장 후 해제한다.
- `tools/test_탐색연결.gd` 신규: 엔진 실행 허가 후 돌릴 회귀 검사.
  - 역할×방향 네 조합을 실제 조립 노드로 확인.
  - 작은1~10/표준1~6의 개구부, 원본 불변, 지지면, 최종 통로 여유 확인.
  - 출력 경로 탈출 거부 확인.

## 실행 허가 후 명령

아래 명령은 이번 세션에 실행하지 않았다. 먼저 난수 자가검사 통과 줄을 확인한다.

```powershell
$engine = 'C:/Users/Public/godot46/Godot_v4.6.3-stable_win64_console.exe'
& $engine --headless --path . -s res://tools/test_탐색연결.gd
& $engine --headless --path . -s res://tools/생성_탐색사슬.gd -- --씨앗=1,2 --미리보기
& $engine --headless --path . -s res://tools/생성_탐색사슬.gd -- --씨앗=1,2
```

시작 씬: `res://scenes/집/생성/탐색/사슬/사슬_작은_1_2_1.tscn`.
미리보기 모드에서는 씬을 만들지 않고 PNG와 연결 계획 JSON만 만든다.
실제 세 씬 전환 확인 및 저장본의 지형형태/플랫폼겹침/레벨 검사가 후속 필수다.
