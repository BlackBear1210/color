# 2-9 배경/지형 구분 개선

- 사용자 요청에 따라 밟을 수 있는 지형처럼 보이던 중간 기둥 받침, 가까운 아치 상단 마감/배관 이미지를 배경 씬에서 제외했다. 기존 파일은 보존했다.
- imagegen으로 돌출 구조 없는 평평한 저대비 석조 벽을 생성해 04_quiet_wall.png로 저장했다. 생성 원본 픽셀 후처리 없음.
- 가까운 층은 새 벽 텍스처의 넓은 세로 벽면, 중간 층은 같은 텍스처의 가늘고 받침 없는 세로 실루엣을 셰이더 마스크로 만든다. 수평 끝선을 없애 발판처럼 읽히지 않게 한다.
- 가까운 벽면 사이의 넓은 영역은 열어 둬 먼 터널을 완전히 가리지 않게 했다. 큰 아치는 먼 층에만 남겼다. 시차 비율과 기존 반복 경계 혼합 유지.
- 배경 색을 중간 회색 주변으로 압축: 원본 대비 잔존 비율 먼 층 22%, 중간 28%, 가까운 층 32%. 실제 흑백 지형의 선명한 윤곽/윗면 마감은 변경하지 않았다.
- 물 및 모든 게임 장치/충돌/지형 배치는 수정하지 않았다. 적용 범위는 기존 v03을 쓰는 2-9.
- 리소스 선언/경로, 기존 두 건축물 이미지 참조 제거, 시차 3층 유지, 셰이더 ASCII 및 diff 공백 정적 검사 통과.
- Godot 실행·실제 화면 가독성 검증은 미실행. graphify update는 종료 코드 1로 실패.
