# 검정·회색 유체 디자인

- 흰물 디자인 셰이더에 물색(검정0/흰색1/회색2)을 추가. 혼합 완료된 물보라까지 마지막에 색을 적용하여 검정 물에서 흰 물보라가 나타나지 않게 함.
- 검정 명도0.018..0.188, 회색0.32..0.57, 흰색 기존값. 몸통 명도 범위를 분리. 실제 배경과 알파 합성 시 가독성은 플레이 검수 필요.
- 검정물_디자인.tscn, 회색물_디자인.tscn 재사용 프리팹 추가. 6개 상황을 세 색으로 보는 삼색물_디자인_비교.tscn 추가. 기존 HTML 각 카드에 물 색 선택 추가.
- stage_2-1의 유체7개와 기존 웅덩이에 공용 어댑터 연결. 실제 색/위치/너비/높이/속도/켜짐은 변경하지 않음. 사용자 편집 W5 위치(7930,1030), 속도250 보존.
- 기존 유체_흰물v2.gd 경로는 참조 호환을 위해 유지하되 이제 세 색을 지원. 원래 혼합/사망/페인트 제거 규칙 유지. 세 색 모두 연속 몸통 충돌, 물보라는 비위험 장식. 혼합 시 색 setter가 새 외관에도 전달됨.
- 사용자 요청대로 착수 물보라 형태는 이번 작업에서 변경하지 않았다.
- 정적 검증: 씬 변경이 어댑터 연결에만 한정됨, 7유체 연결, 색 동기화, 명도 구간 분리, 셰이더 괄호 확인 통과.
- Godot는 기존 네이티브 충돌 이력으로 미실행. 브라우저도 앞선 승인 검토 차단 이후 미실행. 실제 렌더/게임플레이 검증은 미완료.
