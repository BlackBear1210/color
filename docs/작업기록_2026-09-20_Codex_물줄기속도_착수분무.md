# 물줄기 속도와 착수 분무 수정

- 사용자 재피드백: 낙하가 느리고 물보라가 작으며 회색 평행사변형 같은 반복 무늬가 거슬림.
- world_2_클로드/stage_2-1.tscn W5_흰물 흐름속도 390→975 (현재 저장값 대비 2.5배). 흰물 디자인 에디터 속도 범위도 2000까지 확대.
- 64px 폭 물줄기 착수 분무 폭224→288. 기존 이미지 하단의 평평한 안개/바닥 부분은 알파로 제거하고 밝은 상부 분무만 유지.
- 양옆으로 튀는 8개 물방울은 서로 다른 위상/주기로 상승 후 낙하. 바닥 아래3px에서 사라지므로 회색 바닥판을 만들지 않음.
- 셰이더 함수의 분무 영역 밖 조기 반환을 추가. CPU 물리/충돌/색판정 변경 없음. 실제 GPU 성능은 미측정.
- 정적 회귀 검사 통과. 웅덩이 및 지형 배치는 이전 변경 그대로 유지.
- 비교 HTML/비교 씬 재생성 완료. 브라우저 새로고침은 자동 승인 검토 시간초과로 거부되어 이번 화면 확인은 미완료.
- Godot 실행 검사는 이전 네이티브 충돌 때문에 미실행. 현재 요청은 엔진 실행을 새로 승인한 것으로 해석하지 않음.
