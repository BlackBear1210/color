## 1. `브릭구조` — 지형 블록 한 개 = 큰 지형 한 덩어리

```
scripts/집/브릭구조.gd  (StaticBody2D, @tool)
```
- **테두리 벽돌 + 안쪽 검정**(참조 영상 스타일). 9-슬라이스라 크기를 아무리 키워도
  벽돌 테두리는 안 늘어나고 **안쪽 검정만** 늘어난다.
- **무색 구조물** = 누구나 안전(검/백 플레이어 둘 다 밟는다). 집 벽·바닥·계단·플랫폼의 뼈대.
  색 퍼즐(칠해야 밟는 발판)은 이 위에 따로 얹는다(§3).

| 인스펙터 값 | 뜻 |
|---|---|
| `크기` (Vector2) | 블록 크기(px). 원점 = **블록 중심**. 콜리전·그림이 이 값을 함께 쓴다 |
| `룩` | 검정_테두리(기본) / 흰색_테두리 / 검정_꽉참 / 흰색_꽉참 — **그림 톤만** 고른다(안전성 무관) |
| `테두리` | 9-슬라이스 벽돌 테두리 두께(px, 기본 60). 이만큼은 안 늘어난다 |

## 2. ★공중 플랫폼 배치 가이드 (도형님이 직접 놓는 법)

### 방법 A — 에디터에서 (권장, 눈으로 보며)

1. `scenes/집/집_2층방.tscn` 열기 → 트리에서 **`지형`** 노드 선택.
2. 자식 노드 추가 → **`브릭구조`** 검색(또는 `StaticBody2D` 추가 후 `브릭구조.gd` 스크립트 부착).
3. 인스펙터에서 **`크기`** 입력(예: 폭 360 · 높이 100), 2D 뷰에서 **위치**(원점=중심) 드래그.
4. 여러 개 놓으려면 만든 블록을 **Ctrl+D 복제** 후 위치만 옮긴다.
5. 저장(Ctrl+S). ⚠ 이 씬은 빌드툴 산출물이라, **툴을 다시 돌리면 덮어써진다.**
   손으로 튜닝할 거면 빌드툴(`build_집_2층방.gd`)을 **다시 돌리지 말 것**(CLAUDE.md 규칙4).

### 방법 B — 빌드툴 코드로 (재현 가능, 여러 개 한 번에)

`tools/build_집_2층방.gd` 의 `_짓기()` 안에서:
```gdscript
# _브릭(지형층, "이름", 중심Vector2, 크기Vector2)   ← 중심 기준
_브릭(지형층, "발판_C", Vector2(1200, 320 + 55), Vector2(360, 110))  # 윗면 y=320
```
- **윗면 y = 중심 y − 높이/2.** 레벨 수치는 "밟는 면(윗면)" 기준으로 이야기하므로
  중심을 넣을 때 `윗면 + 높이/2` 로 적는다(위 예: 윗면 320 · 높이 110 → 중심 375).

### ★반드시 지킬 점프 안전 수치 (보존값 — 어기면 스테이지가 막힌다)

플레이어: 키 97px · 폭 44px · 점프 높이 160px · 점프 거리 240px (`build_집_2층방.튜닝`).

| 규칙 | 값 | 안 지키면 |
|---|---|---|
| **올라가는** 단차(선반 윗면 차이) | **≤ 120px** | 못 올라가 갇힘(검사 한계 128, 여유 8) |
| 가로 건너기 간격 | **≤ 200px** | 못 건넘(거리 240 × 0.85) |
| 발판 위 머리 여유(위 블록까지) | **≥ 103px** | 겹쳐서 못 지나감(겹침 사고 1위) |
| **의도 없는** 낙차 | **≤ 400px** | 경고 비네트 뜸 / 520 넘으면 즉사 |
| 죽이려는 구멍 | **> 520px** 로 깊게 | 어중간하면 "왜 죽었지?" |

⚠ **명목값 ≠ 실측값.** 블록 윗면은 평평하지만, 배치 후 반드시
`godot --headless --path . -s res://tools/레벨검사.gd -- res://scenes/집/집_2층방.tscn`
를 돌려 **[도달불가]·[소프트락]** 이 0인지 확인한다(치명낙하는 의도면 무시).

### 배치 리듬(레벨디자인 가이드 §1)

- **1방 = 1아이디어.** 2층 방은 "내려가기 + 점프 감각 익히기". 새 함정은 여기 넣지 말 것.
- 내려가는 정식 루트는 **선반을 좌우로 엇갈려** 깔아 "조심히 내려가면 산다"가 그림으로 읽히게.
- 내려간 곳에는 **반드시 올라올 길**(계단 선반)을 둔다 — 없으면 갇힌다(2층 방에 `오름_1/2` 로 예시).

## 3. 색 퍼즐을 얹고 싶을 때 (나중 단계)

집 뼈대(브릭구조)는 무색이라 색이 안 죽는다. 색 규칙을 쓰려면 뼈대 **위에** 기존 칠 가능
발판을 얹는다 — `build_원본_집.gd` 의 `_선반색(루트, 이름, x, 윗면, 길이, 색)` 패턴:
- `발판색_.검정 / .흰색 / .무색`(무색 = 칠해야 밟는 유령, 레이어 8).
- ⚠ 흰 발판을 혼자 띄우지 말고 검정 옆에 붙여 "갈림길"로. 색 바뀌는 구간 앞엔 무색(안전) 발판 하나.
- 얹은 뒤 **레벨검사 필수**(무색 발판은 물감 없으면 통과라 통행성이 바뀐다).

## 4. 다음 스테이지(복도·계단) 만드는 법

`build_집_2층방.gd` 를 복제해 `build_집_2층복도.gd` / `build_집_1층계단.gd` 로:
- 배경: `실내배경_S.방_.복도`(복도) / 계단은 `복도`→`거실` 섞임.
- 복도 = 가로로 긴 방(문 지나가기). 계단 = 아래로 내려가는 **단차 120 선반 연속**(좌우 엇갈림).
- 앞뒤를 `연결통로`로 잇는다: 방 출구 → 복도 입구, 복도 출구 → 계단 입구, 계단 출구 → **굴뚝(기존6)**.
- 3장 다 되면 `챕터.gd` 스테이지표에 새 번호로 등록 → `스마트월드_체인` 으로 굽고, 구본 아카이브.
