# 경계(색 구역) 시스템 — 문서

> **작성일**: 2026-07-19
> **한 줄 요약**: 타일맵 지형 위에 겹쳐 놓는 **다각형 "색 구역" 프레임**. 플레이어가 구역 안에
> 들어오면 지정한 색(흑/백)으로 자동 고정되고, 구역 밖에서는 예전처럼 키보드로 자유 전환한다.
> **`player.gd`는 한 줄도 수정하지 않았다** — 색이 다를 때 `_toggle_color()` 만 호출해 맞추는 방식.

---

## 1. 왜 만들었나 (목적)

기존 색 전환은 **키보드**(`toggle_color` 액션)로 플레이어가 직접 흑↔백을 토글하는 방식이었다.
여기에 더해, **레벨 지형에 따라 색이 자동으로 정해지는 구역**을 만들고 싶었다.

- 예: 가로 경계선 위쪽은 **흰색 구역**, 아래쪽은 **검정 구역**.
  플레이어가 위로 가면 자동으로 흰색, 아래로 가면 자동으로 검정이 된다.
- 지형(타일맵)은 디자이너가 나중에 따로 찍고, 이 색 구역은 그 위에 겹쳐 얹는
  **"색을 강제하는 틀"**일 뿐이다. (구역 색과 지형 색을 일치시키는지는 디자이너 자유.)

---

## 2. 파일

| 파일 | 역할 |
|---|---|
| `scenes/경계/color_zone.tscn` | 재사용 색 구역 씬 (`Area2D` + `CollisionPolygon2D`) |
| `scenes/경계/color_zone.gd` | 색 구역 로직 (`class_name ColorZone`, `@tool`) |

- `@tool` 스크립트라 **에디터에서도 틴트가 실시간으로 보인다** — 꼭짓점을 드래그하면 색 영역이 바로 따라온다.
- `class_name ColorZone` 로 등록되어 있어 코드 어디서든 참조 가능.

---

## 3. 어떻게 작동하는가 (로직)

### 3.1 감지 — Area2D 바디 감지
- 구역은 `Area2D`(`monitoring = true`, `collision_mask = 1`)로, 플레이어(CharacterBody2D, 기본 레이어 1)가
  다각형 안으로 들어오고 나가는 것을 `body_entered` / `body_exited` 시그널로 감지한다.
- 시그널에서 `b.is_in_group("player")` 로 필터 → 총알 등 다른 바디는 무시한다.
  (플레이어는 `player.gd._ready()` 에서 `add_to_group("player")` 됨.)

### 3.2 겹침 우선순위 — 공용 스택
```gdscript
static var _stack: Array = []   # 맨 뒤 = 가장 최근 진입한 구역 = 우선
```
- 모든 `ColorZone` 인스턴스가 공유하는 **정적(static) 스택**.
- 구역 진입 시 자신을 스택 맨 뒤로(`append`), 이탈 시 제거(`erase`).
- 매 물리 프레임, **스택 맨 위(가장 최근 진입) 구역만** 실제로 색을 강제한다.
  → 두 구역이 겹치면 "나중에 진입한 구역"이 이긴다.
  → 스택이 비면(=어느 구역에도 없음) 아무도 강제하지 않는다 = **키보드 자유 전환**.
- 씬 전환/노드 삭제 시 `_exit_tree()` 에서 스택을 청소해 유령 참조를 막는다.

### 3.3 색 강제 — player.gd 무수정
```gdscript
var target := ColorDefs.WHITE if zone_color == ZoneColor.WHITE else ColorDefs.BLACK
if _player.get("player_color") != target:
    _player.call("_toggle_color")
```
- 색이 목표와 다를 때만 `_toggle_color()` 를 호출. 흑/백 2색뿐이라 한 번 토글이면 항상 목표 색이 된다.
- `process_physics_priority = 10` 으로 **플레이어의 물리 처리보다 늦게** 실행 →
  플레이어가 키보드로 토글해도 같은 프레임에 즉시 교정되어 **깜빡임이 없다**.

### 3.4 시각화 — 반투명 틴트 (연출용, 로직과 무관)
- `_draw()` 에서 구역을 반투명 색으로 칠해 "여기가 흑/백 구역"임을 눈으로 알려준다.
  - 흰 구역: 흰색 알파 14%
  - 검정 구역: 검정색 알파 24% (→ **검정 구역은 화면이 그만큼 어두워 보인다**)
- `Show Tint` 를 끄면 틴트 없이 투명해진다(충돌 폴리곤만 남음).

---

## 4. 동작 요약표

| 플레이어 위치 | 색 동작 | 키보드 토글 |
|---|---|---|
| **색 구역 안** | 그 구역의 색(흑/백)으로 자동 고정 | 무시됨(즉시 교정) |
| **색 구역 밖** | 강제 없음 (마지막 색 유지) | **자유 전환 가능** |
| **두 구역 겹침** | 가장 최근 진입한 구역 색으로 고정 | 무시됨 |

---

## 5. 사용법 (디자이너 워크플로)

1. 지형 씬에 `scenes/경계/color_zone.tscn` 을 드래그해 넣는다 (여러 개 가능).
2. 자식 **`CollisionPolygon2D`** 를 선택 → 에디터에서 꼭짓점을 찍고 드래그해 원하는 모양을 잡는다.
3. Inspector 에서 **`Zone Color`** 를 `Black` / `White` 중 선택한다. 끝.

> 예시("위 흰색 / 아래 검정"): 흰 구역을 위쪽, 검정 구역을 아래쪽에 딱 붙여 배치하면
> 경계를 넘나들 때 색이 자동으로 바뀐다. 기본 폴리곤은 384×256 사각형이라 모양만 바꿔 쓰면 된다.

---

## 6. Inspector 속성 (튜닝)

| 속성 | 기본값 | 설명 |
|---|---|---|
| `Zone Color` | `White` | 이 구역이 강제하는 색 (Black / White) |
| `Show Tint` | `true` | 구역을 반투명 색으로 표시할지 (연출용) |

**틴트를 조정하려면** `color_zone.gd` 의 `_draw()` 안 알파값을 바꾼다:
- 검정 구역이 너무 어두우면 `Color(0.05, 0.05, 0.05, 0.24)` 의 `0.24` 를 낮춘다 (예: `0.10`).

## 7. 제약 / 나중에 조정할 점

- **겹침을 "회색(중립)"으로 다루지는 않는다.** 플레이어 색은 흑/백 2가지뿐이고, 회색으로 두면
  캐릭터 애니메이션 시트(흑/백만 존재)가 깨진다. 그래서 겹침은 **"마지막 진입 구역 색으로 고정"**
  까지만 구현했다. 겹침을 진짜 안전지대로 다루고 싶으면 별도 로직을 얹어야 한다.
- **플레이어 물리 레이어를 기본값 1로 가정**했다(`collision_mask = 1`). 나중에 플레이어 레이어를
  바꾸면 구역의 `collision_mask` 도 맞춰야 감지된다.
- 이 시스템은 **범용 컴포넌트**다. 원래는 world_1 의 `SwitchZone`(구역 안에서만 키보드 토글 허용)과
  별개 목적으로 만들었으나, §8-1 의 재구축으로 **world_1 에서는 SwitchZone 을 폐기하고 ColorZone 으로
  대체**했다. `SwitchZone` 자체는 `scenes/world_1/zone_02/zone_02.tscn`(팀 회귀 테스트용 단독 씬,
  `zone02_lab.gd`)에만 구 방식 그대로 보존되어 있으니, 그 씬을 건드릴 때만 상호작용을 검토하면 된다.
  (2026-07-21 도형 — §8-1 과의 서술 불일치 수정)

## 8-1. world_1 실전 적용 (2026-07-19 · 도형)

이 시스템이 **world_1 에 정식 적용**되었다 (상세: `작업기록_2026-07-19_도형_경계재구축_zone3_비주얼고도화.md`):

- **zone2**: 경계선 위 = 백 구역 / 아래 = 흑 구역 (기존 SwitchZone 수동 잠금 폐기).
- **zone3**: 높이 밴드 4개(흑↔백 교대) — 수직 등반 중 색이 자동으로 뒤집힌다.
- ★**중립 틈 규칙**: 인접한 두 구역을 딱 붙이지 말고 **28px 틈**을 둘 것.
  회색 전환 발판 윗면 S 기준, 위 구역 아랫변 = `S − 20`, 아래 구역 윗변 = `S + 8`.
  - 틈(28px) < 플레이어 키(47px) → 경계 통과 중 색 공백 없음 (항상 한쪽에 걸침).
  - 발판에 서 있을 때 반대편 구역에 안 닿음 → 스택 다툼/깜빡임 방지(히스테리시스).
- ★**배치 규약**: 구역 진입은 반드시 공중(점프/낙하)에서 일어나게 레벨을 짤 것.
  색 교정은 진입 다음 물리 프레임(우선순위 10)이라, 교정 전에 반대색 발판에 "착지"하면
  색 사망 판정(우선순위 0)이 먼저 걸린다. 경계 바로 옆에 발판을 붙이지 말 것
  (테스트/스크린샷의 순간이동도 발판 위 80px 이상 공중으로).
