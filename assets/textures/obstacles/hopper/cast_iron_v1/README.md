# 주철 호퍼 v1

승인한 초안을 built-in image_gen으로 게임용 3셀 아트로 제작. hopper_atlas.png:1536×1024 RGBA, 각512px 셀. 원본의 투명 픽셀 RGB에는 배경이 남지만 알파0으로 렌더에서 제외된다. 원본 픽셀/알파를 수정하지 않았다.

프리팹: scenes/집/스마트월드_장애물/호퍼_주철_직하.tscn, 좌하/우하도 동일 경로.
비교: scenes/테스트/호퍼_주철_비교.tscn.
폭/높이는 부모 노드 Scale 대신 속성으로 편집. 출구방향을 바꾸면 아트와 출구_포트 위치가 함께 갱신. 입구 y=-높이, 몸통 목 y=0. 기본 폭200, 높이164. 출구 물 폭 기본-1(연결된 물 값 유지).

기존 호퍼의 혼합/색 판정/끊김 유예를 상속한다. 두 공급 유체의 켜짐은 각 밸브/레버가 제어하도록 연결한다. 신규 밸브 장치/좌우 곡선 출수 판정을 이번 아트 제작으로 구현했다고 간주하지 않는다. 특히 좌우형은 노즐만 기울어져 있으므로 유체 그림만 회전해서 연결하지 말고 곡선과 실제 판정을 맞춰야 한다.
기존 맵 호퍼 자동 교체 안 함. Godot 실행 미검증.

생성 프롬프트: 승인된 낡은 주철 몸통, 같은 크기의 직하/좌하/우하 노즐3종, 정면 2D와 얕은 입구, 무채색 금속/적은 리벳, 물·배경·문자 없는 투명1536×1024 시트. 후속: 위치/질감 유지하며 외부 배경만 실제 RGBA 투명 처리.
