# 주철 밸브 손잡이

호퍼 승인 도안의 원형 주철 밸브를 built-in image_gen으로 제작한 handwheel.png. 투명 RGBA 원본 보존. 제어레버.gd의 원형 모드에서 사용한다. 기존 그림 슬롯에 커스텀 텍스처가 있으면 슬롯 우선 동작을 유지한다.
손잡이는 기존 _각도로 회전하고 배관은 고정. E 상호작용, 반경, 연결 유체, 초기 상태, 직선 레버 기능은 유지한다. 중심 점은 켜짐/꺼짐 표시.
생성 프롬프트: 승인 호퍼 하단의 원형 밸브, 정면 원형4살/볼트 허브/이중 테두리, 닳은 무광 주철, 실제 투명 배경, 배관·물·문자 없는 회전용 바퀴 단독 이미지.
