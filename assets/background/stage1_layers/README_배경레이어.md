## 1. 이게 뭔가

`assets/background/room.png` (2135×1200 한 장짜리 그림)를 **알파로 4 겹 잘라낸** 것입니다.
"배경 작업 참고.pdf" 의 Layer 1~4 구성이 실제로 어떻게 보이는지
**엔진 안에서 미리 확인**하려고 만들었습니다.

- 새로 그린 그림이 아닙니다. 원화에서 영역을 오려내고 가장자리를 부드럽게 흐린 것뿐입니다.
- 그래서 잘린 자국(네모난 소프트 엣지)이 보입니다. **정상입니다.**
- 디자이너가 진짜 레이어 PNG 를 주면 **파일만 갈아끼우면 됩니다.** 씬은 안 고쳐도 됩니다.

## 3. 지금 목업의 한계 (회의 때 짚을 것)

1. **L1 이 "문틀"이 아니라 어두운 네모 덩어리로 보입니다.** 사각형으로 오려서 그렇습니다.
   진짜 아트는 문틀 실루엣 모양대로 알파가 잡혀야 합니다.
2. **L4 천장 무늬가 거울 반전되면서 아치 패턴처럼 반복**됩니다.
   진짜 벽면 타일은 "좌우로 이어 붙여도 티가 안 나는 벽지 패턴 + 하단 걸레받이"여야 합니다.
3. **가구 앞/뒤 분리가 아직 진짜가 아닙니다.** 지금은 같은 그림에서 위치만 갈라놓은 것이라,
   침대 앞부분과 헤드보드가 겹치는 자리는 원화 한 장을 나눠 쓴 티가 납니다.
   PDF §1 의 "전후면 분리(Depth Separation)"는 **디자이너가 따로 그려야** 나옵니다.
4. 방 한 칸이 그대로 4 번 반복됩니다. 4 칸이 서로 다른 방처럼 보이려면
   L2·L3 프랍을 방마다 다르게 배치해야 합니다(프랍이 개별 PNG 로 오면 자동으로 가능).

## 4. 디자이너 PNG 가 오면

1. 이 폴더에 같은 이름으로 덮어쓰거나, 새 이름으로 넣고
2. `scenes/집/테스트_2층방_4칸_배경레이어.tscn` 의 `배경/L*/그림` 노드에서 **texture 만 교체**
3. `scroll_scale` 로 속도를 맞춘다 (위 표가 시작값)

프랍이 **개별 PNG 여러 장**으로 오면, 해당 Parallax2D 아래에 Sprite2D 를 여러 개 두고
원하는 x 에 배치하면 됩니다. 레이어(Parallax2D) 자체는 그대로 씁니다.
