# 2-9 석조 아치 시차 배경

## 가독성 후속 수정

현재 씬은 02_columns/03_wall 대신 `04_quiet_wall.png`를 사용한다. 중간 층은 받침 없는 세로 실루엣, 가까운 층은 넓은 평면 벽으로 마스킹하며 큰 아치는 먼 층에만 남긴다. 원본 대비를 줄여 실제 지형과 구별한다. 이전 두 이미지는 보관용이다.

04_quiet_wall 생성 원본: exec-72651a5e-7239-496f-864f-b5ab77c0515a.png. 이미지 편집 없이 복사했다.

2026-09-24 승인 초안 스타일에서 imagegen으로 레이어별 이미지를 새로 제작했다. 합쳐진 시안을 단순 이동시키는 방식이 아니다. 원본 이미지의 픽셀은 후처리하지 않았다.

| 파일 | 용도 | 픽셀 | 가로/세로 시차 |
|---|---|---|---|
| 01_far.png | 불투명 먼 터널 | 1536×1024 | 0.2 / 0.15 |
| 02_columns.png | 투명 배경의 기둥·배관 | 1536×1024 | 0.5 / 0.4 |
| 03_wall.png | 아치 구멍이 투명한 가까운 벽 | 1536×1024 | 0.85 / 0.75 |

세 PNG의 (500,600) alpha는 각각 255/0/0으로 확인했다. 벽 부착 배관은 벽 이미지에 포함하여 상대적으로 미끄러지지 않는다.

전용 씬: scenes/배경/하수도_다층배경_v03.tscn. 기존 반복 경계 완화 셰이더로 가장자리를 혼합한다. 완벽한 무봉제 타일을 보장하는 이미지는 아니므로 실제 이동 중 경계와 건축 반복은 추가 시각 검토가 필요하다.
