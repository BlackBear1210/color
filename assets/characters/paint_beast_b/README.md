# B 몬스터 스프라이트

- 검정/흰색 각각 걷기(walk), 물감통 차오르기(fill), 발사(shoot).
- PNG 시트 6장, 4열×2행, 프레임 512×512, 총 48프레임, 투명 배경.
- 방향: 오른쪽. 왼쪽은 flip_h 사용. 발 기준: 프레임 y=452. 루트 위치 권장: (256,452).
- monster_frames.tres를 AnimatedSprite2D의 SpriteFrames로 불러올 수 있음. 현재 게임 씬에는 연결하지 않음.
- walk: 10fps 반복 / fill: 12fps 한 번 / shoot: 12fps 한 번.
- 첫 발은 fill_first(0~3), 절반에서 유지. 둘째 발은 fill_second(4~7), 가득에서 유지.
- return은 fill을 역재생하는 회수 보조 모션. 실제 플레이어로 돌아가는 물감 효과는 별도 제작 필요.
- 검정 몸체의 fill은 흰 물감, 흰 몸체의 fill은 검정 물감. 검정/흰색 발사는 각각 자기 색 물감.
- 발사 타이밍: 0부터 센 프레임 4(다섯 번째). 탄도·탄환은 게임 로직에서 따로 생성해야 함.
- 원본 생성: Higgsfield GPT Image 2.5. 선택된 B 시안을 참조.
- 검정/흰색 걷기 및 흰색 차오르기/발사는 생성 원본. 크레딧 부족으로 검정 차오르기/발사는 흰색 프레임의 명암·물감 색을 보정한 파생본.
- 차오르기는 정확한 두 발 수위를 위해 정지 몸체와 유리 내부 마스크로 보정. 수위: 0, 1/6, 1/3, 1/2, 1/2, 2/3, 5/6, 1.
- 모든 시트: 후광 제거, 흑백 변환, 프레임 정렬. 생성형 특성상 걷기/발사 시 천·통의 세부 형상이 조금 변함.
- 실제 엔진 검사/게임 화면 확인 미실행. 파일 검사와 자산 미리보기 확인만 완료.
