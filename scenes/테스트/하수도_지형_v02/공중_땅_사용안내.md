# 공중·땅 플랫폼 구분

> 최신 공중형은 v03 석조 선반 아트로 갱신했다. 아래의 초기 요철 수치는 구버전 설명이다. 현재 상면 폭340, 아트 높이60px이며 넓은 윗면 대신 약3~5px의 앞쪽 면만 표시한다. 공중형 재질은 같은 검정 원본에서 셰이더로 흑백을 만들며, 끝돌 보존/중앙 반복 UV를 사용한다. 프리팹 충돌은 알파 밑면을 표본화한 근사이고, 양끝10px는 모따기되어 있다. 땅형은 그대로다.

`기존_자연형_비교.tscn`의 위쪽은 공중, 아래쪽은 땅 플랫폼이다. 왼쪽 검정·오른쪽 흰색이며 노드 Scale은 모두 1이다.

| 사용처 | 프리팹 |
|---|---|
| 밑면이 드러나는 독립 발판 | 자연형_공중플랫폼_검정.tscn / 자연형_공중플랫폼_흰색.tscn |
| 바닥·아래로 이어지는 벽체 | 자연형_땅플랫폼_검정.tscn / 자연형_땅플랫폼_흰색.tscn |

공중형은 상면 폭 340, 좌우 5px 돌출, 하단 높이 45~61px의 벽돌 단차를 갖는다. 땅형은 340×288의 큰 덩어리이며 위 모서리만 조금 마모했다. 땅 하단은 다음 지형과 연결하거나 카메라 밖까지 내려서 쓴다. 공중형을 바닥 채움으로 늘려 쓰지 않는다.

각 프리팹은 SS2D 하나다. 표시 외곽과 충돌 외곽은 같다. 공중형 돌출부도 접촉·색 판정에 참여하므로 주변 벽이나 점프 통로에 5px 여유를 고려한다. 윗면은 평평하다. 무작위 톱니 대신 길게 이어진 돌 덩어리와 작은 깨짐을 조합했다. 줄눈 픽셀과 모든 요철이 정확히 맞물린 자동 타일 시스템은 아니다.

길이를 바꿀 때 Scale 대신 SS2D 점을 이동하고, 기존 벽돌 폭의 단차를 유지한다. 매우 길게 늘릴 때는 점을 추가하되 현재 근접반사 처리는 최대 32개 선분을 사용한다(공중 프리팹 31개). 더 복잡한 외곽은 반사 처리 개선 후 만든다. 텍스처 배율은 0.18을 유지한다. 다른 크기의 에디터 표면 음영은 재질을 고유화하고 surface_bounds를 맞춘다. 실행 초기에는 실제 충돌 외곽에서 자동 계산된다.

`땅지형` 속성은 하단 음영을 끄는 용도다. 모양 자체를 자동 생성하거나 변경하지 않으므로 맞는 프리팹과 재질을 함께 사용한다. 기존 `자연형_얇은발판_*`은 앞선 비교판 보관용이다. 새 배치에는 공중/땅 이름의 프리팹을 사용한다.

Godot 실행 및 이동/색칠 검증은 이번 수정에서 하지 않았다. 기존 스테이지의 발판은 자동 교체하지 않았다.
