## 2. 사용자에게 승인된 외관

- 기본 지형: 벽돌 본체, 얇은 입체 윗면, 뒤쪽이 안으로 들어가는 사다리꼴 마감. 고정된 2D 시점이다.
- 플레이어의 실제 접촉선이 얕은 윗면 중간에 오도록 한다. 발이 뒤쪽 가장자리에 떠 보이거나 앞면에 박힌 것처럼 바꾸지 않는다.
- 지형 외부로 노출된 양옆에 벽돌 마감을 둔다. 다른 지형에 묻힌 면에는 마감을 만들지 않는다.
- 안쪽 직각 접합에서 낮은 지형의 윗면이 높은 벽을 관통하지 않는다. 지형 내부를 가로지르는 윗면 띠도 금지한다.
- 상단 마감돌은 끝에서 얇은 조각으로 잘리지 않도록 정수 개수로 맞춘다. 본체/무늬/색 경계는 해당 텍스처의 줄눈을 맞춘다.
- 공중 플랫폼: 두꺼운 직사각 벽을 잘라 띄운 느낌이 아닌 얇은 석조 선반. 밑면과 끝에 깨진 돌 실루엣, 필요 시 삼각지지대/쇠사슬 장식.
- 검정과 흰색의 식별을 유지한다. 회색 지형이나 고정 흰 외곽선으로 디자인을 대체하지 않는다. 근접 반사는 기존 기능을 유지한다.
- 3번 바닥 벽돌 잔해는 사용자 보류 상태다. 임의 추가하지 않는다.

## 4. 1번: 지형 내부 반대색 벽돌 무늬

`scenes/지형/하수도/색조합/검정속흰벽돌.tscn`, `흰색속검정벽돌.tscn`을 사용한다. 실제 구현은 반대색 텍스처를 같은 UV에서 합성한다. 별도 Sprite나 충돌 지형을 겹치는 방식이 아니다.

- `내부_벽돌영역`: 지형 로컬 Rect2 배열, 최대16개. 각 행의 실제 줄눈에 맞춘다.
- `내부_바탕흰색`: 기본 재질이 흰색일 때만 true.
- `시작상태=0`, `무색일때_통과=false`, `안칠한_바탕도_색이다=true` 유지. 전용 스크립트가 바탕 접촉색을 반환하므로 이 설정은 안전한 무색 지형이라는 뜻이 아니다.
- 시작상태를1/2로 바꾸면 초기 전체 페인트가 무늬를 덮는다. 일반 지형에 이 설정만 흉내 내지 않는다.
- 모든 실제 외곽에서24px 이상 안쪽에 둔다. 구멍이나 오목한 부분도 외곽이다. 외곽까지 무늬를 연장하려면 2번 실제 색 영역으로 전환한다.
- 페인트 시드보다 먼저 합성한다. 색칠 후 반대색 장식이 위에 그대로 남아서는 안 된다. 회수 후 원래 무늬가 복구되어야 한다.
- 현재 에디터 미리보기 재질의 inlay_rects/count와 런타임 노드의 배열은 수동 편집 시 둘 다 갱신해야 한다. 자동 동기화가 구현됐다고 가정하지 않는다.

## 5. 2번: 실제 흑백 맞물림

같은 색조합 폴더의 `세로경계_검흰검.tscn`, `세로경계_흰검흰.tscn`, `가로경계_검흰검.tscn`, `가로경계_흰검흰.tscn`을 참고한다. 세 독립 SS2D 색 영역이며 충돌·색칠·회수는 실제 지형에 연결된다.

- 양쪽 점을 따로 대충 맞추지 않는다. 공유 경로 하나를 만들고 한쪽은 역순으로 쓴다.
- 반 장~두 장 정도로 깊이가 불규칙하게 바뀌며 흑/백 어느 쪽도 더 들어갈 수 있다. 반 장씩 반복하는 지퍼 형태는 피한다.
- 가로 경계도 줄눈을 따른다. 세로 모듈을90도 회전해 벽돌을 세우지 않는다.
- Scale=1, 같은 부모/UV 위상 유지. 내부 경계 틈0·겹침0. 길의 색 전환 틈과 혼동하지 않는다.
- 다른 모듈 아래에 넣으면 마감 이웃 탐색이 되지 않을 수 있다. 최종 접합 지형은 같은 부모에 배치하고 변환/UV를 검산한다.
- 도안 이미지를 위에 붙여 실제 접촉색과 다르게 보이게 만들지 않는다.

## 7. 배치·성능·검수

- 높이160/거리320, 권장 단차110 이하/가로272 이하/머리 공간112 이상. 플레이어44×96. 기존 노출면·착지 위치를 마감 때문에 움직이지 않는다.
- 통행 흑백 전환에는 기존 ≥80px 틈/도약 설계를 검토한다. 벽 내부 맞물림에는 틈을 만들지 않는다. 내부 줄눈 점에는 이동 외곽의16px 격자·최소변90px 규칙을 강제로 적용하지 않는다.
- 물마다 우회 허용형/필수 퍼즐형을 기록한다. 필수형은 점프 중 두 번 색 전환, 색칠, 높은 곳에서 낙하하는 우회까지 확인한다. 448px는 초기 너비 후보일 뿐 보장값이 아니다. 실제 판정 폭과 장치 작동 후 통과를 검사한다.
- `_CachedTrim_*`은 필요 시 생성되는 마감 메시다. 직접 저장하거나 owner를 붙이지 않는다. 매 프레임 전체 지형을 재생성하거나 넓은 본체 셰이더에 모든 이웃 경계 검사를 되돌리지 않는다.
- `tools/build_*`로 편집된 2-1을 재생성하지 않는다. 부분 수정 도구도 대상/멱등성/수동 변경 여부를 먼저 확인한다.

정적 검사 도구: `tools/test_sewer_color_modules.py`, `tools/test_stage21_masonry_joint.py`. 비교 씬: `scenes/테스트/하수도_흑백벽돌_비교.tscn` (플레이어 없는 에디터 비교용).

**검증 상태를 과장하지 말 것:** 모듈 저장 파일37,288점, 기존2-1 접합980점, 추가 접합9,625점의 정적 검사 및 무늬 여유/참조/UV 검사는 통과했다. 이는 Godot 파싱·실행 화면·색칠·회수·사망·통행·FPS 테스트의 통과를 뜻하지 않는다. 새 무늬/캐시 변경의 해당 실행 검증은 미완료다. 실행은 현재 사용자 허가와 저장소 규약에 따른다.

실행 검수 시: 양쪽 바탕/양쪽 물감 → 부분·전체 색칠 → 회수·리스폰 → 외곽 접촉 사망 → 접합 통행 → 저장/재로드 → 화면 마감 → 프레임 시간 순으로 확인한다. 꺼진 `W3b_복도_물`이 총알을 감지하는 알려진 문제도 미수정이므로, 이를 지형 페인트 오류나 이미 수정한 문제로 보고하지 않는다.
