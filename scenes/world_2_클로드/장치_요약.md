# 장치 요약 — 필요한 행만 읽기

2026-09-20 코드 확인. 문서 하단 SHA-256이 현재 파일과 다르면 관련 함수만 다시 읽고 이 요약을 갱신한다. 해시 일치는 정적 요약의 유효성 단서이며 실행 검증을 뜻하지 않는다.

공통 코드 폴더: `scripts/스마트월드/`. 색/너비/통행 설계 기준은 [공통규칙](맵제작_공통규칙.md) §1·§6에서만 관리한다.

사용 예시는 `하수도_오브젝트_사용법.md`의 해당 장치 절만 읽는다. 그 밖의 장치를 쓸 때는 해당 스크립트의 export/명중/회수/사망/리셋을 확인해 필요한 항목만 이 표에 추가한다.

복합 퍼즐 제안은 구현 상태와 구분한다: 저장고→호퍼→통과플랫폼은 기존 연결을 활용 가능. ‘물이 도착하면 문 열림’, 저장량·제한시간, 자동 배출은 지원 여부를 별도 확인하며 기본 기능으로 가정하지 않는다.
