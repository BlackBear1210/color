# 스테이지2 하수도 배경 — 연속성 디자인 가이드

2026-09-14 · 아스트라 · 사용자 검토용 제안. 이미지 제작과 맵별 배치는 아직 진행하지 않았다.

## 1. 핵심 방향

**각 스테이지를 서로 다른 하수도 그림으로 만들지 말고, 하나의 큰 하수처리 시설 안에서 다른 구역으로 이동하는 경험으로 만든다.**

권장 공간 흐름은 `도시 아래의 오래된 배수로 → 물을 모으는 수로 → 배관·펌프 시설 → 깊은 저수 공간 → 오래된 하부 시설`이다. 실제 맵 진행 방향이 상승이면 상부 점검층이나 제어층을 거치는 것으로 해석한다. 무조건 다음 스테이지일수록 아래로 내려가거나 어두워져야 하는 것은 아니다.

플레이어가 느낄 변화는 “다른 게임의 배경으로 바뀌었다”가 아니라 “아까 보였던 물과 배관이 여기로 이어졌구나”여야 한다.

## 2. 끝까지 유지할 공통 디자인

| 항목 | 공통 기준 |
|---|---|
| 건축 | 둥근 석조 아치, 두꺼운 벽돌 벽, 수직 기둥, 철제 배수구 |
| 금속 | 검게 변색된 철재 배관, 플랜지, 볼트, 낡은 점검 구조 |
| 수분 | 벽의 물때, 아치 아래 누수 흔적, 얕은 수증기·안개 |
| 색 | 무채색 중심. 저채도·중간 명도의 배경, 검정/흰색 플레이 지형과 분리 |
| 조명 | 넓고 부드러운 간접광. 날카로운 흰 윤곽과 강한 금속 번쩍임은 억제 |
| 시점 | 2D 횡스크롤용 고정 시점. 깊이는 배경 안의 원근과 레이어로 표현 |
| 재료 크기 | 가까운 같은 깊이의 벽돌·파이프 굵기가 장면마다 갑자기 바뀌지 않음 |

전체를 같은 회색으로 평평하게 칠하지 않는다. 어두운 개구부, 밝은 안개, 중간 명도 벽면을 나누되 작은 무늬 대비는 낮춘다.

회색 배경은 사용할 수 있다. 게임의 회색 안전 규칙은 충돌하는 오브젝트의 규칙이다. 배경에는 충돌이 없고, 밟을 수 있는 상면처럼 보이는 뚜렷한 선반을 줄여 구분한다.

## 3. 무엇을 바꾸고 무엇을 반복할 것인가

장면마다 공통 부품을 많이 유지하고, 한두 가지 특징만 강하게 바꾼다. 출발점으로 공통60~70%, 구역 변형20~30%, 고유 랜드마크10% 정도를 생각한다. 이는 픽셀 면적이나 노드 수를 강제로 맞추는 규칙이 아니라 디자인 비중의 참고다.

- 공통: 벽돌 계열, 아치 형태, 배관 접합 방식, 물때 질감, 조명 성격.
- 변화: 공간 높이, 아치 간격, 물의 존재감, 배관 밀도, 안개 양, 시설의 노후도.
- 고유 요소: 거대한 배수구 하나, 여러 층을 관통하는 수직 관, 먼 펌프실, 저수조 중앙 기둥 등.

한 스테이지에 고유 요소를 여러 개 경쟁시키지 않는다. 길을 기억하게 할 주인공은 한 개, 보조 요소는 한두 개면 충분하다.

## 4. 구역별 진행안

다음 번호 배정은 **디자인 제안**이며 현재 맵의 실제 동선·출구 연결을 확인한 확정 배치가 아니다. 적용 전에 실제 진행 순서와 각 맵의 시작/도착 방향을 대조한다. 이미 수정된 맵을 이 표에 맞추려고 재생성하지 않는다.

| 제안 구간 | 공간 인상 | 주요 배경 | 다음 구역을 예고하는 요소 |
|---|---|---|---|
| 2-1~2-2: 배수로 입구 | 좁고 낮으며 도시와 가까움 | 작은 아치, 비교적 규칙적인 벽돌, 한두 줄 배관, 얕은 수로 | 끝부분에서 더 큰 집수 아치가 보임 |
| 2-3~2-4: 집수 회랑 | 여러 물길이 모이며 공간이 넓어짐 | 가지 배관, 큰 배수구, 반복 아치, 누수 흔적 | 멀리 굵은 주 배관과 펌프실의 구조가 보임 |
| 2-5~2-7: 펌프·분배 시설 | 사람이 관리하던 기계 시설 | 플랜지, 배관 다발, 뒤쪽 정비 통로, 일정한 철골 리듬 | 창이나 아치 너머로 넓은 저수 공간이 보임 |
| 2-8~2-9: 깊은 저수 공간 | 넓고 조용하며 깊이가 느껴짐 | 큰 기둥, 멀리 내려오는 물, 수면 안개, 희미한 반사 | 상부 점검층 또는 하부 배출로의 수직 구조 |
| 2-10~2-11: 점검 갱도·하부 시설 | 높낮이가 크고 오래된 시설의 중심에 접근 | 층을 관통하는 관, 높이 반복되는 벽체, 오래된 배출 아치 | 실제 도착 방향에 맞춰 다음 공간의 일부를 노출 |

2-10의 상승 동선은 저수조 위 점검층으로 올라가는 느낌, 2-11의 하강 동선은 그 시설의 다른 쪽 배출로로 내려가는 느낌으로 연결할 수 있다. 번호가 늦다고 무조건 폐허·괴물 흔적·새로운 서사를 추가하지 않는다.

## 5. 장면 사이를 연결하는 규칙

### 5-1. 이어지는 물체 하나를 정한다

각 전환마다 최소 하나의 연속 단서를 지정한다. 예: 주 배관, 배수 수로, 동일한 아치 벽, 수직 갱도.

예시: A스테이지 끝에서 오른쪽으로 나가는 굵은 관이 보인다. B스테이지 시작 왼쪽에서 같은 굵기·접합 형태의 관이 들어오며 큰 펌프 시설로 이어진다. 관의 한쪽만 갑자기 흰 금속으로 변하거나 굵기가 두 배가 되면 연결감이 깨진다.

상하 이동이면 배관/기둥을 위아래로 이어 준다. 모든 장면을 좌→우 연결로 제작하지 않는다.

### 5-2. 경계는 이전 공간과 다음 공간을 함께 보여 준다

이전 스테이지 마지막 구간에서 다음 구역의 구조가 일부 보이고, 다음 시작 구간에는 이전 구역의 재료와 구조가 남아 있게 한다. 마지막/첫 화면에 전환용 부품을 배치하면 별도 이미지를 썼어도 자연스럽다.

출구 직전에 장식 하나만 갑자기 등장하는 정도가 아니라, 다음 구역의 배관 밀도나 공간 높이가 서서히 나타나게 한다. 이동 속도에 맞춰 대략 반 화면~한 화면 정도의 예고 구간을 출발점으로 삼는다.

### 5-3. 조명과 카메라를 함께 맞춘다

배경 그림만 같아도 씬 전환 때 노출·줌·배경 위치가 급변하면 끊겨 보인다. 전환 전후의 실제 게임 캡처를 나란히 비교한다. 근거 없는 전역 카메라 수정 대신 해당 경계의 배경 배치와 명암부터 조정한다.

물리적으로 연속되는 통로라면 주요 벽/배관 위치까지 맞춘다. 문이나 긴 암부를 거치는 전환은 약간의 구도 차이를 허용하되 공통 단서를 유지한다.

### 5-4. 연결표를 작성한다

| 전환 | 실제 이동 방향 | 공통 단서 | 이전 끝의 위치/굵기 | 다음 시작의 위치/굵기 | 밝기 차이 | 검증 |
|---|---|---|---|---|---|---|
| A→B | 예: 오른쪽 | 굵은 주 배관 | 캡처와 좌표 기록 | 캡처와 좌표 기록 | 급변 여부 | 미확인/확인 |

연속성은 단지 비슷한 그림 두 장을 생성하는 것으로 끝나지 않는다. 실제 경계 위치를 연결해야 한다.

## 6. 레이어 제작 기준

처음부터 모든 구역을 많은 레이어로 만들지 말고, 공통3층을 먼저 완성한다. 아래 속도는 시험 시작값이며 전체 맵에서 조정한다.

| 레이어 | 내용 | 이미지 조건 | 권장 시차 시작값 |
|---|---|---|---|
| 먼 벽 | 희미한 아치·큰 공간의 깊이 | 화면을 채우는 불투명 배경. 작은 무늬 대비 낮음 | 0.20~0.25 |
| 중간 시설 | 배수구·배관·기둥·다음 방 | 실제 투명 배경. 뒤쪽 공간이 보여야 함 | 0.45~0.60 |
| 근접 구조 | 플레이 영역 뒤의 벽 고정구·근접 관 | 투명 부품, 적은 수. 지형과 혼동하지 않게 배치 | 고정 부착물은1.0 |

안개·물방울·희미한 반사는 필요한 구간에만 별도 효과로 추가한다. 모든 그림에 강한 안개를 구워 넣으면 나중에 조절하기 어렵다. 실제 물 퍼즐의 유체는 배경 폭포 그림과 분리한다.

기존 시험은 먼 벽0.25, 중간 아치0.60을 사용한다. 이 두 층을 공통 기준의 출발점으로 쓸 수 있으나, 현재 이미지 크기·위치를 큰 맵 전체에 그대로 복사하지 않는다.

**중요: 플랫폼에 붙은 브래킷·볼트·체인은 플랫폼과 같은 좌표계에 둔다.** 시차 배경의 벽에 붙인 것처럼 보이게 하면 카메라 이동 때 벽에서 미끄러지는 문제가 생긴다. 실제 고정 부위 주변에는 월드 좌표의 근접 벽 패치를 쓰거나, 부착 관계가 모순되지 않는 구도를 만든다.

## 7. 이미지 한 장이 아니라 배경 키트를 만든다

권장 첫 제작 묶음:

1. 공통 먼 벽 반복 패널1종.
2. 공통 중간 아치/기둥 모듈1종.
3. 작은 배수로→큰 집수 공간 전환 모듈1종.
4. 배관 직선·굽힘·분기·끝단 모듈.
5. 입구/집수/펌프/저수 구역의 고유 랜드마크는 구역당1종씩 순차 제작.

처음부터11개 스테이지용 완성 배경11장을 따로 만들지 않는다. **공통 기준 장면1개 + 서로 인접한 두 구역의 연결 샘플**을 먼저 만든다. 이 샘플로 색·크기·연속성을 확정한 다음 나머지를 확장한다.

거대한 고유 배수구나 특이한 균열은 반복 타일 안에 넣지 않는다. 반복될 때 같은 랜드마크가 계속 나타나면 복제 이미지임이 드러난다. 공통 반복면과 고유 장식을 나눈다.

가로형 배경만 준비하지 않는다. 상승/하강 구간에는 수직 반복 패널·배관 연결·기둥 연장이 필요하다. 사다리꼴 외곽은 사각 화면이 드러내는 바깥 영역까지 채운다.

## 8. 명도·가독성 기준

배경이 분위기는 만들되 플레이어의 다음 행동을 가리지 않게 한다.

- 검정 지형 뒤에는 중간 명도의 벽/안개를 둬 실루엣을 읽게 한다.
- 흰 지형 뒤에는 같은 흰색의 폭포·밝은 안개를 겹치지 않게 한다.
- 배경의 금속 가장자리·배수구 테두리를 플레이 발판보다 날카롭게 그리지 않는다.
- 쉬운 구간은 큰 명암 덩어리, 퍼즐 구간은 조작 장치 주변을 비교적 단순하게 둔다.
- 위험물 뒤에 복잡한 배관 무늬를 겹쳐 가시·톱·총알을 숨기지 않는다.
- “후반이므로 어둡게”만 반복하지 않는다. 후반에도 밝은 안개 공간과 어두운 좁은 통로를 교차해 리듬을 만든다.

숫자 하나로 배경 밝기를 고정하지 않는다. 같은 배경을 검정·흰색 플레이어와 검정·흰색 지형 뒤에 각각 놓고 실제 줌에서 비교한다. 작은 확대 이미지에서 예쁜지보다 게임 화면에서 읽히는지가 기준이다.

## 9. 이미지 제작 요청 양식

이미지 생성/외주 작업마다 다음 항목을 채운다. 기존 승인된 기준 이미지를 함께 제공한다.

```text
목적: GRAY 스테이지2 하수도 배경 키트의 [먼 벽/중간 시설/전환/랜드마크].
구역: [입구/집수/펌프/저수/점검 갱도].
직전 구역과 연결: [어느 방향에서 어떤 배관/아치가 들어오는지].
다음 구역 예고: [어느 방향에 무엇이 조금 보이는지].
시점: 2D 횡스크롤용 고정 시점. 플레이 공간은 정면, 배경 안에만 절제된 원근.
공통 재료: 낡은 벽돌, 석조 아치, 검은 철제 배관, 물때.
명암: 중간 명도, 저채도, 작은 무늬의 대비 낮음, 부드러운 간접광.
구도: [플레이 경로 뒤의 비워 둘 영역], [랜드마크 위치].
레이어 조건: [불투명/진짜 알파 투명], 별도 레이어 이름 명시.
반복 조건: [수평/수직/비반복], 경계에서 이어질 벽돌·배관 높이 명시.
금지: 플레이어, 실제 발판, 가시/톱 등 상호작용물, HUD, 글자, 로고,
       새 강조색, 과도한 흰 윤곽, 강한 스포트라이트, 임의의 바닥 충돌면.
```

한 번의 생성으로 자동 분리된 레이어가 완성된다고 가정하지 않는다. 같은 구도와 기준점을 참조해 레이어별로 제작하고 실제 합성으로 확인한다. 투명한 중간층에 먼 벽이 함께 그려져 있으면 분리가 실패한 것이다.

“seamless”라고 요청했어도 실제로 반복해 보고 경계를 확인한다. 구멍난 아치·끝에서 잘린 관·기둥의 수평 절단면은 렌더링 확인 전까지 해결됐다고 표시하지 않는다.

## 10. 크기·해상도·파일 관리

- 먼저 실제 카메라 줌/뷰포트/이동 범위를 정한다. 기본 줌1.0을 중심으로 가장 넓게 보는 상황까지 고려한다.
- 표시할 크기에서 흐리지 않을 해상도로 제작한다. 무조건 전부4K로 만들지 않는다. 반복 횟수와 GPU 메모리도 함께 본다.
- 원본 해상도와 월드 표시 크기를 따로 기록한다. 이미지 해상도 변경이 배관 굵기나 아치 크기를 바꾸면 안 된다.
- 공통 키트와 구역별 변형, 생성 원본과 게임용 자산을 구분한다. 아래 경로는 새 제작 시의 제안이다.

```text
assets/background/stage_2/sewer_kit_v02/
  common/          공통 먼 벽·아치·배관
  transitions/     입구_집수, 집수_펌프 등 연결 부품
  districts/       구역별 고유 랜드마크
  asset_notes.md   출처/생성 프롬프트/크기/원점/반복 방향
```

스테이지 번호에 종속된 통이미지 이름보다 역할 중심 이름을 권장한다. 예: far_wall_brick_a, mid_arch_tall_a, landmark_pump_hall. 같은 텍스처라도 맵별 배치값은 씬/설정에서 관리한다.

## 11. 검수 체크리스트

- [ ] 공통 기준 장면과 재질·벽돌 크기·조명 성격이 일치한다.
- [ ] 해당 구역만의 특징이 있지만 하수도 전체 스타일은 유지된다.
- [ ] 이전 끝/다음 시작 캡처에서 이어지는 물체를 하나 이상 찾을 수 있다.
- [ ] 실제 진행 방향에 맞게 연결된다. 수직 맵을 억지로 수평 구도로 만들지 않았다.
- [ ] 검정/흰색 플레이어와 지형 모두 배경에서 읽힌다.
- [ ] 배경 폭포/선반을 실제 퍼즐 오브젝트/발판으로 오해하지 않는다.
- [ ] 움직이는 카메라에서 시차가 자연스럽고 고정 장식이 미끄러지지 않는다.
- [ ] 최소 줌, 네 방향 끝, 모서리, 점프·낙하·전환에서도 외부 빈 공간이 없다.
- [ ] 반복 경계가 보이지 않으며 랜드마크가 도장처럼 반복되지 않는다.
- [ ] 중간 레이어의 알파가 실제로 투명하고 테두리 오염이 없다.
- [ ] 노출·줌·레이어 위치가 스테이지 전환 순간 튀지 않는다.
- [ ] 테스트용 생성 이미지와 실제 적용 캡처를 구분해 보고했다.

## 12. 권장 다음 작업

우선 **배수로 입구와 집수 회랑의 연결 샘플**을 만든다. 두 장의 독립된 완성 그림보다, 동일 아치/주 배관이 이어지는 두 구역의 먼 벽·중간층을 제작한다. 현재 SS2D 흑백 발판과 쇠사슬/지지대를 앞에 놓아 대비를 확인한다.

사용자에게 확정받을 것은 “이 공통 하수도 스타일과 구역 변화가 마음에 드는가”다. 그 뒤 실제 맵 순서에 맞춰 구역을 배정하고 펌프·저수·점검 구역을 확장한다. 맵 구조를 새로 만드는 작업이면 기존 사전 질문 규칙도 적용한다.
