# 하수도 오브젝트 사용법

이 문서는 `world_2_클로드` 스테이지를 만드는 사람을 위한 실사용 설명서다.
값은 Godot 인스펙터에서 바꾸며, 경로(NodePath)는 인스펙터의 노드 선택 버튼으로 넣는다.

## 공통 규칙

- 지형(SS2D 시멘트·벽)은 검정 또는 흰색만 쓴다. `시작상태 = 3` 회색 지형은 사용하지 않는다.
- 회색은 버튼·배관·호퍼·물 같은 장애물/유체에는 사용할 수 있다.
- 배관은 반드시 `TEMPLATE_PIPE_OPEN_GRAY.tscn` SS2D를 쓴다. `배관.tscn`은 새 맵에 쓰지 않는다.
- `NodePath`는 노드 이름을 바꾸면 함께 고쳐야 한다. 끊기면 버튼·호퍼·양동이가 대상과 연결되지 않는다.
- 이름은 용도부터 적는다. 예: `양동이_검정_1`, `양동이용_물_검정_1`, `버튼문_1_내려감`.

## 1. 양동이

### 넣는 방법

1. `res://scenes/집/스마트월드_장애물/양동이.tscn`을 `장치` 아래에 인스턴스한다.
2. 이름을 `양동이_검정_1`처럼 붙인다.
3. 바닥 위에 원점(발밑)을 맞춘다. 양동이 그림은 원점보다 위로 그려진다.
4. 물을 받을 자리에는 같은 색의 `유체.tscn` 물줄기를 놓는다.

### 작동 규칙

- 총으로 색칠할 수 없다. 인스펙터에서 정한 `색`은 플레이 중 고정이다.
- 플레이어와 양동이의 색이 정확히 같을 때만 옆에서 밀 수 있다.
- 빈 양동이도 밀 수 있다.
- 양동이는 **자기 색과 같은 색의 켜진 물**에 닿을 때만 물을 담는다.
- `채운뒤_밀수없음`이 켜져 있으면 물을 담은 뒤에는 고정 발판이 된다.
- 이 값이 꺼져 있으면 물을 담은 뒤에도 운반할 수 있다.
- 양동이가 `낙사_y`보다 아래로 빠지면 자기 최초 위치로 되돌아온다.
- 물을 실은 양동이는 압력 버튼의 `양동이` 무게로 인정된다. 빈 양동이는 버튼을 누르지 않는다.

### 인스펙터 값

| 값 | 뜻 | 추천 사용 |
|---|---|---|
| `색` | 검정/흰색/회색 고정 색 | 실제 퍼즐에는 검정 또는 흰색. 플레이어는 회색이 될 수 없으므로 회색은 밀 수 없다. |
| `밀기_속도` | 옆에서 밀 때 속도 | 160~240. 무거운 느낌은 낮춘다. |
| `낙사_y` | 이 y 아래면 시작 자리로 복귀 | 스테이지 `낙사_y`와 같거나 조금 작게. |
| `채운뒤_밀수없음` | 물을 담은 뒤 고정되는지 | 발판 퍼즐은 켬, 물 운반 퍼즐은 끔. |
| `배출_유체` | E로 비울 때 켤 유체 | 운반 퍼즐에서만 지정. |
| `물참` / `물색` | 시작 상태용 값 | 보통 건드리지 않는다. 테스트용으로만 쓴다. |

### 물을 운반해서 비우기

1. `양동이_흰색_운반`의 `색`을 흰색으로 둔다.
2. 같은 색 물줄기 아래로 양동이를 민다. 물이 차면 양동이 안쪽에 물이 보인다.
3. `배출_유체`에 목적지의 꺼진 유체를 지정한다.
4. 양동이 가까이에서 E를 누르면 목적지 유체가 양동이에 담긴 색으로 켜지고, 양동이는 빈다.

E 우선순위는 레버 → 물 찬 양동이 비우기 → 페인트 수동 회수다.

## 2. 압력 버튼

압력 버튼은 스스로 문을 만들지 않는다. 지정한 Node2D를 지정한 만큼 움직인다.

### 넣는 방법

1. `장치` 아래에 `AnimatableBody2D`를 만든다.
2. 스크립트에 `res://scripts/스마트월드/압력버튼.gd`를 넣는다.
3. 이름을 `버튼_1_플레이어`처럼 붙인다.
4. 바닥과 겹치게 하려면 보통 `position.y = 바닥_y + 24`로 둔다.
   버튼 윗면이 바닥 높이에 맞아 상자/양동이가 걸리지 않는다.
5. `대상들`과 `대상_이동량들`을 같은 순서로 넣는다.

### 누를 수 있는 것

`누름_가능_그룹`에 아래 문자열을 넣는다.

| 값 | 누르는 물체 | 주의 |
|---|---|---|
| `player` | 플레이어 | 플레이어가 내리면 유지형 버튼은 즉시 풀린다. |
| `박스` | 색 없는 상자 | 항상 버튼을 누를 수 있다. |
| `양동이` | 물을 담은 양동이 | 빈 양동이는 버튼을 누르지 않는다. |

여러 종류를 허용하려면 `PackedStringArray("player", "박스")`처럼 넣는다.
⚠ `.tscn` 안에서는 **대괄호를 쓰지 않는다.** `PackedStringArray(["player"])` 로 적으면
   씬 파일이 통째로 파싱 실패한다(2026-09-07 에 stage_2-7 이 실제로 그랬다).

### 인스펙터 값

| 값 | 뜻 | 사용 예 |
|---|---|---|
| `폭` | 버튼의 실제/감지 가로 폭 | 박스·양동이는 140~180 권장. |
| `높이` | 버튼 몸체 높이 | 24 기본값 권장. |
| `감지_높이` | 버튼 위에서 무게를 찾는 높이 | 44 기본값, 큰 상자는 60 정도. |
| `작동방식` | `누르는 동안만` 또는 `한 번 누르면 유지` | 무게 퍼즐은 보통 누르는 동안만. |
| `누름_가능_그룹` | 누를 수 있는 그룹 목록 | 위 표 참고. |
| `동시_버튼들` | 함께 눌려야 하는 다른 버튼 | 주 버튼에만 넣는다. |
| `대상들` | 움직일 노드 배열 | NodePath 배열. |
| `대상_이동량들` | 대상별 이동 벡터 배열 | 대상들과 번호를 맞춘다. |
| `이동속도` | 이동하는 속도(px/s) | 문은 500~700, 발판은 300~450 권장. |

### 문 내리기 예시

버튼과 문이 모두 `장치` 아래에 있을 때:

```text
버튼 이름: 버튼_1_플레이어
대상들: [ ../버튼문_1_내려감 ]
대상_이동량들: [ Vector2(0, 820) ]
작동방식: 누르는 동안만
```

`버튼문_1_내려감`은 `Node2D`이고, 그 자식에 SS2D 벽을 둔다.
버튼이 눌리면 문 전체가 아래로 820px 이동한다.

### 두 버튼을 동시에 써야 할 때

두 버튼 모두 같은 대상을 움직이게 하면 서로 위치를 덮어쓴다. 아래처럼 **주 버튼 하나만** 대상을 움직인다.

```text
버튼_4_양동이
  누름_가능_그룹: [ 양동이 ]
  대상들: 비움

버튼_4_플레이어
  누름_가능_그룹: [ player ]
  동시_버튼들: [ ../버튼_4_양동이 ]
  대상들: [ ../버튼문_4_동시 ]
  대상_이동량들: [ Vector2(0, 820) ]
```

## 3. 박스

### 넣는 방법과 규칙

- 씬: `res://scenes/집/스마트월드_장애물/박스.tscn`
- 색이 없으므로 검정·흰 플레이어 모두 민다.
- 총으로 색칠할 수 없다.
- `박스` 그룹에 자동으로 들어가 압력 버튼에 쓸 수 있다.
- `밀기_속도`와 `낙사_y`를 양동이와 같은 방식으로 조정한다.
- 구멍에 빠지면 최초 위치로 돌아온다.

버튼을 처음 가르칠 때는 박스를 쓴다. 색 전환이나 물 채우기까지 한 번에 가르치지 않기 위해서다.

## 4. SS2D 회색 배관

### 넣는 방법

1. `res://scenes/집/스마트 매쉬 assets/PIPE_배관/TEMPLATE_PIPE_OPEN_GRAY.tscn`을 인스턴스한다.
2. `SS2D_배관` 아래에 넣고 이름을 `SS_PIPE_1_양동이용_물`처럼 붙인다.
3. 자식 `경로`를 선택해 점을 이동한다.
4. 직선은 점 2개, ㄱ자는 3개, ㄹ자는 4개 이상을 쓰고 수평/수직으로 꺾는다.

### 조정 방법

- 경로의 첫 점과 마지막 점은 열어 둔다. 마지막 점을 첫 점으로 이어 닫으면 안 된다.
- 길이는 `경로`의 끝 점을 움직여 조정한다.
- 굵기는 노드 `scale`로 바꾸지 않는다. 기본 재질의 두께를 유지한다.
- 인스턴스 전체 `scale`은 배치 크기 조정에만 조심해서 쓴다. 같은 구간에 배관 인스턴스를 겹치지 않는다.
- 이 배관은 장식/연결 시각화다. 충돌·색 섞임·물 흐름 자체는 만들지 않는다.

### 물과 맞추는 법

1. 호퍼나 저장고의 `출구_포트`를 배관 끝 근처에 둔다.
2. 유체 노드의 **루트 원점**을 그 출구 포트 위치에 맞춘다.
3. 물은 유체 원점에서 아래 방향으로 흐른다.

배관 아래에 유체를 놓는다고 자동으로 연결되는 것은 아니다. 실제 연결은 호퍼/저장고의 포트와 유체가 담당한다.

## 5. 호퍼 (물이 흐르는 발판)

호퍼는 밟을 수 있는 깔때기 발판이다. 위에서 들어온 물을 받아 아래 `출구_유체`로 보낸다.

### 넣는 방법

1. `res://scenes/집/스마트월드_장애물/호퍼.tscn`을 인스턴스한다.
2. 위에서 떨어지는 유체가 호퍼 윗면 위의 입구 감지 영역을 지나게 둔다.
3. 호퍼 아래 출구에 `유체.tscn`을 놓는다.
4. 확실한 연결이 필요하면 `출구_유체`에 그 유체 NodePath를 지정한다.

### 작동 규칙

- 호퍼 위에 켜진 물이 닿으면 출구 물줄기가 켜진다.
- 물이 끊기면 출구도 꺼진다.
- 여러 물이 동시에 들어오면 물 색 섞기 규칙을 적용한다.
- 호퍼 윗면은 밟을 수 있다.

### 인스펙터 값

| 값 | 뜻 | 추천 |
|---|---|---|
| `폭` | 윗면/입구 가로 폭 | 150~220 |
| `높이` | 깔때기 높이 | 56 기본값 |
| `출구_유체` | 내보낼 유체 NodePath | 중요한 퍼즐은 반드시 수동 지정 |
| `출구_물줄기_폭` | 출구 물 폭 | 96~120이면 얇아 보이지 않음 |
| `출구_물줄기_길이` | 출구 물 길이 | -1은 유체의 원래 길이 사용 |
| `자동_출구_연결` | 출구 포트 가까운 유체 자동 탐색 | 수동 경로를 쓸 때도 켜도 되지만 수동이 우선 |
| `포트_연결거리` | 자동 연결 허용 오차 | 36 기본값, 배치 여유가 필요하면 48~64 |

## 6. 유체 (물)

### 넣는 방법

1. `res://scenes/집/스마트월드_장애물/유체.tscn`을 인스턴스한다.
2. 유체 루트 원점을 물이 시작할 배관 출구/호퍼 출구에 맞춘다.
3. `종류 = 물`, `색`, `크기`, `켜짐`을 정한다.

### 인스펙터 값

| 값 | 뜻 |
|---|---|
| `종류` | 물 또는 연기. 하수도 물은 `물`. |
| `색` | 검정/흰색/회색. |
| `크기` | `x=폭`, `y=원점부터 아래로 흐르는 길이`. |
| `판정_여유` | 물 충돌 실루엣을 안/밖으로 보정. 0 기본값을 먼저 쓴다. |
| `흐름속도` | 물결 애니메이션 속도. 130 기본값. |
| `켜짐` | 꺼진 유체는 보이지 않고 위험·호퍼 입력도 없다. |

### 물 규칙

- 유체는 총으로 색칠할 수 없다.
- 플레이어가 반대색 물에 닿으면 죽는다. 회색 물은 안전하다.
- 검정 + 흰색 = 회색, 검정 + 회색 = 검정, 흰색 + 회색 = 흰색.
- 순색 물은 닿은 반대색 지형의 페인트를 지우고 탄약을 돌려준다.
- 통과플랫폼은 물이 지나가도 페인트가 지워지지 않는다.

## 7. 통과플랫폼 (물이 흐르는 플랫폼)

`통과플랫폼`은 하수구 격자 발판이다. 플레이어는 밟고, 물은 통과하며, 물이 발판의 색칠을 지우지 않는다.

### 넣는 방법과 값

- 씬: `res://scenes/집/스마트월드_장애물/통과플랫폼.tscn`
- `크기`: 가로/세로 크기. 예: `Vector2(224, 26)`.
- `필요횟수`: 무색 발판을 한 색으로 완전히 칠하는 데 필요한 발사 횟수.

### 색칠 규칙

- 무색 상태는 화면상 검정처럼 보여도 내부 값은 무색이다.
- 같은 색을 `필요횟수`만큼 쏘면 그 색으로 굳는다.
- 반대색을 쏘면 기존 색이 덮인다.
- 검정과 흰색을 섞어 회색이 된 발판은 되돌릴 수 없다.

## 빠른 문제 해결

| 증상 | 먼저 확인할 것 |
|---|---|
| 양동이가 안 밀린다 | 플레이어와 양동이 `색`이 같은지, 양동이가 벽에 막힌 것은 아닌지 확인. |
| 양동이에 물이 안 찬다 | 유체가 켜져 있는지, 양동이와 물의 색이 같은지, 물감지 영역까지 물이 닿는지 확인. |
| 물 찬 양동이가 버튼을 못 누른다 | 버튼 `누름_가능_그룹`에 `양동이`가 있는지, 양동이 `물참`이 참인지 확인. |
| 박스가 버튼을 못 누른다 | 버튼 그룹에 `박스`를 넣고, 버튼을 바닥보다 24px 아래에 놓았는지 확인. |
| 버튼이 문을 안 움직인다 | `대상들` 경로와 `대상_이동량들`의 번호/개수가 맞는지 확인. |
| 두 버튼이 있는 문이 이상하게 움직인다 | 대상 경로는 주 버튼 한 개에만 넣고, 주 버튼 `동시_버튼들`에 다른 버튼을 넣는다. |
| 호퍼에서 물이 안 나온다 | 위 물이 호퍼 입구 감지 영역에 닿는지, `출구_유체` 경로가 맞는지 확인. |
| 호퍼 물이 너무 가늘다 | 호퍼 `출구_물줄기_폭`을 96~120으로 올린다. |
| SS2D 배관이 물을 실제로 옮기지 않는다 | 정상이다. 배관은 시각화고, 호퍼/저장고 포트와 유체를 따로 연결해야 한다. |
