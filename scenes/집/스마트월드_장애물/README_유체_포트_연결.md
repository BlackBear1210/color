# 유체 포트 연결

## 맵에서 만드는 순서

1. `TEMPLATE_PIPE_OPEN_GRAY.tscn`의 SS2D 경로를 원하는 모양으로 놓는다.
   `시작_물_포트`와 `끝_물_포트`는 경로 양 끝을 자동으로 따라가는 편집용 Marker2D다.
2. 호퍼 또는 물저장고의 `출구_포트` Marker2D를 배관 끝 물 포트와 맞춘다.
3. `유체.tscn` 인스턴스의 **루트 원점**을 그 출구 포트에 맞춘다. 물은 원점부터 아래로 흐른다.
   인스펙터의 `색`에서 `흰색`·`회색`·`검정색`을 고를 수 있다.
4. 호퍼 위 `입구` 감지 범위에 물줄기 둘 이상이 닿으면, 호퍼는 기존 `유체.섞기()` 규칙으로
   색을 합쳐 출구 물줄기에 전달한다. 예: 검정 + 흰색 = 회색.

## 자동과 수동 연결

- `출구_유체`(호퍼), `공급_유체`(저장고)를 비우면 출구 포트에서 `36px` 이내인 유체 시작점을
  자동으로 찾는다. 인스펙터의 `포트_연결거리`로 오차 범위를 바꿀 수 있다.
- 기존처럼 특정 유체를 반드시 쓰고 싶으면 해당 NodePath를 지정한다. 수동 연결이 자동 연결보다
  우선한다.
- SS2D 배관은 배치·시각화 역할이고, 실제 물리·색 전달은 유체와 포트가 처리한다. 따라서
  배관 아래에 유체를 놓아도 충돌 규칙이나 색 섞임 규칙은 변하지 않는다.
