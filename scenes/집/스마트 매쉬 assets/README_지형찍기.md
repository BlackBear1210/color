# 지형 찍기 — 5줄 사용법

> 이 폴더는 **맵을 찍는 사람**을 위한 것입니다. 코드를 몰라도 됩니다.
> 최종 갱신: 2026-08-24

## 1. 이렇게 씁니다

1. **원하는 재질 폴더를 엽니다.** (`BRICK_벽돌` `SEWER_하수` `WOOD_나무` `GRASS_잔디`)
2. **`발판_○○_채움`(속이 찬 지형) 또는 `발판_○○_속빔`(속이 빈 지형)** 중에 고릅니다.
3. 그 씬을 **맵 씬으로 드래그**해서 놓습니다.
4. 놓인 노드를 선택하고 **SmartShape2D 로 점을 잡아 늘려** 원하는 지형 모양을 만듭니다.
5. **색은 건드리지 않습니다.** 검정/흰색은 게임이 실행 중에 바꿉니다.
   시작 색만 정하고 싶으면 인스펙터의 **`시작상태`** 를 고르세요 (무색/검정/흰색/회색).

끝입니다. 텍스처를 직접 찾아 연결할 일은 없습니다.

---

## 2. 폴더 안에 뭐가 있나

| 파일 | 뜻 | 언제 쓰나 |
|---|---|---|
| `발판_○○_채움.tscn` | **SOLID** — 속이 꽉 찬 지형 | 평소에 쓰는 것. 바닥·벽·발판 전부 |
| `발판_○○_속빔.tscn` | **HOLLOW** — 속이 **진짜 투명한** 테두리 지형 | 창틀·아치·구멍 난 벽처럼 뒤가 비쳐야 할 때 |
| `프리뷰_○○_검정.tscn` | 시작상태 = 검정 | 확인용. 그냥 배치해도 됨 |
| `프리뷰_○○_흰색.tscn` | 시작상태 = 흰색 | 확인용. 그냥 배치해도 됨 |

`속빔` 은 안쪽을 검정으로 칠한 게 아니라 **정말 뚫려 있습니다.** 뒤 배경이 그대로 보입니다.

## 3. 재질 4종

| 폴더 | 재질 | 상태 |
|---|---|---|
| `GRASS_잔디` | 잔디 (grass_v4) | **기존 LOCK 에셋.** 검증 끝난 것이라 그림을 다시 굽지 않습니다 |
| `BRICK_벽돌` | 벽돌 | 새 master 파이프라인 |
| `SEWER_하수` | 하수도 돌벽 | 새 master 파이프라인 |
| `WOOD_나무` | 나무 판자 | 새 master 파이프라인 |

네 재질 모두 **같은 규격**입니다 — `texture_scale 0.35` · 코너 512(월드 90px) ·
taper 128×256(월드 44.8px). 그래서 서로 이어 붙여도 크기가 안 어긋납니다.

## 4. 색에 대해 (중요)

이 게임에서 **색은 재질이 아니라 상태**입니다.

- 지형 하나에 머티리얼은 **하나**입니다(검정 그림 기준).
- 흰색 그림은 `지형.gd` 가 자동으로 짝을 찾아 페인트 셰이더에 물립니다.
- 총에 맞으면 검정↔흰색이 그 자리에서 섞입니다.

그래서 `BRICK_BLACK` / `BRICK_WHITE` 같은 **색 전용 머티리얼을 만들면 안 됩니다.**
만드는 순간 그 지형은 반대 색으로 칠할 수 없게 되고,
"내 색과 다른 지형에 닿으면 즉사" 라는 규칙이 그 지형에서만 깨집니다.

## 5. 하면 안 되는 것

| 하지 말 것 | 왜 |
|---|---|
| PNG 를 지형에 **직접 연결** | 엣지 4방향·코너·taper 가 안 붙어서 코너가 깨집니다 |
| 머티리얼(`.tres`)을 **복제해서 수정** | 원본이 바뀌어도 안 따라오고, 재질이 두 벌이 됩니다 |
| `texture_scale` **임의 변경** | 재질끼리 크기가 어긋납니다. 0.35 고정입니다 |
| `addons/rmsmartshape` **수정** | 애드온을 고치면 다음 업데이트 때 전부 날아갑니다 |
| **흑/백 전용 머티리얼 새로 만들기** | 위 4번 참고. 게임 규칙이 깨집니다 |
| `assets/textures/smartshape/grass_v4/` **의 PNG 수정** | LOCK 입니다. 검증이 끝난 에셋입니다 |
