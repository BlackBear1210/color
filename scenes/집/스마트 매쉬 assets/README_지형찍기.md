# 지형 찍는 법 (레벨 작업자용)

## 5줄 요약

1. FileSystem 에서 `scenes/집/스마트 매쉬 assets/<재질>/발판_<재질>.tscn` 을 씬에 **드래그**한다.
2. 드래그한 노드를 클릭하면 위쪽에 **SmartShape2D 툴바**가 뜬다.
3. 점을 끌어 모양을 만든다. `Ctrl+클릭` 으로 점 추가, 점 선택 후 `Delete` 로 삭제.
4. 곡선으로 만들려면 점을 고르고 **베지어 핸들**을 끌면 된다.
5. 색은 인스펙터의 **`시작상태`** 로 고른다 — `무색` / `검정` / `흰색` / `회색`.

---

## 어떤 씬을 고르나

재질 4종 × 변형 4종이 있다.

```
스마트 매쉬 assets/
├─ 잔디/  발판_잔디.tscn   발판_잔디_검정.tscn   발판_잔디_흰색.tscn   발판_잔디_속빔.tscn
├─ 벽돌/  발판_벽돌.tscn   발판_벽돌_검정.tscn   발판_벽돌_흰색.tscn   발판_벽돌_속빔.tscn
├─ 하수/  발판_하수.tscn   발판_하수_검정.tscn   발판_하수_흰색.tscn   발판_하수_속빔.tscn
└─ 나무/  발판_나무.tscn   발판_나무_검정.tscn   발판_나무_흰색.tscn   발판_나무_속빔.tscn
```

| 파일 | 언제 쓰나 |
|---|---|
| `발판_<재질>.tscn` | **기본.** 무색이라 플레이어가 칠할 수 있다. 대부분 이걸 쓴다 |
| `발판_<재질>_검정.tscn` | 처음부터 검정인 지형 (흰 플레이어는 밟으면 죽는다) |
| `발판_<재질>_흰색.tscn` | 처음부터 흰색인 지형 (검은 플레이어는 밟으면 죽는다) |
| `발판_<재질>_속빔.tscn` | 내부가 **비어 있는** 테두리 지형. 창틀·액자·구조물 테두리에 |

> 검정/흰색 씬은 그냥 기본 씬에서 `시작상태` 만 미리 바꿔 둔 것이다.
> 기본 씬을 가져다 인스펙터에서 직접 바꿔도 결과는 같다.

## 자주 묻는 것

**Q. 색을 바꿨는데 화면이 그대로다**
`시작상태` 는 **게임을 실행해야** 반영된다. 에디터에서는 검정 텍스처로 보인다.

**Q. 지형을 밟을 수 없다**
씬 안의 `StaticBody2D/CollisionPolygon2D` 를 지우지 않았는지 확인한다. 이게 콜리전이다.

**Q. 90도 모서리가 조금 어색하다**
코너는 엣지 단면에서 수학적으로 합성한다. 확대하면 옅은 이음매가 보일 수 있지만
실제 플레이 거리(카메라 줌 0.82)에서는 보이지 않는다. 그대로 써도 된다.

**Q. 아주 급한 곡선을 그렸더니 이상하다**
곡선 한 조각이 45 월드px 보다 짧아지면 마감(taper)이 생략된다. 점을 조금 벌리면 된다.

**Q. 새 재질이 필요하다**
`docs/SS2D_고해상도_타일셋_마스터템플릿.md` §9 를 보면 원본 4장만 준비하면
나머지 32장과 머티리얼은 도구가 자동으로 만든다.
