# SmartShape2D 지형 제작 가이드

> **맵을 찍는 사람**이 읽는 문서입니다. 코드·텍스처·Aseprite 전부 몰라도 됩니다.
> 최종 갱신: 2026-08-25 · 먼저 `WORKER_GUIDE.tscn` 을 열어 보세요.

---

## 1. 이 시스템은 무엇인가

**도형을 그리면 지정된 재질이 자동으로 지형 외곽에 맞춰지는 시스템**입니다.

여러분은 모양만 그립니다. 벽돌 줄눈이 코너를 어떻게 돌지, 위쪽 갓돌이 어디 붙을지는
시스템이 알아서 합니다. 텍스처를 직접 붙이거나 자를 일이 없습니다.

## 3. 가장 기본적인 사용법 (이게 전부입니다)

1. 위 표에서 Template 을 고른다
2. FileSystem 에서 그 씬을 **복제**한다 (우클릭 → Duplicate)
3. 이름을 바꾼다 (예: `거실_바닥.tscn`)
4. 복제한 씬을 열고 **SmartShape2D 노드를 선택**한다
5. 점을 끌어서 원하는 지형 모양을 만든다 (점 추가/삭제도 여기서)
6. 저장한다

끝입니다. 그 다음 맵 씬에 끌어다 놓으면 됩니다.

> 색(검정/흰색)은 **게임이 실행 중에** 정합니다. 인스펙터의 `시작상태` 만 고르세요
> (무색 / 검정 / 흰색 / 회색). 머티리얼을 색깔별로 만들면 안 됩니다.

## 4. 바닥 만드는 법

기본 사각형을 좌우로 늘리면 됩니다. 두께는 260px 정도가 편합니다.
`WORKER_GUIDE.tscn` 의 **1번**이 이것입니다.

## 5. 벽 만드는 법

같은 사각형을 세로로 길게 늘립니다. 폭은 260px 정도.
`WORKER_GUIDE.tscn` 의 **2번**.

## 6. 공중 플랫폼 만드는 법

- **최소 두께 140 world px**
- **권장 두께 180 world px 이상**

Template 의 기본 크기가 이미 512 × 192 라 그대로 늘려 쓰면 됩니다.
`WORKER_GUIDE.tscn` 의 **3번**.

## 7. 계단 만드는 법

★ **폭과 높이의 규칙이 서로 다릅니다.** 이유가 다르기 때문입니다.

| | 값 | 왜 |
|---|---|---|
| 계단 **폭** | 최소 90px · **권장 180px** | 코너 조각이 90px라 그보다 좁으면 코너끼리 겹쳐 뭉갭니다 |
| 계단 **높이** | **90 ~ 120px** | 플레이어가 올라갈 수 있는 한계가 **128px** 입니다. 넘으면 못 올라갑니다 |

즉 **폭 180 × 높이 110** 정도가 가장 안전합니다.
`WORKER_GUIDE.tscn` 의 **4번**이 그 예제입니다.

> ⚠ 높이를 140px 로 하면 **보기엔 멀쩡한데 플레이어가 못 올라갑니다.**
> 실제로 이 실수를 한 번 했고, `tools/레벨검사.gd` 가 잡아냈습니다.
> 계단을 만들었으면 아래 15번의 레벨검사를 꼭 돌려 보세요.

## 8. L자 / ㄷ자 / 폐곡선

| 모양 | 언제 쓰나 |
|---|---|
| **L자** | 바닥에서 벽이 올라가는 구석, 계단 옆 벽 |
| **ㄷ자** | 파인 공간, 문틀, 우묵한 구덩이 |
| **폐곡선** | 기둥, 섬, 둥근 덩어리. HOLLOW 와 같이 쓰면 링·터널 |

> ⚠ **부드러운 원·타원 폐곡선은 지금 쓰지 마세요.**
> 테두리 45°·135°·225°·315° 위치에 **밝은 틈이 4곳** 생깁니다
> (내부 이슈 `CLOSED-LOOP-TAPER-01`. 작업자가 고칠 수 있는 것이 아닙니다).
> 링·터널이 필요하면 **모서리가 있는 다각형**으로 만드세요 — 직각 코너에는 틈이 안 생깁니다.

`WORKER_GUIDE.tscn` 의 **5 · 6 · 7번**.

## 9. SOLID 와 HOLLOW 차이

### SOLID (채움)
내부가 재질로 채워집니다. **땅 · 벽 · 큰 플랫폼** 에 씁니다. 평소엔 이걸 씁니다.

### HOLLOW (속빔)
내부가 **진짜 투명**합니다. 뒤 배경이 그대로 비칩니다.
**링 · 건축물 외곽 · 터널 · 창틀** 에 씁니다.
검정으로 칠한 게 아니라 정말 뚫려 있습니다.

## 10. 예쁘게 보이는 맵 제작 규칙

### BRICK
- 직선적인 건축 구조로. 사람이 쌓은 벽처럼
- 아주 작은 조각 금지
- 긴 벽을 적극적으로 쓰면 좋습니다
- 계단은 같은 폭·높이로 리듬을 맞추기

### WOOD
- 집 내부 구조물 느낌 — 바닥 · 나무 벽 · 선반 · 플랫폼
- 지나치게 작은 조각 금지
- 나무는 벽돌보다 무늬가 크므로 **너무 얇게 만들면 특히 검게 보입니다**

## 11. 흔한 실수

### "왜 플랫폼이 검은 막대처럼 보여요?"
플랫폼이 너무 얇습니다. 재질 띠 한 장이 90px라, 위아래가 겹치면 안쪽이 사라집니다.
→ **두께 140px 이상, 되도록 180px 이상.**

### "왜 계단이 뭉개져 보여요?"
계단 한 칸이 너무 작습니다. 코너 조각이 90px라 그보다 작으면 서로 겹칩니다.
→ **한 칸 90px 이상, 되도록 140~180px 이상.**

### "왜 코너가 이상해요?"
짧은 선분과 아주 작은 코너를 피하고 평범한 직각으로 만드세요.
코너에서 작은 계단을 만들지 마세요.

### "왜 안쪽이 안 보여요 / 뒤가 비쳐요?"
SOLID 를 써야 할 자리에 HOLLOW 를 썼거나 그 반대입니다. Template 을 확인하세요.

### "지형이 이상해 보여서 텍스처를 고쳐도 되나요?"
**안 됩니다.** 아래 12번 표를 보세요. 먼저 13·14번 체크리스트를 해 보고,
그래도 이상하면 파이프라인 담당자에게 알려 주세요.

## 18. 실제 Stage 에 적용하기

1. Template 을 복제한다
2. 복제본을 **Stage 씬에 배치**한다 (지형을 모아 두는 `지형` 노드 아래에 넣으면 깔끔합니다)

5. 게임을 실행한다
6. 직접 걸어 보고 · 점프해 보고 · 계단을 올라가 본다

> **기존 Stage 를 바로 고치지 마세요.**
> 먼저 테스트 영역이나 복제본에서 검증한 뒤에 옮기세요.
> 참고용 통합 테스트 씬: `scenes/smartshape_test/TERRAIN_INTEGRATION_TEST.tscn`

## 19. 만들고 나서 자동 검사 돌리기 (권장)

지형을 다 그렸으면 이 명령 한 줄이면 됩니다. 눈으로는 안 보이는 사고를 잡아 줍니다.

```bash
Godot --headless --path . -s res://tools/레벨검사.gd -- <내가만든씬경로>
```

무엇을 알려주나:

- **도달 불가** — 발판을 놨는데 점프로 못 닿는 곳 (계단이 너무 높을 때 여기서 걸립니다)
- **소프트락** — 들어갈 수는 있는데 못 나오는 곳
- **치명 낙하** — 걸어 나가면 죽을 만큼 떨어지는 가장자리 (치명 거리 520px)

장식으로 일부러 띄워 둔 것(천장 기둥 등)이 '도달 불가' 로 나오는 건 정상입니다.

## 20. 만들 수 있는 형태 / 만들면 안 되는 형태

### ✅ 허용

```
직선 · L자 · ㄷ자 · U자 · 계단 · 직각 코너 · 직각(축 정렬) 사각형 링·터널
```

### ❌ 금지

```
원 · 타원 · 8각형 — 대각선 변이 있는 모든 폐곡선
```

**이유**: 방향이 바뀌는 지점에서 taper 가 양쪽 다 투명해지면서 테두리 45°·135°·225°·315°
네 곳에 **밝은 틈**이 생깁니다. 직각 코너에는 코너 조각이 들어가 메워지지만
부드러운 곡선에는 메울 것이 없습니다.

작업자가 고칠 수 있는 문제가 아니라 현재 SmartShape2D 파이프라인의 **알려진 한계**입니다
(내부 이슈 `CLOSED-LOOP-TAPER-01`).

⚠ 8각형처럼 **비스듬한 변**이 있으면 똑같이 틈이 생깁니다 (실제로 확인했습니다).

→ 링·터널은 **HOLLOW 템플릿 + 직각(축 정렬) 사각형**으로 만드세요.
   가로세로만 있는 모서리에는 코너 조각이 들어가 틈이 안 생깁니다.
   `WORKER_EXAMPLE_INTERIOR.tscn` 의 "직각 링(HOLLOW)" 이 예제입니다.

## 22. 실제로 어떻게 배치하는지 보고 싶다면


실제 방 하나를 구성한 샘플입니다. **직접 실행해서 걸어 다녀 볼 수 있습니다.**

재질 역할 분담이 이 씬의 요점입니다:

| 재질 | 역할 |
|---|---|
| GRASS | 바깥 자연 지형 |
| BRICK | 건물 바닥 · 벽 · 계단 |
| WOOD | 실내 선반 · 플랫폼 · 목재 구조물 |
