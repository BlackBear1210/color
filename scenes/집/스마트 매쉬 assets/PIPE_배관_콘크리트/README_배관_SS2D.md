# 월드 2 콘크리트 배관 SS2D

`TEMPLATE_PIPE_OPEN_CONCRETE_GRAY.tscn`은 하수도 월드 전용의 열린 SS2D 배관이다.

- 기존 `PIPE_배관/TEMPLATE_PIPE_OPEN_GRAY.tscn`은 수정하지 않는다.
- 자식 `경로`의 점만 움직여 직선·ㄱ자·ㄹ자 관을 만든다. 마지막 점을 첫 점에 연결해 닫지 않는다.
- 기본 굵기는 기존 회색 배관과 같다. 본체와 끝마개가 모두 `0.093` 배율을 쓰므로, 한쪽만 바꾸면 이음부 높이가 어긋난다.
- `깊이 = 3`이 명시돼 있다. 유체의 최상단 유효 고도는 2이므로, 기본 상태에서 관 전체가 물 위에 그려진다. 물 뒤로 보내려는 배치만 인스펙터에서 이 값을 음수로 바꾼다.
- 이 템플릿은 장식·흐름 시각화만 담당한다. 충돌·색칠·유체 흐름은 만들지 않는다.
