## 1. 실행 오류 3건 — 원인은 하나였다

### 증상 (도형님 제보)
```
GDScript::reload: The identifier "ㄹ" has misleading characters …
gun.gd:6 @ @implicit_ready(): Node not found: "Muzzle" (relative to ".../Player/Gun2")
_shoot: Invalid access to property or key 'global_position' on a base object of type 'null instance'
```
그리고 **플레이어가 파란 박스에 갇혀 보임**.

### 원인 ①(오류 2·3 + 파란 박스) — 인스턴스 씬 내부까지 owner 를 지정했다

`tools/build_스마트월드.gd` 의 `_주인_지정()` 이 씬 전체를 재귀하면서
**Player 인스턴스 안쪽 노드까지** `owner = 루트` 로 바꿨다.

Godot 은 owner 가 루트인 노드를 "이 씬이 직접 소유한 노드" 로 보고 `.tscn` 에 **한 벌 더 적는다.**
그래서 저장된 씬이 이렇게 됐다:

```
Player (instance)          ← Player.tscn 이 자기 자식(Gun, Placeholder…)을 만든다
├─ CollisionShape2D2       ← ★빌더가 덧붙인 복제본
├─ Placeholder2            ← ★
├─ CharacterSprite2        ← ★
├─ Gun2                    ← ★ (Muzzle 자식이 없다)
└─ Camera2D2               ← ★
```

- `Gun2` 에는 `Muzzle` 이 없다 → **오류 2**
- 그래서 `muzzle` 이 null 인 채로 `_shoot()` → **오류 3**
- `player_anim.gd` 는 `"Placeholder"` 만 숨기므로 `Placeholder2` 는 남는다 → **파란 박스**

**수정** — 인스턴스 경계에서 재귀를 멈춘다.

```gdscript
func _주인_지정(노드: Node, 루트: Node) -> void:
    for 자식 in 노드.get_children():
        자식.owner = 루트
        if not 자식.scene_file_path.is_empty():
            continue          # 인스턴스 씬 — 내부는 그 씬이 관리한다
        _주인_지정(자식, 루트)
```

> 🔴 **다른 작업자 주의**: 씬을 코드로 만들어 `PackedScene.pack()` 할 때는
> **인스턴스 노드 자신에게만 owner 를 주고, 그 자식에게는 절대 주지 말 것.**
> 이 규칙을 어기면 지금처럼 "노드가 두 벌"이 되고, 증상이 엉뚱한 곳에서 나타나 찾기 어렵다.

### 원인 ②(오류 1) — 한글 자음 한 글자짜리 변수명

`배관.gd` 에서 반쪽 길이를 `ㄹ` 로 줄여 썼는데, Godot 이
`The identifier "ㄹ" has misleading characters` 경고를 낸다(다른 문자와 혼동 가능 판정).
→ `반길이` 로 변경. **한글 변수명은 쓰되, 자음/모음 한 글자짜리는 피할 것.**

### 덤 — 에디터 2D 뷰가 무지개색으로 뒤덮이던 문제

오목한 `CollisionPolygon2D` 는 Godot 이 볼록 조각으로 쪼개서 **조각마다 다른 색**으로 기즈모를
그린다. 지형이 크다 보니 화면이 통째로 무지개가 됐다.
→ 빌더에서 `폴리.visible = false`. **기즈모만 꺼지고 물리 판정에는 영향 없다.**
다시 보고 싶으면 씬 트리에서 눈 아이콘을 켜면 된다.

## 2. ESC 일시정지 메뉴 (신규)

| 파일 | 역할 |
|---|---|
| [scripts/스마트월드/일시정지_메뉴.gd](../scripts/스마트월드/일시정지_메뉴.gd) | 메뉴 UI + 일시정지 + 씬 전환 |
| [scripts/스마트월드/게임설정.gd](../scripts/스마트월드/게임설정.gd) | 밝기 저장/불러오기 (`user://설정.cfg`) |

- **ESC**(`ui_cancel`, Godot 내장 액션이라 project.godot 수정 불필요)로 열고 닫는다
- 계속하기 / 설정(밝기 슬라이더) / 로비로 돌아가기
- 밝기는 **바꾸는 즉시** 화면에 반영되고 자동 저장된다

### 다른 스테이지에 붙이는 법 (두 줄)

```gdscript
var 메뉴 := preload("res://scripts/스마트월드/일시정지_메뉴.gd").new()
add_child(메뉴)
메뉴.연결(어둠_CanvasModulate, 어둠_CanvasModulate.color)   # ← 기준색을 같이 넘긴다
```

### ⚠ 함정 2가지 (둘 다 실제로 겪음)

1. **`PROCESS_MODE_WHEN_PAUSED` 를 쓰면 메뉴가 절대 안 열린다.**
   그건 "멈춰 있을 때만 동작"이라 평소에는 `_input` 조차 안 불린다.
   → **`PROCESS_MODE_ALWAYS`** 가 정답. (자동 테스트가 잡아냈다)
2. **밝기는 항상 "기준색"에서 다시 계산해야 한다.**
   현재 색에 곱하면 슬라이더를 움직일 때마다 값이 누적돼 화면이 점점 어두워진다.
   그래서 `연결()` 에 기준색을 같이 넘기는 구조로 만들었다.

### 오토로드를 왜 안 썼나
`project.godot` 의 `[autoload]` 를 건드리면 **모든 씬**(zone_01, world_1, 스테이지 1~5…)의
실행 환경이 바뀐다. 설정은 파일 입출력이 전부라 상태를 들 필요가 없어 static 클래스로 충분하다.
팀이 원하면 `게임설정.gd` 를 그대로 오토로드로 등록만 하면 된다.

## 3. 조명 — FastNoiseLite 로 크기까지 흔든다

[scripts/스마트월드/발광체.gd](../scripts/스마트월드/발광체.gd)

> ⚠ **Godot 3 의 `OpenSimplexNoise` 는 Godot 4 에 없다.**
> 대체재가 `FastNoiseLite` 이고, `TYPE_SIMPLEX_SMOOTH` 가 예전 OpenSimplex 와 가장 비슷하다.

| 새 속성 | 하는 일 |
|---|---|
| `크기_흔들림` | 빛의 **반경**(`texture_scale`)이 노이즈로 커졌다 작아진다 |
| `흔들림_속도` | 노이즈가 흐르는 속도 |

- 세기와 크기는 **노이즈의 다른 줄기**를 읽는다(`get_noise_2d(t, 0)` / `(t, 37)`).
  같은 값을 쓰면 그냥 깜빡임이 되고, 따로 움직여야 "숨쉬는 빛"이 된다.
- 시드는 노드 이름 해시 → **광원마다 리듬이 다르고, 실행할 때마다 재현된다**(디버깅에 유리).
- 부유(반딧불 떠다님)도 사인 → 노이즈로 바꿨다. 사인은 "8자로 도는" 티가 난다.

## 4. 패럴랙스 안개 / 구름 (신규)

[scripts/스마트월드/안개층.gd](../scripts/스마트월드/안개층.gd)

빌더가 `Parallax2D` 3겹을 깐다:

| 이름 | scroll_scale | z_index | 역할 |
|---|---|---|---|
| 안개_원경 | 0.30 | -26 | 먼 구름 — 하늘과 실루엣 사이 |
| 안개_중경 | 0.65 | -6 | 지형 뒤를 흐르는 안개 |
| 안개_전경 | 1.25 | +14 | **플레이어 앞을 스쳐 지나간다** — 깊이감이 확 산다 |

- 카메라가 멈춰 있어도 안개는 자체적으로 흐른다(`흐름속도`)
- 영역 밖으로 나간 덩어리는 반대쪽에서 다시 들어온다 → 끝이 없다
- 크기는 `FastNoiseLite` 로 천천히 부풀었다 줄어든다

### ⚠ 함정: `draw_circle` 3겹은 안개가 안 된다
처음엔 반지름이 다른 원을 3겹 겹쳐 그렸는데, 원마다 **단단한 경계**가 남아
안개가 아니라 "동심원 고리"로 보였다.
→ 가장자리가 0 으로 부드럽게 떨어지는 텍스처 한 장을 만들어 `draw_texture_rect` 로 늘려 그린다.
   모양이 전부 같으므로 `static var` 로 한 번만 만들어 공유한다(성능).

또 하나: **`draw_set_transform()` 은 그 다음 그리기부터 적용된다.**
그리고 나서 호출하면 아무 효과가 없다.
