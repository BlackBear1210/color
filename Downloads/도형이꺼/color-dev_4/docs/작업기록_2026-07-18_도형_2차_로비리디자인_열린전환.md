## 3. 전환 카메라 보강 (리서치 근거)

추가 리서치: [GMTK "How to Make a Good 2D Camera"](https://gmtk.substack.com/p/how-to-make-a-good-2d-camera),
[Sandro Maglione — Complete Platformer Camera Setup](https://www.sandromaglione.com/articles/complete-platformer-game-camera-setup),
[gamedesignskills — Scroll Back 정리판](https://gamedesignskills.com/game-design/camera-design-2d-side-scroller-games/).
요지: **"구역(섹션)마다 카메라 오프셋·줌을 다르게 주는 것"이 표준 기법**
(DKC 이후 정착, 홀로우 나이트의 구역별 오프셋, "Vary the zoom based on the current section").

- `proto_camera.gd` 에 `set_region_zoom(zoom, animate)` 추가 — 리밋 트윈과 같은
  시간(1.1초)·같은 이징으로 줌이 함께 흘러 **한 호흡의 전환**으로 읽힌다.
- `world_lab.gd` `REGION_ZOOM = {1: 1.0, 2: 0.95}` — 위로 높은 zone2 진입 시 살짝
  줌아웃되며 새 지역 전체가 눈앞에 펼쳐진다 (검증 스크린샷으로 확인).
- ⚠ zoom 0.95 에서 zone2 는 세로 뷰(682px) ≥ 리밋 높이(680px)라 **세로 고정 프레이밍**이
  된다 — 방(room) 전체를 보여주는 연출로 의도된 동작.

## 4. ★로비 전면 리디자인 (`scenes/lobby/` v2)

콘셉트: **"게임 세계의 축소판 디오라마"** — 시작 화면만 봐도 게임의 규칙과 톤이 읽히게.

- **왼쪽 흑 지형 + 흑 캐릭터 / 오른쪽 백 지형 + 백 캐릭터 / 가운데 회색(중립)** —
  핵심 규칙(흑백 반전 + 회색 중립)의 시각 요약. 두 캐릭터가 회색 경계를 사이에 두고
  마주 보는 대칭 구도.
- 캐릭터는 **인게임과 같은 시트**(`assets/p/player_frames.tres`)의 idle 모션 재생 —
  로비가 곧 캐릭터 소개. 아트 교체 시 로비도 자동 반영.
- 무색 발판(x1~x3 점 무늬)을 화면 가장자리에 배치 = 칠하기 퍼즐 예고.
  패럴랙스 도시 원경 3층(+노멀맵) + 세로 그라데이션 하늘 = 모험의 예감.
- 중앙 광원(촛불처럼 맥동) + 부유 먼지 입자 + 필름 그레인·비네트 = 리틀 나이트메어 톤.
- 구형(사선 반전 오버레이·공룡 장식) 제거. `invert_overlay.gdshader` 파일은 남김(재사용 후보).
- 구조: lobby.tscn 은 UI(CanvasLayer)만, 디오라마는 lobby.gd 가 Backdrop(Node2D)에
  런타임 조립 (존 조립과 같은 방식 — 씬 파일이 단순해서 병합 충돌 위험 낮음).
- 창 크기 변화 대응: 디오라마를 cover 스케일로 확대·중앙 정렬 (`_fit_backdrop`).

## 6. 발견한 오류와 수정 (디버깅 기록)

1. **로비 v2 첫 캡처에서 배경 3층이 전부 안 보임.**
   - 원인: 하늘/배경 스프라이트에 z_index 음수(-20~-10)를 줬는데, 로비 루트의
     BG ColorRect 가 z=0 이라 **음수 z 가 그 아래로 들어가 가려짐**
     (Godot 은 같은 캔버스에서 z-index 가 트리 순서보다 우선).
     기존 존 씬들은 전체 화면 ColorRect 가 없어서 같은 코드가 문제없이 보였던 것.
   - 수정: 디오라마 요소 전부 z=0 으로 두고 **Backdrop 안의 트리 순서**(하늘→원경→지형→캐릭터)로
     겹침을 만들었다. → 교훈: "런타임 조립 씬에서 z_index 로 명시하라"(7차)의 반대 사례 —
     **전체 화면 Control 이 깔린 캔버스에서는 음수 z 를 쓰지 말 것.**
2. **캐릭터·발판이 메뉴 버튼과 겹침** (첫 캡처): 캐릭터를 버튼 폭(416~736) 바깥
   (x310/x842)으로, 부유 발판을 화면 가장자리로 재배치. 버튼에 반투명 배경(α0.55)을 깔아
   어떤 배경 위에서도 글자가 뜨지 않게 함.
3. **배열 인덱스 버그(사전 차단)**: 배경 정의 배열에서 z_index 항목을 빼면서
   드리프트 속도 인덱스(def[3]→def[2])를 같이 수정 — 놓쳤으면 실행 즉시 스크립트 오류였음.
