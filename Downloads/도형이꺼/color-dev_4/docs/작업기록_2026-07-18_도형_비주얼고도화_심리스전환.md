## 1. 목표 (도형이 이번에 하려던 것)

1. **카메라**: 기존(플레이어 정중앙 고정)은 빠르게 달릴 때 전방이 화면의 절반밖에 안 보였다.
   반대로 스무딩을 세게 걸면 카메라가 처져서 더 답답해진다 → "전방이 보이는" 플랫포머 카메라로 교체.
2. **캐릭터 움직임**: 레인월드처럼 "관절이 살아있는" 느낌 (참고 영상의 IK 스타일 절차적 모션).
3. **그래픽 퀄리티**: 노멀맵 기반 2D 라이팅 — 배경·타일이 빛을 받으면 입체 음영이 생기는 그 기법.
4. **구역 전환**: '바인(Vane)'처럼 zone1 클리어 → zone2 로 카메라가 자연스럽게 이어지는 심리스 전환.
5. 로비 포함 전체 톤 통일 + 파일 정리/분류 + 전 구간 테스트.

## 4. 시스템이 어떻게 조립되는가 (씬 파일 무수정 원칙)

```
zone_01/zone_02/world_1 씬이 로드되면 zone_lab.gd(_ready) 가:
  Player ── 기존 Gun 제거 → ProtoGun 부착 (기존과 동일)
         ├─ 내장 Camera2D.enabled = false        ← 런타임 속성만 변경
         └─ ProtoMotion 부착 (스쿼시&스트레치)
  존 루트 ─ ProtoCamera 추가 (리밋 = 지형 크기 자동 계산)
         ├─ VerletTail 추가 (월드 좌표 시뮬레이션 — 플레이어 비균등 스케일 회피)
         └─ ZoneVisuals 추가 (환경광·광원·배경 노멀맵 주입·비네트)
world_1 은 추가로 world_lab.gd 가 구역 감지 → 카메라 리밋 트윈 → 바인식 전환
```

## 5. 심리스 전환의 구조 (바인 방식)

- **씬을 바꾸지 않는다.** zone1 지형과 zone2 지형이 `world_1.tscn` 한 씬에 있고,
  사이를 **회색(중립) 바닥 복도**가 잇는다 (회색은 어느 색으로도 안전 → 전환 완충 지대).
- 구역 경계(x=1650±60)를 넘으면 `ProtoCamera.set_limit_rect(REGION_2, true)` 만 호출 —
  **카메라 리밋 사각형이 1.1초 트윈**되며 화면이 다음 구역 프레이밍으로 미끄러진다.
  플레이어 조작은 한 순간도 멈추지 않는다. zone2 리밋은 위로 더 열려 있어서
  전환 때 화면이 위로 스르륵 열리는 것 자체가 "새 구역" 연출이 된다.
- 구역별 체크포인트: zone2 진입 시 리스폰 지점이 회색 복도(1800,445)로 갱신 —
  사망해도 존 처음으로 끌려가지 않아 흐름이 유지된다.
- zone2 골인(ExitZone) → "WORLD 1 CLEAR" → 흰 잉크 와이프로 로비 복귀 (테스트 루프 완성).
- 규칙은 구역별로 유지: zone1 구역 = 자유 전환 / zone2 구역 = SwitchZone 안에서만 Shift.

## 6. 발견한 오류와 수정 (디버깅 기록)

1. **`test_color_death.gd` 2건 FAIL — 7/17에 "커밋 db8f55e(player B) 회귀 의심"으로 기록했던 그 건.**
   - **진짜 원인은 게임 로직이 아니라 테스트의 시간 기준이었다.** 프레임별 상태를 찍어 보니
     사망→리스폰→색 복원 로직은 전부 정상 동작. 다만 헤드리스가 **~145fps(무제한)** 로 돌아서
     "프레임 번호로 진행하는 테스트"와 "실시간 0.55초 사망 타이머"가 어긋남 —
     테스트가 리스폰 **전에** 검사해서 실패한 것. (7/14에 통과했던 건 그날 머신 부하로
     우연히 60fps 근처였기 때문으로 추정. **db8f55e 는 무죄.**)
   - 수정: 테스트 `_init` 에 `Engine.max_fps = 60` (프레임 수 = 시간 고정).
2. **같은 테스트 시나리오 4의 판정이 무의미했다**: 기준 거리 160 인데 텔레포트 지점과 스폰의
   거리가 127 이라 "안 죽어도 통과" → 60 으로 조임 (이제 진짜로 리스폰을 검증).
3. **시나리오 5 타이밍**: 60fps 고정 후, 리스폰 무적(grace 0.6초) 이 끝나기 전에 Shift 를
   시도해서 잠금 감시가 (의도대로) 쉬는 중 → 프레임 200→225 로 이동. **8/8 전부 통과.**
4. **구역 경계가 너무 늦었다(BORDER_X 1750)**: 스크린샷 검증에서 플레이어가 화면 오른쪽
   끝에 몰린 뒤에야 카메라가 풀리는 걸 확인 → 1650(복도 중반)으로 당김.
5. **스크린샷 도구도 같은 fps 문제**: 창모드가 수백 fps 로 돌면 "100프레임 대기"가 0.2초라
   리밋 트윈(1.1초)이 안 끝난 화면을 찍음 → `Engine.max_fps = 60` 고정.
6. **설계로 막은 사고**: 구역 체크포인트를 회색 복도 위로 둠 — 반대색 바닥에 리스폰 →
   즉사 → 무한 루프(7/14에 한 번 겪은 그 사고)가 world_1 에선 원천적으로 불가능.
