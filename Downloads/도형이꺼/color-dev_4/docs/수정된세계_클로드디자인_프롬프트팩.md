# 「수정된 세계」 인게임 화면 목업 — 클로드 디자인 프롬프트 팩

> 용도: 클로드 디자인(Claude Design)에 붙여넣어 게임의 전반적인 룩앤필을 목업으로 뽑고 팀원(김동현, 안성진)에게 공유하기 위한 작업 지시서.
> 기준 문서: 게임 기획서 「수정(修正)된 세계」 (2026-07-04) — 특히 2-3 레이어별 명도 규칙표.

---

## 0. 사용법 (순서대로)

1. **클로드 디자인을 연다.**
2. **첫 메시지**에 아래 두 가지를 함께 넣는다.
   - 기획서 파일 (`게임_기획서_세계관_디자인_도형.md`) 첨부
   - 【프롬프트 1. 마스터 스타일 가이드】 전문 붙여넣기
3. 마스터 가이드가 적용된 걸 확인한 뒤, **한 번에 화면 하나씩** 【프롬프트 2~7】을 순서대로 보낸다. (한 메시지에 여러 화면을 요청하면 품질이 떨어짐)
4. 결과가 마음에 안 들면 【프롬프트 8. 수정 지시 문구】에서 골라 보낸다.
5. 완성된 목업은 스크린샷을 찍거나 공유 링크로 팀 채팅방에 올린다.

> 참고: 클로드 디자인은 그림을 "그리는" AI가 아니라 SVG/HTML로 화면을 "제작"하는 도구다. 우리 게임은 플랫 실루엣 + 명도 계조 기반이라 벡터 방식과 궁합이 아주 좋다. 붓터치·질감 느낌의 컨셉아트가 필요하면 문서 맨 아래 【부록. 이미지 생성 AI용 영문 프롬프트】를 미드저니/DALL·E 등에 사용.

## 1. 마스터 스타일 가이드 (항상 첫 메시지에)

```
너는 지금부터 우리 팀의 2D 퍼즐 플랫포머 「수정된 세계」의 인게임 화면 목업을 제작한다.
첨부한 기획서의 아트 디렉션(섹션 2)을 절대 기준으로 삼는다. 아래 규칙을 모든 화면에 공통 적용한다.

[화면 규격]
- 16:9 가로 화면 (1280×720 기준), 실제 게임 스크린샷처럼 보이게
- 사이드뷰 2D 플랫포머 구도, 카메라는 플레이어 중심

[색상 — 무채색 전용 팔레트, 이 값만 사용]
- 검정 지형: #000000 (내부 디테일만 #141414 허용)
- 흰색 지형: #FFFFFF (내부 디테일만 #E6E6E6 허용)
- 회색 감속 지형: #737373 ~ #8C8C8C (이 명도대는 감속 지형 전용. 배경에 절대 사용 금지)
- 근경 배경: #262626 ~ #4D4D4D
- 중경 배경: #4D4D4D ~ #8C8C8C (감속 지형과 겹치는 구간은 블러 처리로 구분)
- 원경 배경: #8C8C8C ~ #BFBFBF, 부드러운 그라데이션 + 흐림(대기원근)
- 유채색: 기본적으로 금지. 내가 "기억의 조각 연출" 화면을 요청할 때만 사용

[지형 규칙 — 가장 중요]
- 게임플레이 지형(발판, 벽)의 외곽선은 완전히 플랫한 실루엣. 외곽에 그라데이션·그림자 금지
- 지형 내부에만 저대비 2톤 디테일 허용 (예: 검정 지형 안에 #141414 균열 무늬)
- 위험 요소(가시, 톱니)는 지형보다 대비를 한 단계 강하게 + 뾰족한 실루엣

[배경 규칙]
- 패럴랙스 3겹 (근경/중경/원경)이 구분되어 보이게
- 광원 방향은 한 화면에서 통일 (위→아래 또는 좌상→우하)
- 원경일수록 밝고 흐리게

[캐릭터와 HUD]
- 주인공: 작은 소년 실루엣, 낡은 페인트 건을 든 모습. 흑 상태면 순검정, 백 상태면 순백 + 가는 외곽선
- HUD는 최소화: 좌상단에 현재 상태(흑/백) 아이콘, 그 옆에 페인트 잔량 게이지만. 텍스트 UI 없음

이해했으면 "준비 완료"라고만 답해. 이후 내가 화면을 하나씩 요청한다.
```

## 2. 화면 ① — Stage 1, 지하 최심부 (폐허 동굴)

```
첫 번째 화면: Stage 1 "지하 최심부" 인게임 스크린샷.
- 전체 톤: 배경 검정~진회색 (#000000~#4D4D4D). 게임에서 가장 어두운 구간
- 배경: 무너진 지하 도시의 잔해 — 부러진 기둥, 기울어진 건물 실루엣이 근경(#262626)과 중경(#4D4D4D)에 겹겹이
- 원경: 희미하게 위쪽에서 새어 들어오는 빛기둥 하나 (위로 오르는 목표 암시)
- 지형: 흰색(#FFFFFF) 발판이 어둠 속에서 또렷하게 떠 있음 + 검정(#000000) 지형은 배경과 실루엣 경계로만 구분
- 플레이어: 백 상태(흰색)의 소년이 화면 좌측 하단 흰 발판 위에 서서 페인트 건을 들고 있음
- 우측에 회색(#8C8C8C) 감속 지형 한 구간 배치
- 분위기: Limbo처럼 고요하고 무거운, 그러나 위쪽 빛 때문에 희망이 한 줄기 있는 느낌
```

## 3. 화면 ② — 중반, 지하 도시 (배관·공장)

```
두 번째 화면: 중반 "지하 도시" 인게임 스크린샷.
- 전체 톤: 회색 중심. Stage 1보다 반 단계 밝음
- 배경: 거대한 배관, 톱니바퀴, 공장 구조물 실루엣. 근경 파이프가 화면을 대각선으로 가로지름
- 지형: 검정 실루엣 발판 (내부에 #141414 리벳·철판 이음새 디테일), 이동 발판 1개는 레일 위에
- 위험 요소: 화면 중앙 하단에 톱니(뾰족한 실루엣, 지형보다 강한 대비) 배치
- 상호작용 요소: 페인트로 칠해야 나타나는 투명블럭을 점선 외곽선으로 1개 표시
- 플레이어: 흑 상태(검정)의 소년이 이동 발판 위에서 점프 중, 페인트 건에서 발사된 탄환 1발이 투명블럭을 향해 날아가는 순간
- 탄환과 탄착 이펙트에만 아주 절제된 유채색 1가지(청록 계열) 허용 — 기획서의 "페인트 탄착 이펙트" 예외 적용
```

## 4. 화면 ③ — 후반, 지상 폐허 도시 (1차 클라이맥스 직전)

```
세 번째 화면: 후반 "지상" 인게임 스크린샷.
- 전체 톤: 밝은 회색. 하늘이 처음 보이는 구간
- 배경: 덩굴로 뒤덮인 폐허 도시 — 무너진 빌딩 실루엣에 식물 덩굴이 감김. 원경은 #BFBFBF에 가까운 밝은 안개
- 하늘 위쪽에 구름 사이로 태양의 윤곽이 아주 희미하게 (아직 흑백, 존재만 암시)
- 지형: 이 구간은 명도 반전 — 배경이 밝으므로 검정 실루엣 지형이 주력, 흰 지형은 외곽선으로 구분
- 플레이어: 소년이 높은 건물 꼭대기 발판에 서서 위(태양 방향)를 올려다보는 뒷모습
- 분위기: 상승의 끝이 보이기 시작하는, 숨을 고르는 휴식 지대 느낌 (리듬 이론의 저밀도 구간)
```

## 5. 화면 ④ — 최종, 하늘 신전 (백색 구간)

```
네 번째 화면: 최종 스테이지 "하늘 신전" 인게임 스크린샷.
- 전체 톤: 흰색~밝은 회색. 게임에서 가장 밝은 구간
- 배경: 로마·지중해풍 신전 — 코린트식 기둥, 아치, 부서진 조각상이 구름 위에 떠 있음. 전부 흰색 계조
- 지형: 검정 실루엣 발판이 흰 세계 속에서 강하게 대비됨 (Stage 1의 명도 반전 버전)
- 원경: 순백에 가까운 구름 바다
- 위험 요소: 흰 대리석 기둥 사이 검정 가시 트랩
- 플레이어: 흑 상태의 소년이 신전 계단형 발판을 오르는 중
- 화면 최상단에 거대한 문(신과의 대면 입구)의 하단부만 살짝 보이게 — 스케일 압도감
```

## 6. 화면 ⑤ — 기억의 조각 연출 (색이 스며드는 순간)

```
다섯 번째 화면: "기억의 조각" 획득 순간의 연출 스크린샷. 이 게임에서 유채색이 나오는 유일한 순간이다.
- 베이스: 화면 ② (지하 도시)와 같은 무채색 화면
- 화면 중앙의 기억의 조각(빛나는 파편)을 소년이 막 주운 순간
- 조각을 중심으로 반경이 퍼지듯 유채색이 스며듦 — 중심부는 따뜻한 색(주황·노랑)이 선명하고, 바깥으로 갈수록 무채색으로 되돌아가는 원형 그라데이션
- 색이 입혀진 영역 안에서만 배경 사물의 "원래 색"이 살짝 보임 (배관의 녹슨 주황, 이끼의 초록)
- 소년은 이동 가능한 자세 그대로 (컷신이 아님을 보여주기)
- 화면 하단에 작은 자막 한 줄 자리만 표시: "________" (텍스트 1~2문장 원칙)
```

## 7. 화면 ⑥ — 4스테이지 무드보드 (팀 공유용 한 장)

```
마지막: 위에서 만든 화면 ①~④를 한 장에 모은 무드보드를 만들어줘.
- 2×2 그리드, 각 칸 아래에 스테이지 이름과 기준 명도 표기 (지하 최심부 / 지하 도시 / 지상 / 하늘 신전)
- 상단 제목: 「수정된 세계」 — 지하에서 하늘까지, 검정에서 흰색으로
- 네 칸을 나란히 놓았을 때 왼쪽 위→오른쪽 아래로 갈수록 밝아지는 명도 흐름이 한눈에 보이게
- 하단에 무채색 팔레트 바(#000000→#FFFFFF)와 "유채색 = 보상 전용" 문구
```

## 8. 수정 지시 문구 모음 (복사해서 사용)

- "지형 외곽선에 그라데이션이 들어갔어. 기획서 규칙대로 실루엣은 완전 플랫으로, 디테일은 내부 2톤으로만 다시."
- "중경 배경 명도가 #737373~#8C8C8C 대역을 침범했어. 감속 지형 전용 명도대니까 배경을 더 어둡게 내리거나 블러를 강하게."
- "위험 요소가 지형이랑 구분이 안 돼. 대비를 한 단계 올리고 실루엣을 더 뾰족하게."
- "패럴랙스 3겹이 안 느껴져. 근경/중경/원경의 명도 차이를 더 벌리고 원경에 흐림을 추가."
- "광원 방향이 화면 안에서 섞여 있어. 좌상→우하 하나로 통일."
- "화면이 너무 심심해. 배경 실루엣 밀도만 높이고, 지형과 상호작용 요소는 그대로 유지."
- "유채색이 들어갔어. 이 화면은 유채색 금지 구간이야. 전부 무채색으로."

## 부록. 이미지 생성 AI용 영문 프롬프트 (미드저니 / DALL·E 등)

붓터치·조명 질감이 살아있는 컨셉아트가 필요할 때 사용. 스테이지에 맞게 [ ] 부분을 교체.

**공통 베이스:**
```
2D puzzle platformer in-game screenshot, side-scrolling view, strict monochrome palette (pure black, pure white, grayscale only), flat black silhouette terrain with crisp edges, layered parallax background with soft gray gradients and atmospheric fog, small boy silhouette holding an old paint gun, minimal HUD, moody cinematic lighting, in the style of Limbo and Inside, no color --ar 16:9
```

**스테이지별 교체 문구:**
- 지하 최심부: `deep underground ruined cavern, collapsed subterranean city, broken pillars, a single faint light beam from above, darkest tones`
- 지하 도시: `industrial underground city, giant pipes and gears, factory silhouettes, mid-gray tones`
- 지상 폐허: `overgrown ruined city surface, vines covering broken buildings, bright gray fog, faint sun outline behind clouds`
- 하늘 신전: `Greco-Roman marble temple floating above a sea of clouds, Corinthian columns and broken statues, brightest white tones, black silhouette platforms`
- 기억의 조각 연출: 공통 베이스 끝의 `no color`를 빼고 → `a single burst of warm orange and yellow color blooming in a circle around a glowing memory fragment, color fading back to grayscale at the edges`

### 레퍼런스 (프롬프트에 이름을 언급하면 톤 잡기가 빨라짐)
- **OVIVO** — 흑백 전환의 직계 레퍼런스. "레벨 전체가 한 장의 모노크롬 그림"
- **Limbo** — 검정 실루엣 전경 + 회색 계조 배경 + 안개
- **Inside** — 통제된 조명과 포인트 컬러 1개의 위력
- **Gris** — "색 = 감정적 보상" (기억의 조각 연출 화면의 레퍼런스)
